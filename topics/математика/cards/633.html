Арккосинус (arccos) — это обратная тригонометрическая функция к косинусу, которая по заданному значению косинуса (в пределах от -1 до 1) возвращает угол из отрезка [0, π].

основной текст
Арккосинусом числа x, где x ∈ [-1, 1], называется такой угол y ∈ [0, π], что cos y = x. Обозначается y = arccos x. Основная формула: cos(arccos x) = x для всех x ∈ [-1, 1], и arccos(cos y) = y для y ∈ [0, π]. Важное тождество: arccos x + arcsin x = π/2. Также полезно знать: arccos(-x) = π - arccos x. Свойства: функция arccos x убывает на всей области определения. Её график получается из графика косинуса на отрезке [0, π] отражением относительно прямой y = x. Пример: arccos(1/2) = π/3, arccos(0) = π/2, arccos(-1) = π. Область значений — [0, π], область определения — [-1, 1]. Функция не является чётной или нечётной. Арккосинус широко применяется в геометрии для нахождения углов по сторонам треугольника (теорема косинусов), в физике (расчёт фаз колебаний), в теории сигналов и при решении тригонометрических уравнений. Он тесно связан с Арксинусом через приведённое выше тождество. Для полного понимания рекомендуется изучить также смежные темы: Арксинус (определение и свойства), График арксинуса (сравнение с графиком арккосинуса), Свойства арксинуса (взаимосвязь областей определения и значений).
