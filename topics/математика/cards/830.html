Частичная сумма ряда — это сумма первых n членов последовательности, обозначаемая как S_n = a_1 + a_2 + ... + a_n. Она является ключевым понятием для определения сходимости числовых рядов.

основной текст
Частичная сумма S_n ряда ∑_{k=1}^{∞} a_k определяется как сумма его первых n членов: S_n = ∑_{k=1}^{n} a_k. Если последовательность частичных сумм {S_n} имеет конечный предел при n → ∞, то ряд называется сходящимся, а этот предел — его суммой. В противном случае ряд расходится. Для простейших рядов существуют явные формулы: например, для арифметической прогрессии S_n = n(a_1 + a_n)/2, для геометрической прогрессии S_n = a_1(1 - q^n)/(1 - q) при q ≠ 1. Свойства частичных сумм включают линейность (сумма частичных сумм двух рядов равна частичной сумме их суммы) и аддитивность (S_{n+m} = S_n + сумма следующих m членов). Пример: для гармонического ряда 1 + 1/2 + 1/3 + ... частичные суммы растут неограниченно, что доказывает его расходимость. Частичные суммы широко применяются в математическом анализе для исследования сходимости рядов, в численных методах (приближенное вычисление функций через ряды Тейлора) и в теории вероятностей (суммы случайных величин). Они тесно связаны с понятиями суммы подпространств (где сумма векторных подпространств аналогична сложению элементов) и прямой суммы (которая требует единственности разложения). В алгебре частичная сумма может быть обобщена на суммы кубов: например, (1^3 + 2^3 + ... + n^3) = (1 + 2 + ... + n)^2, что демонстрирует связь между частичными суммами разных степеней. Связанные темы: Сумма подпространств — алгебраический аналог сложения множеств, где частичная сумма ряда может рассматриваться как сумма элементов из разных «подпространств» последовательности. Прямая сумма — более строгое понятие, требующее независимости слагаемых, аналогично тому, как члены ряда не должны пересекаться.
