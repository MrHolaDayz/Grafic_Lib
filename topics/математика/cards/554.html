Скалярное произведение двух векторов — это число, равное произведению их длин на косинус угла между ними, которое обладает свойствами коммутативности, линейности и положительной определенности.

основной текст
Скалярным произведением векторов a и b в пространстве называется число (a, b) = |a| * |b| * cos φ, где φ — угол между векторами. В координатной форме для векторов a = (x1, y1, z1) и b = (x2, y2, z2) скалярное произведение вычисляется как x1*x2 + y1*y2 + z1*z2. Из определения также следует формула для нахождения угла: cos φ = (a, b) / (|a| * |b|), и условие перпендикулярности: (a, b) = 0. Длина вектора выражается через скалярное произведение: |a| = √(a, a). Основные свойства: 1) Коммутативность: (a, b) = (b, a). 2) Линейность по первому аргументу: (αa + βb, c) = α(a, c) + β(b, c). 3) Положительная определенность: (a, a) ≥ 0, причем (a, a) = 0 только если a — нулевой вектор. Пример: если a = (1, 2, 0) и b = (0, -1, 3), то (a, b) = 1*0 + 2*(-1) + 0*3 = -2. Если (a, b) = 0, то векторы ортогональны. Скалярное произведение широко применяется в физике (работа силы), компьютерной графике (расчет освещения), а также в аналитической геометрии для проецирования векторов. Оно тесно связано с понятием сопряженных чисел в комплексном пространстве, где скалярное произведение обобщается с учетом комплексного сопряжения. Свойства модуля (длины) вектора напрямую следуют из скалярного произведения, а Свойства транспонирования используются при работе с матрицами, где скалярное произведение векторов-столбцов записывается как a^T * b. В линейной алгебре скалярное произведение лежит в основе ортогонализации Грама-Шмидта и определения нормы.
