Основное свойство первообразной утверждает, что если функция F(x) является первообразной для f(x) на некотором промежутке, то любая другая первообразная для f(x) на этом же промежутке отличается от F(x) на постоянную величину C.

основной текст
Определение и основные формулы: Первообразной функции f(x) на промежутке называется такая функция F(x), производная которой равна f(x), то есть F'(x) = f(x). Основное свойство первообразной формулируется так: если F(x) — одна из первообразных для f(x), то множество всех первообразных для f(x) задается формулой F(x) + C, где C — произвольная постоянная (константа). Это записывается как ∫f(x)dx = F(x) + C. Например, для функции f(x) = x^2 одной из первообразных является F(x) = (x^3)/3, а общее семейство первообразных — (x^3)/3 + C. Свойства и примеры: Из основного свойства следует, что графики первообразных для одной и той же функции получаются друг из друга параллельным переносом вдоль оси Oy. Например, для f(x) = cos x первообразные имеют вид sin x + C; для f(x) = 1/x (при x > 0) — ln|x| + C. Важно, что если функция определена на нескольких промежутках, то константа C может быть различной на каждом из них. Также свойство используется для нахождения первообразной по заданному начальному условию: подставляя значение функции в точке, находят конкретное C. Где применяется, связь с другими темами: Основное свойство первообразной лежит в основе вычисления неопределенных интегралов и решения дифференциальных уравнений. Оно тесно связано с понятием неопределенного интеграла как совокупности всех первообразных. В приложениях (физика, экономика) это свойство позволяет восстанавливать закон движения по скорости (или скорость по ускорению) с точностью до начального положения. Связанные темы: Основное логарифмическое тождество (a^{log_a b} = b) используется при интегрировании показательных и логарифмических функций. Характеристическое свойство (например, свойство первообразной как обратной операции к дифференцированию) дополняет понимание.
