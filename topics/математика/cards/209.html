основной текст
Квадратичная функция задается формулой y = ax^2 + bx + c, где a, b и c — действительные числа, причем a ≠ 0. График этой функции — парабола, ветви которой направлены вверх при a > 0 и вниз при a < 0. Вершина параболы находится в точке с координатами x_в = -b/(2a), y_в = y(x_в). Ось симметрии параболы — прямая x = -b/(2a). Дискриминант D = b^2 - 4ac определяет количество корней уравнения ax^2 + bx + c = 0: при D > 0 — два различных корня, при D = 0 — один корень, при D < 0 — корней нет. Основные свойства квадратичной функции: область определения — все действительные числа; область значений зависит от направления ветвей: при a > 0 — [y_в; +∞), при a < 0 — (-∞; y_в]. Функция не является монотонной на всей области определения: она убывает до вершины и возрастает после нее (или наоборот, в зависимости от знака a). Пример: y = x^2 — 4x + 3. Здесь a = 1, b = -4, c = 3. Вершина: x_в = 2, y_в = -1. Корни: x = 1 и x = 3. Парабола пересекает ось OY в точке (0, 3). Квадратичная функция широко применяется в физике (описание движения тела с постоянным ускорением, например, s = s_0 + v_0t + at^2/2), в экономике (моделирование издержек и прибыли), в инженерных расчетах (форма мостов, антенн). Связанные темы: Линейная функция (y = kx + b) является частным случаем квадратичной при a = 0, но в определении квадратичной a ≠ 0. Степенная функция (y = x^n) при n = 2 дает квадратичную. Функция Эйлера φ(n) не связана напрямую с квадратичной, но используется в теории чисел. Дробно-линейная функция и Обратная пропорциональность (y = k/x) имеют другую природу, но также изучаются в разделе функций алге
