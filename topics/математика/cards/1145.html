основной текст
Инварианты кривых второго порядка — это числовые характеристики её общего уравнения Ax^2 + 2Bxy + Cy^2 + 2Dx + 2Ey + F = 0, которые остаются неизменными при любых ортогональных преобразованиях координат (повороте и переносе). Основные инварианты включают: первый инвариант I1 = A + C (след матрицы квадратичной формы), второй инвариант I2 = AC - B^2 (определитель матрицы квадратичной формы), и третий инвариант I3 = |A B D; B C E; D E F| (определитель полной матрицы). Для эллиптического типа (I2 > 0) и гиперболического (I2 < 0) эти инварианты позволяют отличить, например, Эллипс от гиперболы, а при I2 = 0 — параболу. Свойства инвариантов позволяют классифицировать кривые без построения: если I2 > 0 и I1 * I3 < 0, то кривая — эллипс; если I2 > 0 и I3 = 0 — точка; если I2 < 0 и I3 ≠ 0 — гипербола; если I2 = 0 и I3 ≠ 0 — парабола. Например, для окружности (частного случая эллипса) A = C, B = 0, поэтому I1 = 2A, I2 = A^2, а I3 = A^2F - A(D^2 + E^2). Инвариант I1 и I2 также связаны с Эксцентриситетом и положением фокусов, так как определяют длины полуосей через корни характеристического уравнения λ^2 - I1λ + I2 = 0. В аналитической геометрии инварианты применяются для приведения уравнения кривой к каноническому виду без вычисления угла поворота и координат центра. Они особенно полезны при анализе кривых второго порядка, заданных в общем виде, и тесно связаны с темами фокусов и директрис: например, для эллипса Фокусы находятся на расстоянии √(a^2 - b^2) от центра, где a и b — полуоси, выраженные через инварианты.
