Уравнение касательной — это уравнение прямой, которая касается графика функции в заданной точке и имеет с ней одинаковую производную в этой точке. Оно позволяет локально приближать функцию линейной зависимостью.
связанные темы
Общее уравнение Каноническое уравнение Параметрическое уравнение Уравнение в отрезках Уравнение с угловым коэффициентом
основной текст
Уравнение касательной к графику функции y = f(x) в точке x0 имеет вид: y = f(x0) + f'(x0)(x - x0). Здесь f'(x0) — производная функции в точке x0, которая задаёт угловой коэффициент касательной. Если функция задана неявно или параметрически, уравнение касательной выводится через соответствующие производные. Например, для параметрической кривой (x(t), y(t)) в точке t0 уравнение записывается как (y - y(t0)) / (x - x(t0)) = y'(t0) / x'(t0) при x'(t0) ≠ 0. Основное свойство касательной: она является предельным положением секущей при стремлении приращения аргумента к нулю. Пример: для параболы y = x^2 в точке (1, 1) производная f'(1) = 2, поэтому уравнение касательной: y = 1 + 2(x - 1) = 2x - 1. Касательная может не существовать, если функция не дифференцируема в точке (например, имеет излом). Уравнение касательной применяется в задачах на локальное линейное приближение, в физике для мгновенной скорости (касательная к графику пути), в экономике для предельных величин. Оно тесно связано с общей формой прямой: Уравнение с угловым коэффициентом y = kx + b, где k = f'(x0), b = f(x0) - f'(x0)·x0. Также касательную можно записать в общем виде: Ax + By + C = 0, или в каноническом виде (x - x0)/1 = (y - y0)/k. Для параметрических кривых используется Параметрическое уравнение касательной. В случае неявной функции F(x, y) = 0 уравнение касательной принимает вид F_x(x0, y0)(x - x0) + F_y(x0, y0)(y - y0) = 0.
