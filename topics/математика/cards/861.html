Факториал натурального числа n — это произведение всех натуральных чисел от 1 до n, обозначаемое символом n!. Это одна из базовых операций в комбинаторике, используемая для подсчета количества перестановок и размещений.

основной текст
Определение и основные формулы: Факториал числа n (n! — читается как «эн факториал») определяется рекуррентно: 0! = 1, 1! = 1, и для n ≥ 1: n! = n · (n-1)!. В явном виде: n! = 1 · 2 · 3 · … · n. Для больших n применяют приближение Стирлинга: n! ≈ √(2πn) · (n/e)^n. Двойной факториал n!! — это произведение чисел, уменьшающихся с шагом 2: для четного n: n!! = 2 · 4 · … · n, для нечетного: n!! = 1 · 3 · 5 · … · n. Свойства и примеры: Факториал растет очень быстро: 5! = 120, 10! = 3 628 800. Важное свойство: (n+1)! = (n+1) · n!. Также n! = n · (n-1)!. Пример: 6! = 6 · 5! = 6 · 120 = 720. Факториал определен только для целых неотрицательных чисел (0, 1, 2, …). Для дробных чисел используется гамма-функция Γ(z), где n! = Γ(n+1). Где применяется, связь с другими темами: Факториал — основа для вычисления числа перестановок (P_n = n!), размещений и сочетаний. Например, количество способов расставить 5 книг на полке равно 5! = 120. В теории вероятностей факториал используется в формулах биномиального распределения и гипергеометрического распределения. Также он встречается в разложениях рядов (например, e^x = Σ x^n / n!).
