основной текст
Метод наименьших квадратов (МНК) — это фундаментальный подход в регрессионном анализе, используемый для нахождения такой линии (или кривой), которая наилучшим образом аппроксимирует набор экспериментальных данных. Суть метода заключается в минимизации суммы квадратов отклонений (остатков) фактических значений y_i от значений, предсказанных моделью f(x_i). Для линейной регрессии y = a + bx коэффициенты a и b находятся из системы нормальных уравнений: Σy = an + bΣx и Σxy = aΣx + bΣx^2, где n — число точек. Также коэффициенты можно вычислить по формулам: b = (nΣxy - ΣxΣy) / (nΣx^2 - (Σx)^2) и a = (Σy - bΣx) / n. Оценка качества аппроксимации производится через коэффициент детерминации R^2, который показывает долю дисперсии, объясненную моделью. Основное свойство МНК — несмещенность и состоятельность оценок при выполнении классических условий Гаусса-Маркова (нулевое математическое ожидание остатков, их гомоскедастичность и некоррелированность). Пример: по точкам (1,2), (2,4), (3,5) ищем прямую y = a + bx. Составляем систему: 3a + 6b = 11 и 6a + 14b = 25. Решая, получаем b = 1.5, a = 0.667, то есть прямая y = 0.667 + 1.5x. Сумма квадратов отклонений для этой прямой минимальна. МНК широко применяется в экономике (прогнозирование спроса), физике (обработка экспериментальных данных), биологии (анализ зависимостей) и технике (калибровка датчиков). Метод тесно связан с решением систем линейных уравнений: для нахождения коэффициентов часто используют Метод Крамера, Матричный метод или Метод Гаусса. Например, система нормальных уравнений может быть решена через обратную матрицу (Матричный метод) или последовательным исключением переменных (Метод Гаусса). Также МНК допускает обобщение на нелинейные зависимости и взвешенные варианты.
