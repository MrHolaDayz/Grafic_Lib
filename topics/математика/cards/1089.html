основной текст
Фундаментальная система решений (ФСР) определяется для однородной системы линейных уравнений Ax = 0, где A — матрица размером m x n. Если ранг матрицы r меньше числа неизвестных n, то система имеет бесконечно много решений. ФСР состоит из k = n - r линейно независимых векторов (столбцов) x^1, x^2, ..., x^k, таких что общее решение системы записывается как x = C_1*x^1 + C_2*x^2 + ... + C_k*x^k, где C_i — произвольные постоянные. Для нахождения ФСР обычно используют Метод Гаусса: приводят матрицу к ступенчатому виду, находят базисные и свободные переменные, затем последовательно задают свободным переменным значения (1, 0, ..., 0), (0, 1, ..., 0) и т.д., вычисляя соответствующие базисные переменные. Основное свойство ФСР — линейная независимость входящих в нее решений. Количество векторов в ФСР равно размерности пространства решений однородной системы. Пример: для системы с двумя уравнениями и тремя неизвестными, если ранг равен 2, то ФСР будет содержать один вектор (k = 3 - 2 = 1). Если ранг равен 1, то ФСР будет содержать два линейно независимых вектора. ФСР не единственна: можно выбрать любой набор из k линейно независимых решений, но их количество всегда одинаково. ФСР применяется для описания структуры всех решений однородных систем, что необходимо при решении неоднородных систем: общее решение неоднородной системы Ax = b равно сумме частного решения и общего решения соответствующей однородной системы (которое выражается через ФСР). Связь с другими темами: ФСР тесно связана с однородными системами (для которых она строится), неоднородными системами (где используется для записи общего решения), методом Гаусса (основной способ нахождения ФСР), методом Крамера (применим только для квадратных невырожденных систем, но не для построения ФСР) и матричным методом. Понимание ФСР позволяет анализировать размерность пространства решений и находить базис в этом пространстве.
