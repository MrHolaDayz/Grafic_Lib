Мнимая часть комплексного числа — это действительное число, на которое умножается мнимая единица i. Если Комплексное число имеет вид z = a + bi, то его мнимая часть равна b (обозначается Im(z) = b).

основной текст
Мнимая часть комплексного числа является его ключевой характеристикой, отличающей комплексные числа от действительных. Для числа z, записанного в алгебраической форме z = a + bi, где a и b — действительные числа, а i — Мнимая единица (i^2 = -1), мнимая часть определяется как коэффициент b при i. Обозначение: Im(z) = b. Важно помнить, что мнимая часть — это именно действительное число b, а не выражение bi. Например, для числа z = 5 - 3i мнимая часть равна -3. Свойства мнимой части включают линейность: Im(z1 + z2) = Im(z1) + Im(z2) и Im(k * z) = k * Im(z) для действительного k. Пример: если z1 = 2 + 4i и z2 = 1 - i, то Im(z1 + z2) = Im(3 + 3i) = 3, что равно Im(z1) + Im(z2) = 4 + (-1) = 3. Мнимая часть играет центральную роль в равенстве комплексных чисел: два числа a + bi и c + di равны тогда и только тогда, когда равны их действительные и мнимые части (a = c и b = d). Мнимая часть широко применяется в физике (например, для описания колебаний и волн), электротехнике (анализ цепей переменного тока) и теории сигналов. Она неразрывно связана с мнимой единицей i, которая определяет её природу, и со степенями мнимой единицы (i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1), которые периодически меняют знак мнимой части при умножении. Вместе с действительной частью (Re(z) = a) мнимая часть образует полное представление комплексного числа, позволяя задавать точки на комплексной плоскости.
