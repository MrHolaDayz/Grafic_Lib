Область определения функции — это множество всех допустимых значений аргумента (x), при которых функция имеет смысл (выражение определено). Например, для функции y = √x область определения — все неотрицательные числа.

основной текст
Область определения функции (D(f)) — это множество всех значений x, для которых существует значение y = f(x). В алгебре её нахождение сводится к учёту ограничений: знаменатель не равен нулю, подкоренное выражение чётной степени (√) неотрицательно, основание логарифма положительно и не равно 1. Основные формулы: для y = 1/x область: x ≠ 0; для y = √x: x ≥ 0; для y = x^n (n — натуральное) область — все действительные числа; для y = x^(1/2) — x ≥ 0. Свойства: область определения может быть симметричной (для чётных/нечётных функций) или несимметричной. Примеры: для линейной функции y = kx + b область — все числа (R). Для квадратичной функции y = ax^2 + bx + c — также R. Для обратной пропорциональности y = k/x — x ≠ 0. Для дробно-линейной функции y = (ax+b)/(cx+d) — x ≠ -d/c. Для степенной функции с дробным показателем (например, y = x^(2/3)) — x ≥ 0. Область определения применяется при построении графиков, решении уравнений и неравенств, в анализе поведения функции. Она тесно связана с линейной функцией (область — R), квадратичной функцией (область — R), степенной функцией (область зависит от показателя степени). Понимание области определения — основа для изучения монотонности, экстремумов и асимптот.
