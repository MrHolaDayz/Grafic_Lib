Координаты вектора — это упорядоченный набор чисел, равных разностям соответствующих координат его конца и начала, позволяющий однозначно задать вектор в прямоугольной системе координат.

основной текст
Определение и основные формулы. В прямоугольной системе координат Oxyz вектор a, заданный начальной точкой A(x1; y1; z1) и конечной точкой B(x2; y2; z2), имеет координаты: a = (x2 - x1; y2 - y1; z2 - z1). Координаты вектора обычно записывают в виде a = (ax; ay; az). Длина (модуль) вектора вычисляется по формуле: |a| = √(ax^2 + ay^2 + az^2). Линейные операции над векторами в координатной форме выполняются покоординатно: сумма векторов a + b = (ax + bx; ay + by; az + bz), разность a - b = (ax - bx; ay - by; az - bz), умножение на число k*a = (k*ax; k*ay; k*az). Свойства и примеры. Координаты вектора не зависят от выбора начальной точки, а определяются только его направлением и длиной. Например, если даны точки A(1; 2; 3) и B(4; 6; 8), то вектор AB = (4-1; 6-2; 8-3) = (3; 4; 5). Его длина |AB| = √(3^2 + 4^2 + 5^2) = √50 = 5√2. Нулевой вектор имеет координаты (0; 0; 0). Единичный вектор (орт) в направлении a получается делением каждой координаты на длину вектора. Где применяется, связь с другими темами. Координаты вектора являются фундаментом для аналитической геометрии в пространстве. Они используются для вычисления скалярного и векторного произведения, для нахождения угла между векторами, для записи уравнений прямых и плоскостей. В физике координаты вектора применяются для описания перемещений, скоростей, сил в трехмерном пространстве. Эта тема тесно связана с понятием базиса и разложением вектора по координатным осям.
