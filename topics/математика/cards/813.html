основной текст
Частное решение дифференциального уравнения — это функция, удовлетворяющая как самому уравнению, так и дополнительным условиям (например, начальным условиям Коши). Если общее решение дифференциального уравнения n-го порядка содержит n произвольных постоянных (C1, C2, ..., Cn), то частное решение находится путем подстановки конкретных чисел вместо этих постоянных. Например, для уравнения y' = y общее решение имеет вид y = C * e^x. При начальном условии y(0) = 2 получаем C = 2, и частное решение: y = 2e^x. В случае линейных неоднородных уравнений частное решение часто ищут методом вариации постоянных или методом неопределенных коэффициентов. Основные свойства: частное решение всегда единственно для корректно поставленной задачи (теорема Коши). Оно существует в некоторой окрестности точки, где заданы начальные условия. Примеры: для уравнения y'' + y = 0 с условиями y(0) = 1, y'(0) = 0 частное решение — y = cos x; для уравнения y' = 2x с условием y(1) = 3 частное решение — y = x^2 + 2. Важно, что частное решение не содержит произвольных постоянных и полностью определяется заданными условиями. Частные решения широко применяются в физике, механике, биологии и экономике для моделирования конкретных процессов: движение тела под действием сил, рост популяции с заданной начальной численностью, колебания в электрической цепи. Связь с другими темами: частное решение тесно связано с понятием общего решения, начальных и граничных условий, а также с методами решения дифференциальных уравнений (разделение переменных, метод Эйлера, метод Лагранжа). В задачах Коши частное решение является основным результатом, так как оно описывает конкретный процесс с заданными параметрами.
