Определитель квадратной матрицы — это число, которое ставится в соответствие квадратной матрице и отражает её свойства, например, обратимость. Он вычисляется по специальным правилам и обозначается как det(A) или |A|.

основной текст
Определитель квадратной матрицы размера n×n — это скалярная функция, определённая на множестве квадратных матриц. Для матрицы 2×2 определитель вычисляется по формуле: det(A) = a11 * a22 - a12 * a21. Для матрицы 3×3 используется правило Саррюса или разложение по строке/столбцу: det(A) = a11 * (a22*a33 - a23*a32) - a12 * (a21*a33 - a23*a31) + a13 * (a21*a32 - a22*a31). Для общих n используется формула Лейбница с перестановками или алгоритм приведения к треугольному виду. Основные свойства определителя: если матрица содержит нулевую строку или столбец, определитель равен 0; при перестановке двух строк знак определителя меняется; умножение строки на число λ умножает определитель на λ; определитель произведения матриц равен произведению определителей: det(AB) = det(A) * det(B). Определитель единичной матрицы равен 1, а определитель нулевой матрицы — 0. Пример: для матрицы A = [[2, 3], [1, 4]] det(A) = 2*4 - 3*1 = 8 - 3 = 5. Определитель широко применяется в линейной алгебре для решения систем линейных уравнений (правило Крамера), нахождения обратной матрицы (только если det(A) ≠ 0), анализа линейной зависимости векторов и в геометрии (вычисление объёмов параллелепипедов). Связанные темы: Определение матрицы — основа для введения определителя; Виды матриц (например, треугольные, диагональные) упрощают его вычисление; Квадратная матрица — обязательное условие существования определителя. Определитель также тесно связан с понятием собственных значений и ранга матрицы.
