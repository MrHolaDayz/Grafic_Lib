основной текст
Приведенное квадратное уравнение — это уравнение вида x^2 + px + q = 0, где p и q — действительные числа (коэффициенты). Оно получается из общего квадратного уравнения ax^2 + bx + c = 0 делением обеих частей на a (при a ≠ 0). Корни такого уравнения можно найти по формуле: x = (-p ± √(p^2 - 4q)) / 2, где выражение D = p^2 - 4q называется Дискриминантом приведенного уравнения. Если D > 0, уравнение имеет два различных действительных корня; если D = 0 — один корень (два совпадающих); если D < 0 — действительных корней нет. Основное свойство приведенных квадратных уравнений выражается теоремой Виета: сумма корней равна -p, а произведение корней равно q. Например, для уравнения x^2 - 5x + 6 = 0 корни равны 2 и 3, так как 2 + 3 = 5 (то есть -p = -(-5) = 5) и 2 * 3 = 6 (q = 6). Это свойство позволяет быстро находить корни устно для простых случаев и проверять решения. Также приведенные уравнения часто используются при разложении квадратного трехчлена на множители: x^2 + px + q = (x - x1)(x - x2), где x1 и x2 — корни. Приведенные Квадратные уравнения широко применяются в алгебре, геометрии (например, при решении задач на площади и расстояния), физике (для описания движения с постоянным ускорением) и экономике. Они тесно связаны с полными квадратными уравнениями, так как любое квадратное уравнение можно привести к приведенному виду. Также методы решения квадратных уравнений используются при анализе кубических уравнений (например, для поиска точек экстремума или разложения на множители). В отличие от линейных диофантовых уравнений, которые решаются в целых числах, приведенные квадратные уравнения обычно рассматриваются для действительных корней.
