Уравнение нормали — это уравнение прямой, проходящей через точку касания графика функции и перпендикулярной касательной в этой точке. Оно имеет вид y - y0 = -1/f'(x0) * (x - x0) для случая явно заданной функции.
связанные темы
Общее уравнение Каноническое уравнение Параметрическое уравнение Уравнение в отрезках Уравнение с угловым коэффициентом
основной текст
Уравнение нормали к графику функции y = f(x) в точке с координатами (x0, y0) определяется как прямая, перпендикулярная касательной в этой точке. Основная формула для явно заданной функции: y - y0 = -1/f'(x0) * (x - x0), где f'(x0) ≠ 0. Если f'(x0) = 0, то нормаль имеет вид x = x0. Для функции, заданной неявно уравнением F(x, y) = 0, уравнение нормали записывается через градиент: F_x'(x0, y0)(x - x0) + F_y'(x0, y0)(y - y0) = 0. Для параметрически заданной функции x = φ(t), y = ψ(t) нормаль в точке t0 выражается как (x - x0)ψ'(t0) + (y - y0)φ'(t0) = 0. Ключевое свойство нормали — её перпендикулярность касательной, что выражается в произведении угловых коэффициентов, равном -1 (k_кас * k_норм = -1). Пример: для параболы y = x^2 в точке (1, 1) производная равна 2, поэтому угловой коэффициент нормали равен -1/2, и её уравнение: y - 1 = -1/2(x - 1), или y = -0.5x + 1.5. Нормаль существует для любой гладкой функции (кроме точек, где производная бесконечна, тогда нормаль становится горизонтальной). Уравнение нормали тесно связано с задачами оптимизации и геометрии: оно используется при нахождении расстояний от точки до кривой, в теории кривизны и в физике (например, при расчёте траекторий отражения). Среди связанных тем выделяют Общее уравнение прямой (Ax + By + C = 0), в которое легко преобразуется уравнение нормали; Каноническое уравнение (x - x0)/l = (y - y0)/m, где направляющий вектор (l, m) перпендикулярен касательной; Параметрическое уравнение, задающее нормаль через точку и вектор нормали. Также нормаль взаимосвязана с уравнением в отрезках
