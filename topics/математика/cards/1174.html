основной текст
Малая теорема Ферма (не путать с Великой теоремой Ферма) формулируется так: для любого простого числа p и целого числа a, не кратного p, выполняется сравнение a^(p-1) ≡ 1 (mod p). Эквивалентная форма: a^p ≡ a (mod p) для любого целого a. Например, при p=7 и a=2: 2^6 = 64, 64 mod 7 = 1, что верно. Теорема может быть доказана с помощью свойств мультипликативной группы вычетов по модулю p, порядок которой равен p-1. Основное свойство теоремы — она позволяет упрощать вычисления степеней по модулю простого числа. Например, чтобы найти 3^100 mod 11, достаточно заметить, что 3^10 ≡ 1 (mod 11), поэтому 3^100 = (3^10)^10 ≡ 1^10 = 1 (mod 11). Теорема также служит основой для теста простоты Ферма: если для некоторого a, не кратного n, a^(n-1) ≠ 1 (mod n), то n — составное число. Однако существуют псевдопростые числа (например, 341), которые проходят этот тест, поэтому он не является достаточным. Теорема Ферма широко применяется в криптографии, в частности в алгоритме RSA, где она используется для обоснования расшифровки сообщений. Она также связана с теоремой Эйлера, обобщающей её на составные модули. В контексте других математических тем: Основная теорема алгебры утверждает, что любой многочлен степени n имеет ровно n комплексных корней, что не связано напрямую с теорией чисел, но важно для алгебры. Теорема Руше используется в комплексном анализе для подсчёта корней функций, а Теорема о ранге относится к линейной алгебре и описывает размерность образа линейного отображения. Несмотря на разные разделы, все эти теоремы являются краеугольными камнями своих областей, как и теорема Ферма в теории чисел.
