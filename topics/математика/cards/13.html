основной текст
Распределительный закон (дистрибутивность) — одно из фундаментальных свойств арифметических операций. Он устанавливает правило, как Умножение «распределяется» относительно сложения или вычитания. Основные формулы: a * (b + c) = a * b + a * c и (a + b) * c = a * c + b * c для сложения; для вычитания: a * (b - c) = a * b - a * c и (a - b) * c = a * c - b * c. Здесь a, b, c — натуральные числа. Закон работает как при умножении числа на сумму, так и суммы на число. Свойство распределительности позволяет упрощать вычисления. Например: 7 * 103 = 7 * (100 + 3) = 7 * 100 + 7 * 3 = 700 + 21 = 721. Или при вычитании: 9 * 98 = 9 * (100 - 2) = 9 * 100 - 9 * 2 = 900 - 18 = 882. Важно помнить, что закон работает только в паре умножения со Сложением или Вычитанием; на Деление он распространяется ограниченно (деление суммы на число: (a + b) : c = a : c + b : c, но только если c делит каждое слагаемое нацело). Распределительный закон широко применяется при устном счёте, раскрытии скобок в алгебре, приведении подобных слагаемых и решении уравнений. Он тесно связан с порядком действий: при наличии скобок сначала выполняется операция внутри них, но дистрибутивность позволяет избавиться от скобок, изменив порядок вычислений. Сложение и вычитание — это операции, относительно которых происходит распределение, поэтому понимание этих тем необходимо для правильного применения закона.
