Неопределенный интеграл — это совокупность всех первообразных функции f(x), обозначаемая как ∫f(x)dx, где F'(x) = f(x), плюс произвольная постоянная C.

основной текст
Определение и основные формулы: Неопределенный интеграл функции f(x) есть множество всех её первообразных: ∫f(x)dx = F(x) + C, где F'(x) = f(x), а C — произвольная постоянная. Основные формулы таблицы интегралов включают: ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1), ∫(1/x)dx = ln|x| + C, ∫e^x dx = e^x + C, ∫sin(x)dx = -cos(x) + C, ∫cos(x)dx = sin(x) + C. Также используются правила: ∫k·f(x)dx = k·∫f(x)dx (линейность) и ∫[f(x) ± g(x)]dx = ∫f(x)dx ± ∫g(x)dx. Свойства и примеры: Основное свойство неопределенного интеграла — его производная равна подынтегральной функции: (∫f(x)dx)' = f(x). Пример: ∫(3x^2 + 2x)dx = x^3 + x^2 + C, так как производная x^3 + x^2 равна 3x^2 + 2x. Интеграл от √x (x^(1/2)) вычисляется как x^(3/2)/(3/2) + C = (2/3)x^(3/2) + C. Важно помнить о постоянной C, которая отражает неоднозначность первообразной. Где применяется, связь с другими темами: Неопределенный интеграл является основой для вычисления определенных интегралов (через формулу Ньютона-Лейбница) и решения дифференциальных уравнений. Он применяется в физике для нахождения пути по скорости, в экономике — для восстановления функций спроса, и в геометрии — для вычисления площадей. Связанные темы: Первообразная — функция F(x), такая что F'(x) = f(x); Определение первообразной — ключевое для понимания интеграла; Основное свойство первообразной — две первообразные одной функции отличаются на константу, что и порождает постоянную C в неопределенном интеграле.
