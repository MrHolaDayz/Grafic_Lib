Общее решение системы линейных уравнений — это множество всех векторов (наборов переменных), удовлетворяющих данной системе. Оно представляет собой сумму частного решения неоднородной системы и общего решения соответствующей однородной системы.

основной текст
Общее решение системы линейных уравнений описывает все возможные решения системы. Для неоднородной системы Ax = b общее решение записывается как x = x_ч + x_о, где x_ч — частное решение неоднородной системы, а x_о — общее решение соответствующей однородной системы Ax = 0. В случае однородной системы общее решение представляет собой линейную комбинацию фундаментальных решений: x = c₁·v₁ + c₂·v₂ + ... + c_k·v_k, где c_i — произвольные константы, а v_i — линейно независимые векторы из ядра матрицы A. Количество свободных переменных равно n - rank(A), где n — число неизвестных. Основное свойство общего решения заключается в том, что оно образует аффинное пространство (для неоднородной системы) или векторное подпространство (для однородной). Например, для системы из двух уравнений с тремя переменными, если ранг матрицы равен 2, то общее решение будет содержать одну свободную переменную, и все решения будут лежать на прямой в трехмерном пространстве. Пример: x + y + z = 1, 2x + y = 0. Частное решение можно найти, положив z = 0: x = -1, y = 2, z = 0. Общее решение однородной системы: x = -t, y = 2t, z = t. Тогда общее решение неоднородной: x = -1 - t, y = 2 + 2t, z = t, где t — любое действительное число. Понятие общего решения широко применяется в математическом моделировании, физике, экономике и инженерии при анализе систем с множеством решений. Оно тесно связано с методами решения уравнений, такими как Метод Крамера и Матричный метод, которые позволяют находить частные решения при определенных условиях. В частности, метод Крамера применяется для квадратных систем с ненулевым определителем, а матричный метод использует обратную матрицу. Однако для систем с бесконечным числом решений или несовместных систем именно общее решение дает полное описание.
