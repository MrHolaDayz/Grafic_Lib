Общее уравнение прямой на плоскости — это линейное уравнение вида Ax + By + C = 0, которое задает прямую как множество точек, удовлетворяющих этому равенству. Оно является наиболее универсальной формой записи прямой, позволяющей описать любую прямую, включая вертикальные.

основной текст
Общее уравнение прямой на плоскости представляет собой уравнение первой степени относительно двух переменных: Ax + By + C = 0, где A, B и C — действительные числа, причем A и B не равны нулю одновременно (A^2 + B^2 ≠ 0). Коэффициенты A и B являются координатами нормального вектора прямой n = (A, B), перпендикулярного этой прямой. Если B ≠ 0, уравнение можно преобразовать к виду с угловым коэффициентом y = -A/B * x - C/B, где k = -A/B — угловой коэффициент. Свойства общего уравнения: оно инвариантно относительно умножения на ненулевое число (то есть уравнение 2Ax + 2By + 2C = 0 задает ту же прямую). Частные случаи: при A = 0 (B ≠ 0) получаем горизонтальную прямую y = -C/B; при B = 0 (A ≠ 0) — вертикальную прямую x = -C/A; при C = 0 прямая проходит через начало координат. Пример: прямая 3x - 4y + 12 = 0 имеет нормальный вектор (3, -4), пересекает ось Ox в точке (-4, 0), а ось Oy — в точке (0, 3). Общее уравнение широко применяется в аналитической геометрии для решения задач на взаимное расположение прямых (параллельность, перпендикулярность, нахождение точки пересечения) и расстояния от точки до прямой. Оно тесно связано с другими формами: Каноническое уравнение (x - x0)/m = (y - y0)/n получается из общего при известной точке и направляющем векторе; Параметрическое уравнение (x = x0 + mt, y = y0 + nt) задает прямую через точку и вектор; Уравнение в отрезках x/a + y/b = 1 является частным случаем общего при C ≠ 0. Также общее уравнение связано с понятием общего решения системы линейных уравнений, где прямая может быть решением одного уравнения или пересечением двух плоскостей в пространстве.
