Арксинус (arcsin x) — это функция, обратная синусу, определённая на отрезке [-1, 1] со значениями в [-π/2, π/2]. Основные свойства включают нечётность, связь с арккосинусом и композицию с тригонометрическими функциями.

основной текст
Арксинус (arcsin x) определяется как угол y ∈ [-π/2, π/2], такой что sin y = x. Область определения: x ∈ [-1, 1]; область значений: y ∈ [-π/2, π/2]. Основные формулы: arcsin(-x) = -arcsin x (нечётность), arcsin x + arccos x = π/2 для всех x ∈ [-1, 1], а также sin(arcsin x) = x при x ∈ [-1, 1] и arcsin(sin y) = y при y ∈ [-π/2, π/2]. Производная: d/dx arcsin x = 1/√(1 - x^2). Свойства включают тождества: arcsin x = arctg(x/√(1 - x^2)) для x ≠ ±1, и arcsin(√(1 - x^2)) = π/2 - arcsin x при x ∈ [0, 1]. Пример: arcsin(1/2) = π/6, так как sin(π/6) = 1/2. Важно помнить, что arcsin(sin y) = y только если y ∈ [-π/2, π/2]; в противном случае результат корректируется с учётом периодичности синуса. Арксинус применяется в геометрии для вычисления углов, в физике (например, в волновой оптике), а также в интегральном исчислении при интегрировании выражений вида 1/√(1 - x^2). Связанные темы: Свойства сопряженных чисел (используются при работе с комплексными аргументами arcsin), Свойства модуля (для учёта знаков в тождествах), Свойства транспонирования (применимы в матричных представлениях обратных тригонометрических функций в линейной алгебре).
