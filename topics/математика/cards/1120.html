Объем параллелепипеда, построенного на трех некомпланарных векторах, равен модулю их смешанного произведения. Эта величина показывает, сколько раз единичный куб укладывается внутри данной пространственной фигуры.
связанные темы
Компланарные векторы Векторное произведение Свойства векторного произведения Смешанное произведение Геометрический смысл
основной текст
Объем параллелепипеда, построенного на векторах a, b и c, вычисляется по формуле V = |(a × b) · c|, где a × b — Векторное произведение, а (a × b) · c — Смешанное произведение. В координатной форме, если a = (x1, y1, z1), b = (x2, y2, z2), c = (x3, y3, z3), то V = |det|, где определитель составлен из координат векторов. Также объем можно найти как произведение площади основания на высоту: V = S_осн * h, где S_осн = |a × b| — площадь параллелограмма, а h — высота, равная модулю проекции вектора c на направление векторного произведения. Основное свойство: объем равен нулю тогда и только тогда, когда векторы a, b и c компланарны (лежат в одной плоскости или один из них равен нулю). Например, для векторов a = (1,0,0), b = (0,1,0), c = (0,0,1) объем равен 1 (единичный куб). Если векторы a = (1,0,0), b = (2,0,0), c = (0,1,0), то они компланарны, и объем равен 0. Знак смешанного произведения указывает на ориентацию тройки векторов: положительный — правая тройка, отрицательный — левая. Понятие объема параллелепипеда широко используется в геометрии для вычисления объемов тел через разбиение на параллелепипеды, в физике (например, для нахождения плотности потока векторного поля), а также в линейной алгебре при вычислении определителей и решении систем уравнений. Связанные темы: Компланарные векторы (условие равенства объема нулю), векторное произведение (площадь основания), Свойства векторного произведения (антикоммутативность, билинейность), а также смешанное произведение, которое непосредственно дает объем.
