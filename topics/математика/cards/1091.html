основной текст
Частное решение системы линейных уравнений (СЛУ) — это любое конкретное решение неоднородной системы Ax = b. Если общее решение неоднородной системы записывается как x = x_ч + x_о, где x_о — общее решение соответствующей однородной системы (Ax = 0), то x_ч — это частное решение. Например, для системы из двух уравнений с двумя неизвестными: x + y = 3 и x — y = 1, частным решением будет пара (2, 1). Для нахождения частного решения часто используют Метод Крамера (x_i = Δ_i / Δ, где Δ ≠ 0) или Матричный метод (x = A^(-1) * b). Свойства частного решения: оно не единственно, если система имеет более одного решения; выбор частного решения зависит от метода решения (например, можно задать свободные переменные нулями). Пример: для системы x + y + z = 1, y + z = 0, общее решение: x = 1, y = -t, z = t, где t ∈ R. Частное решение можно получить, взяв t = 0: (1, 0, 0). Если взять t = 1, получим другое частное решение: (1, -1, 1). Частное решение применяется в задачах, где нужно найти конкретные значения переменных, удовлетворяющие условиям (например, в экономике для нахождения равновесия, в физике для начальных условий). Оно тесно связано с темой «Решение уравнений», так как является результатом решения системы. В неоднородных системах частное решение дополняет общее решение однородной системы, а в однородных системах (где b = 0) частное решение — это тривиальное решение (все переменные равны нулю), если система имеет только нулевое решение.
