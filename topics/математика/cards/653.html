основной текст
Метод вспомогательного угла применяется для преобразования линейной комбинации синуса и косинуса в одну тригонометрическую функцию. Основная формула: a·sin(x) + b·cos(x) = R·sin(x + φ), где R = √(a^2 + b^2), а угол φ определяется из условий: sin(φ) = b/R, cos(φ) = a/R. Альтернативно можно использовать формулу R·cos(x - φ). Это позволяет свести уравнение a·sin(x) + b·cos(x) = c к простому виду sin(x + φ) = c/R, который решается стандартными методами. Свойства метода: он применим только при условии |c| ≤ R, иначе уравнение не имеет решений. Пример: решить 3·sin(x) + 4·cos(x) = 5. Здесь R = √(3^2 + 4^2) = 5, cos(φ) = 3/5, sin(φ) = 4/5, тогда уравнение принимает вид 5·sin(x + φ) = 5, то есть sin(x + φ) = 1, откуда x + φ = π/2 + 2πk, x = π/2 - φ + 2πk. Метод особенно удобен при решении тригонометрических уравнений в физике (например, при сложении колебаний) и в инженерных расчетах. Метод вспомогательного угла относится к тригонометрии и часто используется при решении систем уравнений, где также применяются Метод Крамера (для нахождения определителей), Матричный метод (для записи систем в матричной форме) и Метод Гаусса (для приведения систем к треугольному виду). Однако в отличие от этих методов, работающих с линейными алгебраическими системами, метод вспомогательного угла ориентирован исключительно на тригонометрические выражения. Связь между ними проявляется в задачах, где тригонометрические уравнения возникают после решения линейных систем, например, при анализе гармонических процессов.
