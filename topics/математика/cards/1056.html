основной текст
Диагональная матрица — это Квадратная матрица D = (d_ij) размера n×n, для которой d_ij = 0 при i ≠ j. Элементы на главной диагонали могут быть любыми числами. Обозначают такую матрицу как diag(d_11, d_22, ..., d_nn). Например, матрица 3×3: D = [[a, 0, 0], [0, b, 0], [0, 0, c]]. Основные свойства: произведение двух диагональных матриц — снова диагональная матрица, причем перемножение выполняется поэлементно: diag(a1,...,an) * diag(b1,...,bn) = diag(a1*b1,...,an*bn). Обратная матрица для диагональной существует, если все d_ii ≠ 0, и равна diag(1/d_11, ..., 1/d_nn). Возведение в степень: D^k = diag(d_11^k, d_22^k, ..., d_nn^k). Пример: для D = diag(2, -1, 5) имеем D^2 = diag(4, 1, 25). Диагональные матрицы широко применяются в линейной алгебре: они упрощают вычисление собственных значений (сами диагональные элементы являются собственными значениями), используются в спектральном разложении матриц и в методе главных компонент. Связаны с понятием диагонализуемой матрицы — матрицы, которая подобна диагональной. Эта тема тесно связана с общим определением матрицы (как прямоугольной таблицы чисел), классификацией видов матриц (например, треугольных, симметричных) и понятием квадратной матрицы, так как диагональная матрица всегда квадратная.
