основной текст
Вписанная окружность — это окружность, расположенная внутри многоугольника, которая касается каждой его стороны. Для треугольника вписанная окружность существует всегда; её центр (инцентр) находится в точке пересечения биссектрис углов. Радиус r вписанной окружности треугольника можно найти по формуле: r = S / p, где S — площадь треугольника, p — полупериметр (p = (a+b+c)/2). Для правильного многоугольника с n сторонами длины a радиус вписанной окружности равен r = a / (2 * tg(180°/n)). Также для треугольника справедлива формула: r = (a * sin(B) * sin(C)) / (2 * sin(A)), где A, B, C — углы треугольника. Вписанная окружность обладает рядом важных свойств. В треугольнике расстояния от вершин до точек касания с окружностью равны: если стороны треугольника a, b, c, а точки касания делят стороны на отрезки, то, например, от вершины A до точек касания на сторонах AB и AC длины равны (p - a). Касательные, проведённые из одной вершины к вписанной окружности, равны между собой. Для четырёхугольника вписанная окружность существует только в том случае, если суммы длин противоположных сторон равны (условие для описанного четырёхугольника). Пример: в прямоугольный треугольник с катетами 3 и 4 и гипотенузой 5 вписанная окружность имеет радиус r = (3+4-5)/2 = 1. Вписанная окружность широко применяется в геометрии для решения задач на нахождение площадей, длин отрезков и углов. Она тесно связана с понятием описанной окружности: для одного треугольника эти две окружности имеют центры, связанные прямой Эйлера. В архитектуре и дизайне вписанные окружности используются для создания симметричных узоров и расчёта закруглений. В тригонометрии с их помощью выводятся формулы для радиусов вписанных и описанных окружностей. Связанные темы: нет.
