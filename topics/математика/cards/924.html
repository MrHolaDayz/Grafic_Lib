Закон больших чисел — фундаментальный принцип теории вероятностей, утверждающий, что среднее арифметическое результатов большого числа независимых испытаний стремится к математическому ожиданию случайной величины.

основной текст
Закон больших чисел описывает, как эмпирическое среднее сходится к теоретическому ожиданию при увеличении числа наблюдений. В строгой форме для последовательности независимых одинаково распределенных случайных величин X1, X2, ..., Xn с математическим ожиданием µ и дисперсией σ^2 выполняется: для любого ε > 0 предел вероятности P(|(X1 + X2 + ... + Xn)/n - µ| < ε) стремится к 1 при n → ∞. Частный случай — неравенство Чебышёва: P(|X - µ| ≥ ε) ≤ σ^2 / (nε^2). Свойства закона: он работает для любых распределений с конечной дисперсией; сходимость вероятностная, а не детерминированная. Пример: при подбрасывании монеты относительная частота выпадения орла стремится к 0.5 по мере увеличения числа бросков. Другой пример — в страховании: средний убыток на полис приближается к ожидаемому значению при росте числа клиентов. Закон применяется в статистике для обоснования выборочных методов, в физике (статистическая механика), в машинном обучении (сходимость эмпирического риска). Связь с другими темами: закон больших чисел лежит в основе центральной предельной теоремы. В контексте теории чисел он перекликается с бесконечностью простых чисел (Распределение простых чисел подчиняется асимптотическим законам). Также он связан с распределительным законом — вероятностные распределения подчиняются ему при большом числе испытаний. Упомянутые смежные темы: Равенство комплексных чисел (используется в характеристических функциях для доказательства закона), Свойства сопряженных чисел (применяются при анализе комплекснозначных случайных величин), Бесконечность простых чисел (аналогия: как простые числа распределяются равномерно, так и средние сходятся к ожиданию).
