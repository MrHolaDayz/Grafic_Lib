Степень произведения — это правило, согласно которому произведение, возведённое в степень, равно произведению каждого множителя, возведённого в эту же степень: (ab)^n = a^n * b^n.
связанные темы
Возведение в степень Свойства векторного произведения Степень с натуральным показателем Степень с целым показателем Степень с рациональным показателем
основной текст
Определение и основные формулы: Степень произведения определяется как возведение каждого множителя в указанную степень. Для натурального показателя n: (ab)^n = a^n * b^n. Для целого показателя (включая отрицательные): (ab)^(-n) = 1 / (a^n * b^n). Для рационального показателя m/n: (ab)^(m/n) = √[n]((ab)^m) = √[n](a^m * b^m), при условии, что корень извлекается. Это свойство работает для любого конечного числа множителей: (a * b * c)^n = a^n * b^n * c^n. Свойства и примеры: Свойство степени произведения позволяет упрощать выражения и решать уравнения. Пример: (2x)^3 = 2^3 * x^3 = 8x^3. Пример с целым показателем: (3y)^(-2) = 1 / (3^2 * y^2) = 1/(9y^2). Важно помнить, что правило применимо только к умножению, но не к сложению или вычитанию: (a + b)^n ≠ a^n + b^n (за исключением n=1). Для рационального показателя: (4a)^(1/2) = √(4a) = √4 * √a = 2√a. Где применяется, связь с другими темами: Правило степени произведения широко используется в алгебре при упрощении многочленов, в геометрии для вычисления объёмов и площадей (например, (2a)^3 — объём куба), в физике при работе с формулами, содержащими степени. Оно тесно связано с Возведением в степень, так как является частным случаем операций со степенями. В отличие от Свойств векторного произведения, где результат — вектор, степень произведения оперирует со скалярными величинами. Это правило также обобщается на Степень с натуральным показателем, Степень с целым показателем и Степень с рациональным показателем, где оно сохраняет свою форму для каждого типа показателя.
