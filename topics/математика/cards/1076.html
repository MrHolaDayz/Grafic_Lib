След матрицы — это сумма элементов главной диагонали квадратной матрицы, обозначается как tr(A) или Sp(A).
связанные темы
Определение матрицы Виды матриц Квадратная матрица Единичная матрица Нулевая матрица
основной текст
Определение и основные формулы: След матрицы A размера n×n вычисляется как сумма элементов a_ii, где i=1,...,n: tr(A) = Σ_{i=1}^{n} a_ii. Например, для матрицы A = [[2, 5], [3, 4]] след равен 2+4=6. Для единичной матрицы I_n след равен n, а для нулевой матрицы — 0. Свойства и примеры: След обладает свойством линейности: tr(cA) = c·tr(A) и tr(A+B) = tr(A)+tr(B). Важное свойство: для матриц A и B подходящих размеров tr(AB) = tr(BA), даже если AB ≠ BA. След также инвариантен относительно преобразования подобия: tr(P^{-1}AP) = tr(A). Пример: для матриц A = [[1, 2], [0, 3]] и B = [[4, 0], [1, 5]] имеем tr(AB) = tr([[6, 10], [3, 15]]) = 21, и tr(BA) = tr([[4, 8], [1, 17]]) = 21. Где применяется, связь с другими темами: След используется в теории инвариантов, при вычислении дисперсии в статистике (как сумма собственных значений ковариационной матрицы), в квантовой механике (след оператора плотности), а также в машинном обучении для регуляризации (след матрицы Гессе). След тесно связан с определением матрицы — он определен только для квадратных матриц, которые являются одним из видов матриц. Понимание следа требует знания структуры квадратной матрицы, где элементы расположены по строкам и столбцам.
