основной текст
Разложение Вектора по базису — фундаментальная операция в векторной алгебре, позволяющая выразить любой вектор пространства через линейную комбинацию базисных векторов. Если задан базис {e1, e2, e3} в трехмерном пространстве, то любой вектор a может быть единственным образом представлен как a = x*e1 + y*e2 + z*e3, где x, y, z — Координаты вектора. Для проверки линейной независимости используется определитель, составленный из координат векторов: если он не равен нулю, векторы образуют базис. Длина вектора вычисляется как √(x^2 + y^2 + z^2). Основное свойство разложения — единственность: для данного базиса координаты вектора определяются однозначно. Например, в декартовом базисе с ортами i, j, k вектор v = (3, -1, 2) разлагается как v = 3i - j + 2k. Если базис не ортонормированный, координаты находятся через решение системы линейных уравнений. Важно, что разложение по базису позволяет выполнять все векторные операции (сложение, умножение на число) покоординатно. Разложение по базису широко применяется в аналитической геометрии, физике (разложение сил), компьютерной графике (смена систем координат) и теории линейных пространств. Оно тесно связано с понятием координат вектора и длины вектора. В контексте матричных операций выделяют Разложение по строке (представление вектора-строки через базисные строки) и Разложение по столбцу (аналогично для столбцов). Вектор как объект определяется именно через свое разложение в выбранном базисе.
