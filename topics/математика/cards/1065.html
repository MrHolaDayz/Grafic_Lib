основной текст
Свойства операций над матрицами обобщают арифметические законы на случай прямоугольных таблиц чисел. Основные операции включают сложение (A + B), умножение на скаляр (kA) и умножение матриц (AB). Для них справедливы: ассоциативность сложения (A + B) + C = A + (B + C) и умножения (AB)C = A(BC); коммутативность сложения A + B = B + A, но умножение в общем случае некоммутативно (AB ≠ BA); дистрибутивность: A(B + C) = AB + AC и (A + B)C = AC + BC. Для умножения на скаляр: k(A + B) = kA + kB и (k + m)A = kA + mA. Ключевое свойство — некоммутативность умножения. Например, для матриц A = [[1, 2], [3, 4]] и B = [[0, 1], [1, 0]] произведение AB = [[2, 1], [4, 3]], а BA = [[3, 4], [1, 2]] — результаты различны. Также существуют особые матрицы: нулевая (0) ведет себя как нейтральный элемент для сложения (A + 0 = A), а единичная (I) — для умножения (AI = IA = A). Умножение матриц возможно только когда число столбцов первой равно числу строк второй. Эти свойства лежат в основе решения систем линейных уравнений, преобразований координат в компьютерной графике, квантовой механике и экономическом моделировании. Связь с другими темами: Свойства сопряженных чисел (для комплексных матриц операция сопряжения подчиняется правилам (A*)* = A и (AB)* = B*A*); Свойства модуля (норма матрицы обобщает понятие модуля числа); Определение матрицы (матрица как линейный оператор, чьи свойства операций определяют структуру векторных пространств).
