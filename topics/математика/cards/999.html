Алгебра множеств — это раздел математики, изучающий операции над множествами (объединение, Пересечение, разность) и их свойства, образующие булеву алгебру. Она служит основой для формальной логики и теории вероятностей.

основной текст
Алгебра множеств определяет систему операций над произвольными множествами. Основные действия: Объединение (A ∪ B), Пересечение (A ∩ B), Разность (A \ B) и Симметрическая разность (A Δ B = (A \ B) ∪ (B \ A)). Для этих операций выполняются законы: коммутативности (A ∪ B = B ∪ A), ассоциативности ((A ∪ B) ∪ C = A ∪ (B ∪ C)), дистрибутивности (A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)), а также законы идемпотентности (A ∪ A = A) и поглощения (A ∪ (A ∩ B) = A). Универсальное множество U и пустое множество ∅ играют роль единицы и нуля: A ∪ ∅ = A, A ∩ U = A. Свойства алгебры множеств включают законы де Моргана: дополнение объединения равно пересечению дополнений (¬(A ∪ B) = ¬A ∩ ¬B) и наоборот. Пример: если A = {1, 2, 3}, B = {3, 4, 5}, то A ∪ B = {1, 2, 3, 4, 5}, A ∩ B = {3}, A \ B = {1, 2}, A Δ B = {1, 2, 4, 5}. Эти операции наглядно иллюстрируются диаграммами Венна. Алгебра множеств применяется в теории вероятностей (Алгебра событий), где события трактуются как подмножества пространства исходов. Она также лежит в основе булевой алгебры в информатике (логические схемы, базы данных). Связанные темы: объединение и пересечение — базовые операции; разность и симметрическая разность — для моделирования исключающих условий. Алгебра событий является прямым приложением алгебры множеств к случайным процессам.
