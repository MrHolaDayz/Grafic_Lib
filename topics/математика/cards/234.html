основной текст
Гиперболические функции определяются через показательную функцию e^x. Основные из них: гиперболический синус sh x = (e^x - e^(-x))/2, гиперболический косинус ch x = (e^x + e^(-x))/2, гиперболический тангенс th x = sh x / ch x и гиперболический котангенс cth x = ch x / sh x. Для них выполняются тождества, напоминающие тригонометрические: ch^2 x - sh^2 x = 1. Свойства гиперболических функций включают чётность (ch x — чётная, sh x — нечётная), монотонность и асимптотическое поведение: при больших x sh x и ch x ведут себя как e^x/2. График гиперболического косинуса (цепная линия) описывает форму провисающей нити или цепи. Пример: функция y = ch x имеет минимум в точке (0,1). Гиперболические функции применяются в физике (теория относительности, форма кабеля под нагрузкой), в инженерных расчётах, в комплексном анализе и при решении дифференциальных уравнений. Они связаны с линейной функцией через экспоненту, со степенной функцией через свойства чётности и нечётности, а с квадратичной функцией — через тождество ch^2 x - sh^2 x = 1, которое напоминает уравнение гиперболы.
