основной текст
Действия над рациональными числами включают четыре основные арифметические операции: сложение, вычитание, умножение и деление. Основные формулы: a + b = c, a - b = c, a * b = c, a / b = c (при b ≠ 0). Для сложения и вычитания дроби приводят к общему знаменателю: a/b + c/d = (a*d + c*b) / (b*d). Умножение: (a/b) * (c/d) = (a*c) / (b*d). Деление: (a/b) / (c/d) = (a*d) / (b*c). Степень с натуральным показателем: (a/b)^n = a^n / b^n. Корень n-й степени: √[n]{a/b} = √[n]{a} / √[n]{b} (при условии, что корни существуют в рациональных числах). Действия обладают рядом свойств: коммутативность (a + b = b + a, a * b = b * a), ассоциативность ((a + b) + c = a + (b + c)), дистрибутивность (a * (b + c) = a*b + a*c). Пример: 1/2 + 1/3 = (3+2)/6 = 5/6; 2/3 * 3/4 = 6/12 = 1/2; (1/2) / (3/4) = (1/2) * (4/3) = 4/6 = 2/3. Важно помнить, что деление на ноль невозможно. Действия над рациональными числами применяются в повседневной жизни (расчеты, доли, проценты), в физике, экономике и инженерии. Эта тема тесно связана с понятием рациональных чисел как множества, замкнутого относительно всех арифметических действий (кроме деления на ноль). Свойства действий (коммутативность, ассоциативность) позволяют упрощать вычисления. Плотность рациональных чисел означает, что между любыми двумя рациональными числами можно найти еще одно, что используется в приближенных вычислениях.
