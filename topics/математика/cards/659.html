основной текст
Тригонометрические неравенства представляют собой неравенства вида sin x > a, cos x ≤ b, tg x ≥ c и т.д. Основная сложность их решения связана с периодичностью тригонометрических функций и необходимостью учёта всех бесконечных серий решений. Для простейших неравенств используют единичную окружность: например, для sin x > a сначала находят arcsin a, а затем определяют интервал (arcsin a; π - arcsin a) и прибавляют период 2πn, n ∈ Z. Для cos x < a решение записывается как (arccos a + 2πn; 2π - arccos a + 2πn). Неравенства с tg и ctg решаются через промежутки длины π, исключая точки разрыва. При решении более сложных неравенств (например, sin^2 x - 3 sin x + 2 > 0) применяют замену переменной t = sin x, сводя задачу к квадратному неравенству, а затем возвращаются к тригонометрической функции. Важно помнить об области определения: для tg x и ctg x знаменатель (cos x или sin x) не должен равняться нулю. Также используют метод интервалов на окружности, где корни отмечаются точками, а знаки определяются по четвертям. Пример: решить неравенство 2 cos x - √2 ≤ 0 → cos x ≤ √2/2 → x ∈ [π/4 + 2πn; 7π/4 + 2πn], n ∈ Z. Тригонометрические неравенства широко применяются в физике (анализ колебаний, волн), геометрии (нахождение углов в треугольниках) и в задачах с параметрами. Они тесно связаны с тригонометрическими уравнениями, так как после нахождения граничных точек неравенства часто решают уравнение. Знание свойств тригонометрических функций (периодичность, монотонность на промежутках) и обратных тригонометрических функций (arcsin, arccos, arctg) является основой для корректной записи ответа. Также используются навыки решения линейных и квадратных неравенств при заменах переменной.
