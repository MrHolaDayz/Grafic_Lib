основной текст
Уравнение прямой — это фундаментальное понятие аналитической геометрии, которое связывает геометрический образ прямой линии с алгебраическими выражениями. На плоскости прямая может быть задана несколькими способами. Наиболее общая форма — общее уравнение прямой: Ax + By + C = 0, где A, B, C — константы, причём A и B не равны нулю одновременно. Вектор (A, B) является нормальным вектором к прямой. Для прямой, проходящей через точку M0(x0, y0) с направляющим вектором (l, m), используется Каноническое уравнение: (x - x0)/l = (y - y0)/m. Параметрическое уравнение прямой выражает координаты через параметр t: x = x0 + l*t, y = y0 + m*t. В пространстве прямая задаётся как пересечение двух плоскостей или через точку и направляющий вектор с помощью аналогичных трёхмерных форм. Основные свойства прямой следуют из её уравнения. Например, по виду уравнения можно определить угол наклона прямой к осям координат, точки пересечения с осями, а также взаимное расположение двух прямых (параллельность, перпендикулярность, пересечение). Пример: найти уравнение прямой, проходящей через точки A(1, 2) и B(3, 5). Сначала находим направляющий вектор (2, 3), затем используем каноническое уравнение: (x - 1)/2 = (y - 2)/3. После преобразования получаем общее уравнение: 3x - 2y + 1 = 0. Уравнение прямой широко применяется в физике (траектории движения), инженерной графике, компьютерной графике и геодезии. В аналитической геометрии оно тесно связано с уравнением плоскости (прямая может быть линией пересечения двух плоскостей) и углом между плоскостями (через направляющие векторы). Также важны смежные темы: каноническое уравнение (удобно для перехода к параметрическому виду), параметрическое уравнение (незаменимо при построении кривых и в задачах с движением), а также Расстояние от точки до прямой (вычисляется по формуле d = |Ax0 + By0 + C| / √(A^2 + B^2) на плоскости).
