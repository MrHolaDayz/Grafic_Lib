основной текст
Неравенство Йенсена — одно из фундаментальных неравенств математического анализа, обобщающее свойства выпуклости. Пусть f — выпуклая функция на интервале I, а x_1, x_2, ..., x_n — точки из I с положительными весами λ_i, сумма которых равна 1. Тогда неравенство имеет вид: f(λ_1 x_1 + λ_2 x_2 + ... + λ_n x_n) ≤ λ_1 f(x_1) + λ_2 f(x_2) + ... + λ_n f(x_n). Для вогнутой функции знак неравенства меняется на противоположный. Частный случай при равных весах (λ_i = 1/n) особенно популярен: f((x_1+...+x_n)/n) ≤ (f(x_1)+...+f(x_n))/n. Основное свойство неравенства — оно напрямую вытекает из определения выпуклости и доказывается по индукции. Пример: для выпуклой функции f(x)=x^2 имеем ((a+b)/2)^2 ≤ (a^2+b^2)/2, что эквивалентно известному неравенству о среднем квадратичном. Для вогнутой функции f(x)=√x получаем √((a+b)/2) ≥ (√a+√b)/2. Другой классический пример — использование экспоненты (выпуклая функция) для доказательства неравенства между средним арифметическим и средним геометрическим. Неравенство Йенсена широко применяется в теории вероятностей (для математического ожидания), в оптимизации, при доказательстве других неравенств (например, неравенства Гёльдера и Минковского). Оно тесно связано с такими темами, как Линейные неравенства (поскольку линейные функции одновременно выпуклы и вогнуты, неравенство превращается в равенство), Квадратные неравенства (частные случаи для f(x)=x^2 дают квадратичные оценки), а также с Методом интервалов (при исследовании знака второй производной для определения выпуклости функции на интервалах).
