основной текст
Дисперсия случайной величины X определяется как математическое ожидание квадрата отклонения X от её математического ожидания M[X]. Основная формула: D[X] = M[(X - M[X])^2]. Для вычислений часто используется эквивалентная формула: D[X] = M[X^2] - (M[X])^2. Для дискретной случайной величины с конечным числом значений дисперсия вычисляется как сумма произведений квадратов отклонений на соответствующие вероятности: D[X] = Σ (x_i - M[X])^2 * p_i. Для непрерывной величины используется интеграл от (x - M[X])^2 * f(x) dx, где f(x) — плотность распределения. Среднее квадратическое отклонение (стандартное отклонение) равно √D[X] и имеет ту же размерность, что и сама величина. Основные свойства дисперсии: дисперсия постоянной величины равна нулю; при умножении случайной величины на константу c дисперсия умножается на c^2; дисперсия суммы независимых случайных величин равна сумме их дисперсий. Например, если у нас есть два игральных кубика, дисперсия суммы очков будет равна сумме дисперсий каждого кубика. Если выборка состоит из чисел 2, 4, 6 со средним 4, то дисперсия (для генеральной совокупности) равна ((2-4)^2 + (4-4)^2 + (6-4)^2)/3 = 8/3 ≈ 2.67. Дисперсия широко применяется в статистике для оценки разброса данных, в финансовой математике для измерения рисков (например, волатильности цен акций), в теории измерений для оценки погрешностей, а также в машинном обучении для анализа признаков. Она тесно связана с математическим ожиданием (через определение) и стандартным отклонением (как корень из дисперсии). Понятие дисперсии лежит в основе метода наименьших квадратов и анализа вариации (ANOVA). Связанные темы: Математическое ожидание, Стандартное отклонение, Ковариация, Корреляция, Закон больших чисел.
