основной текст
Неопределенность 0/0 — одна из основных неопределенностей в теории пределов. Она возникает, когда при x → a (или n → ∞) функции f(x) и g(x) стремятся к нулю, и рассматривается предел их отношения lim (f(x)/g(x)). В этом случае нельзя напрямую подставить значение a, так как получается выражение 0/0, не имеющее числового смысла. Для раскрытия неопределенности используются алгебраические преобразования: разложение на множители с последующим сокращением общего множителя (например, lim (x^2 - 1)/(x - 1) при x → 1), умножение на сопряженное выражение для корней (lim (√(x+1) - 1)/x при x → 0), или применение первого замечательного предела (lim sin x / x = 1 при x → 0). В более сложных случаях применяется правило Лопиталя, которое сводит предел отношения функций к пределу отношения их производных. Свойства неопределенности 0/0 тесно связаны с непрерывностью и дифференцируемостью функций. Если функции f(x) и g(x) являются бесконечно малыми одного порядка, предел может быть конечным и ненулевым; если числитель — бесконечно малая более высокого порядка, предел равен нулю; если знаменатель — более высокого порядка, предел равен бесконечности. Пример: lim (x^2)/(x) при x → 0 равен 0, так как x^2 — бесконечно малая более высокого порядка, чем x. Другой пример: lim (sin x)/x = 1, где обе функции — бесконечно малые одного порядка. Эта неопределенность широко применяется в математическом анализе при исследовании функций, вычислении производных (через определение производной как предела), в дифференциальном исчислении и при решении задач физики (например, при нахождении мгновенной скорости). Связанные темы включают Предел последовательности, где неопределенность 0/0 также может возникать для последовательностей (например, lim (1/n)/(1/n^2) при n → ∞).
