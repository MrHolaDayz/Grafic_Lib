Метод обратной матрицы — это способ решения систем линейных уравнений, основанный на умножении обеих частей матричного уравнения на обратную матрицу. Для квадратной невырожденной системы A * x = b решение находится по формуле x = A^(-1) * b.

основной текст
Метод обратной матрицы применяется для решения систем линейных уравнений, записанных в матричной форме: A * x = b, где A — квадратная матрица коэффициентов (n x n), x — столбец неизвестных, b — столбец свободных членов. Если определитель матрицы A не равен нулю (det(A) ≠ 0), то существует обратная матрица A^(-1). Решение системы находится как x = A^(-1) * b. Обратная матрица вычисляется по формуле A^(-1) = (1 / det(A)) * (A*)^T, где A* — матрица алгебраических дополнений, а (A*)^T — присоединённая (союзная) матрица. Для матрицы 2x2 обратная матрица находится проще: если A = [[a, b], [c, d]], то A^(-1) = (1 / (ad - bc)) * [[d, -b], [-c, a]]. Основное свойство метода — он применим только для квадратных систем с ненулевым определителем (невырожденных матриц). Пример: решим систему 2x + 3y = 7, 4x + 5y = 11. Матрица A = [[2, 3], [4, 5]], её определитель det(A) = 2*5 - 3*4 = 10 - 12 = -2. Обратная матрица: A^(-1) = (1 / -2) * [[5, -3], [-4, 2]] = [[-2.5, 1.5], [2, -1]]. Тогда x = A^(-1) * b = [[-2.5, 1.5], [2, -1]] * [[7], [11]] = [[(-2.5*7 + 1.5*11)], [(2*7 + (-1)*11)]] = [[(-17.5 + 16.5)], [(14 - 11)]] = [[-1], [3]]. Решение: x = -1, y = 3. Метод обратной матрицы широко применяется в линейной алгебре, физике, экономике и компьютерной графике для решения систем с небольшим числом уравнений (обычно до 3-4), где требуется аналитическая точность.
