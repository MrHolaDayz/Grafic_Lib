основной текст
Частные случаи — это упрощённые формулы для решения тригонометрических уравнений, когда правая часть принимает значения a = 0, a = 1 или a = -1. Для sin x = a: если a = 0, то x = πn; если a = 1, то x = π/2 + 2πn; если a = -1, то x = -π/2 + 2πn. Для cos x = a: если a = 0, то x = π/2 + πn; если a = 1, то x = 2πn; если a = -1, то x = π + 2πn. Для tg x = a: если a = 0, то x = πn; если a = 1, то x = π/4 + πn; если a = -1, то x = -π/4 + πn. Для ctg x = a: если a = 0, то x = π/2 + πn; если a = 1, то x = π/4 + πn; если a = -1, то x = 3π/4 + πn. n ∈ Z. Эти формулы позволяют быстро находить корни без обращения к арксинусам и арккосинусам. Например, уравнение sin x = 0 имеет решение x = πn, а не x = πk (где k — целое), что проще, чем общая формула x = (-1)^n * arcsin(0) + πn. Важно помнить, что для a = ±1 период может меняться: для sin и cos при a = ±1 решения имеют период 2π, а для tg и ctg — период π. Частные случаи широко применяются при решении более сложных тригонометрических уравнений, когда после замены или преобразования получается простейшее уравнение с табличным значением. Они также используются в геометрии (например, для нахождения углов в прямоугольных треугольниках) и в физике (описание колебаний). Связанные темы: Простейшие уравнения sin x = a, cos x = a, tg x = a, ctg x = a — эти уравнения являются базой, а частные случаи — их подмножеством.
