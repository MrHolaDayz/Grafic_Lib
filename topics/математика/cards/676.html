Предел функции по Гейне — это определение предела, основанное на поведении функции на всех последовательностях точек, сходящихся к данной точке: число A называется пределом функции f(x) в точке a, если для любой последовательности x_n → a (x_n ≠ a) соответствующая последовательность значений f(x_n) → A.

основной текст
Определение предела по Гейне формулируется так: пусть функция f(x) определена в некоторой проколотой окрестности точки a. Число A называется пределом функции f(x) при x → a, если для любой последовательности аргументов {x_n}, такой что x_n → a и x_n ≠ a для всех n, соответствующая последовательность значений функции {f(x_n)} сходится к A. В компактной записи: lim_{x→a} f(x) = A ⇔ ∀ {x_n}: (x_n → a, x_n ≠ a) ⇒ f(x_n) → A. Это определение эквивалентно классическому определению на языке ε-δ (определению по Коши), что часто используется для доказательства отсутствия предела: достаточно найти две последовательности, дающие разные пределы. Основные свойства предела, вытекающие из определения по Гейне, включают арифметические свойства (предел суммы, произведения, частного), а также теорему о пределе композиции функций. Например, если lim_{x→a} f(x) = A и lim_{x→A} g(x) = B, то lim_{x→a} g(f(x)) = B, при условии, что f(x) ≠ A в проколотой окрестности. Пример: для функции f(x) = x^2 при x → 2 предел равен 4, так как для любой последовательности x_n → 2 последовательность x_n^2 → 4. Контрпример: функция sin(1/x) при x → 0 не имеет предела, так как можно выбрать последовательности x_n = 1/(π n) → 0 (значения равны 0) и y_n = 1/(π/2 + 2π n) → 0 (значения равны 1). Определение предела по Гейне широко применяется в математическом анализе для исследования непрерывности функций, а также в теории рядов и дифференциальном исчислении. Оно особенно удобно при доказательстве отсутствия предела, поскольку сводит задачу к анализу последовательностей. Связанные темы, такие как Определение матрицы, Разложение по строке и Разложение по столбцу, относятся к линейной алгебре и не имеют прямого отношения к определению предела по Гейне, однако в многомерном анализе
