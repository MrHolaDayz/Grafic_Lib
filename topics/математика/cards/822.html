основной текст
Интегрирующий множитель (обозначается μ(x, y)) — это ненулевая функция, при умножении на которую уравнение вида M(x, y)dx + N(x, y)dy = 0 превращается в полный дифференциал. Для уравнения первого порядка P(x, y)dx + Q(x, y)dy = 0 условие полноты: ∂P/∂y = ∂Q/∂x. Если это не выполняется, интегрирующий множитель μ находится из уравнения: (∂(μP)/∂y) = (∂(μQ)/∂x). В простых случаях μ зависит только от x или только от y: если (∂P/∂y - ∂Q/∂x)/Q = f(x), то μ = e^(∫f(x)dx); если (∂Q/∂x - ∂P/∂y)/P = g(y), то μ = e^(∫g(y)dy). Основное свойство: после умножения на μ уравнение становится полным, и его решение сводится к нахождению функции F(x, y) такой, что dF = μP dx + μQ dy = 0, откуда F(x, y) = C — Общее решение. Пример: уравнение ydx - xdy = 0. Здесь P = y, Q = -x, ∂P/∂y = 1, ∂Q/∂x = -1 — не полное. Находим μ = 1/y^2 (зависит от y). Умножаем: (1/y)dx - (x/y^2)dy = 0. Проверка: ∂(1/y)/∂y = -1/y^2, ∂(-x/y^2)/∂x = -1/y^2 — полное. Решение: d(x/y) = 0, общее решение x/y = C. Интегрирующий множитель применяется для решения дифференциальных уравнений первого порядка, которые не являются полными, но могут быть приведены к таковым. Это важный инструмент в математическом анализе и физике (например, в термодинамике). Связанные темы: Общее решение — результат интегрирования после применения множителя; Частное решение — получается из общего при задании начального условия (Задача Коши). Основные понятия включают полный дифференциал, Порядок уравнения (первый порядок) и условия интегрируемости.
