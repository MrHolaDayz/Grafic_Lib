основной текст
Извлечение корня из частного основано на свойстве: для любого натурального n > 1 и неотрицательных чисел a и b (b ≠ 0) выполняется равенство √(a/b) = √a / √b. Это правило вытекает из свойств степеней, поскольку (a/b)^(1/n) = a^(1/n) / b^(1/n). Для корней нечётной степени (например, кубического) условие неотрицательности можно снять, но важно помнить, что деление на ноль запрещено. Пример: √(9/4) = √9 / √4 = 3/2 = 1.5; ∛(8/27) = ∛8 / ∛27 = 2/3. Свойство извлечения корня из частного широко применяется при упрощении алгебраических выражений, решении уравнений и в геометрии (например, при нахождении стороны квадрата по его площади, выраженной дробью). Оно тесно связано с правилом извлечения корня из произведения и часто используется совместно с ним. Например, √(a^2 * b / c) = a√b / √c. Также это свойство лежит в основе рационализации знаменателя, когда дробь вида 1/√a преобразуется в √a/a. Данная тема является частным случаем общего понятия извлечения корня n-й степени. Она связана с квадратным корнем (n=2), кубическим корнем (n=3) и корнями более высоких порядков. Понимание этого правила необходимо для работы с иррациональными числами и выражениями. В отличие от корней из единицы, которые рассматривают комплексные решения уравнения x^n = 1, извлечение корня из частного оперирует с действительными числами и дробями, являясь базовым инструментом алгебры.
