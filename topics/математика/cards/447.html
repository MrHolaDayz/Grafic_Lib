Движение — это преобразование плоскости, сохраняющее расстояние между любыми двумя точками.
связанные темы
Осевая симметрия Центральная симметрия Поворот Параллельный перенос Гомотетия
основной текст
Движением (или изометрией) называется отображение плоскости на себя, при котором для любых точек A и B расстояние между их образами A' и B' равно исходному: |A'B'| = |AB|. Основные формулы движений включают: Параллельный перенос на вектор (x; y) — (x'; y') = (x + a; y + b); Поворот вокруг точки O на угол φ — (x'; y') = (x·cos φ − y·sin φ; x·sin φ + y·cos φ) для центра в начале координат; Осевая симметрия относительно оси X — (x; y) → (x; −y); Центральная симметрия относительно точки O — (x; y) → (−x; −y). Движения сохраняют длины отрезков, величины углов, площади фигур и коллинеарность точек. Примеры: при параллельном переносе все точки смещаются на одинаковое расстояние в одном направлении; при повороте фигура вращается вокруг неподвижного центра; при осевой симметрии фигура зеркально отражается относительно прямой. Композиция двух движений также является движением. Движения широко применяются в кристаллографии, компьютерной графике, архитектуре и теории симметрии. Они тесно связаны с понятием равенства фигур: две фигуры равны, если одну можно получить из другой движением. В отличие от гомотетии, которая меняет размеры, движения сохраняют форму и размеры. Связанные темы: Осевая симметрия (частный случай движения с неподвижной прямой), Центральная симметрия (поворот на 180°), Поворот (вращение на заданный угол вокруг точки). Эти преобразования вместе с параллельным переносом образуют группу движений плоскости.
