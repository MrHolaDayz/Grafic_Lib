Многоугольник распределения — это графическое представление дискретной случайной величины, где на оси абсцисс откладываются её возможные значения, а на оси ординат — соответствующие им вероятности, при этом точки соединяются отрезками для наглядности.

основной текст
Многоугольник распределения (или полигон распределения) строится для дискретной случайной величины X, которая принимает значения x_1, x_2, ..., x_n с вероятностями p_1, p_2, ..., p_n. На координатной плоскости отмечаются точки (x_i; p_i), которые затем последовательно соединяются прямыми линиями. Основное условие — сумма всех вероятностей равна 1: Σ p_i = 1. Для наглядности часто добавляют отрезки от первой и последней точки до оси абсцисс, чтобы подчеркнуть, что вне этих значений вероятность равна нулю. Свойства многоугольника распределения: все ординаты (вероятности) неотрицательны (0 ≤ p_i ≤ 1), сумма ординар равна 1, а сам график является ломаной линией. Пример: при подбрасывании правильной монеты дважды случайная величина X — число выпадений орла — принимает значения 0, 1, 2 с вероятностями 1/4, 1/2, 1/4 соответственно. На графике точки (0; 0.25), (1; 0.5), (2; 0.25) образуют симметричную ломаную. Многоугольник распределения применяется в статистике для визуального анализа дискретных данных, сравнения распределений и проверки гипотез. Он тесно связан с гистограммой (для непрерывных величин) и функцией распределения. В теории вероятностей это базовый инструмент для изучения случайных величин. Связанные темы: Многоугольник распределения строится для случайных событий, которые могут быть как достоверными (вероятность 1), так и невозможными (вероятность 0). Например, если событие достоверно, на графике будет единственная точка с ординатой 1; если невозможно — точка с ординатой 0. Это наглядно показывает разницу между различными типами событий в рамках классического и статистического определения вероятности.
