Угол между двумя плоскостями — это угол между их нормальными векторами, который определяется как острый угол (от 0 до 90°) между перпендикулярами к этим плоскостям.
связанные темы
Переход между формами Угол между векторами Уравнение плоскости Уравнение прямой Взаимное расположение
основной текст
Угол между двумя плоскостями в пространстве определяется через угол между их нормальными векторами. Если плоскости заданы общими уравнениями A₁x + B₁y + C₁z + D₁ = 0 и A₂x + B₂y + C₂z + D₂ = 0, то нормальные векторы имеют координаты n₁ = (A₁, B₁, C₁) и n₂ = (A₂, B₂, C₂). Косинус угла φ между плоскостями вычисляется по формуле: cos φ = |A₁A₂ + B₁B₂ + C₁C₂| / (√(A₁² + B₁² + C₁²) * √(A₂² + B₂² + C₂²)). Угол берётся острым (0° ≤ φ ≤ 90°), поэтому используется модуль скалярного произведения. Если плоскости перпендикулярны, то cos φ = 0, то есть A₁A₂ + B₁B₂ + C₁C₂ = 0. Если плоскости параллельны, то их нормальные векторы коллинеарны: (A₁, B₁, C₁) = k(A₂, B₂, C₂). Свойства: угол между плоскостями не зависит от выбора точки на линии их пересечения и от направления нормальных векторов (замена знака не меняет модуль скалярного произведения). Пример: найти угол между плоскостями x + y + z = 0 и 2x — y + 3z = 0. Нормальные векторы: n₁ = (1,1,1), n₂ = (2,-1,3). Скалярное произведение: 1*2 + 1*(-1) + 1*3 = 4. Длины: |n₁| = √3, |n₂| = √(4+1+9)=√14. cos φ = 4 / (√3 * √14) = 4 / √42, φ = arccos(4/√42). Данная тема применяется в стереометрии, компьютерной графике (расчёт освещения, отражений), в строительстве (расчёт углов наклона стен и крыш), а также в физике при анализе отражения лучей от поверхностей. Связь с другими темами: через Уравнение плоскости задаются нормальные векторы; через Переход между формами (общее уравнение, уравнение в отрезках, нормальное уравнение)
