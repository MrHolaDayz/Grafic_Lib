основной текст
Уравнение tg x = a является одним из базовых простейших тригонометрических уравнений. Его решение основано на свойстве периодичности тангенса: функция y = tg x имеет период π и определена при x ≠ π/2 + πk, k ∈ Z. Основная формула решения: x = arctg a + πn, n ∈ Z, где arctg a — главное значение арктангенса, лежащее в интервале (-π/2; π/2). В отличие от синуса и косинуса, уравнение tg x = a всегда имеет решение, поскольку область значений тангенса — вся числовая прямая. Частные случаи: при a = 0 решение x = πn; при a = 1 — x = π/4 + πn; при a = -1 — x = -π/4 + πn; при a = √3 — x = π/3 + πn; при a = -√3 — x = -π/3 + πn. Свойства и примеры. Решение строится по единому алгоритму: находим arctg a на интервале (-π/2; π/2) и прибавляем период πn. Например, для tg x = 2: x = arctg 2 + πn (arctg 2 ≈ 63,4°). Для tg x = -0,5: x = arctg(-0,5) + πn = -arctg 0,5 + πn. Важно помнить про область определения: точки, где cos x = 0 (x = π/2 + πk), не входят в решение, так как в них тангенс не определен. При решении более сложных уравнений часто используют замену: приводят уравнение к виду tg f(x) = a, затем решают f(x) = arctg a + πn. Уравнение tg x = a широко применяется в геометрии (нахождение углов по тангенсу), физике (расчет углов наклона, волновые процессы) и инженерных задачах.
