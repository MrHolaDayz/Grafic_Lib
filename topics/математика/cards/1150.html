Взаимное расположение — раздел аналитической геометрии, изучающий различные случаи положения прямой и плоскости в пространстве (пересечение, параллельность, принадлежность прямой плоскости) с помощью их уравнений.
связанные темы
Уравнение плоскости Угол между плоскостями Уравнение прямой
основной текст
Определение и основные формулы. Взаимное расположение прямой и плоскости в пространстве определяется на основе их уравнений. Пусть плоскость задана общим уравнением Ax + By + Cz + D = 0, а прямая — параметрическими уравнениями x = x0 + lt, y = y0 + mt, z = z0 + nt. Для исследования взаимного положения вычисляют скалярное произведение нормального вектора плоскости n = (A, B, C) и направляющего вектора прямой s = (l, m, n). Если n·s ≠ 0, то прямая пересекает плоскость в одной точке. Если n·s = 0, то прямая либо параллельна плоскости (когда точка прямой не удовлетворяет уравнению плоскости), либо лежит в ней (когда точка прямой удовлетворяет уравнению плоскости). Свойства и примеры. При n·s = 0 и Ax0 + By0 + Cz0 + D ≠ 0 прямая параллельна плоскости. Если же n·s = 0 и Ax0 + By0 + Cz0 + D = 0, то прямая целиком принадлежит плоскости. Пример: для плоскости x + y + z — 3 = 0 и прямой x = 1 + t, y = 1 — t, z = 1 + 2t находим n·s = 1·1 + 1·(-1) + 1·2 = 2 ≠ 0 — прямая пересекает плоскость. Точка пересечения находится подстановкой параметрических уравнений в Уравнение плоскости. Где применяется, связь с другими темами. Данный раздел является основой для решения задач на нахождение точек пересечения, расстояний от точки до прямой или плоскости, а также для построения сечений в стереометрии. Он тесно связан с темой «Уравнение плоскости», так как для анализа используется нормальный вектор плоскости, и с темой «Уравнение прямой», откуда берутся направляющий вектор и точка. Кроме того, знание взаимного расположения необходимо при вычислении «Угла между плоскостями» и угла между прямой и плоскостью, где используется аналогичное скалярное произведение.
