основной текст
Свойства в арифметике и алгебре описывают поведение операций над числами. Основные свойства сложения и умножения: коммутативность (a + b = b + a; a * b = b * a), ассоциативность ((a + b) + c = a + (b + c); (a * b) * c = a * (b * c)) и дистрибутивность (a * (b + c) = a * b + a * c). Для вычитания и деления эти свойства не выполняются в общем виде. Также важны свойства нуля (a + 0 = a, a * 0 = 0) и единицы (a * 1 = a). Для степеней действуют правила: a^m * a^n = a^(m+n), (a^m)^n = a^(m*n), (a*b)^n = a^n * b^n. Корни связаны со степенями: √(a*b) = √a * √b, √(a/b) = √a / √b (при неотрицательных a, b). Например, используя дистрибутивность, можно раскрыть скобки: 3 * (x + 5) = 3x + 15. Свойство ассоциативности позволяет группировать слагаемые: (2 + 7) + 3 = 2 + (7 + 3). Для рациональных чисел важно свойство сокращения дробей: (a*c)/(b*c) = a/b, если c ≠ 0. Пример с корнями: √8 = √(4*2) = √4 * √2 = 2√2. Свойства степеней помогают упрощать выражения: (2^3)^2 = 2^6 = 64. Свойства операций лежат в основе всей математики — от решения уравнений до работы с матрицами и векторами. Они позволяют доказывать тождества, преобразовывать выражения и находить неизвестные. Связанные темы расширяют эти идеи на другие объекты: Свойства сопряженных чисел (для комплексных чисел: (a+bi)(a-bi) = a^2 + b^2) используются при делении и упрощении. Свойства модуля (|a*b| = |a|*|b|, |a+b| ≤ |a| + |b|) применяются в неравенства
