основной текст
Углом между двумя прямыми на плоскости называется меньший из двух смежных углов, образованных этими прямыми при их пересечении. Величина угла лежит в пределах от 0 до 90 градусов (или от 0 до π/2 радиан). Если прямые параллельны или совпадают, угол между ними считается равным 0. Основные формулы для вычисления угла φ между прямыми: через направляющие векторы (s1 = (l1, m1), s2 = (l2, m2)): cos φ = |s1·s2| / (|s1|·|s2|) = |l1*l2 + m1*m2| / (√(l1^2 + m1^2) * √(l2^2 + m2^2)); через угловые коэффициенты (y = k1*x + b1, y = k2*x + b2): tg φ = |(k2 - k1) / (1 + k1*k2)|, при условии, что прямые не перпендикулярны (иначе знаменатель равен нулю, и φ = 90°). Угол между прямыми обладает важными свойствами: он симметричен (угол от первой прямой ко второй равен углу от второй к первой) и не зависит от выбора направления векторов. Например, для прямых y = 2x + 1 и y = 3x - 2: tg φ = |(3-2)/(1+2*3)| = |1/7|, φ ≈ arctg(1/7) ≈ 8.13°. Если прямые заданы общими уравнениями A1x + B1y + C1 = 0 и A2x + B2y + C2 = 0, то cos φ = |A1*A2 + B1*B2| / (√(A1^2 + B1^2) * √(A2^2 + B2^2)), что следует из формулы угла между нормальными векторами. Данная тема широко применяется в геометрии, физике (например, при расчете углов падения и отражения), компьютерной графике и навигации.
