Моменты случайных величин — это числовые характеристики распределения, такие как математическое ожидание (первый момент) и дисперсия (второй центральный момент), которые описывают форму, разброс и асимметрию вероятностного закона.

основной текст
Моменты случайных величин обобщают понятие математического ожидания и позволяют количественно описать распределение вероятностей. Начальный момент k-го порядка определяется как E[X^k], то есть среднее значение k-й степени случайной величины X. Центральный момент k-го порядка вычисляется как E[(X - μ)^k], где μ = E[X] — математическое ожидание. Так, первый начальный момент — это само среднее, второй центральный момент — дисперсия (σ^2 = E[(X - μ)^2]), третий центральный момент характеризует асимметрию (скошенность), а четвёртый — эксцесс (остроту пика). Для дискретных величин моменты вычисляются через сумму по значениям с весами-вероятностями, для непрерывных — через интеграл с плотностью. Основные свойства моментов: если случайная величина принимает только одно значение (достоверное событие), то все её центральные моменты равны нулю, а начальные — этому числу. Для невозможного события моменты не определены. Моменты линейно преобразуются: E[aX + b] = aE[X] + b, а дисперсия Var(aX + b) = a^2 Var(X). Пример: для равномерного распределения на отрезке [0,1] математическое ожидание равно 0.5, дисперсия — 1/12, а третий момент симметрии равен нулю. Для нормального распределения все нечётные центральные моменты равны нулю. Моменты широко применяются в статистике (оценка параметров, проверка гипотез), физике (расчёт центра масс, момента инерции), финансовой математике (анализ рисков). Они связаны с классическим и статистическим определениями вероятности: классическое даёт точные формулы для моментов в симметричных схемах, а статистическое позволяет оценивать моменты по выборке. Понимание моментов опирается на базовые понятия случайных событий, достоверных событий (моменты константы) и невозможных событий (моменты не определены).
