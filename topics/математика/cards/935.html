Среднеквадратичное отклонение — это статистическая мера разброса значений относительно среднего арифметического, показывающая, насколько в среднем каждое значение отклоняется от центра распределения.

основной текст
Среднеквадратичное отклонение (σ для генеральной совокупности и s для выборки) определяется как квадратный корень из дисперсии. Формула для генеральной совокупности: σ = √( Σ(xᵢ - μ)^2 / N ), где μ — Среднее арифметическое, N — объём совокупности. Для выборки: s = √( Σ(xᵢ - x̄)^2 / (n-1) ), где x̄ — выборочное среднее, n — объём выборки. Деление на n-1 (поправка Бесселя) даёт несмещённую оценку дисперсии генеральной совокупности. Свойства: среднеквадратичное отклонение всегда неотрицательно и измеряется в тех же единицах, что и исходные данные. Если σ = 0, все значения равны между собой. Чем больше σ, тем сильнее разброс. Пример: для набора {5, 5, 5} σ = 0; для {1, 3, 5} со средним 3 σ ≈ √((4+0+4)/3) ≈ 1.63. В отличие от размаха, оно учитывает все отклонения и менее чувствительно к выбросам. Применяется в науке, финансах и контроле качества для оценки стабильности процессов. Тесно связано с нормальным распределением: в интервале μ ± σ лежит около 68% данных, μ ± 2σ — 95%, μ ± 3σ — 99.7%. Связь с другими темами: для расчёта σ необходимы данные из вариационного ряда (упорядоченного набора значений) и среднее арифметическое. Различают расчёт для генеральной совокупности (все объекты) и для выборки (часть объектов, по которой судят о целом). Медиана, в отличие от среднего, не используется в формуле σ, но вместе с σ даёт полную картину распределения.
