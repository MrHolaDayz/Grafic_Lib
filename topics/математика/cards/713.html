основной текст
Приращение аргумента — фундаментальное понятие математического анализа, обозначающее изменение независимой переменной. Если функция y = f(x) определена в некоторой окрестности точки x0, то приращение аргумента Δx = x - x0, где x — новое значение аргумента. Соответственно, Приращение функции определяется как Δy = f(x0 + Δx) - f(x0). Основные формулы: Δx = x - x0; f(x) = f(x0 + Δx); при малых Δx приращение функции приближенно равно дифференциалу: Δy ≈ f'(x0)·Δx. Приращение аргумента обладает свойством аддитивности: если последовательно изменить аргумент на Δx1, а затем на Δx2, то полное приращение будет равно сумме Δx1 + Δx2. Пример: для функции f(x) = x^2 в точке x0 = 3 при Δx = 0.1 значение f(3.1) = 9.61, приращение функции Δy = 9.61 - 9 = 0.61. Важно, что приращение может быть как положительным, так и отрицательным, что соответствует движению вправо или влево по числовой оси. Понятие приращения аргумента является основой для определения производной: f'(x0) = lim(Δx→0) Δy/Δx. Оно широко применяется при построении касательной (Уравнение касательной: y = f(x0) + f'(x0)·(x - x0)), в численных методах (метод конечных разностей), в физике для описания мгновенной скорости и ускорения. Связанные темы: Главное значение аргумента (используется для однозначного определения угла в тригонометрических функциях), Определение производной (через предел отношения приращений), Приращение функции (взаимосвязано с приращением аргумента), Геометрический смысл производной (угловой коэффициент касательной), Уравнение касательной (линейное приближение функции).
