Однородные системы — это системы линейных уравнений, в которых все свободные члены равны нулю. Они всегда совместны, так как имеют тривиальное (нулевое) решение, и их исследование сводится к анализу ранга матрицы.

основной текст
Однородная система линейных уравнений имеет вид A·x = 0, где A — матрица размера m×n, x — столбец неизвестных. В развернутой форме: a_11·x_1 + a_12·x_2 + ... + a_1n·x_n = 0, ..., a_m1·x_1 + a_m2·x_2 + ... + a_mn·x_n = 0. Фундаментальная система решений (ФСР) состоит из n − r линейно независимых решений, где r = rank(A). Общее решение записывается как линейная комбинация этих решений: x = C_1·v_1 + C_2·v_2 + ... + C_{n−r}·v_{n−r}, где C_i — произвольные постоянные. Ключевое свойство: если x и y — решения однородной системы, то их линейная комбинация также является решением (принцип суперпозиции). Пример: система {x + 2y = 0, 3x + 6y = 0} имеет ранг 1, поэтому ФСР состоит из одного вектора, например, v = (−2, 1). Общее решение: (x, y) = C·(−2, 1). Если ранг матрицы равен числу неизвестных, система имеет только тривиальное решение x = 0. Однородные системы широко применяются в анализе линейных операторов, дифференциальных уравнениях и задачах на собственные значения. Связь с другими темами: решение неоднородной системы A·x = b находится как сумма частного решения и общего решения соответствующей однородной системы. Метод Крамера применим только к квадратным однородным системам с ненулевым определителем (дает нулевое решение), а в случае нулевого определителя используется Матричный метод или Метод Гаусса. Метод Гаусса-Жордана позволяет привести матрицу к ступенчатому виду и найти ФСР.
