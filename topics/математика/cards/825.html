Характеристическое уравнение — это алгебраическое уравнение, получаемое из линейного однородного дифференциального уравнения путем замены производных на степени некоторой переменной, и служащее для нахождения фундаментальной системы решений.

основной текст
Характеристическое уравнение строится для линейного однородного дифференциального уравнения с постоянными коэффициентами. Если дано уравнение вида a*y^(n) + b*y^(n-1) + ... + c*y' + d*y = 0, то замена y = e^(λx) приводит к алгебраическому уравнению: a*λ^n + b*λ^(n-1) + ... + c*λ + d = 0. Например, для уравнения y'' - 3y' + 2y = 0 характеристическое уравнение имеет вид λ^2 - 3λ + 2 = 0, корни которого λ1=1 и λ2=2. Основное свойство характеристического уравнения: каждому действительному корню λ соответствует Частное решение e^(λx), а комплексно-сопряженным корням α ± βi — решения e^(αx)*cos(βx) и e^(αx)*sin(βx). Кратным корням соответствуют решения, умноженные на степени x. Пример: для уравнения y'' + 4y = 0 получаем λ^2 + 4 = 0, корни λ = ±2i, поэтому Общее решение: y = C1*cos(2x) + C2*sin(2x). Характеристическое уравнение широко применяется при решении дифференциальных уравнений в механике, электротехнике и теории колебаний. Оно тесно связано с общим решением, которое строится как линейная комбинация частных решений, найденных по корням характеристического уравнения. Частное решение получается подстановкой конкретных начальных условий в Общее уравнение. Также характеристическое уравнение используется при анализе устойчивости систем, где его корни определяют характер переходных процессов.
