основной текст
Теорема Коши является обобщением теоремы Лагранжа о среднем значении. Формально, пусть функции f и g непрерывны на отрезке [a, b] и дифференцируемы на интервале (a, b), причем g'(x) ≠ 0 для всех x ∈ (a, b). Тогда существует точка c ∈ (a, b), для которой выполняется равенство: (f(b) − f(a)) / (g(b) − g(a)) = f'(c) / g'(c). Если g(x) = x, теорема сводится к классической теореме Лагранжа: f(b) − f(a) = f'(c)(b − a). Формула также может быть записана как [f(b) − f(a)] g'(c) = [g(b) − g(a)] f'(c). Основное свойство теоремы — она устанавливает связь между приращениями двух функций и их производными в одной внутренней точке. Пример: пусть f(x) = x^2, g(x) = x^3 на отрезке [0, 1]. Тогда f(1) − f(0) = 1, g(1) − g(0) = 1, f'(x) = 2x, g'(x) = 3x^2. Уравнение 1/1 = 2c / (3c^2) дает 1 = 2/(3c), откуда c = 2/3, что лежит в (0, 1). Другой пример: если g(x) = e^x, то теорема позволяет оценить отношение приращений экспоненты и другой функции. Теорема Коши используется для доказательства правила Лопиталя при вычислении пределов вида 0/0 или ∞/∞. Она также применяется в численных методах (например, для оценки погрешности интерполяции) и в теории приближений.
