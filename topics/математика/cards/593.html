Угол 0° — это угол, образованный двумя совпадающими лучами; его тригонометрические функции имеют строго определённые значения: синус равен 0, косинус равен 1, а тангенс равен 0.

основной текст
Определение и основные формулы. Для угла 0° тригонометрические функции вычисляются через единичную окружность: точка на окружности имеет координаты (1; 0). Отсюда: sin(0°) = 0, cos(0°) = 1, tg(0°) = sin(0°)/cos(0°) = 0/1 = 0. Котангенс ctg(0°) = 1/tg(0°) не определён, так как деление на ноль невозможно. Секанс sec(0°) = 1/cos(0°) = 1, косеканс csc(0°) = 1/sin(0°) не определён. Свойства и примеры. Угол 0° является граничным случаем для всех тригонометрических функций. Например, при решении уравнений sin x = 0 одним из корней будет x = 0° (или 0 радиан). В прямоугольном треугольнике угол 0° физически невозможен, но в пределе, когда один из острых углов стремится к нулю, противолежащий катет стремится к нулю, а прилежащий — к гипотенузе, что подтверждает значения sin 0° = 0 и cos 0° = 1. Также важно помнить, что tg(0°) = 0, что используется в анализе поведения функций вблизи нуля. Где применяется, связь с другими темами. Значения для угла 0° являются базовыми в тригонометрии и широко используются в физике (например, при разложении сил на оси, когда сила направлена вдоль оси X), в геометрии (для нахождения проекций векторов) и в математическом анализе (в разложениях в ряды). Связь с формулой Эйлера для тригонометрии: e^(i*0) = cos 0° + i sin 0° = 1, что даёт тождество e^0 = 1. В теме Собственные значения угол 0° соответствует нулевому повороту, при котором собственные векторы остаются неизменными.
