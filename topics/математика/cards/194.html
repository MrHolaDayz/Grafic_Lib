основной текст
Метод сложения (также известный как метод алгебраического сложения) применяется к системам линейных уравнений вида: a₁x + b₁y = c₁ a₂x + b₂y = c₂ Основная идея заключается в том, чтобы умножить одно или оба уравнения на такие числа, чтобы коэффициенты при одной из переменных стали противоположными (или равными). После этого уравнения почленно складываются (или вычитаются), в результате чего одна переменная исчезает. Получается уравнение с одной неизвестной, которое легко решается. Затем найденное значение подставляется в любое из исходных уравнений для нахождения второй переменной. Формально, если привести систему к виду, где a₁ = -a₂, то после сложения получим (b₁ + b₂)y = c₁ + c₂. Метод сложения особенно эффективен, когда коэффициенты при переменных являются целыми числами и легко подбираются множители. Например, для системы: 2x + 3y = 7 4x - 3y = 5 Складываем уравнения: (2x + 4x) + (3y - 3y) = 7 + 5, получаем 6x = 12, откуда x = 2. Подставляя x в первое уравнение: 2*2 + 3y = 7, находим y = 1. Решение системы: (2; 1). Важное свойство: метод сложения не изменяет множество решений системы, так как выполняется эквивалентное преобразование (сложение двух верных равенств дает верное равенство). Метод сложения широко применяется при решении систем двух и трех линейных уравнений в школьной алгебре, а также в задачах физики и экономики, где требуется найти точку пересечения прямых или плоскостей. Он является основой для более мощных методов: Метод Гаусса по сути обобщает идею сложения на системы с произвольным числом уравнений, а Метод Гаусса-Жордана доводит этот процесс до получения единичной матрицы. Для однородных систем (где все свободные члены равны нулю) метод сложения позволяет быстро проверить наличие нетривиальных решений.
