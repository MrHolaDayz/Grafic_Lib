основной текст
Квадратное уравнение — это алгебраическое уравнение второй степени, которое в общем виде записывается как ax^2 + bx + c = 0, где a, b, c — действительные числа (коэффициенты), причем a ≠ 0. Корни уравнения находятся с помощью дискриминанта D = b^2 - 4ac. Если D > 0, уравнение имеет два различных корня: x = (-b ± √D) / (2a). Если D = 0, корень один (два совпадающих): x = -b / (2a). Если D < 0, действительных корней нет. Квадратное уравнение обладает рядом свойств. Сумма корней (если они существуют) равна -b/a, а произведение — c/a (теорема Виета). Например, для уравнения x^2 - 5x + 6 = 0 корни равны 2 и 3, так как 2 + 3 = 5, а 2 * 3 = 6. Если a = 1, уравнение называют приведенным. Неполные квадратные уравнения (когда b = 0 или c = 0) решаются вынесением множителя или извлечением корня, например, x^2 - 4 = 0 дает x = ±2. Квадратные уравнения широко применяются в физике (расчет траекторий, равноускоренное движение), экономике (модели спроса и предложения), геометрии (нахождение сторон прямоугольников) и инженерии. Они являются основой для изучения квадратичных функций и их графиков — парабол. В алгебре квадратные уравнения тесно связаны с разложением многочленов на множители и решением более сложных уравнений, сводящихся к квадратным, например, биквадратных уравнений (ax^4 + bx^2 + c = 0).
