Уравнение плоскости — это алгебраическое соотношение, задающее множество точек в трёхмерном пространстве, которые лежат на одной плоскости. Оно является основным инструментом аналитической геометрии для описания взаимного расположения плоскостей и прямых.

основной текст
Уравнение плоскости в трёхмерном пространстве обычно задаётся в виде общего уравнения: Ax + By + Cz + D = 0, где (A, B, C) — координаты вектора нормали, перпендикулярного плоскости. Если известна точка M0(x0, y0, z0), через которую проходит плоскость, и вектор нормали n = (A, B, C), то уравнение можно записать как A(x - x0) + B(y - y0) + C(z - z0) = 0. Для плоскости, проходящей через три точки, используется уравнение вида определителя. Также существует нормальное уравнение, где коэффициенты нормированы, и уравнение в отрезках: x/a + y/b + z/c = 1. Основное свойство: любая плоскость однозначно определяется либо тремя неколлинеарными точками, либо точкой и нормальным вектором. Например, чтобы найти уравнение плоскости, проходящей через точки M1(1, 0, 0), M2(0, 2, 0), M3(0, 0, 3), можно вычислить векторное произведение (M1M2 x M1M3) и получить общее уравнение: 6x + 3y + 2z - 6 = 0. Расстояние от точки до плоскости вычисляется по формуле: |Ax0 + By0 + Cz0 + D| / √(A^2 + B^2 + C^2). Уравнение плоскости широко применяется в компьютерной графике, физике (например, для описания волновых фронтов), навигации и стереометрии. Оно тесно связано с другими темами аналитической геометрии: **Каноническое уравнение** прямой получается как пересечение двух плоскостей, а **Параметрическое уравнение** плоскости задаётся через две направляющие и точку. Хотя **Поворот на комплексной плоскости** относится к двумерному случаю, принципы линейных преобразований и вращений обобщаются на трёхмерное пространство с помощью матриц поворота, что также используется при переходе между различными видами уравнений плоскости.
