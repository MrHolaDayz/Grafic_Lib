Модуль числа (или абсолютная величина) — это расстояние от числа до нуля на числовой прямой, всегда являющееся неотрицательным числом.

основной текст
Модуль действительного числа a обозначается |a|. Для любого действительного числа a модуль определяется как: |a| = a, если a ≥ 0, и |a| = -a, если a < 0. Геометрически модуль показывает расстояние от точки, соответствующей числу a, до начала координат на числовой прямой. Например, |5| = 5, |-5| = 5, |0| = 0. Для квадратного корня справедливо тождество √(a^2) = |a|. Основные Свойства модуля: неотрицательность (|a| ≥ 0, причем |a| = 0 только при a = 0); мультипликативность (|a * b| = |a| * |b|); неравенство треугольника (|a + b| ≤ |a| + |b|). Пример: |3| = 3, |-7| = 7, |3 * (-7)| = |3| * |-7| = 21, |3 + (-7)| = |-4| = 4 ≤ 3 + 7 = 10. Модуль широко применяется при решении уравнений и неравенств с модулем, в анализе для оценки погрешностей, в геометрии для вычисления расстояний. Он тесно связан со свойствами модуля, которые обобщаются на Модуль комплексного числа — для комплексного числа z = a + bi модуль равен √(a^2 + b^2) и также обозначает расстояние от точки на комплексной плоскости до начала координат. Сопряженные числа (a - bi для a + bi) связаны с модулем тем, что |z|^2 = z * z̄, где z̄ — сопряженное число.
