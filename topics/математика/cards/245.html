основной текст
Неравенство с модулем — это неравенство вида |f(x)| < a, |f(x)| > a, |f(x)| ≤ a или |f(x)| ≥ a, где a — действительное число, а f(x) — алгебраическое выражение. Основные формулы решения: при a > 0 неравенство |f(x)| < a равносильно двойному неравенству -a < f(x) < a, а |f(x)| > a — совокупности f(x) < -a или f(x) > a. Если a ≤ 0, решения вырождаются: |f(x)| < a не имеет решений, |f(x)| > a верно для всех x из области определения. При раскрытии модуля с переменным основанием (например, |x - 2|) используют определение: |t| = t при t ≥ 0 и |t| = -t при t < 0, что приводит к решению систем или совокупностей. Свойства модуля: |x| ≥ 0, |x|^2 = x^2, |x·y| = |x|·|y|, |x/y| = |x|/|y| (y ≠ 0). Пример: решить |2x - 1| ≤ 3. По формуле: -3 ≤ 2x - 1 ≤ 3 → -2 ≤ 2x ≤ 4 → -1 ≤ x ≤ 2. Для |x + 2| > 1: x + 2 < -1 или x + 2 > 1 → x < -3 или x > -1. Важно помнить, что при возведении в квадрат обеих частей (если они неотрицательны) неравенство с модулем сводится к квадратному: |f(x)| < a равносильно f(x)^2 < a^2. Неравенства с модулем широко применяются в задачах на расстояния и интервалы (например, в теории приближений, при оценке погрешностей, в оптимизации). Они тесно связаны с линейными неравенствами (после раскрытия модуля) и квадратными неравенствами (при возведении в квадрат).
