Сигнум (от лат. signum — знак) — это математическая функция, которая возвращает знак действительного числа: 1 для положительных, -1 для отрицательных и 0 для нуля.

основной текст
Сигнум, обозначаемый как sgn(x) или sign(x), определяется кусочно: sgn(x) = 1 при x > 0, sgn(x) = -1 при x < 0, и sgn(x) = 0 при x = 0. Существуют также эквивалентные формулы: sgn(x) = x / |x| для x ≠ 0, и sgn(x) = |x| / x при x ≠ 0. Функцию можно выразить через предел: sgn(x) = lim_{n→∞} (2/π) * arctg(nx) для x ≠ 0. График сигнума состоит из двух горизонтальных лучей (y=1 и y=-1) и точки в начале координат, причем в нуле функция терпит разрыв первого рода (скачок). Свойства сигнума включают нечётность: sgn(-x) = -sgn(x), и идемпотентность по модулю: sgn(sgn(x)) = sgn(x). Для любого x справедливо x = sgn(x) * |x|. Функция не является непрерывной, но кусочно-постоянна. Пример: sgn(-5) = -1, sgn(0) = 0, sgn(3.14) = 1. При умножении на константу сигнум сохраняет знак: sgn(kx) = sgn(k) * sgn(x) для k ≠ 0. Сигнум широко применяется в теории управления (релейные системы), обработке сигналов и при анализе кусочно-заданных функций. Он тесно связан с функцией Хевисайда (единичной ступенькой) через соотношение sgn(x) = 2H(x) - 1 для x ≠ 0. В математическом анализе сигнум используется для упрощения записи модуля и производной |x|: d/dx |x| = sgn(x) для x ≠ 0. Среди связанных тем: Линейная функция может быть использована для аппроксимации сигнума (например, через сигмоиду), Квадратичная функция x^2 помогает вывести модуль (|x| = √(x^2)), а Степенная функция x^n при нечётных n ведёт себя подобно сигнуму (сохраняет знак).
