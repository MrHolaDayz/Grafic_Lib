основной текст
Арифметическая прогрессия — это числовая последовательность, в которой каждый следующий член получается прибавлением к предыдущему одного и того же числа d, называемого разностью прогрессии. Формула n-го члена имеет вид: a_n = a_1 + (n - 1) * d, где a_1 — первый член, d — разность, n — номер искомого члена. Если известен не первый, а k-й член, можно использовать обобщённую формулу: a_n = a_k + (n - k) * d. Эти выражения являются линейными функциями от n, что делает прогрессию удобной для анализа. Основное свойство арифметической прогрессии — каждый её член, начиная со второго, равен среднему арифметическому двух соседних: a_n = (a_{n-1} + a_{n+1}) / 2. Пример: дана прогрессия 3, 7, 11, 15,... (a_1 = 3, d = 4). Чтобы найти 10-й член, подставляем в формулу: a_10 = 3 + (10 - 1) * 4 = 3 + 36 = 39. Если нужно проверить, является ли число членом прогрессии, решают уравнение относительно n. Формула n-го члена широко применяется в финансовых расчётах (например, для вычисления равномерных платежей), в физике (равноускоренное движение) и в комбинаторике. Эта тема является базой для изучения суммы арифметической прогрессии и связана с более сложными концепциями: Формула Эйлера (e^{iθ} = cosθ + i*sinθ) используется при анализе колебательных процессов, которые иногда описываются арифметическими прогрессиями по времени; Формула Муавра (cosθ + i*sinθ)^n = cos(nθ) + i*sin(nθ) применяется в тригонометрии и комплексном анализе, где шаг изменения угла может образовывать прогрессию; Формула Эйлера для тригонометрии (e^{iθ} = cosθ + i*sinθ) связывает экспоненту с периодическими функциями, что позволяет моделировать прогрессии в циклических процессах.
