основной текст
Числа Стирлинга второго рода S(n,k) определяются для целых n >= 0 и k >= 0 как количество разбиений n-элементного множества ровно на k непустых блоков. По определению, S(n,0) = 0 при n > 0, S(0,0) = 1, и S(n,k) = 0 при k > n. Основная рекуррентная формула: S(n,k) = k * S(n-1,k) + S(n-1,k-1). Также существует явная формула через сумму: S(n,k) = (1/k!) * sum_{i=0}^{k} (-1)^{k-i} * C(k,i) * i^n, где C(k,i) — биномиальный коэффициент. Свойства: S(n,k) положительны для 1 <= k <= n. Имеют место частные значения: S(n,1) = 1, S(n,n) = 1, S(n,n-1) = C(n,2). Производящая функция: (e^x - 1)^k / k! = sum_{n=k}^{∞} S(n,k) * x^n / n!. Пример: разбить множество из 4 элементов {a,b,c,d} на 2 блока. S(4,2) = 7. Возможные разбиения: {a}{bcd}, {b}{acd}, {c}{abd}, {d}{abc}, {ab}{cd}, {ac}{bd}, {ad}{bc}. Числа Стирлинга второго рода широко применяются в комбинаторике (подсчет разбиений, сюръективных функций), в теории вероятностей (моменты распределений), в теории чисел (связь с числами Белла: B_n = sum_{k=0}^{n} S(n,k)). Они связаны с числами Стирлинга первого рода через взаимно обратные матрицы. В контексте комплексных чисел эти числа могут появляться в разложениях полиномов с комплексными коэффициентами, где используются такие понятия, как Сопряженные числа (для вещественных корней), Модуль комплексного числа (для оценки величины коэффициентов) и Аргумент комплексного числа (при анализе фазовых соотношений в производящих функциях).
