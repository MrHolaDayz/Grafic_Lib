Таблица интегралов — это сводка основных формул для нахождения первообразных наиболее часто встречающихся функций, позволяющая быстро вычислять неопределенные интегралы без повторения процесса интегрирования.

основной текст
Таблица интегралов содержит базовые формулы, полученные из таблицы производных. Основные из них: ∫ x^n dx = x^(n+1)/(n+1) + C (n ≠ -1), ∫ (1/x) dx = ln|x| + C, ∫ e^x dx = e^x + C, ∫ a^x dx = a^x / ln a + C, ∫ sin x dx = -cos x + C, ∫ cos x dx = sin x + C, ∫ (1/√(1-x^2)) dx = arcsin x + C, ∫ (1/(1+x^2)) dx = arctg x + C. Эти формулы являются прямым следствием определения первообразной: если F'(x) = f(x), то ∫ f(x) dx = F(x) + C. Ключевым свойством таблицы интегралов является её линейность: ∫ (af(x) + bg(x)) dx = a∫ f(x) dx + b∫ g(x) dx. Например, ∫ (3x^2 + 2/x) dx = 3∫ x^2 dx + 2∫ (1/x) dx = 3*(x^3/3) + 2*ln|x| + C = x^3 + 2 ln|x| + C. Таблица позволяет быстро интегрировать простые функции, а для сложных случаев часто используется сведение к табличным формулам с помощью замены переменной или интегрирования по частям. Таблица интегралов широко применяется в физике (вычисление работы, пути, электрических полей), экономике (нахождение функций издержек и дохода) и инженерных расчётах. Она тесно связана с понятием первообразной и её определением: каждая строка таблицы по сути является решением задачи нахождения функции по её производной. Основное свойство первообразной (различие на константу) объясняет появление постоянной C в каждой формуле. Связанные темы: Таблица значений (аналогичный справочник для производных), Первообразная (функция F, такая что F' = f), Определение первообразной (процесс обратный дифференцированию), Неопределенный интеграл (совокупность всех первообразных данной функции).
