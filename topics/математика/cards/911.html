Свойства математического ожидания — это набор правил, описывающих линейность и аддитивность среднего значения случайной величины, а также его поведение при преобразованиях.

основной текст
Математическое ожидание (среднее значение) случайной величины X определяется как E[X] = Σ x_i * p_i для дискретной величины, где p_i — вероятности, и E[X] = ∫ x * f(x) dx для непрерывной, где f(x) — плотность распределения. Основополагающее свойство — линейность: E[aX + b] = a*E[X] + b, где a и b — константы. Также для любых двух случайных величин X и Y выполняется E[X + Y] = E[X] + E[Y] (аддитивность). Если X и Y независимы, то E[XY] = E[X] * E[Y]. Ключевые свойства включают: 1) E[c] = c (математическое ожидание константы равно самой константе). 2) Если X ≥ 0, то E[X] ≥ 0 (неотрицательность). 3) Для произвольной функции g(X) математическое ожидание вычисляется как E[g(X)] = Σ g(x_i) * p_i (или интеграл). Пример: если X принимает значения 1 и 3 с вероятностями 0.5 и 0.5, то E[X] = 2, а E[2X + 1] = 2*2 + 1 = 5, что подтверждает линейность. Свойства сопряженных чисел и модуля здесь не применяются напрямую, но аналогия есть: подобно тому, как модуль сохраняет неравенства, математическое ожидание сохраняет порядок (если X ≤ Y, то E[X] ≤ E[Y]). Математическое ожидание широко используется в статистике, теории рисков, финансовой математике и машинном обучении. Оно служит основой для вычисления дисперсии (Var[X] = E[X^2] - (E[X])^2) и ковариации. Связь с другими темами: Свойства транспонирования (в матричной форме ожидание вектора — это вектор ожиданий), а Свойства определителя могут появляться при анализе ковариационных матриц. Свойства сопряженных чисел и модуля редко пересекаются с ожиданием, но в комплексных случайных величинах E[z] = E[x] + i*E[y], а модуль |E[z]| ≤ E[|z|] (неравенство Йенсена).
