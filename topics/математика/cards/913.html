Дисперсия — это мера разброса случайной величины относительно её математического ожидания, показывающая, насколько в среднем значения отклоняются от центра.

основной текст
Дисперсия случайной величины X определяется как математическое ожидание квадрата отклонения X от её математического ожидания: D(X) = M[(X - M(X))^2]. На практике часто используют формулу D(X) = M(X^2) - (M(X))^2, которая удобнее для вычислений. Для дискретной величины с конечным числом значений дисперсия равна сумме произведений квадратов отклонений на соответствующие вероятности. Основные свойства дисперсии включают: D(C) = 0 для постоянной C; D(CX) = C^2 * D(X) для константы C; D(X + Y) = D(X) + D(Y) для независимых случайных величин. Если величины зависимы, то D(X + Y) = D(X) + D(Y) + 2cov(X,Y), где cov — ковариация. Пример: для игральной кости с равномерным распределением M(X)=3.5, M(X^2)=15.167, тогда D(X)≈2.917. Дисперсия широко применяется в статистике для оценки точности измерений, в финансовой математике для измерения риска, в машинном обучении для анализа ошибок моделей. Она связана со стандартным отклонением σ = √D(X), которое имеет ту же размерность, что и исходная величина. Понимание свойств дисперсии необходимо при работе с корреляцией и регрессионным анализом. Среди связанных тем: Свойства сопряженных чисел (используются при работе с комплексными случайными величинами), Свойства модуля (модуль разности связан с отклонением), Свойства транспонирования (применимы к ковариационным матрицам). Эти понятия помогают обобщать дисперсию на многомерные случаи и комплексные пространства.
