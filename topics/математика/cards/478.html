Угол между прямой и плоскостью — это угол между прямой и её проекцией на эту плоскость, который всегда находится в пределах от 0° до 90°.
связанные темы

основной текст
Определение и основные формулы. Углом между прямой l и плоскостью α называется угол между этой прямой и её ортогональной проекцией l' на плоскость α. Если прямая параллельна плоскости, угол считается равным 0°; если перпендикулярна — 90°. Для вычисления угла φ используют направляющий вектор прямой s = (m, n, p) и нормальный вектор плоскости n = (A, B, C). Тогда sin φ = |s·n| / (|s|·|n|), где s·n = Am + Bn + Cp — скалярное произведение, |s| = √(m^2 + n^2 + p^2), |n| = √(A^2 + B^2 + C^2). Угол φ = arcsin(|s·n| / (|s|·|n|)). Свойства и примеры. Угол между прямой и плоскостью всегда не превосходит угла между этой прямой и любой другой прямой в плоскости. Пример: найти угол между прямой x/1 = (y-1)/2 = (z+3)/(-1) и плоскостью 2x - y + 2z + 5 = 0. Находим s = (1, 2, -1), n = (2, -1, 2). |s·n| = |1*2 + 2*(-1) + (-1)*2| = |2 - 2 - 2| = 2. |s| = √(1+4+1) = √6, |n| = √(4+1+4) = 3. sin φ = 2 / (3√6) = √6 / 9. φ = arcsin(√6/9). Где применяется, связь с другими темами. Используется в стереометрии для анализа взаимного расположения объектов, в инженерных расчётах (например, угол падения луча на поверхность), в компьютерной графике для освещения и теней.
