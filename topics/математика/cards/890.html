Алгебра событий — это система операций над событиями (объединение, пересечение, дополнение), которая позволяет моделировать сложные случайные эксперименты, используя основные законы теории множеств и вероятности.

основной текст
Алгебра событий строится на понятиях случайного, достоверного и невозможного событий. Основные операции: объединение (A ∪ B — событие, состоящее в наступлении хотя бы одного из A или B), пересечение (A ∩ B — наступление обоих событий одновременно) и дополнение (Ā — событие, противоположное A). Формулы вероятностей для этих операций: P(A ∪ B) = P(A) + P(B) - P(A ∩ B); для несовместных событий P(A ∪ B) = P(A) + P(B); для независимых событий P(A ∩ B) = P(A) * P(B). Свойства алгебры событий включают коммутативность, ассоциативность, дистрибутивность и законы де Моргана: (A ∪ B) = Ā ∩ B̄, (A ∩ B) = Ā ∪ B̄. Пример: при бросании игральной кости событие A = {выпадение четного числа}, B = {выпадение числа больше 3}. Тогда A ∪ B = {2,4,6} ∪ {4,5,6} = {2,4,5,6}, A ∩ B = {4,6}. Вероятность P(A ∪ B) = 4/6 = 2/3. Дополнение к A — событие Ā = {1,3,5}. Эти операции позволяют строить сложные события из простых, например, "хотя бы одно из двух событий" или "оба события произошли". Алгебра событий применяется в математической статистике, страховании, теории надежности и машинном обучении для формализации вероятностных моделей. Она тесно связана с классическим и статистическим определениями вероятности: классическое определение требует подсчета числа благоприятных исходов (что удобно делать через операции алгебры), а статистическое — использует частотную интерпретацию для оценки вероятностей событий. Случайные события являются элементами алгебры, достоверное событие — это объединение всех исходов (Ω), невозможное — пустое множество (∅). Понимание алгебры событий необходимо для перехода к более сложным разделам теории вероятностей, таким как условная вероятность и формула Байеса.
