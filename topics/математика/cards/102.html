основной текст
Одночлен (или моном) — это алгебраическое выражение, состоящее из произведения числового множителя (коэффициента) и одной или нескольких переменных, каждая из которых может быть возведена в неотрицательную целую степень. Стандартный вид одночлена: a * x₁^k₁ * x₂^k₂ * ... * xₙ^kₙ, где a — коэффициент (число), xᵢ — переменные, kᵢ — степени (показатели). Примеры: 3, -7a, 0.5x²y, √2 * a³b. Степенью одночлена называется сумма показателей степеней всех переменных: для 5x²y³ степень равна 2+3=5, для числа 3 степень равна 0. Основные свойства одночленов: их можно складывать (только подобные — с одинаковой буквенной частью), вычитать, умножать и делить (при делении степень может стать отрицательной, что выводит за рамки классических одночленов). При умножении одночленов коэффициенты перемножаются, а показатели степеней одинаковых переменных складываются: (2x²y) * (3xy³) = 6x³y⁴. При возведении одночлена в степень каждый множитель возводится в эту степень: (2x²y)³ = 8x⁶y³. Одночлены являются фундаментом для изучения многочленов (полиномов), которые представляют собой сумму одночленов. Степень многочлена определяется как наибольшая степень входящих в него одночленов. Понимание одночленов необходимо для операций сложения и умножения многочленов, а также для работы с Основной теоремой алгебры, которая утверждает, что любой многочлен степени n имеет ровно n комплексных корней (с учетом кратности). Таким образом, одночлены служат простейшими «кирпичиками», из которых строятся все полиномиальные выражения и решаются связанные с ними задачи.
