Задача Коши — это задача нахождения частного решения дифференциального уравнения, удовлетворяющего начальному условию (значению функции и её производных в одной точке). Она позволяет выделить единственную интегральную кривую из семейства общих решений.

основной текст
Задача Коши для обыкновенного дифференциального уравнения n-го порядка формулируется так: найти функцию y(x), удовлетворяющую уравнению F(x, y, y', ..., y^(n)) = 0 и начальным условиям: y(x_0) = y_0, y'(x_0) = y_1, ..., y^(n-1)(x_0) = y_(n-1). В простейшем случае уравнения первого порядка y' = f(x, y) задача сводится к решению y(x_0) = y_0. Основная теорема существования и единственности (теорема Коши-Пикара) гарантирует, что если функция f(x, y) непрерывна и удовлетворяет условию Липшица по y в окрестности точки (x_0, y_0), то существует единственное решение. Свойства задачи Коши: решение зависит непрерывно от начальных данных (при выполнении условий теоремы). Пример: для уравнения y' = y, Общее решение y = C*e^x. Задача Коши с условием y(0) = 2 даёт Частное решение y = 2e^x. Если начальное условие не задано, получаем семейство кривых. При нарушении условий теоремы (например, y' = √y, y(0)=0) задача может иметь несколько решений (например, y=0 и y=x^2/4). Задача Коши применяется в физике (законы движения Ньютона, радиоактивный распад), экономике (модели роста) и биологии (модели популяций). Она тесно связана с понятиями общего решения (содержит произвольные постоянные) и частного решения (получается подстановкой начальных условий). Неравенство Коши (неравенство Коши-Буняковского) используется при оценке норм решений в функциональном анализе, но не является прямым элементом задачи Коши — оно помогает доказывать единственность и устойчивость решений. Порядок уравнения определяет количество начальных условий, необходимых для однозначного решения.
