Пучок прямых — это множество всех прямых на плоскости, проходящих через одну общую точку (собственный пучок) или параллельных заданному направлению (несобственный пучок). Основная идея заключается в том, что любая прямая пучка может быть получена как линейная комбинация двух базовых прямых.

основной текст
Пучок прямых определяется как совокупность прямых, проходящих через фиксированную точку (центр пучка). Если даны две пересекающиеся прямые A1x + B1y + C1 = 0 и A2x + B2y + C2 = 0, то уравнение пучка с центром в их точке пересечения записывается как α(A1x + B1y + C1) + β(A2x + B2y + C2) = 0, где α и β — произвольные действительные числа, не равные нулю одновременно. Часто используют форму с одним параметром: A1x + B1y + C1 + λ(A2x + B2y + C2) = 0 (λ ∈ R), которая исключает вторую базовую прямую (случай λ → ∞ соответствует второй прямой). Для несобственного пучка (пучка параллельных прямых) уравнение имеет вид Ax + By + C = 0, где C — переменный параметр, а коэффициенты A и B фиксированы. Свойства пучка: любая прямая, проходящая через центр, принадлежит пучку; если центр пучка не лежит на одной из базовых прямых, то через любую точку плоскости, отличную от центра, проходит ровно одна прямая пучка. Пример: пусть даны прямые x + y - 1 = 0 и 2x - y + 3 = 0. Их точка пересечения находится решением системы: x + y = 1, 2x - y = -3 → 3x = -2 → x = -2/3, y = 5/3. Уравнение пучка: (x + y - 1) + λ(2x - y + 3) = 0. Подставляя λ = 1, получим прямую 3x + 2 = 0 (вертикальная прямая x = -2/3). Пучки прямых широко применяются в задачах на нахождение прямых, проходящих через заданную точку, и при решении систем уравнений с параметром.
