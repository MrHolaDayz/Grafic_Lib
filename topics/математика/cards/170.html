основной текст
Дискриминант (от лат. discriminare — «различать») — это ключевая характеристика многочлена, которая показывает, сколько у него действительных корней и какого они типа. Для квадратного уравнения ax^2 + bx + c = 0 (где a ≠ 0) дискриминант вычисляется по формуле D = b^2 - 4ac. Значение D определяет характер корней: если D > 0, уравнение имеет два различных действительных корня, которые находятся по формуле x = (-b ± √D) / (2a); если D = 0, то корень один (два совпадающих) x = -b / (2a); если D < 0, действительных корней нет, но есть два комплексно-сопряженных корня. Свойства дискриминанта тесно связаны с графиком квадратичной функции y = ax^2 + bx + c. При D > 0 парабола пересекает ось X в двух точках, при D = 0 касается её вершиной, а при D < 0 не пересекает ось X вовсе. Пример: для уравнения x^2 - 5x + 6 = 0 дискриминант D = (-5)^2 - 4*1*6 = 25 - 24 = 1 > 0, следовательно, корни x1 = (5 + 1)/2 = 3 и x2 = (5 - 1)/2 = 2. Помимо квадратных уравнений, дискриминант применяется в более сложных областях. В кубических уравнениях (вида ax^3 + bx^2 + cx + d = 0) также существует дискриминант, который позволяет различать случаи с одним или тремя действительными корнями. Для линейных уравнений (ax + b = 0) понятие дискриминанта не применяется, так как у них всегда ровно один корень. Дискриминант также тесно связан с теоремой Виета и обратной теоремой Виета: зная корни (найденные через дискриминант), можно восстановить исходное квадратное уравнение. Таким образом, дискриминант является фундаментальным инструментом для анализа квадратных уравнений и их обобщений на уравнения высших степеней.
