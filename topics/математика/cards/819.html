основной текст
Метод Лагранжа (метод вариации произвольных постоянных) применяется для нахождения частного решения линейного неоднородного дифференциального уравнения n-го порядка. Если известно Общее решение соответствующего однородного уравнения y_одн = C1*y1 + C2*y2 + ... + Cn*yn, то частное решение неоднородного уравнения ищется в виде y_ч = C1(x)*y1 + C2(x)*y2 + ... + Cn(x)*yn, где Ci(x) — неизвестные функции. Для их определения составляется система линейных алгебраических уравнений относительно производных Ci'(x): C1'*y1 + C2'*y2 + ... + Cn'*yn = 0, C1'*y1' + C2'*y2' + ... + Cn'*yn' = 0, ..., C1'*y1^(n-1) + C2'*y2^(n-1) + ... + Cn'*yn^(n-1) = f(x)/a0(x), где f(x) — правая часть уравнения, а a0(x) — коэффициент при старшей производной. Решая эту систему (например, методом Крамера), находят Ci'(x), затем интегрированием — сами Ci(x). Основное свойство метода — его универсальность: он работает для любых правых частей, в отличие от метода подбора, который применим только для специальных видов f(x). Пример: для уравнения y'' - y = e^x общее решение однородного y_одн = C1*e^x + C2*e^(-x). Частное решение ищем как y_ч = C1(x)*e^x + C2(x)*e^(-x). Составляем систему: C1'*e^x + C2'*e^(-x) = 0, C1'*e^x - C2'*e^(-x) = e^x. Решая, получаем C1' = 1/2, C2' = -e^(2x)/2, откуда C1 = x/2, C2 = -e^(2x)/4. Тогда y_ч = (x/2)*e^x - (1/4)*e^x = (2x-1)*e^x/4. Метод Лагранжа широко применяется в физике
