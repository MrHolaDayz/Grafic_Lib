основной текст
Деление комплексных чисел определяется как операция, обратная умножению. Если даны два комплексных числа z1 = a + bi и z2 = c + di (где z2 ≠ 0), то их частное вычисляется по формуле: (a + bi) / (c + di) = ((a + bi) * (c - di)) / (c^2 + d^2). Здесь (c - di) — комплексно-сопряженное число для знаменателя. В тригонометрической форме, если z1 = r1*(cos φ1 + i sin φ1) и z2 = r2*(cos φ2 + i sin φ2), то деление выполняется проще: z1 / z2 = (r1 / r2) * (cos(φ1 - φ2) + i sin(φ1 - φ2)). Основное свойство деления: модуль частного равен частному модулей (|z1 / z2| = |z1| / |z2|), а аргумент частного равен разности аргументов (arg(z1 / z2) = arg(z1) - arg(z2)). Пример: (3 + 2i) / (1 - i) = ((3 + 2i)*(1 + i)) / (1^2 + (-1)^2) = (3 + 3i + 2i + 2i^2) / 2 = (3 + 5i - 2) / 2 = (1 + 5i) / 2 = 0.5 + 2.5i. Деление широко применяется в электротехнике (расчет цепей переменного тока), теории сигналов и физике для нахождения импедансов и фазовых сдвигов. Оно тесно связано с Умножением (обратная операция), а также со Сложением и Вычитанием, так как все эти действия формируют основу арифметики комплексных чисел. Понимание деления необходимо для работы с формулой Муавра и возведением в степень, где деление позволяет находить корни n-й степени из комплексного числа.
