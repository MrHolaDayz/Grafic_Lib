основной текст
Область значений функции (обозначается E(f) или R(f)) — это множество всех действительных чисел y, которые функция может принять. Для нахождения области значений необходимо проанализировать, какие ограничения накладывает формула функции. Например, для квадратичной функции y = ax^2 + bx + c при a > 0 область значений — [y_min; +∞), а при a < 0 — (-∞; y_max], где y_min и y_max — координаты вершины параболы. Для линейной функции y = kx + b при k ≠ 0 область значений — вся числовая прямая R. Свойства области значений тесно связаны с монотонностью и непрерывностью функции. Если функция непрерывна на отрезке, то её область значений на этом отрезке — отрезок между наименьшим и наибольшим значениями. Пример: для степенной функции y = x^2 при x ∈ R область значений — [0; +∞), так как квадрат любого числа неотрицателен. Для обратной пропорциональности y = k/x (k ≠ 0) область значений — (-∞; 0) ∪ (0; +∞), так как функция не может равняться нулю. Понятие области значений применяется при решении уравнений и неравенств, в задачах на нахождение обратной функции (область значений исходной функции становится областью определения обратной), а также при исследовании графиков. Связанные темы: Линейная функция (область значений — R), Квадратичная функция (зависит от знака старшего коэффициента), Степенная функция (для чётных показателей — [0; +∞), для нечётных — R).
