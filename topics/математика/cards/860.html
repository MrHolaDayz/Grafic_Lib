основной текст
Правило произведения (или принцип умножения) является основой комбинаторики. Оно формулируется так: если объект A можно выбрать k способами, а после каждого такого выбора объект B — l способами, то число способов выбрать пару (A, B) в указанном порядке равно k * l. В общем виде для n последовательных выборов: N = a1 * a2 * ... * an. Это правило напрямую вытекает из определения декартова произведения множеств. Основное свойство правила — его применимость к независимым событиям. Пример: сколько трехзначных чисел можно составить из цифр 1, 2, 3, если цифры не повторяются? Для первой цифры — 3 варианта, для второй — 2, для третьей — 1. Итого: 3 * 2 * 1 = 6 чисел. Если цифры могут повторяться, то для каждой позиции — 3 варианта, и общее число чисел составит 3^3 = 27. В комбинаторике правило произведения лежит в основе формул для числа размещений и перестановок. Правило произведения широко применяется в теории вероятностей для подсчета числа исходов экспериментов, в дискретной математике для оценки мощности множеств, а также в алгоритмике (например, при анализе вложенных циклов). Связанные темы: Свойства векторного произведения — это операция в векторной алгебре, не имеющая прямого отношения к комбинаторике (хотя термин "произведение" общий). Степень произведения (a * b)^n = a^n * b^n — свойство степеней, которое также является мультипликативным правилом. Извлечение корня из произведения √(a * b) = √a * √b — свойство корней, демонстрирующее аналогичный принцип.
