Неравенство Бернулли — это фундаментальное неравенство, связывающее степень числа с линейной функцией: для любого действительного x ≥ -1 и натурального n выполняется (1+x)^n ≥ 1 + nx.

основной текст
Неравенство Бернулли утверждает, что для любого действительного числа x ≥ -1 и натурального показателя степени n ≥ 1 верно: (1 + x)^n ≥ 1 + nx. Равенство достигается только при n = 1 или x = 0. Часто используется обобщение: для x > -1 и любого вещественного r ≥ 1 или r ≤ 0 (с обратным знаком неравенства для 0 < r < 1). Основная формула: (1 + x)^n ≥ 1 + nx. Свойства неравенства следуют из выпуклости показательной функции. Пример: доказать, что 2^n ≥ n + 1 для n ≥ 1. Подставляя x = 1, получаем (1+1)^n = 2^n ≥ 1 + n·1 = n+1. Другой пример: оценить (0.9)^10. Здесь x = -0.1, n = 10: (0.9)^10 ≥ 1 - 1 = 0, что тривиально, но для x = -0.1 и n = 2: (0.9)^2 = 0.81 ≥ 1 - 0.2 = 0.8 — уже нетривиальная оценка. Неравенство Бернулли широко применяется для доказательства других неравенств, в численных оценках, при анализе сходимости рядов и в теории вероятностей (оценка вероятностей редких событий). Оно тесно связано с линейными неравенствами, так как правая часть — линейная функция по x. При решении показательных неравенств его используют для замены сложных выражений более простыми линейными. Метод интервалов и Квадратные неравенства могут комбинироваться с неравенством Бернулли при исследовании знака производных или разложений.
