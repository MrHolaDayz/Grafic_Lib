основной текст
Теорема Виета утверждает, что для квадратного уравнения вида x^2 + px + q = 0 (приведённая форма) сумма корней x1 + x2 = -p, а произведение корней x1 * x2 = q. Для полного квадратного уравнения ax^2 + bx + c = 0 сумма корней равна -b/a, а произведение — c/a. Для кубического уравнения x^3 + ax^2 + bx + c = 0 сумма корней равна -a, сумма попарных произведений равна b, а произведение всех трёх корней равно -c. Теорема работает для действительных и комплексных корней, при этом корни учитываются с их кратностью. Теорема особенно полезна для проверки правильности найденных корней и для составления уравнения по заданным корням. Например, если корни равны 2 и 5, то уравнение имеет вид x^2 - 7x + 10 = 0. Также она упрощает решение систем уравнений с симметричными многочленами. Важно помнить, что теорема применима только к многочленам, у которых старший коэффициент не равен нулю. Теорема Виета широко применяется в алгебре для разложения многочленов на множители, в теории чисел при решении диофантовых уравнений, а также в задачах с параметрами. Она тесно связана с квадратными и кубическими уравнениями, где позволяет находить корни без дискриминанта и проверять их. Теорема также является частным случаем Основной теоремы алгебры, которая утверждает, что любой многочлен n-й степени имеет ровно n корней с учётом кратности — именно эти корни и связываются коэффициентами по Виету.
