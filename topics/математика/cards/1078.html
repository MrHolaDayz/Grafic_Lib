Собственные значения — это числа, характеризующие матрицу, для которых существует ненулевой вектор, не меняющий своего направления при умножении на эту матрицу. Они играют ключевую роль в анализе линейных преобразований.
связанные темы

основной текст
Собственные значения и собственные векторы определяются из уравнения A * v = λ * v, где A — Квадратная матрица, v — ненулевой собственный вектор, λ — собственное значение. Для нахождения λ решается характеристическое уравнение: det(A - λ * I) = 0, где I — Единичная матрица. Это уравнение является полиномом степени n (где n — размер матрицы), его корни (возможно, комплексные) и есть собственные значения. Для каждого λ система (A - λ * I) * v = 0 дает соответствующий собственный вектор. Свойства: сумма собственных значений равна следу матрицы (сумме элементов на главной диагонали), произведение — ее определителю. Если матрица симметрична, все собственные значения действительны. Пример: для матрицы A = [[2, 0], [0, 3]] собственные значения равны 2 и 3 (диагональные элементы), а собственные векторы — (1, 0) и (0, 1). Если матрица вырождена (ее определитель равен нулю), то хотя бы одно собственное значение равно нулю. Собственные значения широко применяются в физике (например, для нахождения главных осей тензора инерции), в машинном обучении (метод главных компонент, PCA), в теории графов (спектральная кластеризация) и в дифференциальных уравнениях. Они тесно связаны с квадратной матрицей (только для них определены) и с единичной матрицей, используемой в характеристическом уравнении. Понимание собственных значений невозможно без знания определения матрицы и ее видов, так как разные типы матриц (например, симметричные) обладают особыми спектральными свойствами.
