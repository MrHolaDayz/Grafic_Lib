основной текст
Каноническое уравнение прямой в пространстве имеет вид (x - x0)/a = (y - y0)/b = (z - z0)/c, где (x0, y0, z0) — координаты точки, через которую проходит прямая, а (a, b, c) — координаты направляющего вектора, не равные нулю одновременно. Если один из знаменателей равен нулю, соответствующая координата считается фиксированной (например, при a=0 прямая параллельна плоскости yz). Для плоскости каноническое уравнение отсутствует, но существует общее уравнение Ax + By + Cz + D = 0. Основное свойство: прямая однозначно определяется точкой и направлением. Пример: прямая через точку (1, -2, 3) с направляющим вектором (2, 0, -1) имеет уравнение (x-1)/2 = (y+2)/0 = (z-3)/(-1), что означает y = -2 и (x-1)/2 = (3-z). Каноническое уравнение удобно для перехода к параметрическому виду: x = x0 + a*t, y = y0 + b*t, z = z0 + c*t. Применяется в стереометрии для описания прямых в пространстве, нахождения точек пересечения прямых и плоскостей, вычисления расстояний. Связано с векторным произведением (для нахождения направляющего вектора через две точки) и скалярным произведением (для проверки перпендикулярности). Также используется в аналитической геометрии и физике для моделирования траекторий. Связанные темы: параметрическое уравнение прямой, общее уравнение плоскости, направляющий вектор, точка на прямой.
