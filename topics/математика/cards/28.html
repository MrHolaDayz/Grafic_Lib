Пропорция — это равенство двух отношений, показывающее, что одна дробь равна другой дроби.
связанные темы

основной текст
Пропорцией называется равенство двух отношений: a : b = c : d (или a/b = c/d). Здесь a и d — крайние члены, b и c — средние члены. Основное свойство пропорции: произведение крайних членов равно произведению средних членов (a * d = b * c). Если в пропорции a : b = c : d известны три члена, четвёртый можно найти по правилу: неизвестный крайний член равен произведению средних, делённому на известный крайний; неизвестный средний — произведению крайних, делённому на известный средний. Пропорции обладают свойством перестановки: если a : b = c : d, то a : c = b : d и d : b = c : a. Пример: 2/3 = 8/12 — это пропорция, так как 2 * 12 = 3 * 8 = 24. Если нужно найти x в пропорции 5 : x = 2 : 6, то x = (5 * 6) / 2 = 15. Пропорции часто используются для решения задач на проценты, масштабы, смеси и сплавы, где требуется найти неизвестную величину при известном соотношении. Пропорции тесно связаны с темами обыкновенных и десятичных дробей, так как отношение — это по сути дробь. Смешанные числа могут входить в пропорции после преобразования в неправильные дроби. Умение сокращать дроби помогает упрощать отношения перед составлением пропорции. В арифметике пропорции — это мост между дробями и практическими расчётами, такими как деление числа в заданном отношении или нахождение части от целого.
