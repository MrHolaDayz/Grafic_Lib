Формула Тейлора позволяет представить произвольную гладкую функцию в виде суммы степенного многочлена (называемого многочленом Тейлора) и остаточного члена, который оценивает погрешность этого приближения в окрестности заданной точки.

основной текст
Формула Тейлора является фундаментальным инструментом математического анализа, обобщающим понятие дифференциала. Если функция f(x) дифференцируема n+1 раз в окрестности точки a, то её можно разложить следующим образом: f(x) = f(a) + f'(a)(x-a) + (f''(a)/2!)*(x-a)^2 + ... + (f^(n)(a)/n!)*(x-a)^n + R_n(x). Здесь R_n(x) — остаточный член, который может быть записан в форме Лагранжа: R_n(x) = (f^(n+1)(ξ)/(n+1)!)*(x-a)^(n+1), где ξ — некоторая точка между a и x. Частный случай при a=0 называется рядом Маклорена: f(x) = f(0) + f'(0)x + (f''(0)/2!)x^2 + ... + (f^(n)(0)/n!)x^n + ... . Основное свойство формулы Тейлора — возможность локально заменять сложные функции простыми многочленами с контролируемой точностью. Например, для функции e^x в окрестности нуля: e^x = 1 + x + x^2/2! + x^3/3! + ... + x^n/n! + ... . Для sin(x): sin(x) = x - x^3/3! + x^5/5! - x^7/7! + ... . Эти разложения позволяют вычислять значения функций с любой наперёд заданной точностью, используя только арифметические операции. Формула Тейлора широко применяется в численных методах, приближённых вычислениях, физике (например, для линеаризации уравнений движения) и теории приближений. Она тесно связана с другими важными формулами. В частности, **Формула Эйлера** e^(ix) = cos(x) + i sin(x) получается подстановкой ix в ряд Тейлора для экспоненты. **Формула Муавра** (cos(x) + i sin(x))^n = cos(nx) + i sin(nx) выводится из той же экспоненциальной записи. **Формула Эйлера для тригонометрии** даёт выражения синуса
