основной текст
Метод вариации произвольных постоянных (метод Лагранжа) применяется для решения линейных неоднородных дифференциальных уравнений. Для уравнения n-го порядка вида y^(n) + a_1(x)y^(n-1) + ... + a_n(x)y = f(x) сначала находят Общее решение однородного уравнения: y_од = C_1 y_1 + C_2 y_2 + ... + C_n y_n. Затем постоянные C_i заменяются на неизвестные функции C_i(x), и для их нахождения составляется система линейных алгебраических уравнений относительно производных C'_i(x). Эта система решается, например, методом Крамера, после чего функции C_i(x) находятся интегрированием. Основные формулы: если y_1 и y_2 — фундаментальная система решений для уравнения второго порядка y'' + p(x)y' + q(x)y = f(x), то частное решение ищется в виде y_ч = C_1(x)y_1 + C_2(x)y_2. Система для производных: C'_1 y_1 + C'_2 y_2 = 0, C'_1 y'_1 + C'_2 y'_2 = f(x). Решая её (например, с помощью определителя Вронского W = y_1 y'_2 - y_2 y'_1), получаем C'_1 = -y_2 f / W, C'_2 = y_1 f / W. После интегрирования находим C_1(x) и C_2(x). Метод универсален и применим к уравнениям любого порядка, а также к системам дифференциальных уравнений. Он тесно связан с методами решения систем линейных уравнений: для нахождения производных C'_i(x) используется Метод Крамера (через определители) или Матричный метод (через обратную матрицу Вронскиана). Также возможна связь с методом Гаусса, если система решается приведением к треугольному виду. В отличие от метода неопределенных коэффициентов, вариация постоянных работает для любой правой части f(x), включая нелинейные и разрывные функции. Метод вариации произвольных постоянных применяется в физике (вынужденные колебания), теории цепей, механике и других областях, где необходимо учесть внешнее воздействие. Он позволяет получить общее решение неод
