основной текст
Распределение простых чисел описывается несколькими фундаментальными формулами и теоремами. Основной результат — асимптотический закон распределения простых чисел: π(x) ~ x / ln x, где π(x) — количество простых чисел, не превосходящих x. Более точная оценка дается интегральным логарифмом: π(x) ≈ li(x) = ∫(2 до x) dt / ln t. Для больших x функция π(x) растет медленнее любой степени x, но быстрее любой логарифмической функции. Ключевые свойства включают бесконечность множества простых чисел (доказанная Евклидом) и теорему Дирихле о простых числах в арифметических прогрессиях. Пример: среди первых 100 чисел есть 25 простых, среди первых 1000 — 168. Гипотеза Римана связывает распределение простых с нулями дзета-функции Римана ζ(s) = ∑(n=1 до ∞) 1/n^s. Плотность простых чисел убывает логарифмически: среднее расстояние между соседними простыми около x равно ln x. Распределение простых чисел применяется в криптографии (RSA), теории кодирования и генерации случайных чисел. Связанные темы: Теорема о делении с остатком лежит в основе алгоритмов проверки простоты; Равенство комплексных чисел и Свойства сопряженных чисел используются при работе с дзета-функцией Римана, где аргумент s может быть комплексным. Связь с простыми числами также проявляется через мультипликативные функции и решето Эратосфена.
