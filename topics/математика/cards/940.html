Полигон частот — это графическое представление дискретного вариационного ряда в виде ломаной линии, соединяющей точки с координатами (x_i, n_i), где x_i — значение признака, а n_i — соответствующая частота.
связанные темы
Генеральная совокупность Выборка Вариационный ряд Среднее арифметическое Медиана
основной текст
Полигон частот строится на координатной плоскости: по оси абсцисс откладываются значения признака (варианты), по оси ординат — частоты (или относительные частоты). Точки (x_i, n_i) последовательно соединяются отрезками, образуя ломаную. Для построения полигона относительных частот по оси ординат откладывают w_i = n_i / n, где n — объем выборки. Если признак задан интервальным рядом, полигон частот строится по серединам интервалов. Основное свойство полигона частот — он наглядно демонстрирует форму распределения данных: симметрию, асимметрию, наличие моды (вершина полигона соответствует наибольшей частоте). Пример: для выборки 2, 2, 3, 4, 4, 4, 5 полигон будет иметь точки (2,2), (3,1), (4,3), (5,1). Чем больше объем выборки, тем ближе полигон частот к кривой распределения генеральной совокупности. Полигон частот применяется в описательной статистике для первичного анализа данных, сравнения распределений нескольких выборок, проверки гипотез о законе распределения. Он тесно связан с гистограммой (для интервальных рядов) и кумулятой (для накопленных частот). В отличие от гистограммы, полигон лучше подходит для дискретных данных и позволяет сравнивать распределения разного объема. При построении полигона частот важно учитывать связь с базовыми понятиями: Генеральная совокупность — это множество всех объектов исследования; Выборка — ее часть, по которой строится полигон; Вариационный ряд — упорядоченная последовательность значений, служащая основой для полигона. Среднее арифметическое и Медиана могут быть визуально оценены по положению полигона: медиана делит площадь под полигоном пополам, а среднее сдвигается в сторону более длинного «хвоста» распределения.
