Субфакториал числа n (обозначается !n) — это количество перестановок n элементов, в которых ни один элемент не остаётся на своём исходном месте (беспорядки).

основной текст
СубФакториал — комбинаторная функция, определяющая число перестановок без неподвижных точек (беспорядков). Основная формула: !n = n! * Σ_{k=0}^{n} ((-1)^k / k!). Также используется рекуррентное соотношение: !n = (n-1) * (!(n-1) + !(n-2)), с начальными значениями !0 = 1 и !1 = 0. Ещё один вид: !n = floor(n! / e + 1/2), где e — основание натурального логарифма. Свойства: субфакториал растёт медленнее факториала, но асимптотически !n ~ n! / e. Пример: для n=3 все Перестановки из 3 элементов: 123, 132, 213, 231, 312, 321. Из них беспорядками являются только 231 и 312, поэтому !3 = 2. Для n=4: !4 = 9. Применяется в задачах о рассылке писем в неверные конверты, в теории вероятностей при вычислении вероятности того, что случайная перестановка не имеет неподвижных точек. Связан с факториалом через округление n!/e, а также с правилом суммы и произведения при выводе рекуррентной формулы: выбор элемента для обмена и комбинирование двух случаев (обмен с фиксированным элементом или нет).
