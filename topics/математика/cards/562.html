основной текст
Нормалью к плоскости называется ненулевой Вектор n = (A, B, C), перпендикулярный каждому вектору, лежащему в этой плоскости. Если плоскость задана общим уравнением Ax + By + Cz + D = 0, то коэффициенты A, B, C являются координатами вектора нормали. Длина нормали вычисляется как |n| = √(A^2 + B^2 + C^2). Для нахождения нормали по трем точкам плоскости можно найти векторное произведение двух неколлинеарных векторов, лежащих в плоскости. Основные свойства: нормаль однозначно определяет направление плоскости (с точностью до знака), а угол между двумя плоскостями равен углу между их нормалями. Пример: для плоскости, проходящей через точки M(1,0,0), N(0,1,0), P(0,0,1), нормаль можно найти как векторное произведение MN = (-1,1,0) и MP = (-1,0,1), что дает n = (1,1,1). Уравнение такой плоскости: x + y + z - 1 = 0. Нормаль широко применяется в стереометрии для вычисления расстояния от точки до плоскости, в компьютерной графике для расчета освещения, а также в физике при описании отражения и преломления. Связанные темы: вектор и Координаты вектора используются для задания нормали, а Поворот на комплексной плоскости может быть связан с преобразованиями нормалей в двумерных задачах.
