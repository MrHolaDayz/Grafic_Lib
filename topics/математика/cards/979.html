основной текст
Объединение множеств A и B обозначается как A ∪ B. Формальное определение: A ∪ B = { x | x ∈ A или x ∈ B }. Основные формулы: если A ⊆ B, то A ∪ B = B; A ∪ ∅ = A; A ∪ A = A (идемпотентность). Мощность объединения для конечных множеств вычисляется по формуле: |A ∪ B| = |A| + |B| - |A ∩ B|. Свойства объединения: коммутативность (A ∪ B = B ∪ A), ассоциативность ((A ∪ B) ∪ C = A ∪ (B ∪ C)), дистрибутивность относительно пересечения (A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)). Пример: если A = {1, 2, 3}, B = {3, 4, 5}, то A ∪ B = {1, 2, 3, 4, 5}. Если множества не пересекаются (A ∩ B = ∅), то объединение называется дизъюнктным. Объединение широко применяется в теории вероятностей для вычисления вероятности суммы событий, в базах данных для операции UNION, в комбинаторике при подсчете вариантов. Эта операция тесно связана с Пересечением (A ∩ B) через законы де Моргана: Дополнение объединения равно пересечению дополнений. Также объединение используется вместе с Разностью (A \ B), симметрической разностью (A ∆ B = (A \ B) ∪ (B \ A)) и дополнением для построения сложных множеств. Пустое множество выступает нейтральным элементом для объединения.
