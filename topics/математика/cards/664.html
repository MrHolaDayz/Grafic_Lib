основной текст
Определение предела на языке ε-N (или определение предела последовательности по Коши) является строгой математической формулировкой интуитивного понятия «члены последовательности неограниченно приближаются к числу A». Формально: число A называется пределом последовательности {x_n} (обозначается lim_{n→∞} x_n = A), если ∀ ε > 0 ∃ N ∈ ℕ такое, что ∀ n > N выполняется неравенство |x_n - A| < ε. Здесь ε — произвольное положительное число (как угодно малое), а N — номер, начиная с которого все члены последовательности попадают в ε-окрестность точки A. Основные свойства: предел суммы, разности, произведения и частного последовательностей (при условии, что пределы существуют и знаменатель не равен нулю); единственность предела; ограниченность сходящейся последовательности. Пример: докажем, что lim_{n→∞} 1/n = 0. Для любого ε > 0 выберем N > 1/ε. Тогда для всех n > N имеем |1/n - 0| = 1/n < 1/N < ε, что удовлетворяет определению. Определение ε-N позволяет строго доказывать сходимость последовательностей и является фундаментом для дальнейшего изучения непрерывности, производных и интегралов. Оно применяется в анализе для обоснования пределов функций (через определение по Гейне или Коши), в теории рядов, при изучении равномерной сходимости функциональных последовательностей. Связь с другими темами: данное определение лежит в основе понятия предела функции, которое, в свою очередь, используется при дифференцировании и интегрировании. Например, производная определяется как предел разностного отношения. Связанные темы: Поворот на комплексной плоскости, Определение матрицы, Умножение матрицы на число. Хотя эти темы относятся к разным разделам математики, они объединены идеей преобразований и операций. В комплексном анализе предел последовательности комплексных чисел определяется аналогично, с заменой модуля на модуль комплексного числа, что важно для изучения поворотов на комплексной плоскости.
