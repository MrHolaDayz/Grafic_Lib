Ранг матрицы — это максимальное количество линейно независимых строк (или столбцов) матрицы, равное размерности её образа. Он показывает, сколько информации содержится в матрице без избыточности.

основной текст
Ранг матрицы A (обозначается rank(A) или r(A)) — это наивысший порядок ненулевого минора этой матрицы. Минором порядка k называется определитель квадратной подматрицы размера k×k, составленной из элементов на пересечении любых k строк и k столбцов. Если все миноры порядка k+1 равны нулю, а среди миноров порядка k есть ненулевой, то ранг равен k. Для матрицы размера m×n справедливо: 0 ≤ rank(A) ≤ min(m, n). Ранг нулевой матрицы равен 0, ранг единичной матрицы порядка n равен n. Свойства ранга: ранг не меняется при элементарных преобразованиях строк и столбцов (перестановка, умножение на ненулевое число, сложение строк). Ранг произведения матриц не превосходит ранга каждого сомножителя: rank(AB) ≤ min(rank(A), rank(B)). Пример: для матрицы [[1, 2], [3, 6]] вторая строка равна первой, умноженной на 3, поэтому миноры второго порядка равны нулю, а ненулевой минор первого порядка (например, элемент 1) существует, следовательно, ранг равен 1. Ранг матрицы применяется для анализа систем линейных уравнений: система Ax = b совместна тогда и только тогда, когда ранг основной матрицы равен рангу расширенной матрицы. Если ранг равен числу неизвестных, система имеет единственное решение; если меньше — бесконечно много. Ранг также используется в теории размерности линейных пространств, для нахождения базиса образа и ядра линейного оператора. Связанные темы: Определение матрицы (как таблицы чисел), Виды матриц (прямоугольные, квадратные, диагональные), Квадратная матрица (для которой ранг не может превышать её порядка). Понимание ранга опирается на знание единичной и нулевой матрицы как крайних примеров.
