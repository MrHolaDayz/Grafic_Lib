основной текст
Линейные однородные дифференциальные уравнения с постоянными коэффициентами имеют вид: a_n y^(n) + a_{n-1} y^(n-1) + ... + a_1 y' + a_0 y = 0, где a_i — постоянные числа. Основной метод решения заключается в составлении характеристического уравнения: a_n λ^n + a_{n-1} λ^(n-1) + ... + a_1 λ + a_0 = 0. Каждому действительному корню λ соответствует Частное решение вида e^(λx); кратному корню λ кратности m — решения e^(λx), x e^(λx), ..., x^(m-1) e^(λx). Для комплексных корней α ± βi (некратных) решения имеют вид e^(αx) cos(βx) и e^(αx) sin(βx); для кратных комплексных корней добавляются множители x, x^2 и т.д. Свойства: сумма решений и произведение решения на константу также являются решениями (принцип суперпозиции). Например, для уравнения y'' - 3y' + 2y = 0 характеристическое уравнение λ^2 - 3λ + 2 = 0 дает корни λ=1 и λ=2, поэтому Общее решение: y = C1 e^x + C2 e^(2x). Для уравнения y'' + 2y' + y = 0 получаем корень λ=-1 кратности 2, и решение: y = (C1 + C2 x) e^(-x). Для y'' + y = 0 корни λ = ±i, решение: y = C1 cos x + C2 sin x. Эти уравнения широко применяются в физике (описание колебаний, электрических цепей), механике (движение с демпфированием) и других науках. Они тесно связаны с однородными системами линейных дифференциальных уравнений, где вместо одного уравнения рассматривается система, а характеристический многочлен заменяется собственными значениями матрицы. Понятия общего решения и частного решения здесь фундаментальны: общее решение содержит все возможные решения, а частное получается заданием начальных условий. Также эти уравнения являются основой для изучения неоднород
