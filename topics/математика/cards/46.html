Признак делимости на 17 — это правило, позволяющее быстро определить, делится ли целое число на 17 без остатка, без выполнения непосредственного деления.

основной текст
Определение и основные формулы. Число делится на 17, если модуль разности между числом без последней цифры и произведением последней цифры на 5 делится на 17. Формально: пусть число N = 10a + b, где b — последняя цифра. Тогда N делится на 17 тогда и только тогда, когда |a — 5b| делится на 17. Например, для числа 289: a = 28, b = 9, вычисляем |28 — 5*9| = |28 — 45| = 17, что делится на 17, значит, 289 делится на 17 (17*17 = 289). Альтернативный признак: число делится на 17, если разность между числом без последней цифры и удвоенной последней цифрой делится на 17 (проверка: |28 — 2*9| = 10, не делится, поэтому этот вариант менее популярен, но также верен для некоторых случаев). Другой способ: можно использовать умножение на 12 (так как 17*12 = 204, и 1/17 ≈ 0.0588), но основной признак — через вычитание 5b. Свойства и примеры. Признак работает для любых целых чисел, включая отрицательные (берется модуль). Пример: проверим 357: a = 35, b = 7, |35 — 5*7| = |35 — 35| = 0, значит, 357 делится на 17 (17*21 = 357). Пример не деления: 100: a = 10, b = 0, |10 — 0| = 10, не делится на 17. Признак можно применять многократно: для больших чисел процесс повторяется, пока не получится число, кратное 17 или нет. Например, 4913: a = 491, b = 3, |491 — 15| = 476; затем для 476: a = 47, b = 6, |47 — 30| = 17, значит, 4913 делится на 17 (17^3 = 4913). Свойство: признак основан на том, что 10 ≡ -7 (mod 17), и 5 ≡ -12 (mod 17), что позволяет заменять умножение на 10 вычитанием 7b. Где применяется, связь с другими темами.
