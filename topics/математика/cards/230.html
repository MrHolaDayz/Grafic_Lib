основной текст
Экстремумы функции (от лат. extremum — «крайний») — это точки, в которых функция принимает наибольшее (максимум) или наименьшее (минимум) значение на некотором интервале. Формально: точка x0 называется точкой максимума, если для всех x из некоторой окрестности выполняется f(x) ≤ f(x0). Для минимума — f(x) ≥ f(x0). Для дифференцируемых функций необходимое условие экстремума: первая производная f'(x0) = 0. Достаточное условие: если f''(x0) < 0 — максимум, если f''(x0) > 0 — минимум. В случае, когда вторая производная равна нулю, используется анализ знаков первой производной. Экстремумы обладают свойством локальности — они могут не быть глобальными. Например, Квадратичная функция y = ax^2 + bx + c (при a ≠ 0) имеет единственный экстремум в вершине параболы: x0 = -b/(2a). Если a > 0 — это минимум, если a < 0 — максимум. Для линейной функции y = kx + b экстремумов нет, так как её производная постоянна и не обращается в ноль (кроме тривиального случая k = 0, когда функция постоянна и экстремумов также нет). Степенная функция y = x^n при чётном n имеет минимум в нуле, при нечётном — не имеет экстремумов. Поиск экстремумов применяется в оптимизации: нахождение максимальной прибыли, минимальных затрат, оптимальных размеров фигур. В анализе поведения функций экстремумы помогают построить график и определить промежутки монотонности. Связанные темы: Линейная функция (отсутствие экстремумов), Квадратичная функция (единственный экстремум в вершине), Степенная функция (экстремум зависит от чётности показателя).
