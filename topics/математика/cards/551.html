Компланарные векторы — это векторы, лежащие в одной плоскости или параллельные одной плоскости. Три вектора компланарны, если их смешанное произведение равно нулю.

основной текст
Определение и основные формулы. Компланарными называются векторы, которые лежат в одной плоскости или параллельны одной плоскости. Для трёх векторов a, b, c условие компланарности записывается как равенство нулю их смешанного произведения: (a × b) · c = 0. Если векторы заданы координатами a = (x1, y1, z1), b = (x2, y2, z2), c = (x3, y3, z3), то условие компланарности принимает вид: определитель |x1 y1 z1; x2 y2 z2; x3 y3 z3| = 0. Любые два вектора всегда компланарны, так как через них можно провести плоскость. Три вектора могут быть как компланарными, так и некомпланарными. Свойства и примеры. Основное свойство: если векторы компланарны, то один из них можно выразить через два других (если они не коллинеарны). Например, для компланарных векторов a, b, c существуют такие числа λ и μ, что c = λa + μb. Пример: векторы a = (1, 0, 0), b = (0, 1, 0), c = (2, 3, 0) компланарны, так как их смешанное произведение равно нулю (все z-координаты нулевые). Если же взять c = (0, 0, 1), то векторы станут некомпланарными. Где применяется, связь с другими темами. Понятие компланарности используется в стереометрии для анализа взаимного расположения векторов и точек в пространстве. Оно применяется при решении задач на нахождение объёмов (объём параллелепипеда, построенного на трёх векторах, равен модулю их смешанного произведения; если векторы компланарны, объём равен нулю). Компланарность связана с линейной зависимостью векторов: три вектора компланарны тогда и только тогда, когда они линейно зависимы. Связанные темы: смешанное произведение векторов, линейная зависимость векторов, базис в пространстве.
