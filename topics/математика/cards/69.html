основной текст
Сложение и Вычитание отрицательных чисел основаны на правилах работы с модулями. Если два числа имеют одинаковые знаки, то их сумма равна сумме модулей с тем же знаком: a + b = (|a| + |b|) * sign(a), где sign(a) — знак чисел. Если знаки разные, то из большего модуля вычитается меньший, а результат получает знак числа с большим модулем: a + b = (|a| - |b|) * sign(большего модуля). Вычитание отрицательного числа заменяется сложением с противоположным знаком: a - (-b) = a + b. Основные свойства: коммутативность (a + b = b + a), ассоциативность ((a + b) + c = a + (b + c)), а также свойство нуля (a + 0 = a). Примеры: (-5) + (-3) = -8; (-7) + 4 = -3; 6 - (-2) = 8. Важно помнить, что модуль числа всегда неотрицателен, и при сложении отрицательных чисел результат всегда меньше каждого из слагаемых. Эти операции широко применяются в алгебре, физике (например, для расчёта векторов сил), экономике (учёт долгов и доходов) и программировании. Они тесно связаны со свойствами модуля, который определяет расстояние от числа до нуля, а также с более сложными операциями, такими как Сложение многочленов и Сложение матриц, где правила знаков сохраняются. В теме «Сложение» и «Вычитание» как самостоятельных разделах эти правила являются фундаментом для работы с любыми числовыми множествами.
