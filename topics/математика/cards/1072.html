Обратная матрица — это такая матрица A^(-1), которая при умножении на исходную квадратную матрицу A даёт единичную матрицу: A * A^(-1) = A^(-1) * A = E. Существует только для невырожденных (с ненулевым определителем) квадратных матриц.

основной текст
Определение и основные формулы: Обратной матрицей для квадратной матрицы A n-го порядка называется матрица A^(-1), удовлетворяющая равенству A * A^(-1) = A^(-1) * A = E, где E — Единичная матрица того же порядка. Основная формула для нахождения: A^(-1) = (1/det(A)) * (C^T), где det(A) — определитель матрицы A (не равен нулю), а C^T — транспонированная матрица алгебраических дополнений (союзная матрица). Для матрицы 2x2 существует простой алгоритм: если A = [[a, b], [c, d]], то A^(-1) = (1/(ad - bc)) * [[d, -b], [-c, a]]. Свойства и примеры: Обратная матрица единственна для данной матрицы. Если матрица A имеет обратную A^(-1), то (A^(-1))^(-1) = A. Для произведения матриц (A * B)^(-1) = B^(-1) * A^(-1). Пример: для единичной матрицы E обратная ей есть E, так как E * E = E. Для нулевой матрицы обратной не существует, так как её определитель равен нулю. Если det(A) = 0, матрица называется вырожденной (сингулярной) и не имеет обратной. Где применяется, связь с другими темами: Обратная матрица широко используется для решения систем линейных уравнений (через X = A^(-1) * B), в криптографии (шифрование и дешифрование), в компьютерной графике (преобразования координат), в экономике (модели Леонтьева) и физике. Она тесно связана с понятием квадратной матрицы (только для них определена) и определителя (который проверяет существование). Понимание обратной матрицы опирается на знание определения матрицы и её видов, так как только Квадратная матрица может быть невырожденной.
