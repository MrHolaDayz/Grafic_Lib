основной текст
Экстремумы функции (от лат. extremum — крайний) — это точки, в которых функция достигает локального максимума или минимума. Формально: точка x0 называется точкой локального максимума (минимума) функции f(x), если существует такая окрестность этой точки, что для всех x из этой окрестности выполняется f(x) ≤ f(x0) (или f(x) ≥ f(x0) для минимума). Необходимое условие экстремума (Теорема Ферма): если в точке x0 функция f(x) дифференцируема и имеет экстремум, то f'(x0) = 0. Достаточные условия: если f'(x) меняет знак с плюса на минус при переходе через x0, то это точка максимума; с минуса на плюс — минимума. Для функций, заданных сложными выражениями, часто используют вторую производную: если f'(x0)=0 и f''(x0)<0 — максимум, если f''(x0)>0 — минимум. Свойства экстремумов: функция может иметь несколько локальных экстремумов, причем наибольший из них называется глобальным максимумом, а наименьший — глобальным минимумом. Пример: для функции f(x) = x^3 - 3x находим f'(x) = 3x^2 - 3 = 0 → x = ±1. Проверяем знаки: при x < -1 производная положительна, между -1 и 1 — отрицательна, после 1 — положительна. Значит, в x = -1 локальный максимум (f(-1)=2), в x = 1 — локальный минимум (f(1)=-2). Для тригонометрических функций, например f(x) = sin x, экстремумы находятся в точках, где cos x = 0, то есть x = π/2 + πk, причем максимумы в точках π/2 + 2πk, минимумы — в 3π/2 + 2πk. Экстремумы широко применяются в оптимизации: при нахождении максимальной прибыли, минимальных затрат, в физике — для определения точек равновесия.
