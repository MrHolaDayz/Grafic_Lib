Признак возрастания — это условие, позволяющее определить, на каких промежутках функция возрастает, с помощью знака её производной: если производная положительна на интервале, то функция на нём возрастает.

основной текст
Признак возрастания формулируется так: если функция f(x) дифференцируема на интервале (a, b) и для всех x из этого интервала выполняется f'(x) > 0, то f(x) строго возрастает на (a, b). Если f'(x) ≥ 0 (с возможным равенством нулю в отдельных точках), функция не убывает. Основное условие — сохранение знака производной. Например, для функции f(x) = x^3 производная f'(x) = 3x^2 ≥ 0, но она равна нулю в точке x = 0, однако функция возрастает на всей числовой прямой, так как равенство нулю производной в изолированной точке не нарушает монотонности. Свойства признака: он работает только для дифференцируемых функций и требует проверки знака производной на каждом интервале между критическими точками. Пример: для f(x) = x^2 - 4x + 5 производная f'(x) = 2x - 4. Решая неравенство 2x - 4 > 0, получаем x > 2 — функция возрастает на (2, +∞). На интервале (-∞, 2) производная отрицательна, функция убывает. Признак применяется для построения графиков, нахождения экстремумов и анализа поведения функций в задачах оптимизации. Где применяется: в математическом анализе для исследования функций, в физике для анализа скорости и ускорения, в экономике для определения точек роста. Признак возрастания тесно связан с теоремой Ферма, которая утверждает, что в точках экстремума производная равна нулю (если она существует). Первый признак экстремума использует смену знака производной с плюса на минус для максимума и с минуса на плюс для минимума, а Второй признак — знак второй производной.
