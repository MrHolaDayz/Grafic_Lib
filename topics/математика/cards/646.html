основной текст
Уравнение ctg x = a (где a — любое действительное число) относится к простейшим тригонометрическим уравнениям. Его общее решение записывается в виде: x = arcctg a + πn, n ∈ Z. Здесь arcctg a — это арккотангенс числа a, то есть угол из интервала (0; π), котангенс которого равен a. В отличие от арктангенса, арккотангенс принимает значения от 0 до π (не включая 0 и π). Также можно использовать формулу через арктангенс: arcctg a = π/2 — arctg a, что удобно для вычислений. Основное свойство: период котангенса равен π, поэтому к найденному частному решению добавляется πn. Частные случаи: если a = 0, то ctg x = 0 => x = π/2 + πn; если a = 1, то x = π/4 + πn; если a = -1, то x = 3π/4 + πn. Для a = √3 и a = 1/√3 получаются углы π/6 и π/3 соответственно (с учетом периода). Пример: решить ctg x = √3. arcctg √3 = π/6, значит x = π/6 + πn. Уравнение ctg x = a тесно связано с другими простейшими уравнениями: sin x = a, cos x = a, tg x = a. Все они решаются по аналогичным алгоритмам с использованием обратных тригонометрических функций. Понимание решения ctg x = a необходимо для решения более сложных тригонометрических уравнений, систем и неравенств, а также в задачах физики (например, колебания) и геометрии (нахождение углов). Связь с tg x = a прямая: ctg x = 1/tg x, поэтому при tg x ≠ 0 можно перейти к уравнению tg x = 1/a.
