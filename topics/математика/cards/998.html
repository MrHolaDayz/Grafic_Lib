Булеан (или множество всех подмножеств) данного множества A — это множество, элементами которого являются все возможные подмножества A, включая пустое множество и само A.
связанные темы
Объединение Пересечение Разность Симметрическая разность Дополнение
основной текст
Булеан множества A, обозначаемый как P(A) или 2^A, состоит из всех подмножеств A. Если |A| = n (количество элементов в A), то количество элементов в булеане равно 2^n. Формально: P(A) = { X | X ⊆ A }. Например, для A = {a, b} булеан: P(A) = { ∅, {a}, {b}, {a, b} }. Основные свойства булеана: пустое множество ∅ и само A всегда входят в P(A). Булеан замкнут относительно операций объединения, пересечения и разности: если X, Y ∈ P(A), то X ∪ Y ∈ P(A), X ∩ Y ∈ P(A), X \ Y ∈ P(A). Пример: для A = {1, 2, 3}, подмножество {1, 2} и {2, 3} дают Объединение {1, 2, 3} ∈ P(A), Пересечение {2} ∈ P(A), Разность {1} ∈ P(A). Булеан широко применяется в теории множеств, комбинаторике, логике и информатике (например, для построения булевых алгебр). Связанные темы: объединение, пересечение и разность позволяют задавать операции на булеане, превращая его в булеву алгебру. Дополнение подмножества (относительно A) также является элементом булеана, а Симметрическая разность задаёт кольцевую структуру. Таким образом, булеан служит универсальным пространством для изучения всех подмножеств данного множества.
