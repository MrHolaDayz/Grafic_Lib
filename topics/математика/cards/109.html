Теорема Безу утверждает, что остаток от деления многочлена P(x) на двучлен (x - a) равен значению этого многочлена при x = a, то есть P(a). Это фундаментальное свойство многочленов, позволяющее находить корни и разлагать их на множители.

основной текст
Теорема Безу формулируется так: пусть P(x) — многочлен степени n, а (x - a) — линейный двучлен. Тогда существует многочлен Q(x) степени n-1 такой, что P(x) = (x - a) * Q(x) + R, где R — число (остаток). Согласно теореме, R = P(a). Если P(a) = 0, то (x - a) является множителем P(x), а число a — корнем многочлена. Следствие из теоремы: многочлен степени n имеет не более n различных корней. Основные свойства: теорема позволяет быстро проверять, является ли число корнем многочлена, не выполняя деление уголком. Например, для P(x) = x^3 - 6x^2 + 11x - 6, проверим a = 2: P(2) = 8 - 24 + 22 - 6 = 0, значит, (x - 2) — множитель. Деление даст Q(x) = x^2 - 4x + 3, который затем раскладывается на (x - 1)(x - 3). Таким образом, корни: 1, 2, 3. Ещё пример: для P(x) = 2x^2 + 5x + 3, P(-1) = 2 - 5 + 3 = 0, значит (x + 1) — множитель, после деления получаем 2x + 3. Теорема Безу широко применяется в алгебре для разложения многочленов на множители, решения уравнений высших степеней и упрощения рациональных выражений. Она тесно связана со схемой Горнера, которая ускоряет вычисление P(a) и деление. Вместе с Основной теоремой алгебры (любой многочлен степени n имеет ровно n корней в комплексной плоскости) и теоремой Руше (о расположении корней) теорема Безу составляет основу теории многочленов.
