Степень числа — это краткая запись умножения числа самого на себя несколько раз; записывается как a^n, где a — основание, n — показатель степени.

основной текст
Степень числа определяется как произведение числа a (основания) на себя n раз (n — натуральный показатель): a^n = a * a * ... * a (n множителей). Основные формулы включают: a^1 = a, a^0 = 1 (при a ≠ 0), a^m * a^n = a^(m+n), a^m / a^n = a^(m-n) (при m > n и a ≠ 0), (a^m)^n = a^(m*n), (a*b)^n = a^n * b^n, (a/b)^n = a^n / b^n (при b ≠ 0). Корень n-й степени — это обратная операция: √[n]{a} = b, если b^n = a. Свойства степеней позволяют упрощать выражения и решать уравнения. Например, 2^3 = 8, 5^2 = 25, (3^2)^3 = 3^6 = 729. Степень с отрицательным показателем: a^(-n) = 1/(a^n) (при a ≠ 0). Степени широко применяются в науке (например, для записи больших чисел, как 10^9 — миллиард), в физике (законы Ньютона, экспоненциальный рост), в экономике (сложные проценты) и в информатике (двоичная система, 2^n). Степень числа тесно связана с порядком действий: в выражениях степень вычисляется первой (до умножения и деления). При работе с комплексными числами степень используется для определения сопряженных чисел (сопряженное число для z = a + bi — это z̄ = a - bi) и модуля комплексного числа: |z| = √(a^2 + b^2) = √(z * z̄). Аргумент комплексного числа также связан с возведением в степень (формула Муавра). Сложение, в свою очередь, не имеет прямых свойств со степенями (нет формулы для (a+b)^n, кроме бинома Ньютона). Таким образом, степень числа — фундаментальная операция, объединяющая арифметику, алгебру и комплексный анализ.
