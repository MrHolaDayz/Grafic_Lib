Биномиальные коэффициенты C(n,k) (число сочетаний из n по k) обладают рядом фундаментальных свойств, таких как симметрия, рекуррентное соотношение Паскаля и связь с биномом Ньютона, что делает их ключевым инструментом в комбинаторике и алгебре.

основной текст
Определение и основные формулы. Биномиальный коэффициент C(n,k) (или (n choose k)) определяется как количество способов выбрать k элементов из n без учёта порядка. Формула: C(n,k) = n! / (k! * (n-k)!). Согласно биному Ньютона, (a + b)^n = Σ_{k=0}^{n} C(n,k) * a^(n-k) * b^k. Важнейшие частные случаи: C(n,0) = C(n,n) = 1, C(n,1) = n. Свойства и примеры. Основные свойства включают: симметрию C(n,k) = C(n, n-k); рекуррентное соотношение Паскаля C(n,k) = C(n-1, k-1) + C(n-1, k); сумму биномиальных коэффициентов Σ_{k=0}^{n} C(n,k) = 2^n; а также тождество для сумм с чередованием знаков Σ_{k=0}^{n} (-1)^k * C(n,k) = 0. Пример: для n=5, C(5,2)=10, и по симметрии C(5,3)=10; по правилу Паскаля C(5,2)=C(4,1)+C(4,2)=4+6=10. Где применяется, связь с другими темами. Свойства биномиальных коэффициентов широко используются в теории вероятностей (формула Бернулли), комбинаторных задачах, разложении многочленов и в дискретной математике. Эти свойства тесно связаны с комбинаторными тождествами и треугольником Паскаля. Среди смежных тем можно выделить Свойства сопряженных чисел (например, при работе с комплексными корнями из единицы в суммах), Свойства модуля (при оценке величин сумм с биномиальными коэффициентами), Свойства транспонирования (в контексте матриц Паскаля, где симметрия коэффициентов соответствует транспонированию матрицы), а также Свойства операций и определителя (при вычислении определителей матриц, элементами которых являются биномиальные коэффициенты).
