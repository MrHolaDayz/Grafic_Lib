Показательная функция — это функция вида y = a^x, где a — положительное число, не равное единице, а x — переменная, являющаяся показателем степени.
связанные темы
Показательная форма Функция Эйлера Линейная функция Квадратичная функция Степенная функция
основной текст
Показательная функция задается формулой y = a^x, где a > 0 и a ≠ 1. Основное свойство: a^0 = 1, a^1 = a. Для a > 1 функция возрастает (например, 2^x), для 0 < a < 1 — убывает (например, (1/2)^x). График всегда проходит через точку (0; 1) и асимптотически приближается к оси Ox. Важное тождество: a^(x+y) = a^x * a^y, a^(x-y) = a^x / a^y, (a^x)^y = a^(x*y). Свойства: область определения — все действительные числа; область значений — положительные числа (y > 0). Пример: рост населения по закону N(t) = N0 * e^(kt) — показательная функция с основанием e. Другой пример: радиоактивный распад m(t) = m0 * 2^(-t/T). Функция не является ни четной, ни нечетной, не имеет экстремумов. Применяется в физике (радиоактивный распад, заряд конденсатора), биологии (рост популяций), экономике (сложные проценты). Связана с линейной функцией через логарифмирование: логарифм показательной функции дает линейную зависимость. Показательная форма используется для записи комплексных чисел: z = r * e^(iφ). Функция Эйлера φ(n) связана с мультипликативными свойствами степеней. Связанные темы: Показательная форма — представление чисел как a^b; Функция Эйлера φ(n) — количество чисел, взаимно простых с n, использует свойства степеней; Линейная функция y = kx + b — ее график является касательной к показательной функции в точке x=0 при a=e.
