Степень с действительным показателем обобщает понятие возведения в степень на случай, когда показатель — любое действительное число. Она определяется для положительного основания как a^p = e^(p * ln a), что позволяет вычислять степени с иррациональными показателями.

основной текст
Степень с действительным показателем a^p, где a > 0, а p — любое действительное число, определяется через экспоненциальную функцию и натуральный логарифм: a^p = e^(p * ln a). Для рациональных показателей вида p = m/n (n — натуральное, m — целое) это согласуется с определением корня: a^(m/n) = (n√a)^m. Для иррациональных показателей (например, 2^π) значение находится как предел последовательности степеней с рациональными показателями, приближающими данное число. Основные свойства сохраняются: a^p * a^q = a^(p+q), (a^p)^q = a^(pq), a^p / a^q = a^(p-q) и (ab)^p = a^p * b^p для положительных a и b. Примеры: 4^(1/2) = √4 = 2; 8^(2/3) = (3√8)^2 = 2^2 = 4; 2^π ≈ 2^(3.14159...) ≈ 8.82498. Свойства позволяют упрощать выражения: (x^√2)^√3 = x^(√6). Важно помнить, что для отрицательных оснований степень с действительным показателем обычно не определена в действительных числах (кроме случаев, когда показатель — целое или рациональное число с нечетным знаменателем). Это понятие широко применяется в математическом анализе, физике и экономике для описания процессов роста (например, сложные проценты, радиоактивный распад), где показатель может быть любым числом. Связь с другими темами: Возведение в степень является частным случаем для натуральных и целых показателей; Уравнение с угловым коэффициентом использует степенные функции для моделирования зависимостей; Теорема о делении с остатком помогает при работе с целыми показателями, но для действительных показателей её роль ограничена, так как деление заменяется вычитанием показателей.
