основной текст
Комплексное число z определяется как z = a + bi, где a называется действительной частью (Re(z) = a), b — мнимой частью (Im(z) = b), а i — Мнимая единица, для которой выполняется i^2 = -1. Если b = 0, число является действительным; если a = 0 — чисто мнимым. Два комплексных числа равны, когда равны их действительные и мнимые части: a + bi = c + di ⇔ a = c и b = d. Основные свойства: комплексные числа можно складывать, вычитать, умножать и делить (кроме деления на ноль) по правилам алгебры с учетом i^2 = -1. Например, (a + bi) + (c + di) = (a+c) + (b+d)i, а умножение: (a+bi)(c+di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i. Пример: (2 + 3i) + (1 - 4i) = 3 - i; (1 + i)^2 = 1 + 2i + i^2 = 2i. Комплексные числа широко применяются в электротехнике (анализ цепей переменного тока), квантовой механике, теории колебаний и волн, а также в математике для решения уравнений, не имеющих действительных корней (например, x^2 + 1 = 0). Они тесно связаны с темой Мнимая единица, которая является основой их построения. Степени мнимой единицы образуют цикл: i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1, и далее повторяются. Действительная часть и Мнимая часть позволяют геометрически представлять комплексные числа на плоскости (комплексная плоскость).
