Правило Крамера — это метод решения систем линейных уравнений с квадратной невырожденной матрицей, основанный на вычислении определителей, где каждое неизвестное находится как отношение определителя матрицы, полученной заменой соответствующего столбца на столбец свободных членов, к определителю основной матрицы.

основной текст
Правило Крамера применяется для решения системы n линейных уравнений с n неизвестными, записанной в матричной форме Ax = b, где A — квадратная матрица коэффициентов, x — столбец неизвестных, b — столбец свободных членов. Если определитель матрицы A не равен нулю (det(A) ≠ 0), то система имеет единственное решение. Каждое неизвестное x_i вычисляется по формуле: x_i = det(A_i) / det(A), где A_i — матрица, полученная из A заменой i-го столбца на столбец свободных членов b. Определитель det(A) обозначается как Δ, а det(A_i) — как Δ_i. Основное свойство правила Крамера — его наглядность и простота для систем небольшого размера (2×2 или 3×3). Например, для системы двух уравнений: a11*x1 + a12*x2 = b1, a21*x1 + a22*x2 = b2, решение записывается как x1 = (b1*a22 - b2*a12) / (a11*a22 - a12*a21), x2 = (a11*b2 - a21*b1) / (a11*a22 - a12*a21). Однако при росте числа уравнений метод становится громоздким из-за необходимости вычисления множества определителей. Правило Крамера применимо только к невырожденным квадратным системам; для вырожденных (det(A)=0) или прямоугольных систем используется Теорема Кронекера-Капелли. Метод применяется в теоретических исследованиях, при решении задач с параметрами, а также в вычислительной математике для малых систем. Правило Крамера тесно связано с методом обратной матрицы: решение x = A^(-1)*b фактически эквивалентно правилу Крамера. Для больших систем эффективнее использовать Метод Гаусса или Метод Гаусса-Жордана, которые менее трудоемки. В случае Однородных систем (b=0) правило Крамера дает тривиальное решение x=0 при det(A)≠0, а при det(A)=0 существуют ненулевые решения, что исследуется отдельно. Метод Краме
