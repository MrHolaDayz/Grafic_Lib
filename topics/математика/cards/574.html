основной текст
В стереометрии (трехмерном пространстве) прямую можно задать несколькими способами. Основные формы: параметрическое уравнение (x = x0 + a*t, y = y0 + b*t, z = z0 + c*t, где (x0, y0, z0) — точка на прямой, (a, b, c) — направляющий вектор, t — параметр) и каноническое уравнение ((x - x0)/a = (y - y0)/b = (z - z0)/c). Также используется уравнение прямой как пересечения двух плоскостей (система линейных уравнений). Для прямой на плоскости (раздел планиметрии) применяется уравнение y = kx + b (с угловым коэффициентом) или общее уравнение Ax + By + C = 0. Свойства прямой: через две различные точки проходит единственная прямая; прямая бесконечна в обе стороны; направляющий вектор определяет ее направление. Пример: найти уравнение прямой, проходящей через точки A(1, 2, 3) и B(4, 5, 6). Направляющий вектор = (3, 3, 3), каноническое уравнение: (x - 1)/3 = (y - 2)/3 = (z - 3)/3. Если направляющий вектор имеет нулевые компоненты (например, a = 0), то соответствующее уравнение принимает вид x = x0 (прямая параллельна плоскости YZ). Уравнение прямой широко применяется в компьютерной графике (построение линий, трассировка лучей), физике (описание траекторий движения), инженерных расчетах (проектирование). В математике оно связано с векторной алгеброй (скалярное и векторное произведения для нахождения расстояний и углов) и аналитической геометрией. В стереометрии прямая служит основой для изучения взаимного расположения фигур (прямая и плоскость, две прямые). В планиметрии уравнение прямой используется для решения задач на пересечение и параллельность.
