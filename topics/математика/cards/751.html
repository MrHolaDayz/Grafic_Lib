Наибольшее значение функции на отрезке — это максимальное значение, которое функция принимает на данном замкнутом интервале, достигаемое либо в критических точках (где производная равна нулю или не существует), либо на концах отрезка.

основной текст
Наибольшее значение функции y = f(x) на отрезке [a, b] — это такое число M, что для всех x из [a, b] выполняется f(x) ≤ M, и существует хотя бы одна точка x_0 ∈ [a, b], где f(x_0) = M. Для нахождения этого значения применяют алгоритм: находят производную f'(x), приравнивают её к нулю, отбирают критические точки, принадлежащие отрезку, вычисляют значения функции в этих точках и на концах отрезка f(a) и f(b), а затем выбирают наибольшее среди полученных чисел. Свойства: если функция непрерывна на отрезке, то по теореме Вейерштрасса она обязательно достигает на нём наибольшего и наименьшего значений. Если функция монотонна, то наибольшее значение находится на одном из концов. Пример: найти наибольшее значение f(x) = x^3 - 3x на отрезке [0, 2]. Производная f'(x) = 3x^2 - 3 = 0 даёт x = 1 (x = -1 не входит в отрезок). Вычисляем: f(0) = 0, f(1) = -2, f(2) = 8 - 6 = 2. Наибольшее значение равно 2 в точке x = 2. Наибольшее значение на отрезке применяется в оптимизационных задачах: нахождение максимальной прибыли, минимальных затрат, расчёт прочности конструкций. Связь с другими темами: методы нахождения экстремумов основаны на теореме Ферма (необходимое условие экстремума). В комплексном анализе понятие максимума модуля связано с Главным значением аргумента. При изучении Поворота на комплексной плоскости и Умножения матрицы на число также возникает задача отыскания наибольшего значения нормы или модуля, что сводится к аналогичному алгоритму.
