основной текст
Главное значение аргумента комплексного числа z = a + bi (где a и b — вещественные числа) обозначается как Arg(z) и является однозначно определённым углом φ из интервала (-π, π]. Аргумент связан с координатами точки на комплексной плоскости: a = |z|·cos φ, b = |z|·sin φ. Формула для вычисления: φ = arctg(b/a) с поправкой на квадрант. Если a > 0, то φ = arctg(b/a); если a < 0 и b ≥ 0, то φ = arctg(b/a) + π; если a < 0 и b < 0, то φ = arctg(b/a) - π; если a = 0 и b > 0, то φ = π/2; если a = 0 и b < 0, то φ = -π/2. Для нулевого числа (0 + 0i) аргумент не определён. Свойства главного значения аргумента: Arg(z1·z2) ≠ Arg(z1) + Arg(z2) в общем случае, так как сумма может выйти за пределы (-π, π]; для произведения верно равенство Arg(z1·z2) = Arg(z1) + Arg(z2) + 2πk, где k = -1, 0 или 1. Пример: для числа z = -1 + i (модуль √2) главное значение Arg(z) = 3π/4, так как точка лежит во втором квадранте. Обычный аргумент arg(z) — это многозначная функция: arg(z) = Arg(z) + 2πn, где n — любое целое число. Главное значение аргумента широко применяется при записи комплексного числа в тригонометрической форме: z = |z|(cos φ + i·sin φ) и в показательной форме: z = |z|·e^(iφ). Это необходимо при извлечении корней n-й степени из комплексного числа, при решении уравнений и в электротехнике (анализ цепей переменного тока).
