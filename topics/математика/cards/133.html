основной текст
Определение и основные формулы. Степень числа a > 0 с рациональным показателем r = p/q, где p — целое, q — натуральное (q > 1), определяется как a^(p/q) = (a^(1/q))^p = (a^p)^(1/q) = q√(a^p). Основное свойство: a^(m/n) = n√(a^m) при условии, что корень существует (для отрицательных a — только если n нечетное). Для a = 0 степень с положительным рациональным показателем равна 0, с отрицательным — не определена. Свойства и примеры. Все свойства степеней для натуральных и целых показателей сохраняются: a^(r+s) = a^r * a^s, (a^r)^s = a^(rs), (ab)^r = a^r * b^r. Примеры: 8^(2/3) = (8^(1/3))^2 = 2^2 = 4; 27^(-1/3) = 1 / (27^(1/3)) = 1/3; 16^(3/4) = (16^(1/4))^3 = 2^3 = 8. Важно помнить, что для отрицательных оснований дробные показатели с четным знаменателем в действительных числах не определены (например, (-4)^(1/2) не имеет смысла в R). Где применяется, связь с другими темами. Степень с рациональным показателем широко используется в алгебре и анализе для упрощения выражений с корнями, решения уравнений и дифференцирования. Она тесно связана с возведением в степень (обобщает натуральные и целые показатели) и с теоремой о делении с остатком (через представление дроби p/q в виде целой части и остатка). Также применяется при работе с уравнениями с угловым коэффициентом (например, для описания кривых вида y = x^(p/q)). В более продвинутых разделах эта тема служит мостом к степени с действительным показателем и показательной функции.
