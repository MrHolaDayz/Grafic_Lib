основной текст
Производная параметрической функции определяется для кривой, заданной параметрически: x = x(t), y = y(t), где t — параметр. Основная формула: dy/dx = (dy/dt) / (dx/dt) = y'(t) / x'(t), при условии, что x'(t) ≠ 0. Для второй производной используется формула: d²y/dx² = ( (dy'/dt) * x'(t) - y'(t) * x''(t) ) / (x'(t))^3, или проще: d²y/dx² = (d/dt (dy/dx)) / (dx/dt). Важно помнить, что все производные берутся по параметру t, а затем преобразуются к производной по x. Свойства параметрической производной включают возможность нахождения касательной и нормали к кривой в любой точке (если x'(t) ≠ 0). Пример: для окружности x = cos(t), y = sin(t) (0 ≤ t < 2π) производная dy/dx = -cos(t)/sin(t) = -ctg(t). В точке t = π/4 получаем dy/dx = -1, что соответствует касательной с углом -45°. Если x'(t) = 0 в некоторой точке, касательная может быть вертикальной, что требует отдельного анализа. Нули функции y(x) в параметрической форме соответствуют значениям t, при которых y(t) = 0, а область определения и область значений параметрической функции определяются через t и соответствующие x(t), y(t). Параметрическая производная широко применяется в физике (например, для нахождения скорости и ускорения точки, движущейся по траектории), в геометрии (исследование кривых, таких как циклоиды или астроиды) и в компьютерной графике.
