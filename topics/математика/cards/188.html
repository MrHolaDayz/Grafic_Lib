основной текст
Формула Кардано применяется к приведенному кубическому уравнению x^3 + px + q = 0. Согласно ней, один из корней выражается как x = ∛(-q/2 + √((q/2)^2 + (p/3)^3)) + ∛(-q/2 - √((q/2)^2 + (p/3)^3)). Дискриминант D = (q/2)^2 + (p/3)^3 определяет тип корней: при D > 0 — один действительный и два комплексных, при D = 0 — кратные корни, при D < 0 — три различных действительных корня (casus irreducibilis). Основное свойство формулы — она сводит решение кубического уравнения к извлечению квадратного и кубического корней. Например, для уравнения x^3 - 3x - 1 = 0 (p = -3, q = -1) получаем D = 1/4 - 1 = -3/4 < 0, что указывает на три действительных корня. В таких случаях корни можно выразить через тригонометрическую форму: x_k = 2√(-p/3) * cos((1/3) arccos(3q/(2p)√(-3/p)) - 2πk/3). Это демонстрирует связь с тригонометрией и формулой Муавра. Формула Кардано применяется в алгебре для анализа кубических уравнений, в теории чисел и при решении задач, сводящихся к кубическим уравнениям. Она тесно связана с квадратными уравнениями, так как содержит квадратный корень, и с формулой Муавра, которая позволяет выражать корни из комплексных чисел в тригонометрической форме. Кроме того, Формула Эйлера e^{iφ} = cos φ + i sin φ используется при переходе к тригонометрическому представлению корней в случае отрицательного дискриминанта. Связанные темы: Формула Эйлера применяется для записи комплексных корней в показательной форме. Формула Муавра (cos φ + i sin φ)^n = cos(nφ) + i sin(nφ) помогает извлекать кубические корни из комплексных чисел.
