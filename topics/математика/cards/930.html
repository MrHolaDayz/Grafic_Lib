основной текст
Среднее арифметическое (или просто среднее) — это ключевая характеристика выборки или генеральной совокупности. Для набора чисел x1, x2, ..., xn среднее арифметическое вычисляется по формуле: x̅ = (x1 + x2 + ... + xn) / n. Если данные представлены в виде вариационного ряда с частотами, используется взвешенное среднее: x̅ = (∑(xi * fi)) / ∑fi, где fi — частота значения xi. Основные свойства среднего арифметического: сумма отклонений всех значений от среднего равна нулю; оно чувствительно к выбросам (одно очень большое или очень маленькое значение может сильно исказить результат). Пример: для чисел 2, 4, 6 среднее равно (2+4+6)/3 = 4. Если добавить значение 100, среднее станет (2+4+6+100)/4 = 28, что уже не отражает типичные значения. Среднее арифметическое широко применяется в экономике (средняя зарплата), науке (средняя температура), образовании (средний балл). Оно тесно связано с другими статистическими характеристиками: медианой и модой. В отличие от медианы, которая делит Вариационный ряд пополам, среднее учитывает все значения. При анализе данных часто сравнивают среднее и медиану для оценки симметричности распределения. В контексте статистики среднее арифметическое может вычисляться как для генеральной совокупности (все объекты исследования), так и для выборки (часть совокупности). Вариационный ряд (упорядоченные данные) позволяет удобно находить не только среднее, но и медиану, и моду. Понимание среднего арифметического — основа для изучения более сложных статистических методов, таких как дисперсия и стандартное отклонение.
