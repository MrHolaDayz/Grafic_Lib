основной текст
Тригонометрическое уравнение — это уравнение вида f(x) = 0, где f(x) — выражение, содержащее тригонометрические функции от неизвестного x. Основные формулы для решения: sin x = a ⇒ x = (-1)^n arcsin a + πn, n ∈ Z; cos x = a ⇒ x = ± arccos a + 2πn, n ∈ Z; tg x = a ⇒ x = arctg a + πn, n ∈ Z; ctg x = a ⇒ x = arcctg a + πn, n ∈ Z. Здесь a — число, |a| ≤ 1 для sin и cos. Часто используются формулы приведения, суммы и разности углов, а также преобразование произведения в сумму. Свойства: тригонометрические уравнения могут иметь бесконечное множество решений из-за периодичности функций. Например, уравнение sin x = 0.5 имеет решения x = π/6 + 2πn и x = 5π/6 + 2πn. При решении часто применяют замену переменной (например, t = sin x), сводя уравнение к алгебраическому, такому как квадратное или кубическое. Важно учитывать область допустимых значений: tg x определён при x ≠ π/2 + πk, ctg x — при x ≠ πk. Применение тригонометрических уравнений широко: в физике (описание колебаний, волн), инженерии (расчёт цепей переменного тока), астрономии (движение небесных тел) и геометрии (нахождение углов в треугольниках). Связь с другими темами: решение квадратных уравнений (через замену sin^2 x = t), кубических уравнений (в задачах с тройными углами), линейных диофантовых уравнений (при нахождении целых решений в градусах). Методы решения включают также разложение на множители и использование Дискриминанта для проверки корней после замены.
