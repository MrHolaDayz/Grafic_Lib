основной текст
Сумма геометрической прогрессии определяется как сумма первых n членов последовательности b_1, b_2, ..., b_n, где b_k = b_1 * q^(k-1). Основная формула выводится через умножение суммы на q и вычитание: S_n = b_1 * (1 - q^n) / (1 - q) при q ≠ 1. Если q = 1, то все члены равны b_1, и сумма равна n * b_1. Для бесконечно убывающей прогрессии (|q| < 1) существует формула суммы всех членов: S = b_1 / (1 - q). Свойства суммы геометрической прогрессии: она линейна по b_1, а при |q| < 1 стремится к конечному пределу. Пример: для b_1 = 2, q = 3, n = 4: S_4 = 2 * (1 - 3^4) / (1 - 3) = 2 * (1 - 81) / (-2) = 80. Другой пример: b_1 = 1, q = 1/2, сумма бесконечной прогрессии равна 1 / (1 - 1/2) = 2. Геометрическая прогрессия применяется в финансовой математике (расчет сложных процентов, аннуитетов), в физике (радиоактивный распад), в теории вероятностей (геометрическое распределение). Связь с другими темами: Арифметическая прогрессия отличается тем, что каждый член получается сложением с разностью, а не умножением на знаменатель. Формула n-го члена арифметической прогрессии — a_n = a_1 + d*(n-1), а сумма — S_n = n*(a_1 + a_n)/2. В линейной алгебре понятие суммы подпространств и прямой суммы аналогично сложению множеств, но не имеет прямого отношения к числовым прогрессиям, хотя термин "сумма" используется в обоих контекстах.
