Извлечение корня из степени — это операция, обратная возведению в степень, позволяющая представить корень n-й степени из числа a в виде степени с дробным показателем: √[n]{a^m} = a^{m/n}. Это свойство объединяет действия с корнями и степенями, упрощая вычисления.

основной текст
Определение и основные формулы. Извлечение корня из степени основано на фундаментальном тождестве: √[n]{a^m} = a^{m/n}, где a ≥ 0 (если n четное, то a ≥ 0). Например, √(a^6) = a^3, так как √(a^6) = a^{6/2} = a^3. В общем случае для корня степени n: (√[n]{a})^m = √[n]{a^m} = a^{m/n}. Если m и n имеют общий делитель, показатель дроби можно сократить: √[4]{a^6} = a^{6/4} = a^{3/2} = √(a^3). Свойства и примеры. Основные свойства: 1) Корень из произведения: √[n]{a^m * b^k} = a^{m/n} * b^{k/n} (при соответствующих условиях). 2) Корень из частного: √[n]{a^m / b^k} = a^{m/n} / b^{k/n}. 3) Вложенные корни: √[m]{√[n]{a}} = a^{1/(mn)}. Пример: √[3]{√(x^6)} = √[3]{x^3} = x, или через степени: (x^6)^{1/2 * 1/3} = x^{6/6} = x. При извлечении корня из степени с четным показателем важно учитывать модуль: √(a^2) = |a|, так как корень из квадрата дает неотрицательное значение. Где применяется, связь с другими темами. Это свойство широко используется в алгебре при упрощении выражений, решении уравнений и работе с иррациональными числами. Оно тесно связано с понятием степени с рациональным показателем, что позволяет переходить от корней к степеням и обратно.
