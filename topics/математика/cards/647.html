основной текст
Общие Формулы решений — это универсальные выражения, которые дают все возможные значения переменной, удовлетворяющие данному тригонометрическому уравнению. Основные из них: для уравнения sin x = a (|a| ≤ 1) корни записываются как x = (-1)^k * arcsin a + πk, k ∈ Z; для cos x = a (|a| ≤ 1) — x = ± arccos a + 2πk, k ∈ Z; для tg x = a — x = arctg a + πk, k ∈ Z. В этих формулах arcsin a, arccos a, arctg a — главные значения обратных тригонометрических функций. Свойства общих формул: они охватывают все корни благодаря добавлению периода (πk или 2πk), где k — любое целое число. Например, для sin x = 0.5: x = (-1)^k * π/6 + πk. При k = 0 получаем π/6, при k = 1 — 5π/6, при k = 2 — 13π/6 и так далее. Важно помнить, что для уравнений вида sin x = 0 или cos x = 0 формулы упрощаются (x = πk или x = π/2 + πk соответственно). Если |a| > 1, уравнение не имеет решений. Общие формулы применяются при решении любых тригонометрических уравнений, сводящихся к простейшим, а также в задачах на нахождение корней на заданном отрезке. Они тесно связаны с темой «Простейшие уравнения sin x = a, cos x = a», являясь их обобщением. Понятие «Фундаментальная система решений» из теории дифференциальных уравнений имеет аналогию: общие формулы задают базис множества решений. «Формулы сокращенного умножения» помогают при преобразовании сложных тригонометрических выражений, а знание общих «Формул» (например, синуса суммы) необходимо для приведения уравнений к простейшему виду.
