основной текст
Область допустимых значений (ОДЗ) — это совокупность всех значений переменной, при которых данное алгебраическое выражение определено. Основные формулы и ограничения: для дробей знаменатель не должен равняться нулю (например, в выражении 1/(x-2) ОДЗ: x ≠ 2); для корней четной степени подкоренное выражение должно быть неотрицательным (√(x+3) → x+3 ≥ 0, то есть x ≥ -3); для логарифмов основание положительно и не равно 1, а аргумент строго положителен; для тангенса исключаются точки, где косинус равен нулю. Свойства ОДЗ: она может быть пустым множеством (если нет ни одного подходящего значения), конечным или бесконечным интервалом. Пример: для неравенства √(x-1) > 2 сначала находим ОДЗ: x-1 ≥ 0 → x ≥ 1. Затем решаем само неравенство, но только на этом множестве. Если в ходе решения мы получим, например, x < 0, то это значение не входит в ОДЗ, и ответом будет пустое множество. Важно: при возведении обеих частей неравенства в четную степень или при умножении на выражение с переменной ОДЗ может изменяться, поэтому её всегда проверяют отдельно. ОДЗ применяется при решении дробно-рациональных неравенств (где знаменатель может обращаться в ноль), иррациональных неравенств (с корнями), логарифмических и показательных неравенств. Связь с другими темами: в линейных неравенствах ОДЗ обычно вся числовая прямая (кроме случаев с дробями), в квадратных неравенствах важно учитывать знак дискриминанта, но ОДЗ также может сужаться знаменателем или корнем. Метод интервалов напрямую использует ОДЗ: сначала находят все точки, где выражение равно нулю или не определено, разбивают числовую ось на интервалы с учётом ОДЗ, а затем проверяют знаки на каждом интервале.
