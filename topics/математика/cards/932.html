Мода — это значение или значения, которые встречаются в наборе данных наиболее часто. Она является одной из мер центральной тенденции, наряду со средним арифметическим и медианой.
связанные темы
Генеральная совокупность Выборка Вариационный ряд Среднее арифметическое Медиана
основной текст
Мода (обозначается как Mo) — это значение признака, которое имеет наибольшую частоту в вариационном ряду. Для дискретного ряда мода определяется как варианта с максимальной частотой. Для интервального ряда моду находят по формуле: Mo = x0 + h * (f_mo - f_mo-1) / ((f_mo - f_mo-1) + (f_mo - f_mo+1)), где x0 — нижняя граница модального интервала, h — ширина интервала, f_mo — частота модального интервала, f_mo-1 — частота интервала перед модальным, f_mo+1 — частота интервала после модального. В отличие от среднего арифметического, мода устойчива к выбросам и может быть не единственной (мультимодальные распределения). Основное свойство моды — она показывает наиболее типичное значение в выборке. Пример: в ряду 2, 3, 3, 5, 7 мода равна 3. Если все значения встречаются одинаково часто, мода отсутствует. Мода часто используется в маркетинге (самый популярный размер одежды), в социологии (наиболее распространенный ответ в опросе) и в анализе данных для выявления предпочтений. Мода связана с медианой и средним арифметическим: в симметричных распределениях они совпадают, в асимметричных — различаются. Мода применяется для описания генеральной совокупности на основе выборки. Для ее нахождения данные сначала упорядочивают в Вариационный ряд — последовательность значений, расположенных по возрастанию. Если данных много, строят интервальный вариационный ряд, где модальный интервал определяется по наибольшей плотности распределения. В отличие от среднего арифметического, моду можно находить для качественных данных (например, цвет глаз). Связь с медианой: для унимодальных распределений существует эмпирическое правило: среднее - мода ≈ 3 * (среднее - Медиана).
