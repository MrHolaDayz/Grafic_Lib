основной текст
Уравнение с разделяющимися переменными — это тип обыкновенного дифференциального уравнения первого порядка, которое может быть представлено в форме, позволяющей разделить переменные. Основная идея заключается в том, чтобы переписать уравнение так, чтобы все функции, зависящие от x, оказались с одной стороны, а все функции, зависящие от y — с другой. Стандартная форма: dy/dx = f(x)g(y). После разделения получаем dy/g(y) = f(x)dx, что позволяет проинтегрировать обе части: ∫ dy/g(y) = ∫ f(x)dx + C, где C — произвольная постоянная. В случае записи через дифференциалы: M(x)N(y)dx + P(x)Q(y)dy = 0, разделение дает dx/P(x) = -Q(y)dy/(M(x)N(y)) после приведения к общему виду, но чаще используют форму dy/g(y) = f(x)dx. Свойства и примеры: Главное свойство — возможность явного разделения переменных без дополнительных преобразований. Пример: решить уравнение y' = 2xy. Здесь f(x) = 2x, g(y) = y. Разделяем: dy/y = 2x dx. Интегрируем: ln|y| = x^2 + C, откуда y = ±e^(x^2 + C) = C₁e^(x^2), где C₁ — произвольная постоянная. Другой пример: (1 + x^2)dy - ydx = 0. Приводим к виду dy/y = dx/(1 + x^2), интегрируем: ln|y| = arctg x + C, y = C₂e^(arctg x). Важно помнить, что при делении на g(y) могут быть потеряны решения, где g(y) = 0, поэтому их нужно проверять отдельно (например, y = 0 в первом примере). Где применяется, связь с другими темами: Уравнения с разделяющимися переменными широко используются в физике (законы охлаждения Ньютона, радиоактивный распад, рост популяций), химии (кинетика реакций) и экономике (модели роста). Они являются базовым типом дифференциальных уравнений, с которого начинается изучение методов решения. Связь
