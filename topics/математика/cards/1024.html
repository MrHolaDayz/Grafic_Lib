Модуль комплексного числа — это расстояние от точки, изображающей число на комплексной плоскости, до начала координат. Он обозначается |z| и вычисляется как квадратный корень из суммы квадратов действительной и мнимой частей.

основной текст
Модуль комплексного числа z = a + bi (где a и b — действительные числа, i — Мнимая единица) определяется по формуле |z| = √(a^2 + b^2). Это неотрицательное действительное число, которое геометрически соответствует длине радиус-вектора точки (a, b) на комплексной плоскости. Например, для числа z = 3 + 4i модуль равен √(3^2 + 4^2) = √(9 + 16) = 5. Для чисто мнимого числа z = bi модуль равен |b|, а для действительного числа z = a — абсолютному значению |a|. Модуль обладает важными свойствами: он мультипликативен (|z1 * z2| = |z1| * |z2|) и удовлетворяет неравенству треугольника (|z1 + z2| ≤ |z1| + |z2|). Модуль также связан с сопряженным числом: |z|^2 = z * z̅, где z̅ = a - bi. Пример: для z = 1 + i, |z| = √2, а произведение z * z̅ = (1+i)(1-i) = 2, что равно |z|^2. Понятие модуля широко применяется в анализе цепей переменного тока (для расчета импеданса), в теории сигналов (амплитуда колебаний) и в геометрии (расстояния между точками на плоскости). Оно неразрывно связано с Комплексным числом, его Действительной и Мнимой частью, а также с Мнимой единицей i, так как модуль позволяет перейти к тригонометрической форме записи. Степени мнимой единицы (i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1) также используются при вычислении модуля в алгебраических выражениях, хотя сам модуль не зависит от знака мнимой части.
