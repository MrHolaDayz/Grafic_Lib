Выпуклость вверх — свойство графика функции, при котором он лежит ниже любой своей касательной; для дважды дифференцируемой функции это эквивалентно неположительности второй производной.
связанные темы
Теорема Ферма Монотонность функции Признак возрастания Признак убывания Экстремумы функции
основной текст
Выпуклость вверх (или вогнутость) определяется следующим образом: функция f(x) называется выпуклой вверх на интервале (a, b), если для любых точек x1, x2 из этого интервала и любого t ∈ [0, 1] выполняется неравенство: f(tx1 + (1-t)x2) ≥ t f(x1) + (1-t) f(x2). Графически это означает, что хорда, соединяющая точки графика, лежит не выше самого графика. Для дважды дифференцируемой функции существует простой аналитический признак: f''(x) ≤ 0 на (a, b). Если f''(x) < 0, то выпуклость вверх строгая. Свойства: если функция выпукла вверх, то ее касательная в любой точке лежит выше графика (кроме точки касания). Примеры: f(x) = -x^2 (парабола ветвями вниз), f(x) = √x (на x>0), f(x) = ln x. Для проверки находим вторую производную: для ln x имеем f'(x)=1/x, f''(x) = -1/x^2 < 0 при x>0 — функция выпукла вверх. Выпуклость вверх сохраняется при линейных преобразованиях и при суммировании с сохранением знака коэффициентов. Данное понятие широко применяется при исследовании формы графика функции, в задачах оптимизации (выпуклые функции вверх имеют единственный максимум), в экономике для анализа функций полезности и издержек. Связь с другими темами: точки перегиба (смена выпуклости) находятся с помощью второй производной; знание выпуклости помогает при построении графиков вместе с монотонностью и экстремумами. Связанные темы: согласно Теореме Ферма, в точках локального экстремума (если производная существует) она равна нулю; Монотонность функции определяется знаком первой производной; Признак возрастания (f'(x) > 0) и Признак убывания (f'(x) < 0) позволяют найти интервалы монотонности. Вместе с выпуклостью вверх эти инструменты дают полное описание поведения функции.
