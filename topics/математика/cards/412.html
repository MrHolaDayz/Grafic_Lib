основной текст
Описанная окружность многоугольника — это окружность, которая проходит через все его вершины. Для треугольника описанная окружность существует всегда и единственна. Её центр (O) находится в точке пересечения серединных перпендикуляров к сторонам треугольника. Радиус описанной окружности (R) для треугольника можно вычислить по формуле: R = a / (2 sin A) = b / (2 sin B) = c / (2 sin C), где a, b, c — стороны, а A, B, C — противолежащие им углы. Также используется формула R = abc / (4S), где S — площадь треугольника. Для правильного многоугольника центр описанной окружности совпадает с его центром, а радиус равен расстоянию от центра до любой вершины. Одно из ключевых свойств: вписанный угол, опирающийся на дугу описанной окружности, равен половине центрального угла, опирающегося на ту же дугу. Для четырёхугольника описанная окружность существует только в том случае, если сумма его противоположных углов равна 180° (теорема Птолемея). Пример: для прямоугольного треугольника центр описанной окружности лежит на середине гипотенузы, а её радиус равен половине гипотенузы. Для равностороннего треугольника R = a / √3. Описанная окружность широко применяется в геодезии, астрономии и архитектуре для расчёта координат и построений. В математике она является основой для задач на вписанные углы, тригонометрию и доказательство теорем. Связь с другими темами: описанная окружность тесно связана с вписанной окружностью (в треугольнике), теоремой синусов и свойством серединных перпендикуляров. Понимание этой темы необходимо для изучения более сложных разделов планиметрии, таких как окружность Эйлера и задачи на комбинации окружностей.
