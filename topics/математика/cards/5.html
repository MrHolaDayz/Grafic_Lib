основной текст
Деление — это математическая операция, обратная умножению. Если a * b = c, то c : b = a и c : a = b. В выражении a : b = c число a называется делимым, b — делителем, c — частным. Основное свойство: деление можно проверить умножением (частное умножить на делитель — получить делимое). Деление на ноль невозможно, так как любое число, умноженное на ноль, даёт ноль, а не заданное делимое. Свойства деления: распределительное свойство относительно суммы и разности ((a + b) : c = a:c + b:c и (a - b) : c = a:c - b:c, если c ≠ 0). Деление связано с дробями: a : b = a/b. Примеры: 12 : 3 = 4 (так как 4 * 3 = 12); 0 : 5 = 0; 7 : 1 = 7. Если остаток от деления не равен нулю, говорят о делении с остатком. Деление применяется в повседневной жизни (раздел поровну, нахождение цены единицы товара), в науке (нахождение среднего значения, деление отрезков), в алгебре и геометрии. Оно тесно связано с понятием дроби, пропорции и процента. Без деления невозможно решение уравнений, где неизвестен множитель. Связанные темы: нет.
