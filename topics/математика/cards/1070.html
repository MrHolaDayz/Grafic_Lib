основной текст
Разложение по строке (также известное как разложение Лапласа) — это способ вычисления определителя квадратной матрицы. Основная формула: det(A) = Σ_{j=1}^{n} a_{ij} * A_{ij}, где a_{ij} — элемент матрицы A в i-й строке и j-м столбце, а A_{ij} — его алгебраическое дополнение. Алгебраическое дополнение вычисляется как A_{ij} = (-1)^{i+j} * M_{ij}, где M_{ij} — минор (определитель подматрицы, полученной удалением i-й строки и j-го столбца). Например, для матрицы 2x2 [[a, b], [c, d]] разложение по первой строке дает det = a*d - b*c. Свойства разложения по строке: оно позволяет свести вычисление определителя больших матриц к вычислению определителей меньшего размера, что удобно для рекурсивного решения. Выбор строки с наибольшим количеством нулей упрощает вычисления, так как слагаемые с нулевыми элементами обнуляются. Метод также лежит в основе доказательства свойств определителя, таких как мультипликативность и линейность по строкам. Пример: для матрицы 3x3 [[1, 0, 2], [3, 4, 5], [6, 7, 8]] разложение по второй строке (с элементом 0) сокращает объем вычислений. Разложение по строке применяется в линейной алгебре для нахождения обратной матрицы (через присоединенную матрицу), решения систем линейных уравнений (правило Крамера) и в анализе собственных значений. Связанные темы: Определение матрицы (матрица как прямоугольная таблица чисел), Виды матриц (включая квадратные, для которых применимо разложение), Квадратная матрица (основной объект для вычисления определителя). Также важно понимать, что разложение по строке работает только для квадратных матриц, а для неквадратных определитель не определен.
