Сумма событий — это логическая операция в теории вероятностей, соответствующая объединению двух или более событий, означающая наступление хотя бы одного из них.

основной текст
Суммой (или объединением) событий A и B называется событие A ∪ B, состоящее в наступлении хотя бы одного из этих событий. Вероятность суммы событий вычисляется по формуле: P(A ∪ B) = P(A) + P(B) - P(A ∩ B), где P(A ∩ B) — вероятность их совместного наступления (пересечения). Для несовместных событий (когда A ∩ B = ∅) формула упрощается до P(A ∪ B) = P(A) + P(B). В общем случае для n событий используется принцип включения-исключения: P(∪ A_i) = Σ P(A_i) - Σ P(A_i ∩ A_j) + Σ P(A_i ∩ A_j ∩ A_k) - ... + (-1)^{n+1} P(∩ A_i). Свойства суммы событий: операция коммутативна (A ∪ B = B ∪ A), ассоциативна (A ∪ (B ∪ C) = (A ∪ B) ∪ C) и идемпотентна (A ∪ A = A). Пример: бросание игрального кубика. Пусть A = {выпадение четного числа}, B = {выпадение числа больше 3}. Тогда A ∪ B = {2, 4, 6, 5, 4} = {2, 4, 5, 6}. Вероятность P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 3/6 + 3/6 - 2/6 = 4/6 = 2/3. Сумма событий широко применяется в статистике, теории надежности (вероятность отказа хотя бы одного элемента системы), страховании и анализе рисков. Она тесно связана с другими разделами математики: например, в линейной алгебре Сумма подпространств (U + W = {u + w | u ∈ U, w ∈ W}) аналогична объединению множеств, но с учетом линейных комбинаций. Прямая сумма (U ⊕ W) — частный случай, когда пересечение подпространств равно {0}.
