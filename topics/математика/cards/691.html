основной текст
Теорема о промежуточном значении (ТПЗ) — фундаментальное свойство непрерывных функций. Формально: пусть функция f непрерывна на отрезке [a, b] и f(a) = A, f(b) = B. Тогда для любого числа C, лежащего между A и B, существует такая точка c ∈ (a, b), что f(c) = C. Частный случай — если f(a) и f(b) имеют разные знаки (то есть f(a)·f(b) < 0), то найдется корень уравнения f(x) = 0 на (a, b). Теорема следует из свойства полноты действительных чисел и определения непрерывности по Коши. Свойства и примеры: ТПЗ гарантирует существование корня, но не указывает его точное значение. Пример: для f(x) = x^3 - 4x + 1 на отрезке [0, 1] f(0) = 1 > 0, f(1) = -2 < 0, значит, есть корень между 0 и 1. Теорема работает для любой непрерывной функции, включая многочлены, тригонометрические и показательные функции. Она не требует дифференцируемости. Обратное неверно: если функция имеет корень, она не обязательно меняет знак (например, f(x) = x^2 в точке 0). Где применяется: ТПЗ используется для доказательства существования решений уравнений, в численных методах (метод бисекции), в топологии (теорема Борсука — Улама). Связь с другими темами: ТПЗ является частным случаем более общей теоремы о промежуточном значении для связных множеств. Она лежит в основе доказательства Основной теоремы алгебры (любой многочлен степени n имеет n комплексных корней) при рассмотрении поведения многочлена на больших окружностях. Теорема Руше, используемая для подсчета корней аналитических функций, также опирается на идеи ТПЗ. В линейной алгебре Теорема о ранге не связана напрямую с ТПЗ, но обе теоремы важны в своих разделах.
