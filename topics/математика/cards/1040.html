основной текст
Корни из единицы n-й степени — это все комплексные числа z, удовлетворяющие уравнению z^n = 1. Используя формулу Муавра, их можно записать в виде: z_k = cos(2πk/n) + i·sin(2πk/n) = e^(2πik/n), где k = 0, 1, 2, ..., n-1. Главным корнем обычно называют ω = e^(2πi/n), тогда все остальные корни — это степени ω: 1, ω, ω^2, ..., ω^(n-1). Например, для n=4 корни: 1, i, -1, -i; для n=3: 1, (-1 + i√3)/2, (-1 - i√3)/2. Корни из единицы обладают важными свойствами: их сумма равна нулю (1 + ω + ω^2 + ... + ω^(n-1) = 0), произведение всех корней равно (-1)^(n-1). Они замкнуты относительно умножения: произведение любых двух корней также является корнем из единицы. Например, для n=3: ω * ω^2 = ω^3 = 1. На комплексной плоскости эти точки располагаются на единичной окружности, деля её на n равных дуг. Эти корни широко применяются в теории чисел, тригонометрии, обработке сигналов (дискретное преобразование Фурье) и при решении алгебраических уравнений. Они тесно связаны с Умножением и Делением комплексных чисел: умножение на корень из единицы соответствует повороту вектора на комплексной плоскости. Сложение и Вычитание корней из единицы используются, например, для нахождения сумм тригонометрических рядов. Возведение в степень корней из единицы даёт другие корни, что демонстрирует их циклическую природу и связь с арифметикой комплексных чисел.
