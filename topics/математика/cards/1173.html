основной текст
Теорема Эйлера является фундаментальным результатом теории чисел, обобщающим малую теорему Ферма. Формально: для любых взаимно простых целых чисел a и n (n > 0) выполняется сравнение a^φ(n) ≡ 1 (mod n), где φ(n) — количество чисел от 1 до n, взаимно простых с n. Например, для n = 10, φ(10) = 4 (числа 1, 3, 7, 9), и для a = 3: 3^4 = 81, а 81 mod 10 = 1. Основные свойства: функция Эльера мультипликативна для взаимно простых чисел; теорема справедлива только при условии gcd(a, n) = 1. Свойства и примеры: если a и n не взаимно просты, теорема не работает напрямую. Например, для n = 6, φ(6) = 2, и a = 2: 2^2 = 4, но 4 mod 6 = 4, а не 1 (так как gcd(2,6) = 2). Теорема широко применяется в криптографии (алгоритм RSA), где используется для шифрования и дешифрования сообщений, а также для вычисления обратных элементов по модулю. Где применяется: в криптографии, теории кодирования, проверке простоты чисел. Связь с другими темами: Теорема Эйлера тесно связана с формулой Эйлера e^(iπ) + 1 = 0 (комплексный анализ), Основной теоремой алгебры (каждый многочлен степени n имеет ровно n корней в комплексной плоскости), а также с Теоремой Руше (аналитическая теория чисел). В теории чисел она также является частным случаем более общих результатов, таких как теорема Лагранжа о группах.
