Базис — это упорядоченный набор линейно независимых векторов векторного пространства, через которые единственным образом можно выразить любой вектор этого пространства.

основной текст
Базисом векторного пространства V над полем F называется такая система векторов B = {e1, e2, ..., en}, которая удовлетворяет двум условиям: 1) векторы e1, ..., en линейно независимы; 2) любой вектор v из V можно представить в виде линейной комбинации v = a1*e1 + a2*e2 + ... + an*en, где коэффициенты a1, ..., an принадлежат полю F. Коэффициенты (a1, ..., an) называются координатами вектора v в базисе B. Если пространство n-мерно, то любой его базис содержит ровно n векторов; запись вектора в координатной форме: v = (a1, a2, ..., an). Разложение вектора по базису единственно: если v = ∑ a_i * e_i = ∑ b_i * e_i, то a_i = b_i для всех i. Основное свойство базиса — он задаёт систему координат в пространстве. Примеры: стандартный базис в R^3: e1 = (1,0,0), e2 = (0,1,0), e3 = (0,0,1). В пространстве многочленов степени не выше 2 базисом служит {1, x, x^2}. Любой набор из n линейно независимых векторов в n-мерном пространстве автоматически образует базис. Если система векторов содержит более n векторов, она линейно зависима; если менее n — не может порождать всё пространство. Базис лежит в основе всех вычислений в линейной алгебре: через него определяют матрицу линейного оператора, решают системы линейных уравнений, находят собственные векторы. При смене базиса координаты вектора преобразуются с помощью матрицы перехода. Понятие базиса неразрывно связано с Размерностью (количество векторов в базисе) и линейной зависимостью/независимостью (базис — максимальная линейно независимая система). Векторное пространство может иметь бесконечный базис (например, пространство всех многочленов), но в конечномерном случае размерность единственна.
