основной текст
Задачи на оптимизацию в математическом анализе сводятся к поиску экстремумов (максимумов и минимумов) функции. Основной инструмент — производная. Согласно теореме Ферма, если функция f(x) дифференцируема и имеет экстремум в точке x0, то f'(x0) = 0. Для нахождения глобального оптимума на отрезке [a, b] необходимо вычислить значения функции в критических точках (где f'(x) = 0 или не существует) и на концах отрезка, а затем выбрать наибольшее или наименьшее. Формула для проверки характера экстремума через вторую производную: если f'(x0) = 0 и f''(x0) > 0, то точка — локальный минимум; если f''(x0) < 0 — локальный максимум. Основные свойства: задача оптимизации всегда включает целевую функцию (которую нужно минимизировать или максимизировать) и, возможно, ограничения. Пример: найти прямоугольник наибольшей площади с фиксированным периметром P. Пусть стороны x и y, тогда 2x + 2y = P, площадь S = x * y. Выразив y = P/2 - x, получим S(x) = x * (P/2 - x) = (P/2)x - x^2. Производная S'(x) = P/2 - 2x, приравниваем к нулю: x = P/4, тогда y = P/4. Квадрат со стороной P/4 даёт максимальную площадь. Проверка второй производной S''(x) = -2 < 0 подтверждает максимум. Задачи на оптимизацию широко применяются в физике (траектории, минимальное время), экономике (максимизация прибыли, минимизация издержек), инженерии (оптимальная форма деталей) и биологии. Связь с другими темами: Поворот на комплексной плоскости может использоваться для оптимизации в задачах с вращением или фазами (например, минимизация расстояния до повёрнутой точки).
