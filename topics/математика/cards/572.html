Уравнение плоскости — это линейное уравнение, связывающее координаты любой точки, лежащей в данной плоскости, и позволяющее однозначно задать её положение в пространстве.

основной текст
Уравнение плоскости в трёхмерном пространстве (декартова система координат) обычно записывается в общем виде: Ax + By + Cz + D = 0, где A, B, C — координаты вектора нормали к плоскости (вектора, перпендикулярного ей), а D — свободный член. Если известна точка M0(x0, y0, z0), через которую проходит плоскость, и вектор нормали n = (A, B, C), то уравнение можно записать как A(x - x0) + B(y - y0) + C(z - z0) = 0. Частные случаи: если D = 0, плоскость проходит через начало координат; если один из коэффициентов A, B или C равен нулю, плоскость параллельна соответствующей оси. Основные свойства: расстояние от точки M1(x1, y1, z1) до плоскости вычисляется по формуле d = |Ax1 + By1 + Cz1 + D| / √(A^2 + B^2 + C^2). Для задания плоскости также используют уравнение в отрезках: x/a + y/b + z/c = 1, где a, b, c — точки пересечения плоскости с осями координат. Пример: составить уравнение плоскости, проходящей через точку (1, -2, 3) и перпендикулярной вектору (2, -1, 4). Решение: 2(x - 1) - 1(y + 2) + 4(z - 3) = 0 → 2x - y + 4z - 16 = 0. Уравнение плоскости широко применяется в аналитической геометрии для описания взаимного расположения точек, прямых и плоскостей (например, для нахождения угла между плоскостями или прямой и плоскостью). Оно является основой для решения задач в компьютерной графике (построение трёхмерных сцен, расчёт освещения), физике (моделирование поверхностей) и инженерных расчётах. Связанные темы включают уравнение прямой в пространстве (задаётся системой двух уравнений плоскостей) и методы нахождения расстояний и углов между геометрическими объектами.
