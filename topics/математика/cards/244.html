Иррациональные неравенства — это неравенства, в которых переменная содержится под знаком корня (радикала). Их решение требует особого внимания к области допустимых значений и часто сводится к возведению обеих частей в степень с последующим анализом знаков.

основной текст
Иррациональные неравенства — это неравенства вида √(f(x)) > g(x), √(f(x)) < g(x) или √(f(x)) ≥ √(h(x)), где f(x), g(x), h(x) — некоторые выражения. Основной метод решения заключается в возведении обеих частей неравенства в степень (чаще всего квадрат) с обязательным учетом области допустимых значений (ОДЗ). Например, для неравенства √(f(x)) < g(x) ОДЗ: f(x) ≥ 0, а также g(x) > 0, и после возведения в квадрат получаем f(x) < (g(x))^2. Для √(f(x)) > g(x) возможны два случая: если g(x) < 0, то неравенство выполняется для всех x из ОДЗ; если g(x) ≥ 0, то возводим в квадрат: f(x) > (g(x))^2. Важно помнить, что возведение в четную степень может привести к появлению посторонних корней, поэтому проверка на ОДЗ обязательна. Пример: решить √(x+1) > x - 5. ОДЗ: x+1 ≥ 0, то есть x ≥ -1. Рассматриваем два случая: 1) x - 5 < 0 (x < 5) — неравенство верно для всех x из ОДЗ, то есть x ∈ [-1; 5). 2) x - 5 ≥ 0 (x ≥ 5) — возводим в квадрат: x+1 > (x-5)^2 → x+1 > x^2 - 10x + 25 → 0 > x^2 - 11x + 24 → x^2 - 11x + 24 < 0. Корни квадратного трехчлена: x = 3 и x = 8. Решение: x ∈ (3; 8). С учетом x ≥ 5 получаем [5; 8). Объединяя оба случая: x ∈ [-1; 8). Иррациональные неравенства широко применяются в задачах на нахождение области определения функций, в геометрии (например, при вычислении расстояний) и в физике (законы движения).
