Знаки по четвертям — это правило, определяющее знак тригонометрических функций (синуса, Косинуса, тангенса и котангенса) в зависимости от того, в какой координатной четверти (от 0° до 360°) находится угол.
связанные темы
Разложение по строке Разложение по столбцу Разложение вектора по базису Синус Косинус
основной текст
Знаки тригонометрических функций по четвертям определяются положением угла на единичной окружности. В первой четверти (0° < α < 90°) все функции положительны: sin α > 0, cos α > 0, tg α > 0. Во второй четверти (90° < α < 180°) Синус положителен, а Косинус и тангенс отрицательны. В третьей четверти (180° < α < 270°) синус и косинус отрицательны, тангенс положителен. В четвертой четверти (270° < α < 360°) синус отрицателен, косинус положителен, тангенс отрицателен. Формулы приведения и основные тождества (sin^2 α + cos^2 α = 1) работают с учетом этих знаков. Свойство знаков по четвертям позволяет быстро определить знак результата без вычисления точного значения. Например, для угла 210° (третья четверть) sin 210° < 0, cos 210° < 0, но tg 210° > 0. На практике это используется при решении тригонометрических уравнений и неравенств, при нахождении значений функций для углов больше 90°, а также в задачах на упрощение выражений. Знание знаков необходимо для корректного применения формул приведения и для проверки полученных решений. Данное правило тесно связано с геометрической интерпретацией тригонометрических функций на единичной окружности. Оно применяется в физике (например, при анализе колебаний и волн), в инженерных расчетах и в компьютерной графике. Понимание знаков по четвертям является фундаментом для изучения более сложных тем, таких как Разложение по строке и Разложение по столбцу (например, при работе с матрицами поворота), а также Разложение вектора по базису, где координаты вектора выражаются через синус и косинус угла, и их знаки зависят от четверти.
