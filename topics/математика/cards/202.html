основной текст
Метод Гаусса (метод последовательного исключения неизвестных) заключается в преобразовании системы линейных уравнений к эквивалентной системе с треугольной (или ступенчатой) матрицей. Основная идея: с помощью элементарных операций (перестановка строк, умножение строки на ненулевое число, сложение строки с другой строкой, умноженной на коэффициент) обнуляются коэффициенты под главной диагональю. Формально, для системы Ax = b строится расширенная матрица (A|b), которая приводится к ступенчатому виду. Затем выполняется обратный ход — из последнего уравнения находится последняя переменная, после чего последовательно подставляются значения в вышестоящие уравнения. Например, для системы: 2x + y - z = 8 -3x - y + 2z = -11 -2x + y + 2z = -3 после прямого хода получается треугольная матрица, и из последнего уравнения находится z = 2, затем y = 3, x = 1. Основные свойства метода: он универсален (решает любые системы, если они совместны), позволяет определить совместность системы (если в процессе преобразований появляется строка вида 0 = c с c ≠ 0 — система несовместна), а также найти ранг матрицы. Метод Гаусса численно устойчив при использовании выбора главного элемента (перестановка строк для минимизации погрешностей округления). Пример: для системы с бесконечным множеством решений после приведения к ступенчатому виду часть переменных объявляется свободными, а базисные выражаются через них. Метод Гаусса применяется в вычислительной математике, физике, экономике (решение задач линейного программирования), инженерных расчетах и машинном обучении (например, при решении задач линейной регрессии). Он является основой для более сложных методов: LU-разложения, метода Крамера (для систем с квадратной невырожденной матрицей), метода обратной матрицы.
