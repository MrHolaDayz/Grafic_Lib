основной текст
Параметрическое уравнение в стереометрии используется для задания линий и поверхностей в пространстве через независимые переменные-параметры. Для прямой в пространстве параметрическое уравнение имеет вид: (x, y, z) = (x0, y0, z0) + t * (a, b, c), где (x0, y0, z0) — координаты точки на прямой, (a, b, c) — направляющий вектор, t — параметр (действительное число). Для плоскости используется два параметра: (x, y, z) = (x0, y0, z0) + u * (a1, b1, c1) + v * (a2, b2, c2), где направляющие векторы не коллинеарны. Основное свойство параметрических уравнений — они позволяют легко получать координаты любой точки объекта, подставляя значения параметров, и удобны для перехода к другим формам (например, канонической). Параметрическое уравнение обладает важным свойством: при изменении параметра непрерывно меняются координаты, что позволяет моделировать движение точки вдоль линии или поверхности. Пример: для прямой, проходящей через точку (1, 2, 3) с направляющим вектором (1, 0, -1), уравнение примет вид: x = 1 + t, y = 2, z = 3 - t. Подставляя t = 0, получаем исходную точку; при t = 1 — точку (2, 2, 2). Для кривых (например, винтовой линии) параметрические уравнения могут включать тригонометрические функции: x = R * cos(t), y = R * sin(t), z = h * t. Параметрические уравнения широко применяются в компьютерной графике (построение 3D-моделей), физике (траектории движения), а также в аналитической геометрии для перехода между различными формами записи. В стереометрии они служат основой для изучения взаимного расположения прямых и плоскостей, пересечений поверхностей. Связанные темы: каноническое уравнение прямой, общее уравнение плоскости, векторное произведение (для нахождения направляющих векторов плоскости).
