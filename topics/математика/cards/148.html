Извлечение корня из произведения — это свойство, согласно которому корень n-й степени из произведения равен произведению корней n-й степени из каждого множителя: n√(a * b) = n√a * n√b (при условии, что корни существуют).
связанные темы
Извлечение корня Корни из единицы Свойства векторного произведения Квадратный корень Кубический корень
основной текст
Определение и основные формулы. Извлечение корня из произведения базируется на свойстве: для неотрицательных чисел a и b (а в случае нечетной степени — для любых действительных чисел) справедливо равенство n√(a * b) = n√a * n√b. В частном случае для квадратного корня: √(a * b) = √a * √b, а для кубического: ³√(a * b) = ³√a * ³√b. Это свойство является следствием свойств степеней, так как n√a = a^(1/n), и (a*b)^(1/n) = a^(1/n) * b^(1/n). Свойства и примеры. Данное свойство позволяет упрощать вычисления, разбивая сложные подкоренные выражения на множители. Например, √(18) = √(9 * 2) = √9 * √2 = 3√2. Важно помнить, что свойство работает в обе стороны: как для извлечения корня из произведения, так и для обратного действия — перемножения корней с одинаковым показателем. Ограничение: для корней четной степени все подкоренные выражения должны быть неотрицательными, иначе равенство может нарушаться (например, √((-4)*(-9)) ≠ √(-4) * √(-9)). Где применяется, связь с другими темами. Это свойство активно используется при упрощении иррациональных выражений, решении уравнений и неравенств с корнями, а также в геометрии для вычисления длин и площадей. Оно тесно связано с общей темой Извлечение корня, так как является частным случаем основных операций с радикалами. Понимание этого свойства необходимо для работы с Корнями из единицы, где произведение корней дает другие корни. В отличие от Свойства векторного произведения, которое некоммутативно и имеет геометрический смысл, данное свойство корней является чисто алгебраическим и коммутативным.
