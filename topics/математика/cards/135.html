Свойства степеней — это набор правил, позволяющих упрощать выражения с возведением в степень, включая умножение, деление и возведение степени в степень. Они являются фундаментом для работы с многочленами, корнями и логарифмами.

основной текст
Свойства степеней описывают поведение выражений вида a^n, где a — основание, а n — показатель степени. Основные формулы включают: a^m * a^n = a^(m+n) (умножение степеней с одинаковым основанием); a^m / a^n = a^(m-n) (деление степеней); (a^m)^n = a^(m*n) (возведение степени в степень); (a*b)^n = a^n * b^n (степень произведения); (a/b)^n = a^n / b^n (степень частного). Также определены нулевая степень: a^0 = 1 (a ≠ 0), и отрицательная степень: a^(-n) = 1 / a^n. Корень связан со степенью: √[n]{a} = a^(1/n). Эти свойства позволяют упрощать сложные выражения. Например, x^3 * x^5 = x^8; (y^2)^4 = y^8; (2*z)^3 = 8*z^3. Важно помнить, что при сложении или вычитании степеней с одинаковым основанием (например, a^m + a^n) эти правила не работают; такие выражения упрощаются только вынесением общего множителя. Свойства степеней применяются в алгебре, тригонометрии, при работе с показательными функциями, логарифмами и в финансовых расчетах (сложные проценты). Связанные темы включают: Свойства сопряженных чисел (используют степени для избавления от иррациональности), Свойства модуля (модуль степени связан с четностью показателя), Свойства транспонирования (в матрицах степени транспонированной матрицы связаны с транспонированием степени).
