основной текст
Среднеквадратичное отклонение (СКО) определяется как квадратный корень из дисперсии. Для дискретной случайной величины формула имеет вид: σ = √(D(X)) = √(Σ(x_i - μ)^2 * p_i), где x_i — возможные значения, μ — математическое ожидание, p_i — их вероятности. Для выборки из n наблюдений используется формула: σ = √( (1/n) * Σ(x_i - x̅)^2 ), где x̅ — выборочное среднее. Часто применяют несмещённую оценку с делением на (n-1): s = √( (1/(n-1)) * Σ(x_i - x̅)^2 ). Основные свойства: СКО всегда неотрицательно; если σ = 0, то все значения равны между собой; при добавлении константы ко всем значениям СКО не меняется, а при умножении на константу k — умножается на |k|. Пример: для набора {1, 3, 5} среднее равно 3, отклонения: -2, 0, 2; их квадраты: 4, 0, 4; среднее квадратов = 8/3 ≈ 2.67; σ = √2.67 ≈ 1.63. В нормальном распределении около 68% значений лежат в интервале (μ - σ, μ + σ), 95% — в (μ - 2σ, μ + 2σ). СКО широко применяется в статистике, физике, финансах и инженерии для оценки рисков, точности измерений и анализа данных. В теории вероятностей оно тесно связано с дисперсией, центральной предельной теоремой и правилом трёх сигм. Связанные темы: математическое ожидание, дисперсия, нормальное распределение, закон больших чисел.
