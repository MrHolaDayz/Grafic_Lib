Метод замены переменной — это способ вычисления интегралов (неопределённых и определённых), при котором вводится новая переменная для упрощения подынтегрального выражения, что позволяет свести интеграл к табличному или более простому виду.

основной текст
Метод замены переменной (или метод подстановки) основан на правиле дифференцирования сложной функции. Для неопределённого интеграла формула имеет вид: ∫ f(g(x)) * g'(x) dx = ∫ f(u) du, где u = g(x). Для определённого интеграла требуется изменить пределы интегрирования: ∫_a^b f(g(x)) * g'(x) dx = ∫_{g(a)}^{g(b)} f(u) du. На практике выбирают подходящую замену u = φ(x), выражают dx через du (dx = du / φ'(x)), после чего интегрируют по новой переменной. Основное свойство метода — обратимость: после нахождения первообразной необходимо вернуться к исходной переменной, подставив обратно x = ψ(u). Пример: вычислить ∫ 2x * √(x^2+1) dx. Замена: u = x^2+1, тогда du = 2x dx, получаем ∫ √u du = (2/3) * u^(3/2) + C = (2/3) * (x^2+1)^(3/2) + C. Для определённого интеграла, например ∫_0^1 2x / (x^2+1) dx, замена u = x^2+1 даёт пределы от 1 до 2, и интеграл превращается в ∫_1^2 du / u = ln2. Метод замены переменной широко применяется в математическом анализе для интегрирования сложных функций, решения дифференциальных уравнений и в теории вероятностей при замене распределений. Он тесно связан с интегрированием по частям и другими методами. В отличие от методов линейной алгебры (Метод Крамера, Матричный метод, Метод Гаусса), которые используются для решения систем линейных уравнений, метод замены переменной работает исключительно с интегралами и производными. Например, Метод Крамера и Метод Гаусса оперируют матрицами и определителями, а замены переменной — с функциями и их дифференциалами. Однако в некоторых задачах, требующих интегрирования после решения системы, эти методы могут сочетаться.
