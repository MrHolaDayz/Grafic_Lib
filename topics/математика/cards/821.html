основной текст
Уравнением в полных дифференциалах называется уравнение M(x, y)dx + N(x, y)dy = 0, для которого выполнено условие ∂M/∂y = ∂N/∂x. Если это условие выполняется, то существует функция F(x, y), такая что ∂F/∂x = M и ∂F/∂y = N. Общее решение уравнения записывается в неявном виде F(x, y) = C, где C — произвольная постоянная. Для нахождения F интегрируют M по x или N по y, а затем уточняют функцию, используя второе частное производное. Свойства: если условие полного дифференциала не выполняется, уравнение можно привести к полному дифференциалу с помощью интегрирующего множителя. Пример: уравнение 2x dx + 2y dy = 0 удовлетворяет условию, так как ∂(2x)/∂y = 0 и ∂(2y)/∂x = 0. Интегрируя, получаем F(x, y) = x^2 + y^2, и общее решение x^2 + y^2 = C. Другой пример: (3x^2 + y) dx + (x - 2y) dy = 0 — проверка показывает, что ∂M/∂y = 1, ∂N/∂x = 1, условие выполнено, решение F(x, y) = x^3 + xy - y^2 = C. Уравнения в полных дифференциалах широко применяются в физике (потенциальные поля, термодинамика) и механике, где полный дифференциал описывает работу консервативных сил. Связь с другими темами: при решении часто приходится использовать Возведение в степень для интегрирования степенных функций, а также решать Квадратные уравнения и Кубические уравнения, когда общее решение F(x, y) = C сводится к алгебраическому уравнению относительно одной переменной. Кроме того, понимание полного дифференциала опирается на анализ функций нескольких переменных и частные производные.
