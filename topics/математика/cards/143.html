основной текст
Квадратный корень — это фундаментальное понятие алгебры. Формально, квадратным корнем из числа a называется число x, удовлетворяющее уравнению x^2 = a. У положительного числа a существуют два квадратных корня: положительный (√a) и отрицательный (-√a). Арифметический квадратный корень (обозначается знаком √) — это неотрицательное значение корня, определенное только для a ≥ 0. Основное тождество: (√a)^2 = a при a ≥ 0, и √(a^2) = |a|. Свойства квадратного корня включают: √(a*b) = √a * √b (для a,b ≥ 0) и √(a/b) = √a / √b (для a ≥ 0, b > 0). Например, √36 = 6, √(4*9) = √4 * √9 = 2*3 = 6, √(16/4) = √16 / √4 = 4/2 = 2. Важно помнить, что √(a+b) ≠ √a + √b. Квадратный корень широко применяется в геометрии (теорема Пифагора, вычисление диагонали квадрата), физике (скорость, ускорение) и статистике (стандартное отклонение). Понятие квадратного корня естественно обобщается до корня n-й степени: Кубический корень (∛a) — это число, дающее a при возведении в третью степень, а Корень n-й степени (n√a) — в n-ю степень. Арифметический корень является частным случаем для четных степеней и неотрицательных чисел.
