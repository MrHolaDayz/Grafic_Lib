Площадь поверхности — это сумма площадей всех граней многогранника, определяющая размер его внешней оболочки. Для многогранников она складывается из площадей боковой поверхности и основания.
связанные темы
Объем параллелепипеда Объем пирамиды Призма Виды призм Прямая призма
основной текст
Площадь поверхности многогранника (S_полн) равна сумме площадей всех его граней. Для призмы формула имеет вид: S_полн = 2S_осн + S_бок, где S_бок = P_осн * h (для прямой призмы). Для пирамиды: S_полн = S_осн + S_бок, где S_бок = 1/2 * P_осн * l (l — апофема). Для прямоугольного параллелепипеда: S_полн = 2(ab + bc + ac), где a, b, c — его измерения. Основное свойство площади поверхности — аддитивность: она равна сумме площадей непересекающихся частей. Например, площадь поверхности куба со стороной a равна 6a^2. При увеличении линейных размеров в k раз площадь поверхности растет пропорционально k^2. Это важно при решении задач на оптимизацию расхода материалов. Площадь поверхности широко применяется в строительстве (расчет материалов для облицовки), в дизайне упаковки и в химии (расчет площади адсорбции). Она тесно связана с объемом: для тел одинаковой формы площадь поверхности влияет на скорость теплообмена. В стереометрии эта тема объединяется с вычислением Объема параллелепипеда, Объема пирамиды и свойствами Призмы, где боковая поверхность зависит от вида призмы (прямая, наклонная, правильная).
