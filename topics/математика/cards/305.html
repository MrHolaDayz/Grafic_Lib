Неравенство треугольника утверждает, что длина любой стороны треугольника всегда меньше суммы длин двух других его сторон и больше их разности. Это фундаментальное свойство евклидовой геометрии, которое также выполняется для расстояний в метрических пространствах.

основной текст
Неравенство треугольника в геометрии формулируется так: для любого треугольника со сторонами a, b и c выполняются три неравенства: a < b + c, b < a + c, c < a + b. В более общей форме для любых трех точек A, B, C на плоскости или в пространстве справедливо: |AB| ≤ |AC| + |CB|, причем равенство достигается только когда точка C лежит на отрезке AB. Обратное неравенство дает оценку снизу: |a - b| < c < a + b. Для векторов в Rn неравенство треугольника записывается как ||x + y|| ≤ ||x|| + ||y||, где ||·|| — норма вектора. Свойства неравенства треугольника включают его роль в определении метрики: любое расстояние обязано удовлетворять этому неравенству. Пример: если стороны треугольника равны 3, 4 и 8, то такой треугольник не существует, так как 3 + 4 = 7 < 8. В геометрии оно используется для проверки существования треугольника по трем сторонам, а также в тригонометрии при решении треугольников. В анализе и топологии неравенство треугольника лежит в основе определения метрических пространств и применяется при доказательстве сходимости последовательностей. Неравенство треугольника тесно связано с другими классическими неравенствами. Неравенство Коши (неравенство Коши-Шварца) для векторов: |x·y| ≤ ||x||·||y||, из которого следует неравенство треугольника для нормы, порожденной скалярным произведением. Неравенство Коши-Буняковского является его интегральным аналогом. Неравенство Бернулли (1+x)^n ≥ 1+nx для x > -1 используется для доказательства других оценок, но не связано напрямую с треугольником. Неравенство Йенсена и Неравенство Гёльдера обобщают эти идеи на выпуклые функции и Lp-пространства. Таким образом, неравенство треугольника служит базовым кирпичиком в иерархии математических неравенств, от элементарной геометрии до функционального анализа.
