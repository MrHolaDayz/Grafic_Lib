основной текст
Предел справа (или односторонний предел) определяется как число L, такое что для любого ε > 0 существует δ > 0, при котором для всех x, удовлетворяющих условию 0 < x - a < δ, выполняется неравенство |f(x) - L| < ε. Обозначается как lim_{x → a⁺} f(x) = L. Здесь x → a⁺ означает, что x стремится к a справа, то есть x > a. Если функция определена на интервале (a, b), то предел справа в точке a существует, если значения f(x) неограниченно приближаются к L при x, достаточно близких к a с правой стороны. Основные свойства предела справа аналогичны свойствам обычного предела: если существуют lim_{x → a⁺} f(x) = A и lim_{x → a⁺} g(x) = B, то предел суммы, разности, произведения и частного (при B ≠ 0) также существуют и равны соответствующим комбинациям A и B. Пример: для функции f(x) = x², lim_{x → 0⁺} x² = 0. Для кусочно-заданной функции f(x) = 1/x при x > 0, lim_{x → 0⁺} 1/x = +∞ (предел равен бесконечности). Важно, что предел справа может существовать, даже если двусторонний предел не существует (например, для функции sign(x) в точке 0: предел справа равен 1, слева — -1). Предел справа широко применяется при исследовании разрывов функций, в дифференциальном исчислении (определение производной как предела разностного отношения справа), в теории вероятностей (функции распределения) и при анализе граничных условий в физике. Он тесно связан с понятием предела последовательности: если взять последовательность x_n → a⁺, то предел f(x_n) будет равен пределу справа. Определение на языке ε-δ для предела справа является частным случаем общего определения предела функции, где окрестность точки a рассматривается только справа. Сходящиеся последовательности используются для проверки существования предела: если для любой последовательности x_n → a⁺ значения f(x_n) сходятся к одному и тому же числу, то это число и есть предел справа.
