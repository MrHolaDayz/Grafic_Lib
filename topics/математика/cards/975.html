Метод математической индукции — это способ доказательства утверждений, зависящих от натурального числа n, основанный на проверке базы и переходе от n к n+1.

основной текст
Метод математической индукции основан на принципе: если утверждение P(n) верно для n=1 (или начального значения) и из предположения его истинности для n=k следует истинность для n=k+1, то P(n) верно для всех натуральных n. Формально: P(1) ∧ (∀k (P(k) ⇒ P(k+1))) ⇒ ∀n P(n). В доказательствах часто используют формулу суммы: 1 + 2 + ... + n = n(n+1)/2, проверяя базу (n=1) и индукционный шаг. Свойства: метод применим только к утверждениям, формулируемым для натуральных чисел; требует строгого доказательства как базы, так и шага. Пример: доказать, что 1^2 + 2^2 + ... + n^2 = n(n+1)(2n+1)/6. База: n=1 — верно. Шаг: предположив истинность для n=k, прибавляем (k+1)^2 и преобразуем к формуле для n=k+1. Метод широко применяется в комбинаторике, теории чисел, алгоритмах (доказательство корректности рекурсивных функций). Связан с темами: Метод Крамера (решение систем линейных уравнений — индукция по размерности), Матричный метод (доказательство свойств определителей или степеней матриц), Метод Гаусса (индукция по числу уравнений для обоснования приведения к ступенчатому виду). В отличие от этих методов, индукция не решает системы, а доказывает общие закономерности.
