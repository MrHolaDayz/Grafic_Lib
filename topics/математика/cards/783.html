Интегрирование рациональных дробей — это метод нахождения интегралов от дробей, числитель и знаменатель которых являются многочленами, путем разложения дроби на сумму простейших (элементарных) дробей.

основной текст
Интегрирование рациональных дробей основано на представлении правильной рациональной дроби (где степень числителя меньше степени знаменателя) в виде суммы простейших дробей вида A/(x-a)^k и (Mx+N)/(x^2+px+q)^k, где квадратный трехчлен не имеет действительных корней. Основная формула для интегрирования: ∫ P(x)/Q(x) dx = ∫ (многочлен + сумма простейших дробей) dx. Для неправильной дроби сначала выделяют целую часть делением многочленов. Ключевые свойства: разложение зависит от корней знаменателя — для действительных различных корней a,b,...: A/(x-a) + B/(x-b) + ...; для кратных корней: A/(x-a) + B/(x-a)^2 + ...; для квадратичных множителей: (Mx+N)/(x^2+px+q). Пример: ∫ (x+1)/(x^2-5x+6) dx = ∫ (A/(x-2) + B/(x-3)) dx = 3ln|x-2| - 2ln|x-3| + C. После нахождения коэффициентов A,B интегралы сводятся к табличным (ln, arctg, степенные функции). Метод широко применяется в физике, теории вероятностей и дифференциальных уравнениях для решения задач, связанных с накоплением величин, описываемых дробно-рациональными функциями. Связь с другими темами: перед интегрированием часто требуется Сокращение алгебраических дробей (упрощение множителей) и сложение/умножение дробей для проверки правильности разложения. Умение складывать и умножать дроби необходимо при обратном сведении суммы простейших дробей к исходной.
