основной текст
Остаточный член в форме Пеано используется для локального приближения функции f(x) в окрестности точки x_0. Если функция n раз дифференцируема в точке x_0, то её разложение по формуле Тейлора с остаточным членом в форме Пеано записывается как: f(x) = sum_{k=0}^{n} (f^{(k)}(x_0)/k!)*(x-x_0)^k + o((x-x_0)^n) при x → x_0. Здесь o((x-x_0)^n) — это остаточный член, обозначающий бесконечно малую величину более высокого порядка малости, чем (x-x_0)^n. Например, для f(x)=e^x в точке x_0=0: e^x = 1 + x + x^2/2 + ... + x^n/n! + o(x^n). Свойства остаточного члена в форме Пеано: он не требует дополнительных условий на производные (например, непрерывности) за пределами точки x_0, что делает его удобным для теоретических оценок. Пример: для f(x)=√(1+x) в точке 0: √(1+x) = 1 + x/2 - x^2/8 + o(x^2). Этот член полезен при нахождении пределов, так как позволяет заменять сложные функции их многочленами с контролируемой погрешностью. Основное свойство — остаток является o((x-x_0)^n), то есть его отношение к (x-x_0)^n стремится к нулю. Применяется остаточный член в форме Пеано в математическом анализе для исследования локального поведения функций, доказательства теорем (например, о необходимых условиях экстремума) и асимптотических разложений. Связь с другими темами: при возведении в степень остаточный член помогает разлагать функции вида (1+x)^a; в комплексных числах в геометрии формула Тейлора используется для приближения аналитических функций; Уравнение в отрезках (например, разложение по формуле Тейлора с остатком) позволяет находить приближённые решения. Также стоит упомянуть теорему Ферма (условие экстремума) и возведение
