Интеграл степенной функции — это первообразная для функции вида x^n, где n — любое действительное число, кроме -1. Основная формула имеет вид ∫x^n dx = x^(n+1)/(n+1) + C, а для случая n = -1 интеграл равен ln|x| + C.

основной текст
Интеграл степенной функции является одним из базовых понятий интегрального исчисления. Для функции f(x) = x^n (где n ≠ -1) неопределенный интеграл вычисляется по формуле: ∫x^n dx = x^(n+1)/(n+1) + C, где C — произвольная постоянная. Если n = -1, то есть функция имеет вид f(x) = 1/x, то интеграл равен натуральному логарифму: ∫(1/x) dx = ln|x| + C. Важно учитывать, что при n = -1 Область определения функции исключает точку x = 0, поэтому модуль в логарифме необходим. Для корней, например √x = x^(1/2), формула также применима: ∫√x dx = (2/3)x^(3/2) + C. Свойства интеграла степенной функции включают линейность: ∫(a*x^n + b*x^m) dx = a*∫x^n dx + b*∫x^m dx. Пример: ∫(3x^2 + 2x) dx = 3*(x^3/3) + 2*(x^2/2) + C = x^3 + x^2 + C. Для отрицательных степеней, например ∫x^(-3) dx = x^(-2)/(-2) + C = -1/(2x^2) + C, требуется учитывать область определения (x ≠ 0). Нули функции (точки, где f(x) = 0) часто служат границами при вычислении определенных интегралов. Интеграл степенной функции широко применяется в физике (вычисление работы, пути по скорости), экономике (модели роста) и геометрии (площади под кривыми). Связь с тригонометрическими функциями проявляется в интегралах вида ∫sin^n(x) dx, которые сводятся к степенным через замену. Обратные Тригонометрические функции, такие как arctg(x), также интегрируются с использованием степенных рядов. Область определения функции критична: для n — целого отрицательного числа (например, x^(-2)) функция не определена при x = 0, что влияет на пределы интегрирования.
