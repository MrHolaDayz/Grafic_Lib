Арктангенс (arctg или arctan) — это обратная тригонометрическая функция к тангенсу, которая для заданного числа x возвращает угол y в интервале (-π/2; π/2), такой что tg(y) = x.

основной текст
Арктангенс определяется как функция y = arctg x, где x — любое действительное число, а y — угол в радианах из интервала (-π/2; π/2). Основное тождество: tg(arctg x) = x для всех x ∈ R, и arctg(tg y) = y для y ∈ (-π/2; π/2). Функция нечётная: arctg(-x) = -arctg x. Важные формулы: arctg x + arcctg x = π/2; arctg x ± arctg y = arctg((x ± y)/(1 ∓ xy)) при условии xy ≠ 1. Свойства арктангенса: область определения — все действительные числа, область значений — (-π/2; π/2). Функция строго возрастает, непрерывна и имеет горизонтальные асимптоты y = -π/2 при x → -∞ и y = π/2 при x → +∞. Производная: (arctg x)' = 1/(1 + x^2). Пример: arctg 1 = π/4, arctg 0 = 0, arctg √3 = π/3. Арктангенс широко применяется в геометрии для нахождения углов по координатам (например, в полярных координатах), в физике при расчёте фазовых углов, в аналитической геометрии и в интегральном исчислении (интеграл от 1/(1+x^2) даёт arctg x). Функция тесно связана с Арксинусом (arcsin x) и Арккосинусом (arccos x): например, arctg x = arcsin(x/√(1+x^2)). Для изучения рекомендуется также рассмотреть График арксинуса и Свойства арксинуса, так как все обратные тригонометрические функции имеют схожую логику построения и взаимные формулы преобразования.
