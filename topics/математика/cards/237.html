Целая часть числа [x] — это наибольшее целое число, не превосходящее x, а дробная часть {x} — это разность между числом и его целой частью: {x} = x - [x].

основной текст
Определение и основные формулы. Для любого действительного числа x целая часть (антье) обозначается [x] и определяется как максимальное целое число, такое что [x] ≤ x. Дробная часть {x} равна x - [x], поэтому 0 ≤ {x} < 1. Например, [3.7] = 3, {3.7} = 0.7; [-2.3] = -3, {-2.3} = 0.7 (так как -3 ≤ -2.3). Основное свойство: x = [x] + {x}. Для целых n: [x + n] = [x] + n, {x + n} = {x}. Свойства и примеры. Целая часть нелинейна: [x + y] не равно [x] + [y] в общем случае (например, [1.5 + 1.5] = 3, а [1.5] + [1.5] = 2). Дробная часть периодична с периодом 1: {x + 1} = {x}. График [x] — ступенчатая функция с разрывами в целых точках, график {x} — пилообразная кривая. Часто используется в задачах на делимость и в теории чисел для выделения остатков. Где применяется, связь с другими темами. Целая и дробная части широко применяются в алгоритмах (округление, выделение цифр числа), в комбинаторике (формула Лежандра для степени простого числа в факториале), в анализе (интегрирование периодических функций). В комплексном анализе существуют аналоги: Действительная часть Re(z) и Мнимая часть Im(z) комплексного числа z = a + bi, где a = Re(z), b = Im(z). Сопряженное число z̅ = a - bi связано с ними: Re(z) = (z + z̅)/2, Im(z) = (z - z̅)/(2i). В отличие от вещественных целой и дробной частей, Re(z) и Im(z) — это координаты на плоскости, а не остаток от деления.
