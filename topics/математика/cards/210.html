Степенная функция — это функция вида y = x^n, где n — любое действительное число, определяющая зависимость между переменной и её степенью.

основной текст
Степенная функция в общем виде записывается как y = x^n, где n — показатель степени (действительное число). Частные случаи: при n = 1 получаем линейную функцию y = x; при n = 2 — квадратичную функцию y = x^2; при n = -1 — обратную пропорциональность y = 1/x; при n = 0 — постоянную функцию y = 1 (x ≠ 0). Для дробных показателей, например, n = 1/2, функция принимает вид y = √x (арифметический корень). График степенной функции зависит от чётности/нечётности n и его знака: для чётных n (например, 2, 4) график симметричен относительно оси OY, для нечётных (1, 3) — относительно начала координат. При n > 0 функция возрастает на области определения, при n < 0 — убывает, а при n = 0 график — прямая, параллельная оси OX. Свойства: область определения зависит от n — для целых положительных n это все действительные числа, для отрицательных — все числа, кроме нуля, для дробных с чётным корнем — неотрицательные числа. Функция непрерывна на своей области, дифференцируема (кроме точек разрыва). Пример: y = x^3 — нечётная, возрастает на R, проходит через точку (0,0). Для n = -2: y = 1/x^2 — чётная, убывает на (0, +∞), имеет вертикальную асимптоту x = 0. Степенная функция тесно связана с функцией Эйлера (при целых n она определяет количество взаимно простых чисел), а также с линейной и квадратичной функциями как её частные случаи. Дробно-Линейная функция y = (ax + b)/(cx + d) может быть сведена к степенной через замену переменной. Применение: степенные функции описывают законы физики (закон всемирного тяготения F ~ 1/r^2, закон Гука F ~ x), экономические модели (спрос, предложение), биологические процессы (рост популяции).
