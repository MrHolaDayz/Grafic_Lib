основной текст
Описанная окружность треугольника — это окружность, которая проходит через все три вершины треугольника. Её центр (O) является точкой пересечения серединных перпендикуляров, проведённых к каждой стороне треугольника. Радиус описанной окружности (R) связан со сторонами треугольника a, b, c и его площадью S формулой: R = a / (2 sin A) = b / (2 sin B) = c / (2 sin C) = abc / (4S), где A, B, C — углы треугольника. Для прямоугольного треугольника центр описанной окружности лежит на середине гипотенузы, а её радиус равен половине гипотенузы. Свойства описанной окружности включают: для остроугольного треугольника центр находится внутри треугольника, для тупоугольного — снаружи, а для прямоугольного — на гипотенузе. В равностороннем треугольнике центр описанной окружности совпадает с центром вписанной окружности и центром тяжести. Пример: если дан треугольник со сторонами 5, 6, 7, можно вычислить его площадь по формуле Герона, а затем найти R по формуле abc/(4S). Описанная окружность также используется для доказательства теорем (например, теоремы синусов) и в задачах на нахождение расстояний и углов. Описанная окружность широко применяется в геометрии для решения задач на построение, в тригонометрии (теорема синусов), а также в астрономии и навигации для расчёта положений точек на сфере. Она тесно связана с понятиями вписанной окружности, серединных перпендикуляров и свойств треугольников. В более сложных разделах она используется для описания циклических четырёхугольников и в теории окружностей Эйлера.
