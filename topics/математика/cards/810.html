основной текст
Дифференциальное уравнение (ДУ) — это уравнение вида F(x, y, y', y'', ..., y^(n)) = 0, где y = y(x) — искомая функция, а y', y'', ..., y^(n) — её производные. Порядок уравнения — это наивысший порядок производной, входящей в уравнение. Например, уравнение y' = 2x имеет первый порядок, а y'' + y = 0 — второй. Решением ДУ называется функция y = φ(x), которая при подстановке обращает уравнение в тождество. Свойства решений: Общее решение ДУ n-го порядка содержит n произвольных постоянных (например, y = C1 * e^x + C2 * e^(-x) для y'' - y = 0). Частное решение получается из общего при задании конкретных значений постоянных. Задача Коши — это нахождение частного решения, удовлетворяющего начальным условиям: y(x0) = y0, y'(x0) = y1, ..., y^(n-1)(x0) = y_(n-1). Пример: для уравнения y' = y общее решение y = C * e^x, а частное при y(0) = 2 — это y = 2 * e^x. Дифференциальные уравнения применяются в физике (законы движения, радиоактивный распад), биологии (рост популяции), экономике (модели роста). Простейший тип — Уравнения с разделяющимися переменными, которые решаются приведением к виду g(y) dy = f(x) dx и интегрированием. Связанные темы: общее решение (содержит произвольные постоянные), частное решение (конкретная функция), порядок уравнения (определяет количество начальных условий). Задача Коши — ключевой инструмент для выделения единственного решения из семейства.
