основной текст
Теорема Гамильтона-Кэли является фундаментальным результатом линейной алгебры. Пусть A — Квадратная матрица размера n×n, а p(λ) = det(λI - A) = λ^n + c_{n-1}λ^{n-1} + ... + c_1λ + c_0 — её характеристический многочлен. Тогда теорема утверждает, что p(A) = A^n + c_{n-1}A^{n-1} + ... + c_1A + c_0I = 0, где 0 — нулевая матрица. Это позволяет выразить любую степень матрицы A^k при k ≥ n через линейную комбинацию младших степеней (вплоть до A^{n-1}) с помощью рекуррентных соотношений, полученных из характеристического уравнения. Свойства и примеры: Для матрицы 2×2 A = [[a, b], [c, d]] характеристическое уравнение имеет вид λ^2 - (a+d)λ + (ad - bc) = 0, и теорема даёт A^2 = (a+d)A - (ad - bc)I. Для диагонализируемых матриц теорема следует из того, что собственные значения удовлетворяют многочлену, и для жордановых клеток также проверяется прямым вычислением. Теорема полезна для нахождения обратной матрицы: если c_0 ≠ 0, то из p(A)=0 получаем A^{-1} = -(1/c_0)(A^{n-1} + c_{n-1}A^{n-2} + ... + c_1I). Где применяется: теорема широко используется в теории управления (вычисление матричной экспоненты), в квантовой механике (соотношения для операторов), а также при решении систем дифференциальных уравнений. Связь с другими темами: Основная теорема алгебры гарантирует разложение характеристического многочлена на линейные множители над комплексными числами, что упрощает понимание спектра матрицы. Теорема Руше используется в комплексном анализе для подсчёта корней многочленов, но в данном контексте она не является прямой, хотя может применяться при доказательстве существования собственных значений. Определение матрицы как прямоугольной таблицы чисел лежит в основе всей теории
