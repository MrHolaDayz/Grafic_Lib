Квадратные неравенства — это неравенства вида ax^2 + bx + c > 0 (или <, ≥, ≤), где a ≠ 0. Их решение основано на нахождении корней соответствующего квадратного уравнения и анализе знаков квадратного трехчлена.

основной текст
Квадратным неравенством называется неравенство, которое можно привести к виду ax^2 + bx + c > 0, ax^2 + bx + c < 0, ax^2 + bx + c ≥ 0 или ax^2 + bx + c ≤ 0, где a, b, c — действительные числа, причем a ≠ 0. Основой для решения служит квадратное уравнение ax^2 + bx + c = 0, корни которого (если они есть) разбивают числовую ось на интервалы. Знак квадратного трехчлена на каждом интервале определяется знаком коэффициента a и расположением корней: при a > 0 ветви параболы направлены вверх, при a < 0 — вниз. Основное свойство: квадратный трехчлен сохраняет знак на каждом из интервалов между корнями (или на всей числовой оси, если дискриминант D < 0). Например, для неравенства x^2 - 5x + 6 > 0 находим корни уравнения x^2 - 5x + 6 = 0: x1 = 2, x2 = 3. Так как a = 1 > 0, то трехчлен положителен на интервалах (-∞; 2) и (3; +∞), и отрицателен на (2; 3). Ответ: (-∞; 2) ∪ (3; +∞). Если бы неравенство было x^2 - 5x + 6 ≤ 0, решение включало бы отрезок [2; 3]. Квадратные неравенства широко применяются при решении задач на нахождение области определения функций, исследовании квадратичных моделей в физике (например, движение с ускорением) и экономике. Они тесно связаны с методом интервалов, который является универсальным способом решения не только квадратных, но и дробно-рациональных и показательных неравенств. Понимание квадратных неравенств опирается на навыки решения квадратных уравнений и линейных неравенств. В более сложных темах, таких как Дробно-рациональные неравенства, после приведения к общему знаменателю часто возникает необходимость решать именно квадратные неравенства.
