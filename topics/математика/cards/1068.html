Минор — это определитель квадратной подматрицы, полученный из исходной матрицы вычёркиванием некоторых строк и столбцов. Миноры лежат в основе вычисления ранга матрицы и обратной матрицы.
связанные темы
Определение матрицы Виды матриц Квадратная матрица Единичная матрица Нулевая матрица
основной текст
Минором M_ij матрицы A размера m x n называется определитель квадратной матрицы порядка k, полученной из A вычёркиванием (m-k) строк и (n-k) столбцов. Наиболее часто используется минор элемента a_ij: чтобы его получить, удаляют i-ю строку и j-й столбец. Для квадратной матрицы порядка n существует понятие дополнительного минора и алгебраического дополнения A_ij = (-1)^(i+j) * M_ij. Основная формула разложения определителя по строке: det(A) = sum_{j=1}^{n} a_ij * A_ij. Миноры обладают свойством: если все миноры порядка r равны нулю, то равны нулю и все миноры более высокого порядка. Максимальный порядок ненулевого минора называется рангом матрицы. Пример: для матрицы 3x3, состоящей из единиц, минор второго порядка (из любых двух строк и двух столбцов) равен 0, следовательно, ранг матрицы равен 1. Миноры применяются при нахождении обратной матрицы (через союзную матрицу из алгебраических дополнений), при решении систем линейных уравнений (теорема Крамера) и при вычислении ранга матрицы. Понятие минора тесно связано с базовыми темами: Определение матрицы как прямоугольной таблицы чисел, Виды матриц (например, Квадратная матрица, для которой минор определён как детерминант подматрицы). Квадратная матрица позволяет говорить о главных минорах (с совпадающими номерами строк и столбцов), которые используются в критерии Сильвестра для проверки положительной определённости.
