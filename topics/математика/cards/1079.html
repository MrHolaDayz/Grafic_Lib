Собственный вектор ненулевой вектор, который при умножении на матрицу не меняет своего направления, а только масштабируется на число, называемое собственным значением.

основной текст
Собственный вектор квадратной матрицы A — это ненулевой вектор v, удовлетворяющий уравнению A*v = λ*v, где λ — собственное значение (скаляр). Основная формула для нахождения собственных векторов: (A - λI)*v = 0, где I — Единичная матрица. Собственные значения находятся из характеристического уравнения det(A - λI) = 0. Свойства: если λ — собственное значение, то соответствующие собственные векторы образуют линейное пространство (собственное подпространство). Для симметричных матриц собственные векторы, соответствующие разным собственным значениям, ортогональны. Пример: для единичной матрицы любой ненулевой вектор является собственным с λ=1. Для нулевой матрицы любой ненулевой вектор — собственный с λ=0. Собственные векторы применяются в анализе данных (метод главных компонент), квантовой механике, теории устойчивости, компьютерной графике (преобразования). Тесно связаны с определением матрицы как линейного оператора, различными видами матриц (например, симметричные матрицы имеют вещественные собственные значения) и понятием квадратной матрицы, так как только для квадратных матриц определено характеристическое уравнение.
