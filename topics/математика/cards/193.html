Метод подстановки — это способ решения систем уравнений, при котором одно уравнение выражается через одну переменную, а затем подставляется в другое уравнение для нахождения всех неизвестных.

Однородные системы Метод Крамера Матричный метод Метод Гаусса Метод Гаусса-Жордана
основной текст
Метод подстановки основан на последовательном исключении переменных. Для системы двух линейных уравнений с двумя неизвестными вида: a1*x + b1*y = c1 a2*x + b2*y = c2 алгоритм состоит из трех шагов: 1) выразить одну переменную из одного уравнения, например, x = (c1 - b1*y)/a1 (при a1 ≠ 0); 2) подставить это выражение во второе уравнение, получив уравнение с одной переменной y; 3) решить полученное уравнение и найти y, затем подставить найденное значение в выражение для x. В общем случае для n переменных процесс повторяется последовательно. Основное свойство метода — его универсальность: он применим к любым системам уравнений (линейным и нелинейным), но может быть громоздким при большом числе переменных. Пример: решить систему {x + y = 5, 2x - y = 1}. Из первого уравнения y = 5 - x. Подставляем во второе: 2x - (5 - x) = 1 → 3x = 6 → x = 2, тогда y = 3. Метод особенно эффективен, когда одно из уравнений уже решено относительно переменной. Метод подстановки применяется в алгебре, физике, экономике для решения задач с несколькими неизвестными. Он тесно связан с другими методами: в однородных системах (где свободные члены равны нулю) подстановка часто приводит к тривиальным решениям или требует дополнительного анализа. По сравнению с методом Крамера (использующим определители) и матричным методом (основанным на обратной матрице), метод подстановки проще для понимания, но менее алгоритмичен для больших систем. Метод Гаусса и Метод Гаусса-Жордана, напротив, предлагают более систематический подход к исключению переменных через матричные преобразования, что делает их предпочтительными для систем с числом уравнений больше трех.
