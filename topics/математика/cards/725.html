основной текст
Определение и основные формулы. Производная тригонометрической функции показывает, как быстро меняется её значение при изменении аргумента. Ключевые формулы: (sin x)' = cos x, (cos x)' = -sin x, (tg x)' = 1/cos^2 x, (ctg x)' = -1/sin^2 x. Для обратных функций: (arcsin x)' = 1/√(1 - x^2), (arccos x)' = -1/√(1 - x^2), (arctg x)' = 1/(1 + x^2), (arcctg x)' = -1/(1 + x^2). Эти формулы выводятся из определения производной через предел отношения приращений. Свойства и примеры. Производные тригонометрических функций сохраняют свойство периодичности: производная sin x (период 2π) даёт cos x (также период 2π). Пример: найти производную f(x) = sin(2x). Используя правило композиции функций (цепное правило), получаем f'(x) = cos(2x) * 2 = 2cos(2x). Для f(x) = tg^2 x: производная равна 2tg x * 1/cos^2 x = 2tg x / cos^2 x. Чётность и нечётность функций также отражаются: sin x — нечётная, её производная cos x — чётная; cos x — чётная, её производная -sin x — нечётная. Где применяется и связь с другими темами. Производные тригонометрических функций широко используются в физике (гармонические колебания, волны), инженерии (анализ сигналов) и экономике (модели циклических процессов). Они тесно связаны с графиками функций: зная производную, можно определить точки экстремума и интервалы монотонности тригонометрических кривых. Связь с композицией функций проявляется при дифференцировании сложных тригонометрических выражений (например, sin(3x^2 + 1)).
