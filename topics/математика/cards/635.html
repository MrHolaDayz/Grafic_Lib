Арккосинус — это обратная тригонометрическая функция к косинусу, определённая на отрезке [-1; 1] со значениями в [0; π]. Основные свойства включают чётность, связь с арксинусом и формулы преобразования.

основной текст
Арккосинус (arccos x) определяется как угол y ∈ [0; π], косинус которого равен x: cos(y) = x. Основные формулы: arccos(-x) = π - arccos x (свойство чётности относительно точки π/2); arccos x + arcsin x = π/2; arccos(cos α) = α при α ∈ [0; π]; cos(arccos x) = x. Также справедливо: arccos x = arcsin(√(1 - x^2)) для x ∈ [0; 1]. Свойства арккосинуса включают монотонное убывание на области определения, непрерывность и дифференцируемость на (-1; 1). Пример: arccos(1/2) = π/3, arccos(-1/2) = 2π/3. Для решения уравнений вида cos y = a используется arccos a с учётом периодичности косинуса. Арккосинус применяется в геометрии для нахождения углов по сторонам треугольника (теорема косинусов), в физике (расчёт фаз колебаний), а также в комплексном анализе. Связанные темы: Свойства сопряжённых чисел (arccos от комплексного аргумента), Свойства модуля (ограниченность значений), Свойства транспонирования (связь с матрицами поворота). При работе с определителями арккосинус может появляться в формулах углов между векторами.
