Скалярное произведение двух векторов — это операция, результатом которой является число (скаляр), равное произведению длин векторов на косинус угла между ними. Оно позволяет определить угол между векторами и проверить их перпендикулярность.

основной текст
Скалярное произведение Векторов a и b определяется формулой: a · b = |a| * |b| * cos φ, где |a| и |b| — длины векторов, а φ — угол между ними. В координатной форме для векторов a = (x1, y1) и b = (x2, y2) на плоскости скалярное произведение вычисляется как a · b = x1*x2 + y1*y2. Из определения следует, что если векторы перпендикулярны (φ = 90°), то их скалярное произведение равно нулю, так как cos 90° = 0. Длина вектора выражается через скалярное произведение: |a| = √(a · a). Свойства скалярного произведения: коммутативность (a · b = b · a), дистрибутивность относительно сложения (a · (b + c) = a · b + a · c), и ассоциативность по отношению к умножению на число (k*a · b = k*(a · b)). Пример: для векторов a = (3, 4) и b = (0, 1) скалярное произведение равно 3*0 + 4*1 = 4. Длина вектора a равна √(3^2 + 4^2) = 5, длина b равна 1, тогда cos φ = 4/(5*1) = 0.8, откуда φ ≈ 36.87°. Скалярное произведение широко применяется в физике (работа силы равна скалярному произведению силы на перемещение), в компьютерной графике (расчет освещения, определение угла падения света), а также в геометрии для нахождения проекций векторов. Эта тема тесно связана с понятием вектора, его координат и длины, так как все эти элементы используются в формулах. Знание скалярного произведения позволяет перейти к более сложным операциям, таким как векторное произведение и анализ взаимного расположения векторов.
