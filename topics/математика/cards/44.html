Признак делимости на 11 — правило, позволяющее быстро определить, делится ли натуральное число на 11 без остатка. Оно основано на разности сумм цифр, стоящих на чётных и нечётных местах.

основной текст
Определение: Число делится на 11, если модуль разности суммы цифр, стоящих на нечётных позициях (считая справа, начиная с единиц), и суммы цифр на чётных позициях, делится на 11. В виде формулы: пусть число имеет цифры a_n a_{n-1} ... a_1 a_0 (a_0 — цифра единиц). Тогда число делится на 11, если (a_0 + a_2 + a_4 + ...) - (a_1 + a_3 + a_5 + ...) ≡ 0 (mod 11). Например, для числа 121: нечётные позиции: 1+1=2, чётные: 2, разность 0, значит, 121 делится на 11 (11*11=121). Для числа 2728: нечётные: 2+2=4, чётные: 7+8=15, разность |4-15|=11, делится (11*248=2728). Это свойство следует из того, что 10 ≡ -1 (mod 11), поэтому 10^k ≡ (-1)^k (mod 11). Свойства и примеры: Признак работает для любых целых чисел, включая многозначные. Если разность равна 0 или кратна 11, число делится на 11. Например, 14641: нечётные (1+6+1=8), чётные (4+4=8), разность 0 — делится (11*1331=14641). Если разность 11, 22 и т.д., правило также выполняется. Удобно применять для проверки больших чисел, например, 123456789: нечётные (1+3+5+7+9=25), чётные (2+4+6+8=20), разность 5 — не делится на 11. Можно использовать повторное применение признака для очень длинных чисел. Где применяется, связь с другими темами: В арифметике признак делимости на 11 используется для быстрой проверки в вычислениях, шифровании, теории кодов (например, контрольные суммы ISBN).
