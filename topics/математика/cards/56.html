Разложение на простые множители — это представление натурального числа в виде произведения простых чисел, при котором каждый множитель является простым, а само разложение единственно с точностью до порядка множителей.

основной текст
Разложение на простые множители (факторизация) основывается на основной теореме арифметики: любое натуральное число n > 1 можно единственным образом представить как произведение простых чисел. Запись обычно имеет вид n = p1^a1 * p2^a2 * ... * pk^ak, где pi — простые числа, а ai — натуральные показатели степени. Например, число 84 = 2^2 * 3 * 7, а 100 = 2^2 * 5^2. Для нахождения разложения применяют последовательное деление на простые числа, начиная с 2, 3, 5 и т.д., или используют признаки делимости. Свойства разложения: оно единственно, позволяет находить наибольший общий делитель (НОД) и наименьшее общее кратное (НОК) чисел. Например, для чисел 84 и 100: НОД = 2^2 = 4, НОК = 2^2 * 3 * 5^2 * 7 = 2100. Разложение также упрощает работу с дробями, корнями (например, √72 = √(2^3 * 3^2) = 6√2) и сравнениями по модулю. Применяется в криптографии (RSA), теории чисел, алгоритмах компьютерной математики. Связано с другими темами: при повороте на комплексной плоскости модуль числа раскладывается на множители для нахождения аргумента; в умножении матрицы на число факторизация помогает упрощать вычисления; при разложении по строке или столбцу определителя матрицы простые множители элементов влияют на кратность определителя.
