Выпуклость вниз (вогнутость) — свойство графика функции, при котором он лежит выше любой своей касательной. Математически это выражается через вторую производную: если f''(x) > 0 на интервале, то функция выпукла вниз на этом интервале.

основной текст
Определение и основные формулы. Функция y = f(x) называется выпуклой вниз (или вогнутой) на интервале (a, b), если для любых точек x1, x2 из этого интервала график функции лежит не ниже отрезка, соединяющего точки (x1, f(x1)) и (x2, f(x2)). Если функция дважды дифференцируема, то достаточное условие выпуклости вниз: f''(x) > 0 для всех x из (a, b). Вторая производная в этом случае положительна, что означает возрастание первой производной (скорости изменения функции). Для проверки выпуклости вниз находят вторую производную и определяют знак на каждом интервале. Свойства и примеры. Классический пример выпуклой вниз функции — парабола y = x^2. Её вторая производная равна 2, что больше нуля на всей числовой прямой. Другой пример — экспонента y = e^x, для которой f''(x) = e^x > 0. Функция y = √x (корень из x) при x > 0 также выпукла вниз, так как её вторая производная отрицательна? На самом деле, для y = √x вторая производная равна -1/(4x^(3/2)) < 0, то есть функция выпукла вверх. Важно не путать: выпуклость вниз соответствует положительной второй производной, а выпуклость вверх — отрицательной. Точка, где вторая производная меняет знак, называется точкой перегиба. Где применяется, связь с другими темами. Понятие выпуклости вниз широко используется в оптимизации для определения характера экстремумов: если в критической точке f'(x0) = 0 и f''(x0) > 0, то в точке x0 — локальный минимум (график выпукл вниз). Это дополняет теорему Ферма, которая даёт необходимое условие экстремума. Выпуклость также связана с монотонностью первой производной: если f''(x) > 0, то f'(x) возрастает, что является признаком возраста
