Неравенство треугольника для модуля утверждает, что модуль суммы двух чисел не превосходит суммы их модулей: |a + b| ≤ |a| + |b|. Это одно из фундаментальных свойств абсолютной величины, обобщающее геометрический факт, что длина любой стороны треугольника не больше суммы длин двух других сторон.

основной текст
Неравенство треугольника для модуля — это ключевое свойство абсолютной величины (модуля) действительных или комплексных чисел. В простейшей форме для действительных чисел оно записывается как |a + b| ≤ |a| + |b|. Для комплексных чисел, где |z| = √(x^2 + y^2), неравенство также выполняется: |z1 + z2| ≤ |z1| + |z2|. Существует и обратная форма: | |a| - |b| | ≤ |a - b|. Эти неравенства следуют из аксиом метрического пространства и являются основой для оценки расстояний. Основные свойства: неравенство треугольника аддитивно и положительно однородно (|c·a| = |c|·|a| для любого множителя c). Пример: проверим для a = 5, b = -3. |5 + (-3)| = |2| = 2, |5| + |-3| = 5 + 3 = 8, 2 ≤ 8 — верно. Для комплексных чисел: z1 = 3 + 4i (модуль 5), z2 = 1 - i (модуль √2). |z1 + z2| = |4 + 3i| = √(16+9) = 5, а сумма модулей 5 + √2 ≈ 6.41, неравенство выполняется. Неравенство треугольника широко применяется в анализе, теории чисел и геометрии для оценки погрешностей, доказательства сходимости рядов и в неравенствах расстояний. Вместе с другими свойствами модуля (например, |ab| = |a||b|) оно образует базис для работы с абсолютными величинами. Оно тесно связано с неравенством Коши (сумма квадратов) и неравенством Коши-Буняковского, которые также задают границы для сумм. В тригонометрии неравенство треугольника для комплексных чисел перекликается с формулой Эйлера e^(iθ) = cosθ + i sinθ, так как модуль комплексной экспоненты всегда равен 1, что упрощает анализ колебательных процессов.
