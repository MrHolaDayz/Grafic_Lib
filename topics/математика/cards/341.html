Прямоугольный треугольник — это треугольник, имеющий один прямой угол (90°). Его стороны имеют специальные названия: гипотенуза (сторона напротив прямого угла) и два катета, образующие прямой угол.

основной текст
Прямоугольный треугольник определяется как треугольник, у которого один из углов равен 90°. Основные соотношения для него задаются теоремой Пифагора: квадрат гипотенузы равен сумме квадратов катетов (c^2 = a^2 + b^2, где c — гипотенуза). Также для острых углов α и β выполняются тригонометрические соотношения: sin α = a/c, cos α = b/c, tg α = a/b. Площадь прямоугольного треугольника равна половине произведения катетов: S = (1/2) * a * b. Ключевые свойства прямоугольного треугольника включают: медиана, проведенная из вершины прямого угла, равна половине гипотенузы; высота, опущенная из прямого угла на гипотенузу, делит треугольник на два подобных исходному треугольника; катет, лежащий против угла в 30°, равен половине гипотенузы. Пример: в треугольнике с катетами 3 и 4 гипотенуза равна √(3^2 + 4^2) = 5. Если один из острых углов равен 30°, то противолежащий катет будет в два раза меньше гипотенузы. Прямоугольные треугольники широко применяются в геодезии, архитектуре, физике (например, при разложении векторов на компоненты). Связь с другими темами включает использование свойств модуля при вычислении длин сторон (модуль вектора), свойств транспонирования — при работе с матрицами поворота, где прямоугольные треугольники задают координаты, и свойств сопряженных чисел — в тригонометрической записи комплексных чисел (аргумент комплексного числа определяется через прямоугольный треугольник).
