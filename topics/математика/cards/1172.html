основной текст
Функция Эйлера (или φ-функция) определяется для натурального числа n как количество целых чисел k в диапазоне 1 ≤ k ≤ n, для которых gcd(k, n) = 1. Обозначается как φ(n). Основная формула для вычисления: если n = p1^a1 * p2^a2 * ... * pk^ak (каноническое разложение на простые множители), то φ(n) = n * (1 - 1/p1) * (1 - 1/p2) * ... * (1 - 1/pk). Например, φ(12) = 12 * (1 - 1/2) * (1 - 1/3) = 12 * 1/2 * 2/3 = 4 (числа 1, 5, 7, 11). Для простого числа p: φ(p) = p - 1. Свойства функции Эйлера включают мультипликативность: если m и n взаимно просты, то φ(mn) = φ(m) * φ(n). Также важна теорема Эйлера: если gcd(a, n) = 1, то a^φ(n) ≡ 1 (mod n) — обобщение малой теоремы Ферма. Пример: для n = 10, φ(10) = 4, и 3^4 = 81 ≡ 1 (mod 10). Функция строго мультипликативна, но не полностью мультипликативна (например, φ(4) = 2, но φ(2) * φ(2) = 1 * 1 = 1, так как 2 и 2 не взаимно просты). Функция Эйлера широко применяется в криптографии (алгоритм RSA), где φ(n) используется для вычисления секретного ключа. Она связана с кольцом вычетов Z_n: φ(n) — это количество обратимых элементов в этом кольце. Также используется в решении линейных сравнений и в китайской теореме об остатках.
