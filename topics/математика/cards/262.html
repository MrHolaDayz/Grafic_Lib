основной текст
Геометрическая прогрессия — это числовая последовательность {b_n}, где для всех натуральных n выполняется условие: b_(n+1) = b_n * q, причем q ≠ 0. Здесь q — знаменатель прогрессии, а b_1 — первый член. Основная формула для нахождения n-го члена: b_n = b_1 * q^(n-1). Сумма первых n членов вычисляется по формуле S_n = b_1 * (1 - q^n) / (1 - q) при q ≠ 1. Если |q| < 1, то существует сумма бесконечно убывающей геометрической прогрессии: S = b_1 / (1 - q). Важнейшее свойство геометрической прогрессии — характеристическое: квадрат любого члена (кроме первого и последнего для конечной последовательности) равен произведению двух соседних с ним членов: (b_n)^2 = b_(n-1) * b_(n+1). Пример: последовательность 2, 4, 8, 16, ... — это геометрическая прогрессия со знаменателем q = 2. Ее пятый член равен 2 * 2^(5-1) = 32, а сумма первых пяти членов: S_5 = 2 * (1 - 2^5) / (1 - 2) = 2 * (1 - 32) / (-1) = 62. Геометрическая прогрессия широко применяется в финансах (расчет сложных процентов, кредитов и вкладов), в физике (радиоактивный распад, затухающие колебания), в биологии (рост популяций). Она тесно связана с арифметической прогрессией: если взять логарифмы членов геометрической прогрессии, получится Арифметическая прогрессия. Это позволяет использовать формулы n-го члена арифметической прогрессии для решения показательных уравнений. Геометрическая интерпретация прогрессии наглядно показывает экспоненциальный рост или убывание. Понимание разницы между арифметической и геометрической прогрессиями — ключ к анализу линейных и нелинейных процессов.
