основной текст
Непосредственное интегрирование представляет собой простейший способ вычисления неопределенного интеграла, при котором подынтегральное выражение уже имеет вид, совпадающий с одной из табличных формул, или легко приводится к такому виду с помощью алгебраических преобразований. Основой метода служит таблица интегралов от элементарных функций, например: ∫x^n dx = x^(n+1)/(n+1) + C (n ≠ -1), ∫dx/x = ln|x| + C, ∫e^x dx = e^x + C, ∫sin x dx = -cos x + C, ∫cos x dx = sin x + C, ∫dx/(√(1-x^2)) = arcsin x + C и другие. Ключевой принцип — использовать производные известных функций в обратном порядке. Метод опирается на два основных Свойства неопределенного интеграла: линейность (∫(f(x) ± g(x)) dx = ∫f(x)dx ± ∫g(x)dx) и вынесение постоянного множителя (∫k·f(x)dx = k·∫f(x)dx). Пример: ∫(3x^2 + 2/x - 5) dx = 3∫x^2 dx + 2∫dx/x - 5∫dx = 3·(x^3/3) + 2·ln|x| - 5x + C = x^3 + 2ln|x| - 5x + C. Другой пример: ∫(2cos x - 3e^x) dx = 2∫cos x dx - 3∫e^x dx = 2 sin x - 3e^x + C. Важно помнить, что результат всегда содержит произвольную постоянную C. Непосредственное интегрирование широко применяется как начальный этап в решении более сложных задач: при вычислении определенных интегралов, при решении дифференциальных уравнений, в физике для нахождения пути по скорости или работы по силе. Этот метод тесно связан с понятием первообразной: процесс интегрирования восстанавливает функцию по ее производной. Связь с другими темами проявляется через Определение первообразной (функция F(x) называется первообразной для f(x), если F'(x)=f(x)), Основное свойство первообразной (если F(x) — Первообразная, то F(x)+C — тоже первообразная, и других нет), а также через неопределенный интегра
