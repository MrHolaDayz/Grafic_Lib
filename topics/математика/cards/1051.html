Матрица — это прямоугольная таблица чисел, расположенных в m строках и n столбцах. Она является фундаментальным объектом линейной алгебры, используемым для представления линейных преобразований и систем уравнений.

основной текст
Матрица A размера m × n (читается «m на n») — это упорядоченная совокупность элементов a_ij, где i — номер строки (от 1 до m), j — номер столбца (от 1 до n). Общий вид: A = (a_ij) = [[a_11, a_12, ..., a_1n], [a_21, a_22, ..., a_2n], ..., [a_m1, a_m2, ..., a_mn]]. Если m = n, матрица называется квадратной. Нулевая матрица — это матрица, все элементы которой равны нулю. Единичная матрица E — Квадратная матрица, у которой на главной диагонали стоят единицы, а остальные элементы равны нулю. Основные свойства матриц связаны с операциями сложения, умножения на число и умножения матриц. Сложение возможно только для матриц одинакового размера и выполняется поэлементно. Умножение матрицы A размера m × n на матрицу B размера n × p дает матрицу C размера m × p, где элемент c_ij равен сумме произведений элементов i-й строки A на j-й столбец B: c_ij = Σ(k=1 до n) a_ik * b_kj. Пример: для A = [[1, 2], [3, 4]] и B = [[0, 1], [1, 0]] произведение AB = [[2, 1], [4, 3]]. Матрицы применяются для решения систем линейных уравнений, в компьютерной графике (преобразования координат), в экономике (модели Леонтьева), физике и статистике. Определение матрицы тесно связано с такими понятиями, как Виды матриц (прямоугольные, квадратные, диагональные, треугольные), квадратная матрица (основа для определителя и обратной матрицы), единичная матрица (нейтральный элемент при умножении) и нулевая матрица (нейтральный элемент при сложении). Диагональная матрица — частный случай квадратной матрицы, где все элементы вне главной диагонали равны нулю.
