основной текст
Комбинаторные тождества представляют собой равенства, которые выполняются для биномиальных коэффициентов, чисел перестановок и других комбинаторных величин. Основой многих из них является бином Ньютона: (1 + x)^n = C(n,0) + C(n,1)x + C(n,2)x^2 + ... + C(n,n)x^n, где C(n,k) = n!/(k!(n-k)!). Классические примеры включают тождество Паскаля: C(n,k) = C(n-1,k-1) + C(n-1,k), и тождество суммы биномиальных коэффициентов: C(n,0) + C(n,1) + ... + C(n,n) = 2^n. Свойства комбинаторных тождеств часто основаны на симметрии (C(n,k) = C(n,n-k)) и рекуррентных соотношениях. Например, тождество Вандермонда: C(m+n,r) = sum_{k=0}^r C(m,k) * C(n,r-k) позволяет разбивать выборки из двух групп. Другой важный пример — тождество для суммы квадратов: sum_{k=0}^n [C(n,k)]^2 = C(2n,n), которое вытекает из комбинаторной интерпретации выбора n элементов из 2n. Эти тождества широко применяются в теории вероятностей, статистике, алгебре и дискретной математике для упрощения вычислений и доказательства других формул. Они тесно связаны с правилом суммы (сложение количества вариантов из непересекающихся множеств) и правилом произведения (умножение количества вариантов на каждом шаге). Факториал n! используется в определениях C(n,k) и P(n,k) = n!/(n-k)!, а Двойной факториал n!! встречается в тождествах для нечётных и чётных степеней. Перестановки и комбинации служат базой для вывода многих тождеств, например, через подсчёт числа способов выбрать подмножества.
