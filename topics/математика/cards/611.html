Формулы двойного угла — это тригонометрические тождества, которые выражают синус, косинус и тангенс угла 2α через тригонометрические функции угла α.
связанные темы
Формулы сокращенного умножения Формулы Биссектриса угла Свойство внешнего угла Свойство вписанного угла
основной текст
Формулы двойного угла выводятся из формул сложения аргументов. Основные из них: sin(2α) = 2 sin α cos α; cos(2α) = cos^2 α - sin^2 α = 2 cos^2 α - 1 = 1 - 2 sin^2 α; tg(2α) = (2 tg α) / (1 - tg^2 α). Для котангенса: ctg(2α) = (ctg^2 α - 1) / (2 ctg α). Эти равенства справедливы для всех α, при которых определены обе части (например, для tg(2α) знаменатель не равен нулю, а α ≠ π/2 + πk). Свойства формул двойного угла позволяют упрощать тригонометрические выражения, решать уравнения и доказывать тождества. Например, с их помощью можно выразить sin^2 α через cos(2α): sin^2 α = (1 - cos(2α))/2. Пример: вычислить sin(60°), зная sin(30°)=1/2 и cos(30°)=√3/2: sin(60°) = 2*(1/2)*(√3/2) = √3/2. Эти формулы также используются для понижения степени в интегралах и при решении задач с удвоением угла. Формулы двойного угла применяются в геометрии (например, при вычислении биссектрисы угла через стороны треугольника), в физике (сложение колебаний, оптика) и в анализе (интегрирование тригонометрических функций). Связанные темы: Формулы сокращенного умножения (аналогия с (a+b)^2 = a^2 + 2ab + b^2, где cos(2α) = cos^2 α - sin^2 α напоминает разность квадратов), Формулы (общий раздел тригонометрических тождеств) и Биссектриса угла (её длина может быть выражена через формулы двойного угла в треугольнике).
