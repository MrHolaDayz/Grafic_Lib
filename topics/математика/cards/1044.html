основной текст
Кубическое уравнение — это алгебраическое уравнение третьей степени. В общем виде оно записывается как ax^3 + bx^2 + cx + d = 0, где a, b, c, d — комплексные числа, a ≠ 0. Основная формула для его решения — формула Кардано. Сначала уравнение приводится к неполному виду y^3 + py + q = 0 с помощью замены x = y - b/(3a). Тогда один из корней находится как y = ∛(-q/2 + √((q/2)^2 + (p/3)^3)) + ∛(-q/2 - √((q/2)^2 + (p/3)^3)). Остальные корни получаются Умножением кубических корней на комплексные кубические корни из единицы (ω и ω^2). Свойства кубических уравнений: они всегда имеют три корня (с учетом кратности) в поле комплексных чисел. Если дискриминант D = (q/2)^2 + (p/3)^3 положителен, то один корень вещественный, а два других — комплексно-сопряженные; если D = 0, все корни вещественные, и хотя бы два из них совпадают; если D < 0, все три корня вещественные, но выражаются через комплексные числа (casus irreducibilis). Пример: уравнение x^3 - 1 = 0 имеет корни x = 1, x = (-1 + i√3)/2, x = (-1 - i√3)/2. Кубические уравнения применяются в физике (например, в задачах о колебаниях и в теории упругости), в инженерии (расчет объемов и деформаций), а также в финансовой математике. Они тесно связаны с комплексными числами, так как решение требует извлечения кубических корней из комплексных величин. Арифметические действия над комплексными числами — Сложение, Вычитание, Умножение — используются при проверке корней и упрощении выражений в процессе решения. Например, при умножении корней на ω и ω^2 применяется умножение комплексных чисел, а при подстановке в исходное уравнение — сложение и вычитание.
