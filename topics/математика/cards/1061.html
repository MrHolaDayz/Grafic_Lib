Транспонирование матрицы — это операция, при которой строки исходной матрицы становятся столбцами, а столбцы — строками. Свойства транспонирования описывают, как эта операция взаимодействует со сложением, умножением матриц и взятием обратной матрицы.

основной текст
Транспонирование матрицы A размера m×n дает матрицу A^T размера n×m, где элемент (i, j) равен элементу (j, i) исходной матрицы. Основные формулы: (A^T)^T = A (двойное транспонирование возвращает исходную матрицу), (A + B)^T = A^T + B^T (транспонирование суммы равно сумме транспонированных), (cA)^T = cA^T для скаляра c. Ключевое свойство для произведения: (AB)^T = B^T A^T — порядок множителей меняется на обратный, что аналогично правилу для сопряженных чисел: (z1 * z2)^* = z2^* * z1^*. Свойства включают: если A — квадратная симметричная матрица, то A^T = A; для кососимметричной A^T = -A. Пример: для A = [[1, 2], [3, 4]], A^T = [[1, 3], [2, 4]]. Для обратной матрицы: (A^(-1))^T = (A^T)^(-1), если A обратима. Эти свойства тесно связаны с определением матрицы и видами матриц — например, симметричные и ортогональные матрицы определяются через равенство A^T = A или A^T = A^(-1). Транспонирование широко применяется в линейной алгебре: при решении систем уравнений (метод наименьших квадратов), в анализе данных (ковариационные матрицы), в физике (тензоры). Связь с другими темами: Свойства сопряженных чисел (аналогия с комплексным сопряжением), Свойства модуля (норма матрицы через след A^T A), а также понятие квадратной матрицы, для которой транспонирование особенно важно при изучении собственных значений. Понимание транспонирования опирается на базовое Определение матрицы как прямоугольной таблицы чисел.
