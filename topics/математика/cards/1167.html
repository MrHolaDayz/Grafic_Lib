основной текст
Определение и основные формулы: Бесконечность простых чисел — теорема, доказывающая, что количество простых чисел бесконечно. Классическое доказательство Евклида (около 300 г. до н.э.) строится от противного: если предположить, что существует конечное множество всех простых чисел p1, p2, ..., pn, то число N = p1 * p2 * ... * pn + 1 не делится ни на одно из них, так как дает остаток 1 при делении. Следовательно, N либо само является простым, либо имеет простой делитель, не входящий в исходный список, что противоречит предположению. Свойства и примеры: Из бесконечности простых чисел следует, что их распределение не подчиняется простой закономерности. Например, Простые числа встречаются все реже по мере роста чисел, но никогда не исчезают полностью. Пример: первые простые числа — 2, 3, 5, 7, 11, 13, 17, 19, 23... — их последовательность бесконечна. Следствием является также то, что для любого натурального n можно найти n подряд идущих составных чисел (например, n! + 2, n! + 3, ..., n! + n). Где применяется, связь с другими темами: Эта теорема лежит в основе многих разделов теории чисел, включая изучение распределения простых чисел (асимптотический закон), криптографию (RSA), а также связана с теоремой о делении с остатком, которая используется в доказательстве Евклида. В более широком контексте, бесконечность простых чисел является частным случаем вопросов о бесконечности в математике. Связанные темы: Равенство комплексных чисел и Свойства сопряженных чисел не имеют прямого отношения к этой теореме, но в теории чисел комплексные числа применяются, например, в аналитической теории чисел (дзета-функция Римана) для изучения распределения простых чисел. Теорема о делении с остатком является основой для доказательства бесконечности простых чисел, так как позволяет утверждать, что N не делится ни на одно из предполагаемых простых чисел.
