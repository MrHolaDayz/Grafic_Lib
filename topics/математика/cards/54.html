основной текст
Составное число — это натуральное число n > 1, которое можно представить в виде произведения двух меньших натуральных чисел, больших единицы. Формально: n = a * b, где 1 < a ≤ b < n. Например, 4 = 2 * 2, 6 = 2 * 3, 8 = 2^3. Все составные числа, кроме 1, имеют более двух делителей. Основная теорема арифметики утверждает, что любое составное число единственным образом (с точностью до порядка множителей) разлагается на простые множители: n = p1^k1 * p2^k2 * ... * pm^km, где pi — Простые числа, ki — натуральные степени. Свойства составных чисел: они всегда делятся на некоторое простое число, меньшее или равное √n (критерий проверки на простоту). Примеры: 9 = 3^2 (делители: 1, 3, 9); 12 = 2^2 * 3 (делители: 1, 2, 3, 4, 6, 12). Наименьшее составное число — 4. Важно: число 1 не является ни простым, ни составным. Составные числа образуют бесконечное множество, так как, например, все четные числа больше 2 — составные. Понятие составных чисел тесно связано с простыми числами (простые числа — это «кирпичики» для составных). В более широком контексте, при изучении делимости в кольце целых чисел Гаусса (комплексные числа вида a + bi, где a, b — целые) возникают аналоги простых и составных гауссовых чисел. Сопряженные числа (a - bi) используются для вычисления нормы N(a+bi) = a^2 + b^2, которая является целым числом и определяет свойства делимости в этом кольце. Модуль комплексного числа |z| = √(a^2 + b^2) — это аналог абсолютной величины, а аргумент — угол на комплексной плоскости. Составные числа в комплексной плоскости могут быть разложены на множители, если их норма — составное натуральное число. Например, число 5 = (2+i)(2-i), так как норма 2+i равна 2^2+1^2=5.
