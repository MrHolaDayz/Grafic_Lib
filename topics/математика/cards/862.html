Двойной факториал числа n (обозначается n!!) — это произведение всех натуральных чисел от 1 до n, взятых с шагом 2. Он используется для подсчёта количества способов в задачах, связанных с разбиением на пары и перестановками с ограничениями.

основной текст
Двойной Факториал числа n определяется по-разному для чётных и нечётных n. Для чётного n = 2k: (2k)!! = 2 * 4 * 6 * ... * 2k = 2^k * k!. Для нечётного n = 2k+1: (2k+1)!! = 1 * 3 * 5 * ... * (2k+1) = (2k+1)! / (2^k * k!). По определению, 0!! = 1 и (-1)!! = 1. Основное рекуррентное свойство: n!! = n * (n-2)!!. Примеры: 5!! = 1*3*5 = 15, 6!! = 2*4*6 = 48. Двойной факториал тесно связан с комбинаторными задачами, где элементы группируются попарно. Например, количество способов разбить 2n различных объектов на n неупорядоченных пар равно (2n-1)!!. Он также возникает в подсчёте числа совершенных паросочетаний в полном графе и в формулах для некоторых интегралов (например, в выражении для площади поверхности n-мерной сферы). Связь с обычным факториалом выражается через формулы, приведённые выше, что позволяет упрощать вычисления в комбинаторных выражениях. Двойной факториал применяется в комбинаторике, теории вероятностей и математическом анализе. В частности, он используется при подсчёте перестановок с ограничениями (например, количество способов рассадить людей за круглым столом с условием, что некоторые пары сидят рядом). Связанные темы: Правило суммы и Правило произведения лежат в основе вывода рекуррентных соотношений для двойного факториала. Факториал является частным случаем двойного факториала при шаге 1, и между ними существует прямая связь через степени двойки. Перестановки и Перестановки с повторениями также могут быть выражены через двойные факториалы в задачах с группировкой элементов.
