основной текст
Нули функции — это решения уравнения f(x) = 0. Для нахождения нулей необходимо приравнять функцию к нулю и решить полученное уравнение относительно x. Например, для линейной функции f(x) = kx + b нуль находится из уравнения kx + b = 0, откуда x = -b/k (при k ≠ 0). Для квадратичной функции f(x) = ax^2 + bx + c нули — это корни квадратного уравнения ax^2 + bx + c = 0, которые вычисляются по формуле x = (-b ± √(b^2 - 4ac)) / (2a). Функция может иметь один, несколько или бесконечно много нулей, а также не иметь их вовсе (например, f(x) = x^2 + 1 не имеет действительных нулей). Свойства нулей тесно связаны с поведением функции. Если функция непрерывна, то между двумя её нулями она меняет знак (теорема Больцано-Коши). Нули функции позволяют решать неравенства методом интервалов: разбивая область определения на промежутки, в каждом из которых функция сохраняет знак. Примеры: для f(x) = x^2 - 4 нули равны x = -2 и x = 2; для f(x) = (x-1)^2 нуль x = 1 является кратным. В случае дробно-линейной функции f(x) = (ax + b)/(cx + d) нуль находится из условия ax + b = 0, при этом знаменатель не должен обращаться в ноль. Понятие нулей функции применяется в алгебре, математическом анализе и физике для нахождения точек равновесия, решения уравнений и анализа графиков. Нули связаны с корнями многочленов и точками пересечения графиков разных функций. Например, при решении системы уравнений f(x) = g(x) нули функции h(x) = f(x) - g(x) дают точки пересечения графиков. В прикладных задачах нули используются для определения моментов, когда некоторая величина обращается в ноль (например, скорость, температура).
