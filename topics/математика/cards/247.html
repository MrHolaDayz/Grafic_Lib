Совокупность неравенств — это набор неравенств, объединённых фигурной скобкой, решение которых представляет собой объединение решений каждого неравенства в отдельности. Она отличается от системы неравенств тем, что для системы требуется выполнение всех условий одновременно, а для совокупности — хотя бы одного.

основной текст
Совокупность неравенств записывается в виде { f(x) ≥ 0, g(x) < 0, ... } (где скобка обозначает "или") и означает, что решением является множество всех x, удовлетворяющих хотя бы одному из неравенств. Формально: если даны неравенства A(x) > 0, B(x) ≤ 0, то совокупность [A(x) > 0; B(x) ≤ 0] имеет решение как объединение множеств решений каждого. Для обозначения совокупности часто используют квадратную скобку, в отличие от фигурной для системы. Основное свойство: решение совокупности — это объединение, а не пересечение решений. Пример: совокупность x > 0 и x < -1 даёт решение (-∞; -1) ∪ (0; +∞). При решении сложных неравенств, например дробно-рациональных или показательных, часто разбивают исходное условие на несколько совокупностей, чтобы избавиться от модулей или учесть разные области определения. Свойства совокупностей тесно связаны с методом интервалов: при нахождении знаков выражения на числовой оси совокупность позволяет учесть случаи, когда выражение обращается в ноль или теряет смысл. Например, при решении неравенства (x-1)/(x+2) > 0 его заменяют совокупностью двух систем: { x-1 > 0; x+2 > 0 } или { x-1 < 0; x+2 < 0 }. Однако если требуется учесть, что знаменатель не равен нулю, используют совокупность условий. Совокупности применяются при решении неравенств с модулем: |f(x)| > a равносильно совокупности f(x) > a или f(x) < -a. Также они встречаются в показательных и логарифмических неравенствах, когда основание степени меняет знак. Связь с другими темами: Линейные неравенства часто объединяются в совокупности для нахождения промежутков, где выполняется хотя бы одно условие. Квадратные неравенства сводятся к совокупности линейных после разложения на множители. Метод интервалов является основным инструментом для решения совокупностей, так как позволяет наглядно представить объединение
