основной текст
Свойства пределов — это фундаментальные правила, которые упрощают нахождение пределов функций. Если существуют конечные пределы lim f(x) = A и lim g(x) = B, то выполняются следующие основные соотношения: предел суммы равен сумме пределов: lim (f(x) + g(x)) = A + B; предел произведения равен произведению пределов: lim (f(x) * g(x)) = A * B; предел частного при B ≠ 0 равен частному пределов: lim (f(x) / g(x)) = A / B. Также действует правило для степени: lim (f(x))^n = A^n, и для корня: lim √(f(x)) = √(A) при A ≥ 0 для корня четной степени. Эти свойства активно применяются для раскрытия неопределенностей вида 0/0 или ∞/∞. Например, при вычислении предела (x^2 - 1)/(x - 1) при x → 1, сначала используют разложение на множители, а затем применяют свойство частного. Свойства пределов тесно связаны со свойствами сопряженных чисел (для избавления от иррациональности в числителе или знаменателе), со свойствами модуля (для оценки расстояния между значением функции и пределом), а также со свойствами транспонирования (в контексте пределов последовательностей или матричных функций). Данные правила лежат в основе всего математического анализа, так как позволяют переходить от сложных выражений к простым. Они используются при доказательстве непрерывности функций, в дифференциальном и интегральном исчислении. Понимание свойств пределов необходимо для работы с производными (через определение предела приращения) и для анализа сходимости рядов. Связанные темы: Свойства сопряженных чисел применяются при умножении числителя и знаменателя на сопряженное выражение для раскрытия неопределенностей с корнями. Свойства модуля важны для формального определения предела на языке ε-δ и для доказательства единственности предела. Свойства транспонирования могут быть использованы при рассмотрении пределов от матричных функций, где предел матрицы находится поэлементно, а транспонирование коммутирует с предельным переходом.
