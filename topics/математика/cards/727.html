основной текст
Правила дифференцирования включают в себя основные формулы для производных элементарных функций и алгебраических комбинаций. Ключевыми являются: производная суммы (f + g)' = f' + g', производная произведения (f * g)' = f' * g + f * g', производная частного (f / g)' = (f' * g - f * g') / g^2 (при g ≠ 0), а также производная сложной функции (правило цепочки): (f(g(x)))' = f'(g(x)) * g'(x). Для степенной функции: (x^n)' = n * x^(n-1). Для тригонометрических: (sin x)' = cos x, (cos x)' = -sin x. Эти правила обладают свойством линейности: производная суммы функций равна сумме их производных, а константу можно выносить за знак производной: (c * f)' = c * f'. Пример: найти производную функции y = x^2 * sin x. Используем правило произведения: y' = (x^2)' * sin x + x^2 * (sin x)' = 2x * sin x + x^2 * cos x. Еще пример: y = √(3x + 1). Представим как (3x + 1)^(1/2). По правилу цепочки: y' = (1/2)*(3x + 1)^(-1/2) * 3 = 3 / (2√(3x + 1)). Правила дифференцирования широко применяются при исследовании функций (нахождение экстремумов, точек перегиба), в физике для вычисления скорости и ускорения, в экономике для нахождения предельных издержек и прибыли. Они тесно связаны с определением производной, которое базируется на понятиях приращения функции и приращения аргумента. Например, производная в точке — это предел отношения приращения функции к приращению аргумента, когда последнее стремится к нулю. Геометрический смысл производной состоит в том, что она равна угловому коэффициенту касательной к графику функции в данной точке, что позволяет составлять Уравнение касательной. Знание правил дифференцирования необходимо для работы со всеми этими приложениями.
