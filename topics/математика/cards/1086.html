основной текст
Метод Гаусса (метод последовательного исключения неизвестных) — это фундаментальный алгоритм линейной алгебры для решения систем линейных уравнений вида A·x = b. Основная идея заключается в преобразовании расширенной матрицы системы (A|b) к верхнетреугольной форме (прямой ход) путем элементарных операций над строками: перестановка строк, умножение строки на ненулевое число и прибавление к одной строке другой, умноженной на коэффициент. После приведения к треугольному виду решение находится обратной подстановкой (обратный ход), начиная с последнего уравнения. Модификация метода — Метод Гаусса-Жордана — приводит матрицу к единичной, что дает решение сразу, без обратной подстановки. Формально, если после прямого хода матрица имеет ступенчатый вид, то ранг матрицы r определяет количество базисных переменных, а остальные n-r переменных являются свободными. Свойства метода: он универсален (применим к любым системам, включая вырожденные), устойчив к вычислительным погрешностям (особенно с выбором главного элемента) и имеет сложность O(n^3). Пример: для системы {2x + y = 5, 4x - y = 1} расширенная матрица [[2,1|5],[4,-1|1]] после вычитания удвоенной первой строки из второй дает [[2,1|5],[0,-3|-9]], откуда y = 3, x = 1. Если в процессе прямого хода получается строка вида (0 0 ... 0 | 0), то система имеет бесконечно много решений; если (0 0 ... 0 | c) при c≠0 — система несовместна. Метод Гаусса широко применяется в численных расчетах, компьютерной алгебре, физике, экономике и инженерии для решения больших систем уравнений. Он тесно связан с другими темами: Однородные системы (где b=0) решаются аналогично, но всегда имеют тривиальное решение x=0; для неоднородных систем метод позволяет определить совместность.
