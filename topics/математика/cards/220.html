основной текст
Растяжение и сжатие графика функции — это аффинные преобразования, которые изменяют масштаб изображения вдоль одной из координатных осей. Основные формулы: для растяжения/сжатия вдоль оси OY используется множитель k перед функцией: y = k·f(x). Если |k| > 1, происходит растяжение (график «вытягивается» по вертикали); если 0 < |k| < 1 — сжатие. Для преобразования вдоль оси OX используется коэффициент внутри аргумента: y = f(k·x). Здесь при |k| > 1 происходит сжатие к оси OY, а при 0 < |k| < 1 — растяжение от оси OY. Знак k также влияет на отражение графика относительно оси. Свойства растяжения и сжатия тесно связаны с чётностью функции. Например, для чётной функции (f(x) = f(-x)) вертикальное растяжение/сжатие сохраняет симметрию относительно оси OY, а для нечётной (f(-x) = -f(x)) — симметрию относительно начала координат. Пример: Квадратичная функция y = x^2 при растяжении вдоль OY в 2 раза превращается в y = 2x^2 — парабола становится более «узкой» по вертикали. Для линейной функции y = kx + b растяжение/сжатие вдоль OY изменяет угол наклона прямой, а вдоль OX — частоту изменения аргумента. Эти преобразования широко применяются в физике (например, изменение амплитуды колебаний), экономике (масштабирование данных) и компьютерной графике. В алгебре растяжение и сжатие помогают анализировать поведение функций, строить графики сложных зависимостей на основе простых. Связь с другими темами: для степенной функции y = x^n растяжение меняет крутизну графика, а для обратной пропорциональности y = 1/x — асимптоты.
