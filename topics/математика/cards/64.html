Теорема Вильсона — это критерий простоты натурального числа: натуральное число p > 1 является простым тогда и только тогда, когда (p-1)! + 1 делится на p, то есть (p-1)! ≡ -1 (mod p).

основной текст
Теорема Вильсона формулируется так: натуральное число p > 1 является простым тогда и только тогда, когда (p-1)! ≡ -1 (mod p). В развернутом виде: (p-1)! + 1 = p * k для некоторого целого k. Например, для p = 5: (5-1)! = 24, 24 + 1 = 25, что делится на 5. Для p = 7: 6! = 720, 720 + 1 = 721, 721 / 7 = 103. Обратное утверждение также верно: если p составное, то (p-1)! ≡ 0 (mod p) для p > 4 (за исключением p = 4, где 3! = 6 ≡ 2 mod 4). Основное свойство теоремы — она дает необходимое и достаточное условие простоты числа, однако на практике используется редко из-за вычислительной сложности факториала для больших p. Пример: для p = 11: 10! = 3628800, 3628800 + 1 = 3628801, которое делится на 11 (11 * 329891 = 3628801). Для p = 13: 12! = 479001600, 479001600 + 1 = 479001601, делится на 13 (13 * 36846277 = 479001601). Теорема Вильсона применяется в теории чисел для доказательства других теорем о простых числах, а также в криптографии для проверки простоты чисел (хотя на практике используют более эффективные тесты, например, тест Миллера-Рабина). Связанные темы: Основная теорема алгебры утверждает, что любой многочлен степени n имеет ровно n комплексных корней (с учетом кратности), что используется при разложении полиномов. Теорема Руше помогает определить количество корней аналитической функции в области. Теорема о ранге связывает размерность образа и ядра линейного оператора. Теорема Гамильтона-Кэли и Теорема Кронекера-Капелли относятся к линейной алгебре и теории матриц.
