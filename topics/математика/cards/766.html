Формула Маклорена — это частный случай ряда Тейлора с центром в нуле, позволяющий представить функцию в виде многочлена с остаточным членом для приближённых вычислений.

основной текст
Формула Маклорена представляет собой разложение функции f(x) в окрестности точки x=0 в степенной ряд: f(x) = f(0) + f'(0)x + f''(0)x^2/2! + f'''(0)x^3/3! + ... + f^(n)(0)x^n/n! + R_n(x), где R_n(x) — остаточный член в форме Лагранжа или Пеано. Например, для e^x: e^x = 1 + x + x^2/2! + x^3/3! + ... + x^n/n! + e^(θx)x^(n+1)/(n+1)!, 0<θ<1. Для sin x: sin x = x - x^3/3! + x^5/5! - ... + (-1)^k x^(2k+1)/(2k+1)! + R. Для cos x: cos x = 1 - x^2/2! + x^4/4! - ... + (-1)^k x^(2k)/(2k)! + R. Основное свойство формулы Маклорена — возможность замены сложной функции многочленом с контролируемой погрешностью. Пример: вычисление √(1+x) при малых x: √(1+x) ≈ 1 + x/2 - x^2/8. Ошибка оценивается через остаточный член. Формула позволяет находить пределы (например, lim(x→0) (sin x - x)/x^3 = -1/6) и приближённые значения функций с любой точностью. Формула Маклорена широко применяется в численных методах, физике (разложение потенциалов), теории вероятностей (аппроксимация распределений) и анализе. Она тесно связана с формулой Эйлера e^(ix) = cos x + i sin x, которая получается подстановкой ix в разложение e^x. Формула Муавра (cos x + i sin x)^n = cos(nx) + i sin(nx) следует из свойств экспоненты. Формула Эйлера для тригонометрии связывает тригонометрические функции с экспонентой, а Теорема Ферма и Формула сложного радикала относятся к другим разделам анализа.
