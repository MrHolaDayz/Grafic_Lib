основной текст
Определение и основные Формулы. Формулы через тангенс половинного угла (универсальная тригонометрическая подстановка) позволяют заменить тригонометрические функции от угла α на рациональные выражения от переменной t = tg(α/2). Основные формулы: sin α = 2t/(1 + t^2), cos α = (1 - t^2)/(1 + t^2), tg α = 2t/(1 - t^2). Эти равенства справедливы для всех углов, где знаменатели не обращаются в ноль (α ≠ π + 2πk для tg α, α ≠ π + 2πk для cos α). Вывод основан на формулах двойного угла: sin α = 2 sin(α/2) cos(α/2), cos α = cos^2(α/2) - sin^2(α/2), после деления на cos^2(α/2) (при cos(α/2) ≠ 0) и замены tg(α/2) = t. Свойства и примеры. Главное свойство — сведение тригонометрических уравнений к алгебраическим, что упрощает их решение. Например, уравнение sin x + cos x = 1 после подстановки t = tg(x/2) превращается в (2t)/(1+t^2) + (1-t^2)/(1+t^2) = 1, что приводит к квадратному уравнению 2t + 1 - t^2 = 1 + t^2, или 2t - 2t^2 = 0, откуда t = 0 или t = 1. Возвращаясь к x, получаем x/2 = πk или x/2 = π/4 + πk, то есть x = 2πk или x = π/2 + 2πk. Однако важно помнить об ограничениях: подстановка теряет углы, где cos(x/2) = 0 (x = π + 2πk), которые нужно проверять отдельно. Где применяется, связь с другими темами.
