Алгоритм Евклида — это эффективный метод нахождения наибольшего общего делителя (НОД) двух целых чисел, основанный на последовательном делении с остатком.

основной текст
Алгоритм Евклида базируется на свойстве: НОД(a, b) = НОД(b, a mod b), где a mod b — остаток от деления a на b. Для натуральных чисел a и b (a ≥ b) процесс выглядит так: a = b * q1 + r1, затем b = r1 * q2 + r2, и так далее, пока остаток не станет нулевым. Последний ненулевой остаток и есть НОД(a, b). Формально: если r0 = a, r1 = b, то r_{i-1} = r_i * q_i + r_{i+1}, где 0 ≤ r_{i+1} < r_i. Алгоритм завершается, когда r_{k+1} = 0, и тогда НОД(a, b) = r_k. Основное свойство алгоритма — его скорость: количество шагов не превышает пятикратного числа цифр меньшего числа. Пример: найти НОД(252, 105). 252 = 105 * 2 + 42, 105 = 42 * 2 + 21, 42 = 21 * 2 + 0 → НОД = 21. Алгоритм легко расширяется на случай нескольких чисел и используется в расширенной версии для нахождения коэффициентов x, y таких, что ax + by = НОД(a, b). Алгоритм Евклида является фундаментом для многих разделов теории чисел. Он применяется для проверки взаимной простоты чисел (если НОД = 1), что напрямую связано с простыми числами. В криптографии расширенный алгоритм используется для нахождения обратного элемента по модулю, что необходимо в Китайской теореме об остатках. Также алгоритм лежит в основе вычисления функции Эйлера φ(n) через разложение на простые множители, где предварительно находится НОД для проверки взаимной простоты. Связь с другими темами: Простые числа — проверка взаимной простоты; Китайская теорема об остатках — нахождение обратных элементов; Функция Эйлера — вычисление количества взаимно простых чисел. Важно не путать с аксиомой параллельности Евклида или признаками делимости на 2, которые относятся к другим разделам математики.
