Координаты точки деления отрезка — это формулы, позволяющие найти координаты точки, которая делит отрезок в заданном отношении (внутренним или внешним образом) на основе известных координат его концов.

основной текст
Координаты точки деления отрезка определяются с помощью формул, основанных на принципе подобия векторов. Пусть даны точки A(x1, y1, z1) и B(x2, y2, z2). Если точка M(x, y, z) делит отрезок AB в отношении λ = AM / MB (где λ > 0 для внутреннего деления, λ ≠ -1), то её координаты вычисляются так: x = (x1 + λ·x2) / (1 + λ), y = (y1 + λ·y2) / (1 + λ), z = (z1 + λ·z2) / (1 + λ). Для деления пополам (λ = 1) получаются формулы середины отрезка: x = (x1 + x2)/2, y = (y1 + y2)/2, z = (z1 + z2)/2. В случае внешнего деления (когда точка лежит на продолжении отрезка) λ становится отрицательным, но формула остаётся применимой, если знаменатель не равен нулю. Свойства этих формул вытекают из линейности координат: точка деления единственна для заданного отношения, а при изменении знака λ точка перемещается на противоположную сторону отрезка. Пример: даны A(1, 2, 3) и B(4, 6, 8). Точка, делящая отрезок в отношении 2:1 от A к B, имеет координаты: x = (1 + 2·4)/3 = 3, y = (2 + 2·6)/3 = 14/3 ≈ 4.67, z = (3 + 2·8)/3 = 19/3 ≈ 6.33. Если же λ = -2 (внешнее деление), то x = (1 - 2·4)/(-1) = 7, y = (2 - 2·6)/(-1) = 10, z = (3 - 2·8)/(-1) = 13. Координаты точки деления применяются для нахождения центроидов треугольников и тетраэдров, в задачах на нахождение точек пересечения прямой с плоскостью (через параметрическое задание прямой), а также в компьютерной графике для интерполяции. Эта тема тесно связана с координатами вектора, так как отношение деления можно выразить через коллине
