Наклонная асимптота — это прямая вида y = kx + b, к которой неограниченно приближается график функции при x → +∞ или x → -∞, не пересекая её на бесконечности.

основной текст
Наклонная асимптота определяется уравнением y = kx + b, где угловой коэффициент k и свободный член b находятся по формулам: k = lim_{x→∞} f(x)/x (при условии, что предел существует и не равен 0 или ∞), затем b = lim_{x→∞} (f(x) - kx). Если k = 0, асимптота называется горизонтальной; если же предел для k не существует или равен ∞, наклонной асимптоты нет. Аналогично рассматривается предел при x → -∞, причём значения k и b могут различаться для разных направлений. Основное свойство наклонной асимптоты — расстояние от точки графика до прямой стремится к нулю при удалении аргумента в бесконечность. Пример: для функции f(x) = (x^2 + 1)/x при x → ∞ получаем k = 1, b = 0, то есть асимптота y = x. Другой пример — функция f(x) = √(x^2 + 1) + x: здесь k = 2, b = 0 при x → +∞, но при x → -∞ асимптота будет y = 0 (горизонтальная). Важно проверять оба направления, так как асимптоты могут быть разными. Наклонные асимптоты широко применяются в исследовании функций и построении графиков, особенно для рациональных и иррациональных функций. Эта тема тесно связана с понятием предела последовательности, так как вычисление k и b сводится к нахождению пределов. Определение предела на языке ε-N используется для строгого доказательства существования асимптоты: для любого ε > 0 найдётся N, такое что для всех |x| > N выполняется |f(x) - (kx + b)| < ε. Кроме того, Асимптоты гиперболы (например, y = 1/x) являются частным случаем наклонных асимптот, а сходящиеся и раСходящиеся последовательности помогают анализировать поведение функции на бесконечности.
