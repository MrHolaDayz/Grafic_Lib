основной текст
Сдвиг графика (параллельный перенос) — это операция, при которой каждой точке исходного графика функции y = f(x) ставится в соответствие точка, смещенная на постоянную величину вдоль одной из осей. Вертикальный сдвиг задается формулой y = f(x) + a: если a > 0, график смещается вверх на a единиц; если a < 0 — вниз. Горизонтальный сдвиг описывается формулой y = f(x - b): при b > 0 график сдвигается вправо на b единиц, при b < 0 — влево. В общем случае можно комбинировать оба сдвига: y = f(x - b) + a. Свойства сдвига: форма графика не изменяется, изменяется только его положение. Например, для линейной функции y = kx сдвиг вверх на 3 дает y = kx + 3, что соответствует параллельной прямой. Для квадратичной функции y = x^2 сдвиг вправо на 2 и вверх на 1 дает y = (x - 2)^2 + 1 — вершина параболы перемещается в точку (2; 1). Для степенной функции y = x^3 сдвиг влево на 1 дает y = (x + 1)^3. Сдвиги часто используются для построения графиков сложных функций на основе простых. Сдвиг графика широко применяется в физике (описание движения с начальным смещением), экономике (модели спроса и предложения), а также в компьютерной графике. Тесно связан с другими преобразованиями: растяжением/сжатием и отражением. Понимание сдвига необходимо для изучения всех базовых функций: линейной (y = kx + b), квадратичной (y = a(x - p)^2 + q), степенной (y = a(x - c)^n + d) и обратной пропорциональности (y = k/(x - m) + n).
