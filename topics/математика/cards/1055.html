основной текст
Нулевая матрица — это матрица любого размера m×n, каждый элемент которой равен нулю: O = [0] (где 0 на всех позициях). Формально, для матрицы A = [a_ij] размера m×n нулевая матрица O удовлетворяет условию: a_ij = 0 для всех i = 1,...,m и j = 1,...,n. Обозначается она часто как 0_m×n или просто 0, если размер ясен из контекста. Нулевая матрица может быть как прямоугольной, так и квадратной (например, 0_2×2 = [[0, 0], [0, 0]]). Основные свойства нулевой матрицы: она является нейтральным элементом относительно сложения матриц, то есть A + 0 = 0 + A = A для любой матрицы A того же размера. При умножении на любую матрицу (согласованного размера) нулевая матрица даёт нулевую матрицу: A * 0 = 0 и 0 * A = 0. Важно отметить, что нулевая матрица не является единичной (которая содержит единицы на диагонали) и не является обратимой (её определитель равен нулю). Пример: для матрицы B = [[1, 2], [3, 4]] имеем B + 0_2×2 = [[1, 2], [3, 4]]. Нулевая матрица применяется в решении систем линейных уравнений (как тривиальный случай), в теории линейных операторов (нулевой оператор), а также при доказательстве свойств матричных пространств. Она тесно связана с определением матрицы как таблицы чисел, видами матриц (например, Квадратная матрица нулевого размера — частный случай), и противопоставляется единичной матрице, которая играет роль мультипликативного нейтрального элемента. В контексте диагональной матрицы, нулевая матрица — это Диагональная матрица с нулями на главной диагонали.
