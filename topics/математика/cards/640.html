График арккотангенса (y = arcctg x) — это кривая, обратная ветви котангенса на интервале (0, π), представляющая собой убывающую линию, проходящую через точку (0, π/2) и имеющую горизонтальные асимптоты y = 0 и y = π.

основной текст
Определение и основные формулы. Арккотангенс — это функция, обратная котангенсу, то есть y = arcctg x, если ctg y = x и y ∈ (0, π). Для построения графика нужно взять ветвь котангенса на интервале (0, π) и отразить её относительно прямой y = x. Полученная кривая проходит через точки: при x = 0, y = π/2; при x → +∞, y → 0; при x → −∞, y → π. Основные формулы: arcctg x = π/2 − arctg x, arcctg(−x) = π − arcctg x (для x ∈ R). Свойства и примеры. Функция y = arcctg x определена на всей числовой прямой (−∞, +∞), её область значений — интервал (0, π). Она строго убывает и непрерывна. График симметричен относительно точки (0, π/2): arcctg(−x) + arcctg x = π. Пример: arcctg(1) = π/4, arcctg(0) = π/2, arcctg(−1) = 3π/4. В отличие от арктангенса, арккотангенс не является нечётной функцией. Где применяется, связь с другими темами. График арккотангенса используется в тригонометрических уравнениях (например, для решения ctg x = a), в геометрии при вычислении углов, а также в физике и инженерии (например, в задачах с фазовыми сдвигами). Понимание этого графика тесно связано с изучением Графика Арксинуса и Графика Арккосинуса, так как все обратные тригонометрические функции имеют схожие принципы построения через отражение.
