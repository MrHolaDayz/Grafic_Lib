основной текст
Внешний угол треугольника — это угол, образованный одной стороной треугольника и продолжением другой его стороны. Основное свойство внешнего угла формулируется так: внешний угол треугольника равен сумме двух внутренних углов, не смежных с ним. Если обозначить внутренние углы треугольника как A, B и C, а внешний угол при вершине C — как d, то верно равенство: d = A + B. Кроме того, внешний угол всегда больше любого из внутренних углов, не смежных с ним (d > A и d > B). Данное свойство является прямым следствием теоремы о сумме углов треугольника (A + B + C = 180^). Поскольку смежный с внешним углом внутренний угол C дополняет его до 180^ (d + C = 180^), то, вычитая из равенства A + B + C = 180^ равенство d + C = 180^, получаем d = A + B. Пример: в треугольнике с углами 30^, 60^ и 90^ внешний угол при вершине с углом 90^ будет равен 30^ + 60^ = 90^. Свойство внешнего угла широко применяется для нахождения неизвестных углов в треугольниках, доказательства других геометрических теорем (например, неравенства треугольника), а также в задачах на построение и вычисление. Оно тесно связано с темой «Виды треугольников»: в остроугольном, прямоугольном и тупоугольном треугольниках это свойство выполняется одинаково, но значения внешних углов различаются. Также свойство внешнего угла перекликается с «Характеристическим свойством» (как свойство, однозначно определяющее взаимосвязь углов) и с «Основным свойством дроби» (через пропорции и отношения, возникающие при вычислениях).
