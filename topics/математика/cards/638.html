Арктангенс — обратная тригонометрическая функция к тангенсу, которая возвращает угол, тангенс которого равен заданному числу. Основные свойства включают нечётность, монотонность и формулы для суммы и разности арктангенсов.

основной текст
Арктангенс (arctg x или arctan x) определяется как функция, обратная тангенсу на интервале (-π/2; π/2). Основные формулы: arctg(-x) = -arctg x (нечётность), arctg x + arctg y = arctg((x+y)/(1-xy)) + kπ, где k = 0 при xy < 1, k = 1 при x>0, xy > 1, и k = -1 при x<0, xy > 1. Также важна формула arctg x + arctg(1/x) = π/2 для x > 0, и arctg x - π/2 для x < 0. Для отрицательных чисел: arctg(-x) = -arctg x. Свойства арктангенса включают его область определения (все действительные числа) и область значений (-π/2; π/2). Функция является строго возрастающей, непрерывной и дифференцируемой. Производная: (arctg x)' = 1/(1+x^2). Интеграл: ∫ arctg x dx = x·arctg x - 1/2·ln(1+x^2) + C. Пример: arctg 1 = π/4, arctg 0 = 0. При решении уравнений вида tg x = a используется arctg a, что даёт x = arctg a + πn, n ∈ Z. Арктангенс широко применяется в геометрии для нахождения углов по координатам (например, в полярной системе координат), в физике (расчет фазовых углов), в комплексном анализе (аргумент комплексного числа) и в интегральном исчислении. Связь с другими темами проявляется через Свойства сопряженных чисел (арктангенс комплексно-сопряжённого числа), Свойства модуля (|arctg x| ≤ π/2) и Свойства транспонирования (в матричных вычислениях арктангенс от матрицы). Также арктангенс связан с другими обратными функциями: arctg x = π/2 - arcctg x.
