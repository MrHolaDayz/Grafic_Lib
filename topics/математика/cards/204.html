основной текст
Определитель (детерминант) квадратной матрицы A размера n x n — это скалярная функция её элементов, обозначаемая det(A) или |A|. Для матрицы 2x2 определитель вычисляется по формуле det(A) = a11*a22 - a12*a21. Для матрицы 3x3 используется правило Саррюса или разложение по строке: det(A) = a11*det(A11) - a12*det(A12) + a13*det(A13), где A1j — миноры (определители подматриц). В общем случае определитель n-го порядка находится через разложение по строке или столбцу, а также через формулу Лейбница, включающую сумму по всем перестановкам. Важнейшие свойства определителя: он меняет знак при перестановке двух строк (или столбцов); если матрица имеет две одинаковые строки, её определитель равен нулю; умножение одной строки на число λ умножает определитель на λ; определитель суммы матриц не равен сумме определителей, но определитель произведения равен произведению определителей: det(A*B) = det(A)*det(B). Также определитель треугольной матрицы равен произведению её диагональных элементов. Пример: для матрицы A = [[2, 3], [1, 4]] det(A) = 2*4 - 3*1 = 8 - 3 = 5. Определитель широко применяется в решении систем линейных уравнений (правило Крамера), в вычислении обратной матрицы, в анализе линейных преобразований (объём параллелепипеда), в дифференциальных уравнениях (определитель Вронского) и в экономике (модель Леонтьева). Связанные темы включают Определение матрицы (определитель существует только для квадратных матриц), Умножение матрицы на число (свойство умножения строки), Определитель квадратной матрицы (основа для вычисления ранга и следа). Ранг матрицы, например, — это максимальный порядок ненулевого минора (определителя подматрицы), а след — сумма диагональных элементов, не связанный напрямую с определителем, но используемый в характеристическом многочлене.
