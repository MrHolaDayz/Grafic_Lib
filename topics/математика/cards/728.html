основной текст
Производная суммы — одно из фундаментальных правил дифференцирования, которое гласит: если функции u(x) и v(x) дифференцируемы в точке x, то производная их суммы равна сумме производных: (u + v)' = u' + v'. Это правило обобщается на любое конечное число слагаемых: (f1 + f2 + ... + fn)' = f1' + f2' + ... + fn'. Например, для функции y = x^2 + √x + 5 производная равна y' = 2x + 1/(2√x) + 0. Данное свойство вытекает из линейности производной и позволяет упрощать вычисления. Например, для нахождения производной многочлена достаточно продифференцировать каждый член по отдельности: (3x^3 - 2x^2 + x - 7)' = 9x^2 - 4x + 1. Правило производной суммы работает вместе с правилом производной произведения и частного, образуя основу техники дифференцирования. Правило широко применяется в физике (скорость как производная пути, сумма скоростей), экономике (предельные издержки как сумма предельных издержек по ресурсам) и в математическом анализе при исследовании функций. Оно тесно связано с другими темами: если рассматривать Квадрат суммы (a + b)^2 = a^2 + 2ab + b^2, то производная от такого выражения вычисляется именно через производную суммы. Аналогично, Куб суммы (a + b)^3 и Квадрат суммы трех слагаемых (a + b + c)^2 дифференцируются по этому же правилу, что существенно упрощает нахождение производных сложных полиномиальных выражений. Производная суммы является частным случаем линейности дифференцирования и служит основой для изучения более сложных правил, таких как производная произведения и частного. Без этого правила было бы невозможно эффективно дифференцировать функции, представленные в виде суммы элементарных составляющих, включая тригонометрические функции (например, Синус суммы и Косинус суммы), где правило суммы применяется после использования формул приведения.
