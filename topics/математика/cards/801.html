Длина дуги кривой — это расстояние между двумя её точками, измеренное вдоль самой кривой. Она вычисляется с помощью определённого интеграла, который суммирует бесконечно малые отрезки на кривой.

основной текст
Длина дуги кривой определяется как предел суммы длин ломаных линий, вписанных в кривую, при стремлении звеньев ломаной к нулю. Для плоской кривой, заданной явно функцией y = f(x) на отрезке [a, b], длина дуги L вычисляется по формуле: L = ∫_a^b √(1 + (f'(x))^2) dx. Если кривая задана параметрически (x = x(t), y = y(t), t ∈ [α, β]), то формула принимает вид: L = ∫_α^β √((x'(t))^2 + (y'(t))^2) dt. Для кривой в полярных координатах r = r(θ) используется формула: L = ∫_θ1^θ2 √(r^2 + (r'(θ))^2) dθ. Основным свойством длины дуги является её аддитивность: длина всей кривой равна сумме длин её непересекающихся частей. Например, длина дуги окружности радиуса R для центрального угла φ (в радианах) равна Rφ — это частный случай общей формулы. Длина дуги не зависит от параметризации кривой, если она гладкая. Для отрезка прямой между точками (x1, y1) и (x2, y2) формула упрощается до длины отрезка: √((x2-x1)^2 + (y2-y1)^2), что согласуется с теоремой Пифагора. Понятие длины дуги широко применяется в физике (например, для вычисления пути при движении по криволинейной траектории), в геометрии (для нахождения периметров криволинейных фигур) и в инженерии (при расчёте длины проводов, труб или дорог). Связанные темы: Длина вектора используется для нахождения длины касательной или радиуса кривизны. Общее уравнение кривой второго порядка (эллипса, гиперболы, параболы) позволяет вычислить длину их дуг через эллиптические интегралы. Длина отрезка является простейшим случаем длины дуги для прямой линии. Градусная мера дуги связывает длину дуги окружности с углом.
