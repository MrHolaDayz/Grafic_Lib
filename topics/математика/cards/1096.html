основной текст
Линейная независимость — фундаментальное понятие линейной алгебры. Набор векторов {v1, v2, ..., vk} в векторном пространстве называется линейно независимым, если уравнение c1*v1 + c2*v2 + ... + ck*vk = 0 (где 0 — нулевой вектор) имеет единственное решение: c1 = c2 = ... = ck = 0. Если существует хотя бы один ненулевой набор коэффициентов, удовлетворяющий этому уравнению, векторы называются линейно зависимыми. Эквивалентное определение: векторы линейно независимы, если ни один из них не является линейной комбинацией остальных. Основные свойства: любой набор, содержащий нулевой вектор, линейно зависим; один ненулевой вектор всегда линейно независим; два вектора линейно зависимы тогда и только тогда, когда они коллинеарны (один является скалярным кратным другого). Пример: в пространстве R^3 векторы (1,0,0), (0,1,0) и (0,0,1) линейно независимы, так как их линейная комбинация даёт ноль только при нулевых коэффициентах. Векторы (1,2), (2,4) линейно зависимы, так как (2,4) = 2*(1,2). Понятие линейной независимости тесно связано с другими темами. Максимальная линейно независимая система векторов образует Базис векторного пространства. Количество векторов в таком базисе определяет Размерность пространства. Линейная независимость используется для проверки, образуют ли данные векторы базис, для нахождения координат вектора в заданном базисе, а также в задачах на построение подпространств и их пересечений. На практике свойство независимости применяется в криптографии, теории кодирования и численных методах (например, при решении систем линейных уравнений методом Гаусса).
