основной текст
Описанный четырехугольник — это выпуклый четырехугольник, в который можно вписать окружность, то есть окружность, касающуюся всех четырех его сторон. Центр вписанной окружности находится в точке пересечения биссектрис всех углов четырехугольника. Главное необходимое и достаточное условие для существования вписанной окружности: суммы длин противоположных сторон должны быть равны: a + c = b + d, где a, b, c, d — стороны в порядке обхода. Радиус r вписанной окружности можно найти через площадь S и полупериметр p: r = S / p, где p = (a + b + c + d) / 2. Свойства описанных четырехугольников: в любой описанный четырехугольник можно вписать окружность, и обратно — если суммы противоположных сторон равны, то четырехугольник является описанным. Примеры: ромб, квадрат (частные случаи, где a = b = c = d), а также дельтоид. Для Прямоугольника условие a + c = b + d выполняется только если он является квадратом, так как у прямоугольника a = c, b = d, и равенство a + a = b + b дает a = b. Таким образом, не каждый Параллелограмм является описанным — только ромб. Данная тема тесно связана с параллелограммом, его признаками и свойствами. Например, если параллелограмм является описанным, то он обязательно ромб (все стороны равны). Признаки параллелограмма (равенство и параллельность сторон) помогают доказывать, что фигура является параллелограммом, а затем проверять условие описанности. Свойства параллелограмма (например, диагонали точкой пересечения делятся пополам) используются при вычислении площадей и радиусов вписанных окружностей. Тема также применяется в задачах на построение, в тригонометрии и при решении геометрических неравенств.
