основной текст
Определение предела по Коши (также называемое определением на языке ε-δ) является фундаментальным понятием математического анализа. Формально: число A называется пределом функции f(x) в точке a, если для любого ε > 0 существует δ > 0 такое, что для всех x, удовлетворяющих условию 0 < |x - a| < δ, выполняется неравенство |f(x) - A| < ε. Это определение записывается как lim_{x→a} f(x) = A. Ключевая идея заключается в том, что мы можем сделать значение функции сколь угодно близким к A, выбрав x достаточно близко к a, но не равным a. Основные свойства предела по Коши включают: единственность предела (если предел существует, то он единственен), арифметические свойства (предел суммы, произведения и частного функций равен сумме, произведению и частному их пределов при условии, что знаменатель не равен нулю), а также теорему о двух милиционерах (если g(x) ≤ f(x) ≤ h(x) и lim g(x) = lim h(x) = A, то lim f(x) = A). Пример: докажем, что lim_{x→2} (3x - 1) = 5. Для любого ε > 0 выберем δ = ε/3. Тогда если 0 < |x - 2| < δ, то |(3x - 1) - 5| = 3|x - 2| < 3δ = ε. Определение предела по Коши широко применяется для строгого обоснования непрерывности функций, дифференцируемости и сходимости рядов. Оно тесно связано с понятием неравенства Коши (например, Неравенство Коши-Буняковского), которое часто используется для оценки расстояний в анализе. В отличие от этого, темы "Определение матрицы", "Разложение по строке" и "Разложение по столбцу" относятся к линейной алгебре и не имеют прямого отношения к пределам, однако они могут применяться в численных методах при вычислении пределов с помощью матричных преобразований.
