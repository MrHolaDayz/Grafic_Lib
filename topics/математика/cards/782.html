основной текст
Формула интегрирования по частям выводится из правила дифференцирования произведения: d(uv) = u dv + v du. Интегрируя обе части, получаем основную формулу: ∫ u dv = uv - ∫ v du. Здесь u = u(x) и v = v(x) — дифференцируемые функции. Для определенного интеграла формула принимает вид: ∫_a^b u dv = uv|_a^b - ∫_a^b v du. Ключевой момент — правильный выбор u и dv, обычно u выбирают так, чтобы её производная была проще, а dv — легко интегрируемым. Свойства метода: он эффективен для интегралов, содержащих произведение функций, например, степенной и показательной, логарифмической или тригонометрической. Пример: ∫ x e^x dx. Положим u = x, dv = e^x dx, тогда du = dx, v = e^x. По формуле: ∫ x e^x dx = x e^x - ∫ e^x dx = x e^x - e^x + C. Другой пример: ∫ ln x dx. Берем u = ln x, dv = dx, получаем du = (1/x) dx, v = x, тогда ∫ ln x dx = x ln x - ∫ x * (1/x) dx = x ln x - x + C. В некоторых случаях метод применяется повторно. Формула интегрирования по частям широко применяется в математическом анализе, физике и инженерии для вычисления интегралов от логарифмов, обратных тригонометрических функций, а также в выводе рекуррентных соотношений. Она связана с другими темами: например, при выводе Формулы Эйлера e^{ix} = cos x + i sin x через интегрирование по частям получают интегралы от экспонент и тригонометрических функций. Формула Муавра (cos x + i sin x)^n = cos(nx) + i sin(nx) также использует подобные интегралы. Формула Эйлера для тригонометрии, выражающая sin и cos через экспоненты, может быть проинтегрирована по частям для нахождения первообразных. Кроме того, метод применяется в разложении по строке или столбцу при интегрировании матричных функций, хотя это более узкая тема.
