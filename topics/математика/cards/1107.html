Длина (модуль) вектора — это неотрицательное число, равное расстоянию между началом и концом вектора. Она показывает, насколько далеко точка «уходит» от начала координат или от начальной точки вектора.

основной текст
Длина Вектора (или его модуль) определяется как расстояние между его началом и концом. Если вектор задан координатами на плоскости: a = {x; y}, то его длина вычисляется по формуле: |a| = √(x^2 + y^2). В пространстве для вектора a = {x; y; z} формула принимает вид: |a| = √(x^2 + y^2 + z^2). Если вектор задан двумя точками A(x1; y1) и B(x2; y2), то длина вектора AB равна √((x2 - x1)^2 + (y2 - y1)^2). Основные свойства длины вектора: длина любого вектора неотрицательна (|a| ≥ 0), и равна нулю только для нулевого вектора. При умножении вектора на число k его длина умножается на |k|: |k * a| = |k| * |a|. Длина суммы векторов не равна сумме длин (кроме случая, когда векторы сонаправлены), для неё выполняется неравенство треугольника: |a + b| ≤ |a| + |b|. Пример: для вектора a = {3; 4} длина равна √(3^2 + 4^2) = √25 = 5. Понятие длины вектора является основой для вычисления расстояний в геометрии и физике (например, расстояние между точками, модуль скорости или силы). Оно тесно связано с координатами вектора, так как именно через координаты удобно находить длину. Также длина используется при сложении и вычитании векторов для проверки правильности построений и в правиле параллелограмма. Понимание длины необходимо для дальнейшего изучения скалярного произведения и угла между векторами.
