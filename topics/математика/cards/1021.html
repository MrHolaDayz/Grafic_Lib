Сопряженные числа — это пара комплексных чисел a+bi и a-bi, которые отличаются знаком мнимой части. Основные свойства сопряженных чисел включают: сумма сопряженных равна удвоенной действительной части, произведение — квадрату модуля, а сопряжение суммы/произведения равно сумме/произведению сопряженных.

основной текст
Сопряженным числом для комплексного числа z = a + bi (где a и b — действительные числа, i — Мнимая единица, i^2 = -1) называется число z̄ = a - bi. Основные формулы: z + z̄ = 2a (удвоенная Действительная часть), z - z̄ = 2bi (удвоенная Мнимая часть, умноженная на i), z * z̄ = a^2 + b^2 = |z|^2 (квадрат модуля). Также важно свойство: (z1 ± z2)̄ = z̄1 ± z̄2, (z1 * z2)̄ = z̄1 * z̄2, (z1 / z2)̄ = z̄1 / z̄2 (при z2 ≠ 0). Свойства сопряженных чисел широко используются для упрощения выражений с комплексными числами. Например, чтобы найти действительную и мнимую части дроби (1+2i)/(3-4i), умножают числитель и знаменатель на сопряженное знаменателя: (1+2i)(3+4i)/((3-4i)(3+4i)) = (3+4i+6i+8i^2)/(9+16) = (-5+10i)/25 = -0.2 + 0.4i. Другое применение — доказательство того, что корни многочлена с действительными коэффициентами образуют сопряженные пары. Также сопряжение сохраняет модуль: |z̄| = |z|, и геометрически отражает точку относительно действительной оси на комплексной плоскости. Применение свойств сопряженных чисел охватывает алгебру, анализ и физику. В электротехнике они используются для расчета импедансов цепей переменного тока, в квантовой механике — для нахождения вероятностей (через квадрат модуля волновой функции).
