основной текст
Классическое определение вероятности вводится для экспериментов с конечным числом равновозможных исходов. Пусть пространство элементарных исходов Ω содержит n равновозможных исходов. Вероятность события A, состоящего из m благоприятных исходов, вычисляется по формуле: P(A) = m / n. Например, при бросании правильной монеты вероятность выпадения орла равна 1/2, так как всего два равновозможных исхода, из которых один благоприятный. Основные свойства классической вероятности: 0 ≤ P(A) ≤ 1, вероятность достоверного события равна 1, вероятность невозможного события равна 0. Для несовместных событий выполняется правило сложения: P(A ∪ B) = P(A) + P(B). Пример: при бросании игрального кубика вероятность выпадения числа больше 4 равна 2/6 = 1/3, так как благоприятны исходы 5 и 6 из шести равновозможных. Классическое определение применяется в задачах с симметричными исходами: азартные игры, лотереи, контроль качества, простая выборка. Оно является основой для геометрического и статистического определений вероятности. Связь с другими темами: в отличие от Определения матрицы, которое описывает таблицу чисел, и Определения логарифма как обратной операции возведения в степень, классическая вероятность оперирует отношениями количества исходов. С Определением предела на языке ε-N её роднит строгость формализации: и там, и там задаются точные условия для вычисления величины. В более сложных задачах, где число исходов бесконечно, классическое определение уступает место аксиоматическому подходу.
