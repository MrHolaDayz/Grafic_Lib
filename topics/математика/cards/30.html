основной текст
Периодическая дробь — это форма записи рационального числа в виде бесконечной десятичной дроби, где начиная с некоторого разряда определённая группа цифр (период) повторяется. Различают чистые периодические дроби, у которых период начинается сразу после запятой (например, 0,(3) = 1/3), и смешанные, у которых между запятой и периодом есть одна или несколько неповторяющихся цифр (например, 0,1(6) = 1/6). Для перевода обыкновенной дроби в периодическую достаточно разделить числитель на знаменатель; если в разложении знаменателя на простые множители есть числа, отличные от 2 и 5, то дробь будет периодической. Обратный переход осуществляется по правилу: для чистой периодической дроби в числитель записывают период, а в знаменатель — число из девяток по количеству цифр в периоде; для смешанной — из числа, образованного всеми цифрами до конца периода, вычитают число до периода, а в знаменатель ставят число из девяток по количеству цифр периода и нулей по количеству цифр до периода. Основное свойство периодических дробей — они всегда представляют рациональные числа, то есть могут быть записаны в виде обыкновенной дроби a/b, где a и b — целые числа, b ≠ 0. Например, 0,(142857) = 1/7, 0,0(9) = 1/10. Важно отметить, что любая конечная десятичная дробь может быть представлена как периодическая с периодом 0 (например, 0,5 = 0,5(0)), однако по соглашению период 0 обычно не записывают. Также существует редкий случай, когда период состоит из девятки: 0,(9) = 1, что следует из равенства 0,(9) = 9/9 = 1. Периодические дроби широко применяются в алгебре при работе с рациональными выражениями, в задачах на проценты и доли, а также в финансовых расчётах, где требуется точное представление дробных чисел.
