Уравнение с угловым коэффициентом — это форма записи прямой на плоскости, имеющая вид y = kx + b, где k — угловой коэффициент (тангенс угла наклона прямой к оси OX), а b — ордината точки пересечения прямой с осью OY.
связанные темы
Общее уравнение Каноническое уравнение Параметрическое уравнение Уравнение в отрезках Угол между прямыми
основной текст
Уравнение с угловым коэффициентом определяется как y = kx + b. Здесь k = tg(α), где α — угол между прямой и положительным направлением оси OX (0 ≤ α < π, α ≠ π/2). Если k > 0, прямая возрастает; если k < 0, прямая убывает; при k = 0 прямая параллельна оси OX. Коэффициент b показывает, в какой точке прямая пересекает ось OY: (0; b). Если прямая проходит через начало координат, то b = 0. Для прямой, параллельной оси OY, уравнение с угловым коэффициентом неприменимо, так как k не определен (α = π/2). В этом случае используется уравнение вида x = a. Основные свойства: угловой коэффициент k равен отношению приращения y к приращению x: k = (y₂ - y₁) / (x₂ - x₁) для любых двух точек прямой. Пример: прямая, проходящая через точки (1; 2) и (3; 6), имеет k = (6 - 2) / (3 - 1) = 4/2 = 2. Подставив точку (1; 2) в y = 2x + b, получим 2 = 2·1 + b, откуда b = 0. Итоговое уравнение: y = 2x. Если дана прямая y = -3x + 5, то она пересекает ось OY в точке (0; 5) и наклонена вниз под углом, тангенс которого равен -3. Уравнение с угловым коэффициентом широко применяется в физике (например, для описания линейной зависимости скорости от времени при равноускоренном движении), в экономике (линейные функции спроса и предложения), а также при анализе графиков функций. Эта форма тесно связана с другими представлениями прямой: Общее уравнение (Ax + By + C = 0) легко преобразуется в y = kx + b, если B ≠ 0; Каноническое уравнение (x - x₀)/m = (y - y₀)/n позволяет найти k = n/m; Параметрическое уравнение (x = x₀ + mt, y = y₀ + nt) также выражает угловой коэффициент как n/m.
