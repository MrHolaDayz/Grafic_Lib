Производная сложной функции — это правило дифференцирования, позволяющее найти производную функции, аргументом которой является другая функция. Оно выражается формулой f(g(x))' = f'(g(x)) * g'(x).

основной текст
Производная сложной функции (правило цепочки) определяется следующим образом: если дана функция y = f(u), где u = g(x), то производная y по x равна произведению производной f по u и производной g по x: (f(g(x)))' = f'(g(x)) * g'(x). В более компактной записи: dy/dx = (dy/du) * (du/dx). Для степенных функций, если y = (u(x))^n, то y' = n * (u(x))^(n-1) * u'(x). Для корней, например y = √(u(x)), производная равна (1 / (2√(u(x)))) * u'(x). Основные свойства: правило применимо к композиции любого конечного числа функций. Пример: найти производную функции y = sin(x^2). Здесь внешняя функция — синус, внутренняя — x^2. Тогда y' = cos(x^2) * (x^2)' = cos(x^2) * 2x. Другой пример: y = (3x + 1)^5. Тогда y' = 5*(3x + 1)^4 * 3 = 15*(3x + 1)^4. Данное правило широко применяется в физике (например, для нахождения скорости при сложном законе движения), в экономике (предельный анализ сложных зависимостей) и в других разделах математики. Производная сложной функции тесно связана с тригонометрическими функциями (sin, cos, tg и их композиции), а также с обратными тригонометрическими функциями (arcsin, arccos и т.д.), где правило цепочки обязательно для дифференцирования. При нахождении производной важно учитывать Область определения функции, так как внутренняя функция может накладывать ограничения (например, подкоренное выражение должно быть неотрицательным). Также правило помогает находить Нули функции — точки, где производная равна нулю, что критично для исследования монотонности и экстремумов.
