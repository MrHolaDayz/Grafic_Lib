основной текст
Общее уравнение кривой второго порядка в декартовой системе координат записывается как: Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0, где A, B, C, D, E, F — действительные числа, причем A, B, C не равны нулю одновременно. Это уравнение объединяет все типы кривых второго порядка: эллипсы (включая Окружность), гиперболы, параболы, а также вырожденные случаи (точка, две пересекающиеся или параллельные прямые). Для анализа типа кривой используется инвариант — дискриминант Δ = B^2 - 4AC: если Δ < 0 — эллиптический тип, Δ = 0 — параболический, Δ > 0 — гиперболический. Свойства общего уравнения включают возможность приведения к каноническому виду путем поворота и переноса системы координат, что упрощает анализ геометрических характеристик. Например, для окружности A = C ≠ 0, B = 0, и уравнение сводится к (x - x0)^2 + (y - y0)^2 = R^2. Пример: уравнение x^2 + y^2 + 4x - 6y + 9 = 0 после выделения полных квадратов дает (x + 2)^2 + (y - 3)^2 = 4 — окружность с центром (-2; 3) и радиусом 2. Общее уравнение широко применяется в аналитической геометрии, физике (оптика, механика) и компьютерной графике для моделирования траекторий и поверхностей. Связь с другими темами: Отношение порядка помогает классифицировать кривые по типу, Общее решение дифференциальных уравнений часто приводит к таким кривым, а Каноническое уравнение является конечной формой после преобразований. Параметрическое уравнение задает ту же кривую через параметр, а окружность — частный случай эллиптического типа.
