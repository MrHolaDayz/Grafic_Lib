основной текст
Метод Крамера применяется для решения систем n линейных уравнений с n неизвестными вида Ax = b, где A — квадратная матрица. Основная формула: x_i = det(A_i) / det(A), при условии, что det(A) ≠ 0. Здесь A_i — матрица, полученная из A заменой i-го столбца на столбец свободных членов b. Для нахождения определителей обычно используют разложение по строке или столбцу, а для матриц 2×2 и 3×3 — правило треугольников или Саррюса. Например, для системы {2x + 3y = 7; x — y = 1} определитель основной матрицы det(A) = 2*(-1) — 3*1 = -5, det(A_1) = 7*(-1) — 3*1 = -10, откуда x = (-10)/(-5) = 2, y = (2*1 — 7*1)/(-5) = 1. Свойства метода: он даёт явные формулы, удобен для систем с небольшим числом уравнений (до 3-4) и когда определители легко вычисляются. Однако при больших n метод становится громоздким из-за вычисления множества определителей (требуется n+1 определитель порядка n), что приводит к высокой вычислительной сложности. Для неоднородных систем (b ≠ 0) метод применим только при det(A) ≠ 0. Для однородных систем (b = 0) тривиальное решение x = 0 получается, если det(A) ≠ 0; если же det(A) = 0, метод Крамера не работает, и система имеет ненулевые решения. Метод Крамера широко применяется в теоретических исследованиях, например, для доказательства существования решения и вывода формул в линейной алгебре. На практике его используют в задачах с небольшим числом переменных, таких как расчёты в экономике, физике и инженерии (например, нахождение токов в электрических цепях). Связь с другими темами: метод Крамера тесно связан с матричным методом (решение через обратную матрицу: x = A^{-1}b), так как оба требуют невырожденности матрицы.
