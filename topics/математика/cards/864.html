основной текст
Определение и основные формулы. Перестановки с повторениями — это упорядоченные наборы, составленные из n элементов, среди которых есть одинаковые (повторяющиеся). Если имеется k различных типов элементов, причем элемент первого типа встречается n1 раз, второго — n2 раза, …, k-го — nk раз (n1 + n2 + ... + nk = n), то число различных перестановок с повторениями вычисляется по формуле: P_n(n1, n2, …, nk) = n! / (n1! * n2! * … * nk!). Здесь n! — факториал общего числа элементов, а в знаменателе — произведение факториалов количества повторений каждого типа. Эта формула позволяет избежать подсчета одинаковых последовательностей, возникающих из-за неразличимости элементов одного типа. Свойства и примеры. Основное свойство: перестановки с повторениями учитывают мультимножества, где важен только порядок, но не уникальность элементов. Пример: сколько различных слов можно составить из букв слова «МАТЕМАТИКА»? Здесь буквы: М — 2, А — 3, Т — 2, Е — 1, И — 1, К — 1, всего 10 букв. Число перестановок: 10! / (2! * 3! * 2! * 1! * 1! * 1!) = 3628800 / (2 * 6 * 2) = 3628800 / 24 = 151200. Другой пример: сколькими способами можно расставить на полке 3 красные, 2 синие и 1 зеленую книгу (книги одного цвета неразличимы)? Ответ: (3+2+1)! / (3! * 2! * 1!) = 720 / (6 * 2 * 1) = 60. Где применяется, связь с другими темами.
