основной текст
Обратные тригонометрические функции — это семейство функций, обратных к основным тригонометрическим функциям (sin, cos, tg, ctg). Поскольку тригонометрические функции не являются взаимно однозначными на всей области определения, для построения обратных функций выбирают их главные ветви (промежутки монотонности). Основные обозначения: y = arcsin x (область определения: -1 ≤ x ≤ 1, область значений: -π/2 ≤ y ≤ π/2), y = arccos x (область определения: -1 ≤ x ≤ 1, область значений: 0 ≤ y ≤ π), y = arctg x (область определения: все действительные числа, область значений: -π/2 < y < π/2), y = arcctg x (область определения: все действительные числа, область значений: 0 < y < π). Основные формулы: arcsin(-x) = -arcsin x, arccos(-x) = π - arccos x, arctg(-x) = -arctg x, arcctg(-x) = π - arcctg x, а также sin(arcsin x) = x, cos(arccos x) = x, tg(arctg x) = x, ctg(arcctg x) = x. Свойства обратных тригонометрических функций включают монотонность (arcsin и arctg возрастают, arccos и arcctg убывают), нечетность для arcsin и arctg, и ограниченность области значений. Пример: arcsin(1/2) = π/6, arccos(√2/2) = π/4, arctg(1) = π/4. Важно помнить, что главные значения выбираются так, чтобы функция была однозначной. Обратные тригонометрические функции часто используются для решения тригонометрических уравнений (например, sin x = a ⇒ x = (-1)^k arcsin a + πk, k ∈ Z) и в геометрических задачах для нахождения углов по сторонам треугольника.
