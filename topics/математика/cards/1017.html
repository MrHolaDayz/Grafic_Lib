основной текст
Действительная часть комплексного числа z = a + bi, где a и b — вещественные числа, а i — Мнимая единица (i^2 = -1), определяется как Re(z) = a. Например, для z = 5 - 3i, Re(z) = 5; для z = √2 + 0i, Re(z) = √2. Если число задано в тригонометрической форме z = r(cos φ + i sin φ), то Re(z) = r cos φ. Основные свойства: Re(z1 + z2) = Re(z1) + Re(z2) и Re(k·z) = k·Re(z) для любого вещественного k. Однако Re(z1·z2) ≠ Re(z1)·Re(z2). Для сопряженного числа z̅ = a - bi выполняется: Re(z) = (z + z̅)/2. Пример: если z = 3 + 4i, то z̅ = 3 - 4i, и (z + z̅)/2 = (6)/2 = 3 = Re(z). Действительная часть широко применяется в электротехнике (расчет активной мощности), физике (описание колебаний) и анализе сигналов. Она неразрывно связана с понятием комплексного числа: вместе с мнимой частью (Im(z) = b) определяет положение точки на плоскости. Связанные темы: Мнимая единица (i), Степени мнимой единицы (i^1 = i, i^2 = -1, i^3 = -i, i^4 = 1) и Комплексное число как пара (a, b). Равенство комплексных чисел требует равенства как действительных, так и мнимых частей.
