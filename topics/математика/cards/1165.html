Теорема о делении с остатком утверждает, что для любых целых чисел a и b (b ≠ 0) существуют единственные целые числа q и r, такие что a = bq + r, где 0 ≤ r < |b|. Это фундаментальное утверждение в теории чисел, описывающее процесс деления с остатком.

основной текст
Определение и основные формулы: Для любых целых a и ненулевого b существует единственная пара целых чисел q (неполное частное) и r (остаток), удовлетворяющая равенству a = bq + r, при условии 0 ≤ r < |b|. Если r = 0, то a делится на b нацело. В обобщении для многочленов: для любых многочленов P(x) и ненулевого Q(x) существуют единственные многочлены S(x) и R(x), такие что P(x) = Q(x)S(x) + R(x), где степень R(x) меньше степени Q(x). Свойства и примеры: Остаток r всегда неотрицателен и строго меньше модуля делителя. Пример: при делении 17 на 5 получаем 17 = 5·3 + 2, где q=3, r=2. При делении -17 на 5: -17 = 5·(-4) + 3, так как остаток должен быть от 0 до 4. В кольце многочленов деление с остатком позволяет находить корни: если P(a)=0, то P(x) делится на (x-a) без остатка. Где применяется: Теорема лежит в основе алгоритма Евклида для нахождения НОД, систем счисления, теории сравнений и кодирования. В алгебре она используется для разложения многочленов и в доказательстве основной теоремы алгебры (каждый многочлен степени n имеет ровно n комплексных корней с учетом кратности). Связь с теоремой Руше: последняя позволяет оценивать число корней многочлена в области, опираясь на свойства деления. Теорема о ранге в линейной алгебре использует аналогичную идею разложения пространства на прямую сумму ядра и образа. Связанные темы: Основная теорема алгебры гарантирует существование корней, что тесно связано с делением многочленов на линейные множители.
