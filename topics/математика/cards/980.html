Пересечение множеств — это операция, результатом которой является новое множество, состоящее из элементов, принадлежащих одновременно всем исходным множествам.
связанные темы
Объединение Разность Симметрическая разность Дополнение Пустое множество
основной текст
Пересечением множеств A и B (обозначается A ∩ B) называется множество, содержащее те и только те элементы, которые принадлежат и A, и B. Формально: A ∩ B = { x | x ∈ A и x ∈ B }. Если множества заданы характеристическим свойством, то пересечение соответствует логическому «И». Для пустого множества выполняется: A ∩ ∅ = ∅. Если A ⊆ B, то A ∩ B = A. Основные свойства пересечения: коммутативность (A ∩ B = B ∩ A), ассоциативность ((A ∩ B) ∩ C = A ∩ (B ∩ C)) и идемпотентность (A ∩ A = A). Пересечение дистрибутивно относительно объединения: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C). Пример: если A = {1, 2, 3, 4}, B = {3, 4, 5}, то A ∩ B = {3, 4}. Если множества не имеют общих элементов, их пересечение пусто (A ∩ B = ∅), такие множества называют непересекающимися. Пересечение широко применяется в теории вероятностей (вероятность одновременного наступления событий), булевой алгебре (логическое И), базах данных (операция JOIN), а также в анализе данных при поиске общих признаков у объектов. Эта операция тесно связана с Объединением (A ∪ B), Разностью (A \ B — элементы A, не входящие в B) и симметрической разностью (A Δ B = (A \ B) ∪ (B \ A)). Вместе с Дополнением эти операции образуют алгебру множеств.
