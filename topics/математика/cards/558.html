Смешанное произведение векторов — это скаляр, равный объёму параллелепипеда, построенного на трёх векторах, и вычисляемый как определитель их координат. Оно обладает ключевыми свойствами: антисимметрией, линейностью и равенством нулю при компланарности векторов.

основной текст
Смешанное произведение трёх векторов a, b, c определяется как (a × b) · c и обозначается (a, b, c). В координатной форме для векторов a = (x1, y1, z1), b = (x2, y2, z2), c = (x3, y3, z3) оно равно определителю матрицы 3×3: | x1 y1 z1; x2 y2 z2; x3 y3 z3 |. Геометрически модуль смешанного произведения равен объёму параллелепипеда, построенного на этих векторах: V = |(a, b, c)|. Знак произведения указывает на ориентацию тройки векторов (правая или левая). Основные свойства: 1) Антисимметричность (циклическая перестановка не меняет знак, а перестановка двух векторов меняет знак на противоположный): (a, b, c) = (b, c, a) = (c, a, b) = -(b, a, c). 2) Линейность по каждому аргументу: (αa + βa', b, c) = α(a, b, c) + β(a', b, c). 3) Условие компланарности: три вектора компланарны (лежат в одной плоскости) тогда и только тогда, когда их смешанное произведение равно нулю. 4) Связь с определителем: смешанное произведение равно определителю матрицы, составленной из координат векторов, что связывает его со свойствами определителя (например, транспонирование матрицы не меняет определитель, что соответствует свойству (a, b, c) = (a, b, c) при замене строк на столбцы).
