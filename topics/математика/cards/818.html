основной текст
Метод Бернулли применяется к дифференциальным уравнениям вида y' + P(x)y = Q(x)y^n, где n — любое действительное число, не равное 0 или 1. Для решения выполняется замена z = y^(1-n), что позволяет преобразовать исходное уравнение в линейное относительно z: z' + (1-n)P(x)z = (1-n)Q(x). После нахождения общего решения для z производится обратная замена y = z^(1/(1-n)). Основная формула метода выводится через дифференцирование замены: z' = (1-n)y^(-n) y', что подставляется в исходное уравнение. Метод обладает свойством универсальности: он работает как для простых случаев, когда n — целое число, так и для дробных показателей степени. Например, для уравнения y' + y = xy^2 (n=2) замена z = y^(-1) приводит к линейному уравнению z' - z = -x. Решая его методом интегрирующего множителя, получаем z = Ce^x + x + 1, откуда y = 1/(Ce^x + x + 1). Важно помнить, что при n>0 решение y=0 может быть потеряно при делении на y^n. Метод Бернулли широко применяется в физике, биологии и экономике для моделирования процессов с нелинейной динамикой, таких как рост популяций или химические реакции. Он тесно связан с линейными дифференциальными уравнениями, к которым сводится после замены. В отличие от методов линейной алгебры, таких как Метод Крамера, Матричный метод или Метод Гаусса, которые решают системы алгебраических уравнений, метод Бернулли работает с дифференциальными уравнениями. Однако эти темы объединяет общий принцип: сведение сложной задачи к более простой (линейной) форме для нахождения общего решения.
