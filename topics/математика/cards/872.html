Полиномиальная теорема — это обобщение бинома Ньютона на случай разложения степени суммы нескольких слагаемых, позволяющее представить (x1 + x2 + ... + xk)^n в виде суммы одночленов с полиномиальными коэффициентами.

основной текст
Полиномиальная теорема утверждает, что для любого натурального n и любого числа слагаемых k справедливо разложение: (x1 + x2 + ... + xk)^n = Σ (n! / (n1! n2! ... nk!)) * x1^n1 * x2^n2 * ... * xk^nk, где суммирование ведется по всем наборам неотрицательных целых чисел n1, n2, ..., nk, таким что n1 + n2 + ... + nk = n. Коэффициент n! / (n1! n2! ... nk!) называется полиномиальным коэффициентом и обобщает биномиальный коэффициент C(n, m) = n! / (m! (n-m)!). Например, для (a + b + c)^2 получаем: a^2 + b^2 + c^2 + 2ab + 2ac + 2bc, где каждый коэффициент 2 = 2! / (1!1!0!). Основное свойство полиномиальной теоремы — она дает явную формулу для членов разложения, что позволяет вычислять вероятности в мультиномиальных распределениях. Пример: количество способов разделить n различных объектов на k групп заданных размеров n1, n2, ..., nk равно полиномиальному коэффициенту. Теорема тесно связана с комбинаторными тождествами и производящими функциями. Полиномиальная теорема применяется в статистике (мультиномиальное распределение), теории вероятностей, комбинаторике и алгебре. Она обобщает биномиальную теорему и служит основой для доказательства многих комбинаторных формул. Связь с другими темами: Основная теорема алгебры утверждает, что любой многочлен степени n имеет ровно n комплексных корней, что дополняет разложение. Теорема Руше используется для определения числа корней многочлена в области, а Теорема о ранге связана с линейной независимостью систем векторов, что важно при работе с полиномиальными пространствами.
