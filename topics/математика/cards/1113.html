Угол между векторами — это наименьший угол, на который нужно повернуть один вектор, чтобы он совпал по направлению с другим. Он вычисляется через скалярное произведение векторов и их длины.
связанные темы
Переход между формами Вектор Координаты вектора Длина вектора Сложение векторов
основной текст
Угол между двумя ненулевыми Векторами a и b, отложенными от одной точки, определяется как угол φ, где 0 ≤ φ ≤ π. Основная формула для его нахождения использует скалярное произведение: cos φ = (a · b) / (|a| * |b|). В координатной форме для векторов a(x1, y1) и b(x2, y2) на плоскости: cos φ = (x1*x2 + y1*y2) / (√(x1^2 + y1^2) * √(x2^2 + y2^2)). Угол между векторами также можно найти через формулу тангенса, если известны их углы наклона. Свойства угла между векторами: если угол равен 0°, векторы сонаправлены; если 180° — противоположно направлены; если 90° — перпендикулярны (ортогональны). Пример: для векторов a(1, 0) и b(0, 1) cos φ = (1*0 + 0*1) / (1*1) = 0, значит φ = 90°. Угол не зависит от длин векторов, а только от их направления. Понятие угла между векторами широко применяется в геометрии для нахождения проекций, в физике (работа силы, угол между силой и перемещением), в компьютерной графике (освещение, нормали). Оно тесно связано с другими темами: через Координаты вектора вычисляется скалярное произведение, а Длина вектора используется в знаменателе формулы. Переход между формами (геометрической и координатной) позволяет гибко решать задачи, а Сложение векторов помогает визуализировать углы через правило треугольника или параллелограмма.
