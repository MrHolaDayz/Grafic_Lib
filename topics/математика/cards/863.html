основной текст
Перестановка — это комбинаторная конфигурация, представляющая собой любой упорядоченный набор из n различных объектов. Основная формула для подсчета числа перестановок P(n) = n! = 1 * 2 * 3 * ... * n. Например, для трех элементов A, B, C существует 3! = 6 перестановок: ABC, ACB, BAC, BCA, CAB, CBA. В случае, когда некоторые элементы повторяются, используется формула перестановок с повторениями: P(n; k1, k2, ..., km) = n! / (k1! * k2! * ... * km!), где ki — количество повторений i-го типа. Свойства перестановок тесно связаны с правилами комбинаторики. Правило произведения объясняет, почему число перестановок растет как Факториал: на первое место можно поставить n вариантов, на второе — (n-1), и так далее. Перестановки не обладают свойством коммутативности (порядок критичен), а их количество быстро возрастает: 10! = 3 628 800. Пример из жизни: количество способов расставить 5 книг на полке равно 5! = 120. Перестановки широко применяются в теории вероятностей (например, подсчет числа исходов при случайном упорядочивании), в криптографии (шифры перестановки), в задачах оптимизации (задача коммивояжера). Они связаны с двойным факториалом, который используется для подсчета числа перестановок с дополнительными ограничениями (например, разбиение на пары). Правило суммы применяется, когда нужно разбить множество на непересекающиеся группы перестановок. Вместе с правилом произведения и факториалом перестановки образуют фундаментальную основу комбинаторного анализа.
