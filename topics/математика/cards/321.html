основной текст
Теорема Стюарта: Если в треугольнике ABC точка D лежит на стороне BC, причем BD = m, DC = n, а AD = d — чевиана, то выполняется равенство: b^2 * m + c^2 * n = a * (d^2 + m * n), где a = BC = m + n, b = AC, c = AB. В более симметричной форме: b^2 * m + c^2 * n = a * (d^2 + m * n). Часто используется формула: d^2 = (b^2 * m + c^2 * n) / a - m * n. Основное свойство теоремы: она позволяет найти длину чевианы (например, медианы, биссектрисы или высоты) по известным сторонам треугольника и отрезкам основания. Пример: для медианы (m = n = a/2) формула сводится к известному выражению: d^2 = (2b^2 + 2c^2 - a^2) / 4. Для биссектрисы (m : n = c : b) также можно вывести частный случай. Теорема Стюарта широко применяется в планиметрии для решения задач на нахождение неизвестных отрезков в треугольнике, особенно при работе с чевианами. Она связана с теоремой Пифагора (через проекции) и теоремой косинусов, но является более общим инструментом. Теорема полезна при доказательстве других фактов, например, формулы длины биссектрисы или медианы. Связанные темы: нет.
