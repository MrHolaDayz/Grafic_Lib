Формула Герона для четырехугольника — это обобщение классической формулы Герона для треугольника, позволяющее вычислить площадь вписанного в окружность четырехугольника (циклического четырехугольника) по длинам его сторон.

основной текст
Формула Герона для четырехугольника, также известная как формула Брахмагупты, применяется исключительно к циклическим четырехугольникам (тем, которые можно вписать в окружность). Если стороны четырехугольника равны a, b, c, d, а его полупериметр p = (a + b + c + d)/2, то площадь S вычисляется как: S = √((p - a)(p - b)(p - c)(p - d)). В отличие от треугольника, для произвольного четырехугольника этой формулы недостаточно — требуется знать хотя бы один угол или диагональ. Для нециклических четырехугольников существует более общая формула с использованием тригонометрических функций. Основное свойство циклического четырехугольника — сумма противоположных углов равна 180°. Это позволяет вывести формулу Брахмагупты через разбиение фигуры на два треугольника и применение теоремы косинусов. Пример: для четырехугольника со сторонами 5, 6, 7, 8 полупериметр p = 13, тогда площадь S = √((13-5)(13-6)(13-7)(13-8)) = √(8 * 7 * 6 * 5) = √1680 ≈ 40,99. Если четырехугольник не является вписанным, формула дает лишь приближение, а точное значение требует дополнительных данных. Формула Герона для четырехугольника широко применяется в геодезии, картографии и архитектуре при расчете площадей участков и многоугольных конструкций. Она связана с другими математическими темами: Формула Эйлера для многогранников (V - E + F = 2) помогает анализировать топологию фигур, Формула Муавра ( (cos x + i sin x)^n = cos(nx) + i sin(nx) ) используется при работе с комплексными числами в тригонометрическом представлении, а Формула Эйлера для тригонометрии (e^{ix} = cos x + i sin x) связывает экспоненту и тригонометрические функции, что полезно при выводе формул площадей через углы.
