Возрастание и убывание функции описывают, как меняется её значение при увеличении аргумента: функция возрастает, если большему x соответствует большее y, и убывает, если большему x соответствует меньшее y.

основной текст
Функция y = f(x) называется возрастающей на интервале, если для любых x₁ < x₂ из этого интервала выполняется f(x₁) < f(x₂). Функция называется убывающей, если для x₁ < x₂ выполняется f(x₁) > f(x₂). Для дифференцируемых функций возрастание и убывание определяют с помощью производной: если производная f'(x) > 0 на интервале, функция возрастает; если f'(x) < 0 — убывает. Точки, где f'(x) = 0 или не существует, называются критическими и могут быть точками экстремума. Свойства монотонности: сумма возрастающих функций возрастает, произведение положительных возрастающих функций возрастает. Пример: Линейная функция y = kx + b возрастает при k > 0 и убывает при k < 0. Квадратичная функция y = ax^2 + bx + c при a > 0 убывает на (-∞; -b/(2a)) и возрастает на (-b/(2a); +∞); при a < 0 — наоборот. Степенная функция y = x^n возрастает на всей области при нечетном n, а при четном n — убывает на (-∞; 0) и возрастает на (0; +∞). Обратная пропорциональность y = k/x при k > 0 убывает на каждом из промежутков (-∞; 0) и (0; +∞). Понятие возрастания и убывания широко применяется при исследовании функций, решении неравенств, нахождении экстремумов и построении графиков. Оно тесно связано с темой четных и нечетных чисел: например, четная функция (y = x^2) симметрична относительно оси y и меняет монотонность в нуле, а нечетная (y = x^3) монотонна на всей области. В линейной функции монотонность определяется знаком коэффициента k, в квадратичной — знаком a и положением вершины. Понимание монотонности помогает анализировать поведение сложных составных функций и решать задачи на оптимизацию.
