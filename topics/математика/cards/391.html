основной текст
Формула Брахмагупты позволяет вычислить площадь S вписанного (циклического) четырёхугольника со сторонами a, b, c и d. Она имеет вид: S = √((p - a)(p - b)(p - c)(p - d)), где p = (a + b + c + d)/2 — полупериметр. Формула является прямым аналогом формулы Герона для треугольника (которую можно получить, положив d = 0). Важное условие: четырёхугольник обязательно должен быть вписанным, то есть все его вершины лежат на одной окружности. Если это условие не выполнено, формула даёт завышенное значение площади. Свойства и примеры: Для квадрата со стороной a формула даёт S = √((2a - a)^4) = √(a^4) = a^2, что верно. Для прямоугольника со сторонами a и b (который всегда вписанный) p = a + b, и S = √((b)(a)(b)(a)) = ab. Если четырёхугольник вырождается в треугольник (d = 0), формула превращается в формулу Герона. Существует также обобщение для произвольных (невписанных) четырёхугольников — формула Бретшнайдера, которая добавляет поправку на сумму противоположных углов. Где применяется и связь с другими темами: Формула Брахмагупты широко используется в геометрии для решения задач на вписанные четырёхугольники, в комбинаторной геометрии и при вычислении площадей многоугольников. Она связана с формулой Эйлера для расстояния между центрами вписанной и описанной окружностей четырёхугольника. В тригонометрии её можно вывести через теорему Птолемея и формулу Муавра. Также она перекликается с формулой Эйлера для тригонометрии (e^(ix) = cos x + i sin x), так как обе основаны на комплексных числах и свойствах окружностей.
