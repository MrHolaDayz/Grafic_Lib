основной текст
Дискретная случайная величина (ДСВ) — это числовая функция, заданная на пространстве элементарных исходов, принимающая конечное или счетное множество значений. Основной характеристикой ДСВ является закон распределения — таблица или формула, где каждому возможному значению x_i ставится в соответствие вероятность p_i = P(X = x_i). Основные формулы: математическое ожидание M(X) = Σ (x_i * p_i), дисперсия D(X) = Σ ( (x_i - M(X))^2 * p_i ) = M(X^2) - (M(X))^2, среднее квадратическое отклонение σ(X) = √D(X). Вероятность попадания в интервал [a; b] вычисляется как сумма вероятностей всех x_i, попадающих в этот интервал. Свойства ДСВ: сумма всех вероятностей в законе распределения равна 1 (условие нормировки); математическое ожидание характеризует среднее значение величины; дисперсия и среднеквадратическое отклонение измеряют разброс значений относительно среднего. Примеры: число выпавших орлов при трех подбрасываниях монеты (значения 0, 1, 2, 3); количество бракованных деталей в партии; число попаданий в мишень при нескольких выстрелах. Важный частный случай — биномиальное распределение, описывающее число успехов в серии независимых испытаний с постоянной вероятностью успеха. ДСВ широко применяются в статистике, теории массового обслуживания, экономике и физике для моделирования дискретных процессов. Связь с другими темами: ДСВ является обобщением понятия случайного события — каждое событие можно описать как принятие величиной определенного значения. Достоверное событие соответствует сумме вероятностей всех значений, равной 1. Невозможное событие — это значение, вероятность которого равна 0. Изучение ДСВ опирается на классическое и статистическое определения вероятности: классическое используется для симметричных исходов (игральные кости, монеты), а статистическое — для оценки вероятностей по частотам в реальных данных.
