основной текст
Теорема Брахмагупты утверждает, что для любого вписанного (циклического) четырёхугольника со сторонами a, b, c, d его площадь S вычисляется по формуле: S = √((p - a)(p - b)(p - c)(p - d)), где p = (a + b + c + d)/2 — полупериметр. Важнейшее условие — четырёхугольник должен быть вписанным (сумма противоположных углов равна 180°). Если одна из сторон равна нулю, формула превращается в формулу Герона для треугольника. Основное свойство теоремы — она даёт точное значение площади только для циклических четырёхугольников. Для произвольных четырёхугольников существует обобщение — формула Бретшнайдера, добавляющая поправку на диагонали. Пример: для квадрата со стороной 1 (a=b=c=d=1) полупериметр p=2, площадь S = √((2-1)^4) = 1, что верно. Для прямоугольника 3×4 (вписанного) p=7, S = √((7-3)(7-4)(7-3)(7-4)) = √(4·3·4·3) = 12, что совпадает с обычной площадью. Теорема Брахмагупты широко применяется в геометрии и тригонометрии при расчётах площадей многоугольников, в задачах на вписанные фигуры, а также в компьютерной графике. Она связана с теоремой Птолемея (длины диагоналей) и теоремой Пифагора для частных случаев. Среди перечисленных связанных тем: Основная теорема алгебры (о корнях многочленов) не имеет прямой геометрической связи, но используется в алгебраических методах вывода формул; Теорема Руше (о расположении корней) применяется при анализе устойчивости, но не относится к геометрии; Теорема о ранге (линейная алгебра) связана через матричные представления преобразований, но не с площадями четырёхугольников.
