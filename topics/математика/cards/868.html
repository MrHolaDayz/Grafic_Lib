основной текст
Определение и основные формулы сочетаний с повторениями: в комбинаторике сочетание с повторениями из n элементов по k — это неупорядоченный набор k элементов, каждый из которых принадлежит одному из n типов, при этом элементы одного типа могут повторяться. Количество таких сочетаний вычисляется по формуле: C(n + k - 1, k) = (n + k - 1)! / (k! * (n - 1)!). Другой способ записи: число сочетаний с повторениями равно биномиальному коэффициенту C(n + k - 1, k). Для наглядности используется метод «звездочек и палочек»: k одинаковых звездочек разделяются n - 1 палочками, что дает (n + k - 1)! / (k! * (n - 1)!) способов. Свойства и примеры сочетаний с повторениями: число сочетаний с повторениями всегда больше или равно числу обычных сочетаний (без повторений) при тех же n и k. Пример: сколько способов выбрать 3 пирожных из 4 видов (корзиночка, эклер, наполеон, безе), если можно брать пирожные одного вида несколько раз? Ответ: C(4+3-1, 3) = C(6,3) = 20 способов. Свойства: симметричность C(n+k-1, k) = C(n+k-1, n-1); при k = 0 результат равен 1; при n = 1 результат равен 1 для любого k. Где применяются сочетания с повторениями: в теории вероятностей (задачи о выборе с возвращением), в статистике (распределение частиц по ячейкам), в экономике (составление портфелей с повторяющимися активами), в криптографии (генерация паролей с повторяющимися символами). Связь с другими темами: формула основана на теореме о делении с остатком (факториалы делятся нацело), а вычисления включают Степень с натуральным показателем (факториалы как произведения степеней чисел).
