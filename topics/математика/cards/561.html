Уравнение плоскости — это линейное уравнение вида Ax + By + Cz + D = 0, задающее множество всех точек (x, y, z) в пространстве, принадлежащих одной плоскости. Оно является основным инструментом аналитической геометрии для описания плоских поверхностей в трёхмерном пространстве.

основной текст
Уравнение плоскости в трёхмерном пространстве обычно записывается в общем виде: Ax + By + Cz + D = 0, где A, B, C — координаты нормального вектора n = (A, B, C), перпендикулярного плоскости, а D — свободный коэффициент. Если известна точка M₀(x₀, y₀, z₀), лежащая на плоскости, и нормальный вектор n, то уравнение можно записать как A(x - x₀) + B(y - y₀) + C(z - z₀) = 0. Частные случаи: если D = 0, плоскость проходит через начало координат; если A = 0, плоскость параллельна оси Ox; если A = B = 0, плоскость параллельна плоскости Oxy (z = const). Расстояние от точки M₁(x₁, y₁, z₁) до плоскости вычисляется по формуле d = |Ax₁ + By₁ + Cz₁ + D| / √(A² + B² + C²). Уравнение плоскости обладает важным свойством: любые три неколлинеарные точки однозначно определяют плоскость, и по ним можно составить уравнение через определитель или через векторное произведение. Например, для точек A, B, C нормальный вектор n = (B - A) × (C - A). Плоскость может быть задана также в отрезках: x/a + y/b + z/c = 1, где a, b, c — точки пересечения с осями координат. В задачах часто используется условие параллельности (пропорциональность нормалей) и перпендикулярности (скалярное произведение нормалей равно нулю) двух плоскостей. Уравнение плоскости широко применяется в стереометрии для нахождения углов между плоскостями и прямыми, в компьютерной графике для построения трёхмерных сцен, в физике при описании волновых фронтов и в инженерных расчётах. Оно тесно связано с векторной алгеброй: нормальный вектор, скалярное и векторное произведения лежат в основе вывода формул. Также уравнение плоскости используется при решении систем линейных уравнений в трёхмерном пространстве и в аналитической геометрии для описания взаимного расположения
