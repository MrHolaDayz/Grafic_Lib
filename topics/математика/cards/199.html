Однородная система линейных уравнений — это система, в которой все свободные члены равны нулю. Она всегда совместна, так как имеет тривиальное (нулевое) решение, а её нетривиальные решения существуют, когда определитель матрицы равен нулю.

основной текст
Однородная система линейных уравнений имеет вид A·x = 0, где A — матрица коэффициентов размером m×n, x — вектор неизвестных. В развёрнутой форме для n переменных это записывается как система: a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = 0, a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = 0, ..., aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = 0. Фундаментальное свойство: если x₁ и x₂ — решения, то их линейная комбинация c₁·x₁ + c₂·x₂ также является решением. Множество всех решений образует линейное пространство размерности n − rank(A). Нетривиальные решения существуют, если rank(A) < n, в частности, для квадратных систем (m = n) — когда det(A) = 0. Свойства: однородная система всегда совместна (нулевое решение). Если система имеет хотя бы одно ненулевое решение, то их бесконечно много. Пример: система x + y = 0, 2x + 2y = 0 имеет решения вида (t, −t) для любого t. Для нахождения фундаментальной системы решений (ФСР) нужно найти rank(A) и выразить базисные переменные через свободные. Например, для системы x₁ + x₂ + x₃ = 0, x₁ − x₂ = 0 получаем x₁ = x₂, x₃ = −2x₂, ФСР состоит из одного вектора (1, 1, −2). Однородные системы широко применяются в линейной алгебре для нахождения ядра линейного оператора, в дифференциальных уравнениях (однородные системы ДУ), в физике (анализ колебаний, квантовая механика). Они тесно связаны с понятием собственных векторов и собственных значений матрицы (уравнение (A − λE)·x = 0 — однородная система). Также используются в компьютерной графике для решения задач перспективы и в экономике для моделирования балансовых моделей. Связанные темы: нет.
