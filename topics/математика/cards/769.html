Первообразная — это функция F(x), производная которой равна заданной функции f(x). Нахождение первообразной является операцией, обратной дифференцированию.

основной текст
Первообразной функции f(x) на интервале (a, b) называется такая функция F(x), что для любого x из этого интервала выполняется равенство F'(x) = f(x). Основное свойство первообразной заключается в том, что если F(x) является первообразной для f(x), то любая другая первообразная имеет вид F(x) + C, где C — произвольная постоянная. Это свойство лежит в основе понятия неопределенного интеграла: ∫ f(x) dx = F(x) + C. Например, для функции f(x) = x^2 первообразной будет F(x) = x^3 / 3, так как (x^3 / 3)' = x^2. Другой пример: для f(x) = 1/x первообразной является F(x) = ln|x| при x ≠ 0. Свойства первообразной напрямую вытекают из свойств производной. Линейность: если F и G — первообразные для f и g, то aF + bG — первообразная для af + bg. Также важно помнить, что первообразная от суммы равна сумме первообразных, а постоянный множитель можно выносить за знак интеграла. Например, ∫ (3x^2 + 2) dx = x^3 + 2x + C. Для нахождения первообразных используется Таблица интегралов, где собраны основные формулы: ∫ x^n dx = x^(n+1)/(n+1) + C (n ≠ -1), ∫ e^x dx = e^x + C, ∫ cos x dx = sin x + C и другие. Первообразная широко применяется для вычисления площадей под кривыми, объемов тел вращения и решения дифференциальных уравнений. Понятие первообразной тесно связано с Определением первообразной как обратной операции к дифференцированию, Основным свойством первообразной (единственность с точностью до константы) и Неопределенным интегралом, который представляет собой множество всех первообразных. Вместе эти темы образуют фундамент интегрального исчисления.
