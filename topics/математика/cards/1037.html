Возведение комплексного числа в степень — это операция, многократно умножающая число само на себя, которая для комплексных чисел удобно выполняется в тригонометрической форме с помощью формулы Муавра.
связанные темы
Сложение Вычитание Умножение Деление Формула Муавра
основной текст
Возведение комплексного числа в степень определяется как многократное Умножение числа на себя: z^n = z * z * ... * z (n раз). Для комплексных чисел в алгебраической форме (a + bi) эта операция выполняется последовательным умножением с учётом, что i^2 = -1. Однако гораздо удобнее использовать тригонометрическую форму: если z = r(cos φ + i sin φ), то по формуле Муавра: z^n = r^n (cos(nφ) + i sin(nφ)). Для целых отрицательных степеней используется правило: z^(-n) = 1 / z^n. Для корней n-й степени применяется формула: √z = r^(1/n) (cos((φ+2πk)/n) + i sin((φ+2πk)/n)), где k = 0, 1, ..., n-1, что даёт n различных значений. Свойства возведения в степень для комплексных чисел аналогичны свойствам для действительных чисел: (z1 * z2)^n = z1^n * z2^n, (z1 / z2)^n = z1^n / z2^n при z2 ≠ 0. Пример: найти (1 + i)^4. Сначала переводим в тригонометрическую форму: 1 + i = √2 (cos 45° + i sin 45°). Тогда (1 + i)^4 = (√2)^4 (cos(4*45°) + i sin(4*45°)) = 4 (cos 180° + i sin 180°) = 4(-1 + 0i) = -4. Возведение в степень широко применяется в электротехнике (расчёт цепей переменного тока), теории колебаний и квантовой механике. Эта операция тесно связана с умножением (так как степень — это многократное умножение) и Делением (через отрицательные степени). Сложение и Вычитание используются при приведении результата к алгебраической форме. Формула Муавра является ключевым инструментом для вычисления степеней и корней, что связывает эту тему с тригонометрией и экспоненциальной формой комплексных чисел.
