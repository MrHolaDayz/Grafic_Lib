Арккотангенс (arccot(x) или cot^(-1)(x)) — это обратная тригонометрическая функция к котангенсу, которая возвращает угол α в интервале (0, π), такой что cot(α) = x. Основные свойства включают чётность (arccot(-x) = π - arccot(x)), связь с арктангенсом и композицию с котангенсом.

основной текст
Арккотангенс определяется как функция, обратная котангенсу на интервале (0, π). Основное тождество: cot(arccot(x)) = x для всех действительных x, и arccot(cot(α)) = α при α ∈ (0, π). Важные формулы: arccot(x) = π/2 - arctan(x) для x ∈ R, и arccot(x) = arctan(1/x) при x > 0 (для x < 0 требуется корректировка на π). График функции симметричен относительно точки (0, π/2), а производная равна -1/(1 + x^2). Свойства арккотангенса включают: нечётность по отношению к сдвигу (arccot(-x) = π - arccot(x)), монотонное убывание на всей области определения, и асимптоты y = 0 при x → +∞ и y = π при x → -∞. Пример: arccot(√3) = π/6, так как cot(π/6) = √3. Композиция с котангенсом: arccot(cot(2π/3)) = arccot(-1/√3) = 2π/3 (поскольку 2π/3 ∈ (0, π)). Функция широко применяется в интегральном исчислении (например, ∫ dx/(1+x^2) = arccot(x) + C), в геодезии для вычисления углов, и в комплексном анализе при работе с аргументом комплексного числа. Связь с другими темами: Свойства сопряженных чисел позволяют выразить arccot(z) для комплексного z через логарифм; Свойства модуля используются при оценке области значений; Свойства транспонирования матриц могут встречаться в задачах на углы поворота. Также свойства определителей и операций (сложение, умножение) применяются при решении систем с тригонометрическими функциями.
