основной текст
Модуль комплексного числа z = a + bi, где a и b — действительные числа, а i — Мнимая единица (i^2 = -1), определяется как неотрицательное действительное число |z| = √(a^2 + b^2). Геометрически это длина радиус-вектора точки (a, b) на комплексной плоскости. Основные свойства: |z| = |-z|, |z1 * z2| = |z1| * |z2|, |z1 / z2| = |z1| / |z2| (при z2 ≠ 0), а также неравенство треугольника |z1 + z2| ≤ |z1| + |z2|. Важно, что |z| = 0 только если z = 0. Свойства модуля широко применяются при работе с комплексными числами, например, для нахождения расстояния между двумя точками на комплексной плоскости (|z1 - z2|), для доказательства сходимости рядов и в тригонометрической форме записи числа. Пример: если z = 3 + 4i, то |z| = √(3^2 + 4^2) = 5. Модуль также связан с сопряженным числом: |z|^2 = z * z̅, где z̅ = a - bi. Это позволяет упрощать деление комплексных чисел. В контексте темы «Комплексные числа → Основы» модуль неразрывно связан с понятием комплексного числа как точки на плоскости, а также со степенями мнимой единицы (так как |i| = 1, |i^2| = |-1| = 1). Модуль используется для перехода от алгебраической формы к тригонометрической: z = |z|(cos φ + i sin φ), где φ — аргумент числа. Понимание свойств модуля необходимо для изучения более сложных разделов, таких как корни из комплексных чисел и комплексный анализ.
