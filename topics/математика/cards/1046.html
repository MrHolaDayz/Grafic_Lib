Теорема Руше — это фундаментальный результат в комплексном анализе, который позволяет определить количество нулей аналитической функции в заданной области, сравнивая её с другой, более простой функцией на границе области.
связанные темы
Сложение Вычитание Умножение Деление Возведение в степень
основной текст
Теорема Руше формулируется следующим образом: Пусть f(z) и g(z) — аналитические функции в односвязной области D и на её границе C (замкнутый контур). Если на контуре C выполняется строгое неравенство |f(z) - g(z)| < |g(z)| (или, в другой форме, |f(z)| > |g(z)|), то функции f(z) и g(z) имеют одинаковое количество нулей (с учетом кратности) внутри области D. Основная формула для подсчета числа нулей N функции h(z) внутри контура C выражается через интеграл: N = (1/(2πi)) ∫_C (h'(z)/h(z)) dz. Теорема Руше упрощает этот подсчет, заменяя сложную функцию на более простую. Свойство теоремы заключается в том, что она не требует точного знания расположения нулей, а лишь оценки модулей функций на границе. Пример: определим количество корней многочлена z^5 + 3z + 1 внутри единичного круга |z| = 1. Пусть g(z) = 3z, f(z) = z^5 + 3z + 1. На границе |z| = 1 имеем |f(z) - g(z)| = |z^5 + 1| ≤ |z|^5 + 1 = 2, а |g(z)| = |3z| = 3. Так как 2 < 3, то по теореме Руше количество нулей f(z) равно количеству нулей g(z) = 3z, которое равно 1 (один корень z=0). Значит, исходный многочлен имеет один корень внутри единичного круга. Теорема Руше широко применяется для доказательства основной теоремы алгебры (каждый многочлен степени n имеет ровно n комплексных корней), а также в гидродинамике и теории управления для анализа устойчивости систем. Она тесно связана с принципом аргумента и интегральной формулой Коши. Для применения теоремы часто используются операции Сложения, Вычитания и Умножения комплексных чисел при оценке модулей на границе области, а также Возведение в степень при работе с многочленами.
