основной текст
В исчислении высказываний интерпретация задается как функция, которая каждой пропозициональной переменной ставит в соответствие значение 1 (истина) или 0 (ложь). Истинность сложных формул вычисляется рекурсивно: для отрицания (¬A) истинность обратная; для конъюнкции (A ∧ B) — 1 только если обе части истинны; для дизъюнкции (A ∨ B) — 1 если хотя бы одна часть истинна; для импликации (A → B) — 0 только при истинном A и ложном B; для эквиваленции (A ↔ B) — 1 при совпадении значений. Формула называется выполнимой, если существует хотя бы одна интерпретация, при которой она истинна, и общезначимой (тавтологией), если истинна при всех возможных интерпретациях. Интерпретация обладает свойством однозначности: каждая интерпретация полностью определяет истинностное значение формулы. Пример: для формулы (p → q) ∧ p при интерпретации p=1, q=0 результат будет 0, так как импликация p→q ложна. Если p=1, q=1, то формула истинна. Интерпретация лежит в основе семантики исчисления высказываний, отличая его от синтаксиса (формальных выводов). С её помощью проверяют логическое следование: формула B логически следует из A, если при всех интерпретациях, где A истинно, B также истинно. Интерпретация применяется в доказательстве теорем, проверке корректности логических схем, в теории баз данных (для проверки выполнимости запросов) и в искусственном интеллекте (логическое программирование).
