основной текст
Формула Герона определяет площадь S треугольника со сторонами a, b, c через полупериметр p = (a + b + c) / 2: S = √(p(p - a)(p - b)(p - c)). Эта формула является следствием теоремы Пифагора и алгебраических преобразований, и её можно записать также в виде: S = 1/4 √((a + b + c)(-a + b + c)(a - b + c)(a + b - c)). Свойства и примеры: Формула работает для любого треугольника (остроугольного, тупоугольного, прямоугольного), если выполняется неравенство треугольника. Пример: для треугольника со сторонами 3, 4, 5 полупериметр p = 6, тогда площадь S = √(6 * 3 * 2 * 1) = √36 = 6 (что совпадает с классическим результатом для прямоугольного треугольника). Если одна из сторон больше суммы двух других, подкоренное выражение становится отрицательным — это признак несуществующего треугольника. Где применяется: Формула Герона широко используется в геодезии, строительстве и навигации для расчёта площадей земельных участков, когда доступны только длины границ. Она также применяется в задачах на нахождение площади треугольника по трём сторонам, если неизвестны углы. В аналитической геометрии формула позволяет вычислить площадь треугольника по координатам его вершин через длины сторон. Формула связана с теоремой косинусов и может быть выведена из неё.
