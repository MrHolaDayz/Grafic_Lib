Транспонирование — это операция, при которой строки исходной матрицы становятся столбцами новой матрицы, а столбцы — строками. Полученная матрица называется транспонированной и обозначается A^T.
связанные темы
Определение матрицы Виды матриц Квадратная матрица Единичная матрица Нулевая матрица
основной текст
Определение и основные формулы. Пусть дана матрица A размером m x n. Транспонированная матрица A^T имеет размер n x m, и её элемент (i, j) равен элементу (j, i) исходной матрицы: (A^T)_{ij} = A_{ji}. Например, если A = [[1, 2], [3, 4]], то A^T = [[1, 3], [2, 4]]. Для квадратной матрицы (связанная тема: Квадратная матрица) транспонирование может совпадать с исходной матрицей, если она симметрична. Свойства и примеры. Основные свойства: (A^T)^T = A (повторное транспонирование возвращает исходную матрицу); (A + B)^T = A^T + B^T; (kA)^T = k * A^T для скаляра k; (AB)^T = B^T * A^T (порядок множителей меняется). Пример: для A = [[1, 0], [2, 3]] и B = [[4, 1], [0, -1]] имеем A^T = [[1, 2], [0, 3]], B^T = [[4, 0], [1, -1]]. Где применяется, связь с другими темами. Транспонирование широко используется в линейной алгебре при решении систем уравнений (например, для нахождения обратной матрицы), в теории графов (матрицы смежности), в статистике (матрицы ковариации), а также в компьютерной графике и машинном обучении. Операция тесно связана с понятием симметричных матриц и ортогональных преобразований. Упомяни связанные темы: Определение матрицы, Виды матриц, Квадратная матрица. Транспонирование применимо к любой матрице, независимо от её типа (связанная тема: Определение матрицы и Виды матриц). Для квадратных матриц транспонирование позволяет выделить класс симметричных матриц, где A = A^T. Единичная и нулевая матрицы (связанные темы: Единичная матрица, Нулевая матрица) инвариантны относительно транспонирования: I^T = I, O
