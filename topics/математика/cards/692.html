основной текст
Теорема Больцано-Коши (также известна как теорема о промежуточном значении) является фундаментальным результатом математического анализа. Формально: если функция f непрерывна на отрезке [a, b] и f(a) * f(b) < 0 (то есть значения на концах имеют разные знаки), то существует такая точка c ∈ (a, b), что f(c) = 0. Обобщение: для любого числа d, лежащего между f(a) и f(b), найдется точка c ∈ [a, b] такая, что f(c) = d. Это свойство называется свойством промежуточного значения и характеризует непрерывные функции на связных множествах. Основное свойство теоремы — она гарантирует существование корня уравнения f(x)=0 без необходимости его явного нахождения. Пример: функция f(x) = x^3 - 4x + 1 непрерывна на отрезке [0, 2]; f(0)=1 > 0, f(2)=8 - 8 + 1 = 1 > 0 — знаки одинаковые, теорема не применима. Однако на отрезке [0, 1]: f(0)=1, f(1)=1 - 4 + 1 = -2, знаки разные, значит, существует корень между 0 и 1. Другой пример: f(x) = sin(x) - 0.5 на [0, π/2]: f(0) = -0.5, f(π/2) = 0.5, корень существует (x = π/6). Теорема широко применяется для доказательства существования решений уравнений, в численных методах (метод бисекции), а также в доказательстве других важных теорем. Связь с другими темами: Основная теорема алгебры утверждает, что любой многочлен с комплексными коэффициентами имеет корень в комплексной плоскости — ее доказательство опирается на непрерывность и свойства, близкие к теореме Больцано-Коши. Теорема Руше используется для определения числа корней аналитической функции в области. Теорема о ранге относится к линейной алгебре и не связана напрямую, но вместе с теоремой Больцано-Коши применяется в анализе для исследования отображений.
