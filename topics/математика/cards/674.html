Предел функции — это значение, к которому стремится функция f(x), когда её аргумент x приближается к некоторой точке a (или к бесконечности). Это фундаментальное понятие анализа, лежащее в основе непрерывности, производной и интеграла.

основной текст
Предел функции формально определяется так: число A называется пределом функции f(x) в точке a (обозначается lim_{x→a} f(x) = A), если для любого ε > 0 существует такое δ > 0, что из неравенства 0 < |x - a| < δ следует |f(x) - A| < ε. Для односторонних пределов используют обозначения lim_{x→a-} (слева) и lim_{x→a+} (справа). Основные формулы: lim_{x→0} sin x / x = 1, lim_{x→0} (1 + x)^(1/x) = e, lim_{x→∞} (1 + 1/x)^x = e, lim_{x→0} (a^x - 1)/x = ln a. Свойства пределов включают линейность (предел суммы, разности, произведения и частного), а также теорему о двух милиционерах (сжатой функции). Пример: вычислить lim_{x→0} (1 - cos x) / x^2. Используя формулу 1 - cos x = 2 sin^2(x/2) и первый замечательный предел, получаем 1/2. Другой пример: lim_{x→∞} (x^2 + 3x) / (2x^2 - 1) = 1/2 (делим числитель и знаменатель на x^2). Понятие предела применяется всюду в математическом анализе: для определения непрерывности функции (f непрерывна в точке a, если lim_{x→a} f(x) = f(a)), для вычисления производной (через предел приращения), для исследования асимптотического поведения функций. Связь с другими темами: Тригонометрические функции (sin x, cos x) часто требуют использования первого замечательного предела; Обратные тригонометрические функции (arcsin x, arccos x) имеют свои предельные переходы при x→0; Область определения функции критически важна, так как предел может существовать только в точках накопления области определения.
