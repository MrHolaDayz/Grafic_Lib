основной текст
Теорема Кронекера-Капелли (критерий совместности) гласит: система m линейных уравнений с n неизвестными вида Ax = b совместна (имеет хотя бы одно решение) тогда и только тогда, когда ранг основной матрицы A равен рангу расширенной матрицы (A|b). Если rank(A) = rank(A|b) = r, то система имеет решение. При r = n решение единственно, при r < n система имеет бесконечное множество решений, зависящих от (n - r) свободных переменных. Если же rank(A) ≠ rank(A|b), то система несовместна (решений нет). Основные формулы: rank(A) = rank(A|b) — условие совместности; количество свободных переменных = n - rank(A). Свойства и примеры: Теорема работает для любых систем — как квадратных, так и прямоугольных. Пример: система {x + y = 2; 2x + 2y = 4} имеет rank(A) = 1 и rank(A|b) = 1, следовательно, совместна (бесконечно много решений). Пример несовместной системы: {x + y = 1; x + y = 3} — rank(A) = 1, а rank(A|b) = 2, решений нет. Теорема не требует вычисления самих решений, а только проверки рангов, что делает её мощным инструментом анализа. Где применяется, связь с другими темами: Теорема является фундаментом для решения систем линейных уравнений в линейной алгебре, численных методах и прикладной математике. Она связана с методом Гаусса (приведение к ступенчатому виду для определения ранга) и теоремой Руше (аналогичный критерий для систем с квадратной матрицей). В отличие от теоремы Руше, Кронекера-Капелли применима к любым прямоугольным системам. Она также тесно связана с однородными системами (Ax = 0), которые всегда совместны (нулевое решение), и неоднородными системами, где условие равенства рангов критично.
