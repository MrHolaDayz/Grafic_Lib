основной текст
Неопределенность ∞/∞ — это ситуация, в которой предел отношения двух функций (или последовательностей) не может быть найден непосредственной подстановкой, поскольку оба стремятся к бесконечности. Основной приём для раскрытия такой неопределённости — деление числителя и знаменателя на старшую степень аргумента (для многочленов) или на самый быстрорастущий член (для показательных и логарифмических функций). Например, для предела lim_{x → ∞} (2x^2 + 3x) / (x^2 — 1) делим на x^2: lim (2 + 3/x) / (1 — 1/x^2) = 2/1 = 2. Если степень числителя меньше степени знаменателя, предел равен 0; если больше — бесконечности. Свойства раскрытия ∞/∞ тесно связаны со сравнением порядков роста: степенные функции растут медленнее показательных, а логарифмические — медленнее степенных. Пример: lim_{x → ∞} (e^x) / (x^2) = ∞, так как e^x растёт быстрее любой степени x. В случае последовательностей аналогичные правила работают для lim a_n / b_n, где a_n, b_n → ∞. Часто применяется правило Лопиталя (если функции дифференцируемы), которое сводит предел отношения к пределу отношения производных. Неопределённость ∞/∞ — одна из базовых в математическом анализе, она встречается при исследовании асимптотического поведения функций и последовательностей. Она связана с понятием предела последовательности, где для строгого доказательства используется определение на языке ε-N (по Коши): для любого ε > 0 существует N, такое что для всех n > N разность меньше ε. Сходящиеся последовательности имеют конечный предел, а расходящиеся — бесконечный, что и порождает неопределённость ∞/∞. Свойства пределов (арифметические операции, теорема о двух милиционерах) помогают корректно обрабатывать такие случаи.
