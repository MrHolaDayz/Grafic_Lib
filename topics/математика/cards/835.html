Признак Даламбера — это достаточный признак сходимости числовых рядов, основанный на вычислении предела отношения последующего члена ряда к предыдущему.

основной текст
Признак Даламбера применяется к знакоположительным числовым рядам. Пусть дан ряд Σ a_n, где a_n > 0. Вычисляется предел D = lim (n→∞) a_{n+1} / a_n. Если D < 1, то ряд сходится; если D > 1, то ряд расходится; если D = 1, то признак не даёт ответа (требуется дополнительное исследование). Формула предела: D = lim (n→∞) a_{n+1} / a_n. Основное свойство признака — его простота и удобство для рядов, члены которых содержат факториалы, показательные функции или степени. Пример: ряд Σ n! / 10^n. Вычисляем a_{n+1} / a_n = ((n+1)! / 10^{n+1}) / (n! / 10^n) = (n+1) / 10. Предел D = ∞, значит ряд расходится. Другой пример: ряд Σ 2^n / n! даёт D = 0, ряд сходится. Признак Даламбера широко применяется в теории рядов для быстрой проверки сходимости, особенно в задачах с факториалами и экспонентами. Он тесно связан с радикальным признаком Коши (оба используют предел отношения или корня). Также его используют при изучении степенных рядов для нахождения радиуса сходимости. Среди связанных тем: Первый признак (сравнения), Второй признак (предельный признак сравнения), Третий признак (интегральный признак Коши).
