основной текст
Однородные уравнения второй степени в тригонометрии имеют вид a sin^2 x + b sin x cos x + c cos^2 x = 0, где a, b, c — действительные числа, причём a и c не равны нулю одновременно. Основной метод решения: разделить обе части уравнения на cos^2 x (если cos x ≠ 0), что даёт a tg^2 x + b tg x + c = 0. Полученное квадратное уравнение относительно tg x решается стандартно: tg x = t, at^2 + bt + c = 0, откуда находятся корни t1 и t2, а затем x = arctg(t_k) + πn. Если cos x = 0, то проверяется, является ли x = π/2 + πn решением исходного уравнения (подстановкой sin x = ±1, cos x = 0). Свойства: уравнение является однородным, так как сумма показателей степеней синуса и косинуса в каждом слагаеме равна 2 (sin^2 x — степень 2, sin x cos x — степень 2, cos^2 x — степень 2). Если a = 0 или c = 0, уравнение вырождается, но метод деления на квадрат косинуса или синуса остаётся применим. Пример: 3 sin^2 x + 5 sin x cos x - 2 cos^2 x = 0. Делим на cos^2 x: 3 tg^2 x + 5 tg x - 2 = 0. Решаем: D = 25 + 24 = 49, tg x = (-5 ± 7)/6, tg x = 1/3 или tg x = -2. Ответ: x = arctg(1/3) + πn, x = -arctg(2) + πn. Однородные уравнения второй степени широко применяются при решении тригонометрических задач, в физике (например, при анализе колебаний), а также в задачах на преобразование выражений. Связь с другими темами: после деления получается квадратное уравнение, методы решения которого (дискриминант, теорема Виета) используются напрямую. Также возможно появление мнимых корней, что отсылает к теме степени мнимой
