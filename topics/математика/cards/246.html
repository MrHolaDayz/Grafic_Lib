основной текст
Система неравенств — это набор из нескольких неравенств, записанных, как правило, в фигурных скобках. Общее решение системы — это множество всех значений переменной (или переменных), при которых каждое неравенство системы обращается в верное числовое неравенство. Для системы с одной переменной x вида { f1(x) > 0, f2(x) ≤ 0 } решение находится как пересечение множеств решений каждого неравенства: X = X1 ∩ X2. Если система состоит из линейных неравенств (например, { 2x - 3 > 0, x + 4 ≤ 0 }), то решение обычно представляет собой отрезок, интервал или пустое множество. Для квадратных неравенств (например, { x^2 - 4 < 0, x ≥ 0 }) решение находится с учетом знаков квадратичной функции и условий. Основное свойство системы неравенств: изменение порядка неравенств не влияет на решение, а умножение обеих частей любого из неравенств на отрицательное число требует смены знака этого неравенства. Пример: решим систему { x + 1 > 0, 3 - x ≥ 0 }. Первое неравенство дает x > -1, второе — x ≤ 3. Пересечение: x ∈ (-1; 3]. Если же система несовместна, например { x > 5, x < 2 }, то решений нет. Важно помнить, что при решении систем с модулями или рациональными выражениями часто требуется учитывать ОДЗ. Системы неравенств широко применяются в задачах оптимизации, экономике (нахождение области допустимых планов), физике (ограничения на параметры) и при исследовании функций (область определения). В алгебре они тесно связаны с темами "Линейные неравенства" и "Квадратные неравенства", так как методы решения систем основаны на их комбинировании. Связанные темы включают: "Однородные системы" (где все неравенства имеют нулевую правую часть и одинаковую степень), "Неоднородные системы" (с произвольными правыми частями), а также "Аксиоматические системы" — более общий математический подход, где неравенства рассматриваются как аксиомы, задающие упорядоченное множество.
