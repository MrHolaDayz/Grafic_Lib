Отражение — это преобразование графика функции, при котором он зеркально отображается относительно оси координат (оси X или оси Y). Основные виды отражения: относительно оси X (вертикальное отражение) и относительно оси Y (горизонтальное отражение).

основной текст
Отражение графика функции — это один из видов геометрических преобразований, при котором каждая точка графика перемещается в симметричную относительно выбранной оси. Основные формулы: для отражения относительно оси X (вертикальное отражение) используется запись y = -f(x); для отражения относительно оси Y (горизонтальное отражение) — y = f(-x). Также существует отражение относительно начала координат, которое задается формулой y = -f(-x). В этих формулах f(x) — исходная функция, а знак минус перед аргументом или значением функции меняет направление графика. Свойства отражения: при отражении относительно оси X все точки графика меняют знак y-координаты, поэтому график переворачивается «вверх ногами». Например, для квадратичной функции y = x^2 отражение дает y = -x^2 — парабола, направленная ветвями вниз. При отражении относительно оси Y знак меняет x-координата, что приводит к зеркальному отображению графика слева направо. Для линейной функции y = kx отражение относительно Y дает y = -kx. Отражение сохраняет форму графика, но меняет его ориентацию. Отражение широко применяется в анализе симметрии функций, при решении уравнений и построении графиков. Оно тесно связано с четностью и нечетностью функций: если функция четная (f(-x) = f(x)), то ее график симметричен относительно оси Y; если нечетная (f(-x) = -f(x)), то график симметричен относительно начала координат. В связанных темах отражение используется для изучения поведения линейных функций (y = kx + b), квадратичных функций (y = ax^2 + bx + c), степенных функций (y = x^n), обратной пропорциональности (y = k/x) и дробно-линейных функций (y = (ax + b)/(cx + d)). Например, для степенной функции y = x^3 отражение относительно оси Y дает y = (-x)^3 = -x^3, что показывает нечетность функции.
