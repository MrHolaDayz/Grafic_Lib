основной текст
Уравнение cos x = a является одним из простейших тригонометрических уравнений. Его решение основано на определении косинуса как абсциссы точки на единичной окружности. Основная формула решений: если |a| ≤ 1, то x = ± arccos a + 2πk, где k ∈ Z. Здесь arccos a — главное значение арккосинуса, лежащее в отрезке [0; π]. Частные случаи: cos x = 0 → x = π/2 + πk; cos x = 1 → x = 2πk; cos x = -1 → x = π + 2πk. Уравнение обладает свойством четности: если x — решение, то -x также является решением (с учетом периода). Например, cos x = 1/2 дает x = ±π/3 + 2πk. Графически решение соответствует пересечению графика y = cos x с горизонтальной прямой y = a. При a > 1 или a < -1 пересечений нет, поэтому решений не существует. Данное уравнение широко применяется в физике (описание колебаний, волн), геометрии (нахождение углов в треугольниках) и инженерных расчетах. Оно тесно связано с другими простейшими уравнениями: sin x = a (решается через x = (-1)^k arcsin a + πk), tg x = a (x = arctg a + πk), ctg x = a (x = arcctg a + πk). Все эти уравнения объединены общим подходом — использованием обратных тригонометрических функций и учета периодичности. Связь с другими темами: для полного понимания cos x = a необходимо знание тригонометрической окружности, свойств арккосинуса, а также умение решать уравнения, сводящиеся к простейшим с помощью замен или преобразований.
