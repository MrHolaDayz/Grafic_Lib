Монотонность — это свойство функции сохранять направление своего изменения (возрастание или убывание) на заданном промежутке. Функция называется монотонной, если она либо только возрастает, либо только убывает на этом интервале.

основной текст
Монотонность функции определяется через сравнение значений функции для различных аргументов. Функция f(x) называется возрастающей на интервале I, если для любых x1 и x2 из I, таких что x1 < x2, выполняется f(x1) < f(x2). Функция называется убывающей на I, если для x1 < x2 выполняется f(x1) > f(x2). Для исследования монотонности с помощью производной используется правило: если f'(x) > 0 на интервале, то функция возрастает; если f'(x) < 0, то убывает. Для строгой монотонности неравенства строгие, для нестрогой (невозрастание/неубывание) допускается равенство. Свойства монотонных функций: они имеют обратную функцию (если строго монотонны на всей области определения), и композиция двух монотонных функций одного направления также монотонна. Пример: Линейная функция f(x) = kx + b монотонна на всей прямой: возрастает при k > 0 и убывает при k < 0. Квадратичная функция f(x) = x^2 не является монотонной на всей области, но монотонна на промежутках: убывает на (-∞; 0] и возрастает на [0; +∞). Степенная функция f(x) = x^n для нечетных n монотонно возрастает на R, а для четных n — убывает на (-∞; 0] и возрастает на [0; +∞). Монотонность широко применяется для решения неравенств, нахождения экстремумов функций, доказательства существования корней уравнений и в оптимизационных задачах. Связь с другими темами: при изучении обратных функций монотонность является необходимым условием их существования. В экономике и физике монотонность описывает процессы без колебаний (например, рост населения или остывание тела). Также монотонность важна для анализа дробно-линейных функций и обратной пропорциональности, где функция y = 1/x монотонно убывает на каждом из промежутков (-∞; 0) и (0; +∞) отдельно.
