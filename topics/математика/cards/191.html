Возвратные уравнения — это алгебраические уравнения, коэффициенты которых симметричны относительно середины, что позволяет сводить их к уравнениям меньшей степени с помощью специальной замены.

основной текст
Возвратным (или симметрическим) уравнением называется уравнение вида a_n x^n + a_{n-1} x^{n-1} + ... + a_1 x + a_0 = 0, для которого выполняется условие a_k = a_{n-k} для всех k. Для чётной степени n=2m такое уравнение можно свести к уравнению степени m с помощью замены t = x + 1/x. Например, возвратное уравнение четвёртой степени ax^4 + bx^3 + cx^2 + bx + a = 0 делится на x^2 (при x ≠ 0) и преобразуется к квадратному относительно t: a(t^2 - 2) + bt + c = 0. Основное свойство возвратных уравнений — если число α является корнем, то и 1/α также является корнем (при α ≠ 0). Это позволяет вдвое сокращать степень уравнения. Пример: для кубического возвратного уравнения ax^3 + bx^2 + bx + a = 0 один корень всегда равен -1, после деления на (x+1) получается квадратное уравнение. Для уравнений более высоких степеней применяется аналогичная замена, приводящая к уравнениям вдвое меньшей степени. Возвратные уравнения применяются в задачах на симметрию и при решении некоторых типов рациональных и иррациональных уравнений. Они тесно связаны с квадратными уравнениями (к которым сводятся после замены) и кубическими уравнениями (частный случай возвратных третьей степени). В отличие от линейных диофантовых уравнений, которые ищут целые решения, возвратные уравнения обычно решаются в поле действительных или комплексных чисел, но их симметричная структура упрощает процесс решения.
