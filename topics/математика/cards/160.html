основной текст
Логарифм произведения — одно из основных свойств логарифмов, которое гласит: логарифм произведения двух положительных чисел равен сумме логарифмов этих чисел по тому же основанию. Формула записывается как log_a (x * y) = log_a x + log_a y, где a > 0, a ≠ 1, x > 0, y > 0. Это свойство обобщается на произведение любого конечного числа множителей: log_a (x_1 * x_2 * ... * x_n) = log_a x_1 + log_a x_2 + ... + log_a x_n. Доказательство основано на определении логарифма: если a^p = x и a^q = y, то x * y = a^p * a^q = a^(p+q), откуда log_a (x * y) = p + q = log_a x + log_a y. На практике это свойство используется для преобразования произведений в суммы, что упрощает вычисления, особенно при работе с большими числами или в логарифмической линейке. Пример: log_2 (8 * 4) = log_2 8 + log_2 4 = 3 + 2 = 5, что совпадает с log_2 32 = 5. Другой пример: log_10 (100 * 1000) = log_10 100 + log_10 1000 = 2 + 3 = 5. Свойство также применяется для разложения сложных выражений, например, log_3 (9x) = log_3 9 + log_3 x = 2 + log_3 x. Логарифм произведения широко применяется в науке и технике: в физике для расчёта уровней звука (децибелы), в химии для вычисления pH, в экономике для моделирования сложных процентов и в информатике для анализа алгоритмов (например, сложность бинарного поиска). Это свойство тесно связано с определением логарифма, которое устанавливает связь между показательной и логарифмической функциями. Кроме того, оно является основой для десятичного логарифма (log_10) и натурального логарифма (ln), где основание — число e.
