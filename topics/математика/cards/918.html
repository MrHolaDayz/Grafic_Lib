Функция распределения — это функция, задающая вероятность того, что случайная величина X примет значение, не превосходящее заданного числа x. Она является универсальным способом описания любого распределения вероятностей.

основной текст
Функция распределения случайной величины X определяется как F(x) = P(X ≤ x). Для дискретной случайной величины F(x) = Σ_{x_i ≤ x} p(x_i), где p(x_i) — вероятности отдельных значений. Для непрерывной случайной величины F(x) = ∫_{-∞}^{x} f(t) dt, где f(t) — плотность распределения. Основные свойства: F(x) не убывает, lim_{x→-∞} F(x) = 0, lim_{x→+∞} F(x) = 1, и она непрерывна справа. Важнейшие свойства: функция распределения всегда принимает значения от 0 до 1. Пример: для равномерного распределения на отрезке [a, b] функция F(x) = 0 при x < a, F(x) = (x-a)/(b-a) при a ≤ x ≤ b, F(x) = 1 при x > b. Для нормального распределения F(x) выражается через интеграл от функции Гаусса и не имеет простого аналитического вида. Функция распределения позволяет вычислять вероятности попадания в интервал: P(a < X ≤ b) = F(b) - F(a). Функция распределения применяется в статистике, теории надежности, финансовой математике (например, для расчета рисков) и машинном обучении. Она тесно связана с функциями, описывающими зависимость: Линейная функция может служить моделью равномерного распределения (F(x) = kx + b на отрезке). Квадратичная функция встречается в распределениях с параболической плотностью. Функция Эйлера φ(n) не имеет прямого отношения к вероятностям, но используется в комбинаторике для подсчета количества взаимно простых чисел, что важно в задачах с равномерным распределением на множествах. Степенная функция и Дробно-линейная функция могут описывать хвосты распределений (например, в законе Парето).
