Выпуклость функции — это свойство графика функции располагаться по одну сторону от касательной в любой точке интервала; различают выпуклость вверх (вогнутость) и выпуклость вниз.

основной текст
Функция f(x) называется выпуклой вниз на интервале (a, b), если для любых точек x₁ и x₂ из этого интервала выполняется неравенство: f( (x₁+x₂)/2 ) ≤ (f(x₁)+f(x₂))/2. Для дважды дифференцируемой функции условие выпуклости вниз эквивалентно условию f''(x) ≥ 0 на (a, b). Выпуклость вверх (вогнутость) определяется противоположным знаком второй производной: f''(x) ≤ 0. Точки, в которых вторая производная меняет знак (или обращается в нуль при условии существования первой производной), называются точками перегиба. Основная формула для проверки: если f''(x) > 0, то функция выпукла вниз; если f''(x) < 0 — выпукла вверх. Свойства выпуклых функций включают: любая касательная к графику выпуклой вниз функции лежит под графиком (для выпуклой вверх — над графиком); сумма выпуклых функций одного направления выпукла; композиция выпуклой функции с линейной функцией сохраняет выпуклость. Примеры: f(x) = x² выпукла вниз на всей числовой прямой (f''(x)=2>0), f(x)=√x выпукла вверх на (0, +∞) (f''(x) = -1/(4x√x) < 0). Для тригонометрических функций: f(x)=sin x на интервале (0, π) имеет f''(x) = -sin x, что дает выпуклость вверх на (0, π) и выпуклость вниз на (π, 2π); точки x=π и x=0 являются точками перегиба. Выпуклость широко применяется в задачах оптимизации: если функция выпукла вниз, то любая стационарная точка (где f'(x)=0) является точкой локального минимума, что связано с теоремой Ферма (необходимое условие экстремума).
