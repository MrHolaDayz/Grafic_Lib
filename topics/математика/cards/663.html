Предел последовательности — это число, к которому стремятся члены последовательности при неограниченном возрастании их номера. Формально, число a называется пределом последовательности {x_n}, если для любого положительного ε найдется такой номер N, что для всех n > N выполняется неравенство |x_n - a| < ε.

основной текст
Предел последовательности является фундаментальным понятием математического анализа, описывающим поведение бесконечной упорядоченной совокупности чисел. Формальное определение на языке ε-N гласит: число a есть предел последовательности {x_n}, если ∀ε > 0 ∃N ∈ ℕ такое, что ∀n > N ⇒ |x_n - a| < ε. В этом случае пишут lim_{n→∞} x_n = a. Последовательность, имеющая предел, называется сходящейся; в противном случае — расходящейся. Основные Свойства пределов включают: единственность предела (если предел существует, то он единственен); ограниченность сходящейся последовательности; арифметические свойства (Предел суммы, разности, произведения и частного при условии, что предел знаменателя не равен нулю). Например, предел последовательности x_n = 1/n равен 0, так как для любого ε > 0 достаточно взять N = ⌈1/ε⌉. Предел последовательности широко применяется в анализе для определения непрерывности функций, суммы рядов, производной и интеграла. Это понятие тесно связано с другими темами: Сходящиеся последовательности образуют основу для изучения рядов, а Расходящиеся последовательности (например, x_n = n) демонстрируют отсутствие конечного предела. Свойства пределов, такие как предел суммы, позволяют вычислять сложные пределы, разбивая их на более простые части. Например, используя предел суммы, можно найти lim_{n→∞} (1/n + 2/n) = 0 + 0 = 0. В прикладных задачах предел последовательности используется в численных методах (например, для нахождения корней уравнений методом итераций), в теории вероятностей (закон больших чисел) и в физике (моделирование процессов с дискретным временем). Понимание этого понятия необходимо для перехода к более сложным темам, таким как предел функции и непрерывность, где язык ε-N адаптируется для функций.
