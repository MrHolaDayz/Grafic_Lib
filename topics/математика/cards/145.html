Корень n-й степени из числа a — это такое число x, что x^n = a (где n — натуральное число больше 1). Он обобщает понятия квадратного и кубического корня на любую степень.
связанные темы
Степени мнимой единицы Квадратный корень Кубический корень Арифметический корень Свойства корней
основной текст
Определение и основные формулы: Корнем n-й степени из числа a (обозначается √[n]{a}) называется такое число x, что x^n = a. Если n — нечетное, то корень существует для любого действительного a и является единственным. Если n — четное, то корень существует только для неотрицательного a, и его арифметическое значение неотрицательно. Основные формулы: (√[n]{a})^n = a, √[n]{a^n} = |a| при четном n, и √[n]{a^n} = a при нечетном n. Свойства и примеры: Корень n-й степени обладает свойствами, аналогичными квадратному и кубическому корням: √[n]{a * b} = √[n]{a} * √[n]{b}, √[n]{a / b} = √[n]{a} / √[n]{b} (при b ≠ 0), и √[n]{√[m]{a}} = √[n*m]{a}. Примеры: √[3]{8} = 2, так как 2^3 = 8; √[4]{16} = 2, так как 2^4 = 16; √[3]{-27} = -3, так как (-3)^3 = -27. Где применяется, связь с другими темами: Корень n-й степени широко применяется в алгебре, геометрии (например, для нахождения сторон объемных фигур), физике и инженерии. Он тесно связан с понятием степени: a^(1/n) = √[n]{a}, что позволяет использовать свойства степеней для упрощения выражений. Связанные темы: Квадратный корень (n=2) и Кубический корень (n=3) являются частными случаями. Степени мнимой единицы i позволяют извлекать корни из отрицательных чисел при четных n в комплексной плоскости, где корень n-й степени имеет n значений.
