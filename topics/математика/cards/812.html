основной текст
Общее решение дифференциального уравнения n-го порядка представляет собой функцию y = φ(x, C₁, C₂, ..., Cₙ), которая при подстановке в уравнение обращает его в тождество для любых значений постоянных C₁, ..., Cₙ. Например, для уравнения y'' + y = 0 общее решение имеет вид y = C₁cos(x) + C₂sin(x). Для уравнения первого порядка y' = f(x)g(y) общее решение записывается как ∫dy/g(y) = ∫f(x)dx + C. Важно, что общее решение описывает всё множество решений, за исключением особых случаев (например, особых решений, не получающихся из общего ни при каких C). Основное свойство общего решения — его полнота: любое частное решение получается из общего при конкретных значениях постоянных, найденных из начальных или граничных условий. Например, для уравнения y' = 2x общее решение y = x² + C. Если задано начальное условие y(0) = 1, то C = 1, и частное решение y = x² + 1. Другой пример: для линейного однородного уравнения y'' - 3y' + 2y = 0 общее решение y = C₁e^(x) + C₂e^(2x). При подстановке начальных условий y(0)=0, y'(0)=1 получаем C₁ = -1, C₂ = 1. Общее решение широко применяется в физике, механике и инженерных задачах для моделирования процессов с неопределёнными начальными условиями. Например, в задачах о радиоактивном распаде, колебаниях маятника или электрических цепях. Понятие общего решения тесно связано с методами интегрирования, теорией устойчивости и краевыми задачами. В рамках математического анализа оно является основой для изучения дифференциальных уравнений, так как позволяет перейти от абстрактного уравнения к конкретному описанию процесса при заданных условиях.
