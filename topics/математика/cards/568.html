Формула расстояния между точками позволяет вычислить длину отрезка, соединяющего две точки в пространстве, через их координаты. Она обобщает теорему Пифагора на многомерные случаи и является основой метрики в евклидовой геометрии.

основной текст
Формула расстояния между двумя точками A(x1, y1, z1) и B(x2, y2, z2) в трехмерном пространстве имеет вид: d = √((x2 - x1)^2 + (y2 - y1)^2 + (z2 - z1)^2). Для двумерного случая (на плоскости) формула упрощается до d = √((x2 - x1)^2 + (y2 - y1)^2). В n-мерном пространстве расстояние определяется как корень квадратный из суммы квадратов разностей соответствующих координат: d = √(Σ (xi - yi)^2). Основное свойство формулы — она всегда дает неотрицательное значение, равное нулю только при совпадении точек. Расстояние симметрично: d(A,B) = d(B,A), и удовлетворяет неравенству треугольника: d(A,C) ≤ d(A,B) + d(B,C). Пример: найти расстояние между точками (1,2,3) и (4,6,7). Решение: d = √((4-1)^2 + (6-2)^2 + (7-3)^2) = √(9 + 16 + 16) = √41. Формула широко применяется в геометрии для нахождения длин отрезков, в физике — для вычисления перемещений, в компьютерной графике — для определения расстояний между объектами. Она связана с углом между векторами через скалярное произведение: если известны координаты точек, можно найти косинус угла между векторами, соединяющими их с началом координат. Среди связанных тем: Формула Эйлера связывает комплексные числа с тригонометрией, Переход между формами (алгебраической и тригонометрической) использует расстояние от точки до начала координат как модуль комплексного числа, а Формула Муавра применяется для возведения комплексных чисел в степень, где модуль также вычисляется через расстояние.
