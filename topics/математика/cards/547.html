основной текст
Сложение векторов — это бинарная операция, которая ставит в соответствие двум векторам a и b третий вектор c = a + b. В геометрическом представлении сложение выполняется двумя основными способами: правилом треугольника (когда начало второго вектора совмещается с концом первого, а сумма — это вектор от начала первого к концу второго) и правилом параллелограмма (когда векторы откладываются от общего начала, и сумма — это диагональ параллелограмма). В координатной форме, если a = (x1, y1, z1) и b = (x2, y2, z2), то a + b = (x1 + x2, y1 + y2, z1 + z2). Длина суммы векторов вычисляется через скалярное произведение: |a + b| = √(|a|^2 + |b|^2 + 2|a||b|cos α), где α — угол между векторами. Операция сложения векторов обладает рядом важных свойств: коммутативностью (a + b = b + a), ассоциативностью ((a + b) + c = a + (b + c)), существованием нулевого вектора (a + 0 = a) и противоположного вектора (a + (-a) = 0). Пример: если к вектору скорости тела v = (3, 0, 4) м/с добавить вектор ускорения a = (0, 2, 0) м/с^2, то результирующий вектор скорости через 1 секунду будет v + a = (3, 2, 4) м/с. Длина этого вектора равна √(3^2 + 2^2 + 4^2) = √29 ≈ 5.39 м/с. Сложение векторов лежит в основе многих разделов физики и математики. В механике оно используется для нахождения равнодействующей сил, в кинематике — для сложения перемещений и скоростей. В геометрии сложение векторов применяется при доказательстве теорем о средних линиях фигур и при решении задач на нахождение координат точек. Операция тесно связана с вычитанием векторов (которое является сложением с противоположным вектором) и с умножением вектора на число (скалярное умножение), так как эти операции образуют линейное пространство.
