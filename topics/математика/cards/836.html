Радикальный признак Коши — это критерий сходимости числовых рядов с неотрицательными членами, основанный на вычислении верхнего предела корня n-й степени из общего члена ряда.

основной текст
Радикальный признак Коши (также известный как признак Коши в радикальной форме) применяется к рядам вида ∑ a_n, где a_n ≥ 0. Пусть существует предел (или верхний предел) C = limsup √(a_n) при n→∞. Если C < 1, ряд сходится; если C > 1, ряд расходится; если C = 1, признак не даёт ответа. В случае, когда предел существует в обычном смысле, используется lim √(a_n). Формально: если lim (a_n)^(1/n) = L, то при L < 1 ряд сходится, при L > 1 расходится. Признак особенно эффективен для рядов, общий член которых содержит степень n (например, a_n = (n/(2n+1))^n). Пример: ряд ∑ (1/n)^n — сходится, так как √( (1/n)^n ) = 1/n → 0 < 1. Другой пример: ряд ∑ (2^n / n^2) — расходится, так как √(2^n / n^2) = 2 / (n^(2/n)) → 2 > 1. При L = 1 требуется дополнительное исследование, например, с помощью признака сравнения. Радикальный признак Коши широко применяется в теории степенных рядов для нахождения радиуса сходимости: R = 1 / limsup √(|c_n|). Он связан с Неравенством Коши (для последовательностей) и с другими признаками сходимости: Первый признак (сравнения), Второй признак (предельный признак сравнения). В отличие от признака Даламбера, радикальный признак часто работает, когда признак Даламбера даёт L = 1. Также существует Третий признак (интегральный) и Четвертый признак равенства (признак сравнения с эталонными рядами).
