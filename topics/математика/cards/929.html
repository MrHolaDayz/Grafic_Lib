Вариационный ряд — это последовательность значений статистического признака, расположенных в порядке возрастания (или убывания), которая служит основой для первичного анализа данных и вычисления выборочных характеристик.

основной текст
Вариационный ряд представляет собой упорядоченную выборку значений x_1, x_2, ..., x_n, где x_1 ≤ x_2 ≤ ... ≤ x_n. Основные характеристики ряда: размах R = x_n - x_1, мода (наиболее часто встречающееся значение), медиана (значение, делящее ряд пополам). Для вычисления среднего арифметического используется формула: x̄ = (1/n) * Σ x_i. Если данные сгруппированы по частотам, то ряд называют дискретным вариационным рядом, а для непрерывных данных строится интервальный вариационный ряд с частотами f_i. Свойства вариационного ряда: он сохраняет всю информацию о распределении, но не показывает закономерности в сжатом виде. Пример: для данных {3, 1, 4, 1, 5} вариационный ряд будет {1, 1, 3, 4, 5}. Медиана равна 3, мода — 1, размах — 4. Вариационный ряд чувствителен к выбросам: если добавить значение 100, ряд изменится на {1, 1, 3, 4, 5, 100}, и среднее резко возрастёт. Вариационный ряд применяется в описательной статистике, анализе данных, социологии и экономике для первичного ознакомления с выборкой. Он связан с понятием гармонического ряда (как пример упорядоченной последовательности) и с рядами Тейлора и Маклорена (которые также представляют упорядоченные суммы, но для функций). В отличие от аналитических рядов, вариационный ряд не имеет формулы общего члена, а задаётся эмпирически. Связанные темы: Гармонический ряд (1 + 1/2 + 1/3 + ...) — пример бесконечного упорядоченного ряда, но не статистического. Ряд Тейлора и Ряд Маклорена — разложения функций в степенные ряды, которые, как и вариационный ряд, используют упорядоченное расположение членов, но для аппроксимации, а не для анализа данных. Биномиальный ряд (разложение (1+x)^m) также является степенным рядом, но применяется в комбинаторике и теории вероятностей
