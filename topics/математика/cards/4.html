основной текст
Умножение — это бинарная операция, обозначаемая знаком × или ·, которая для натуральных чисел определяется как многократное сложение. Если число a умножается на число b, то результатом является сумма b слагаемых, каждое из которых равно a: a × b = a + a + ... + a (b раз). Основные формулы: a × b = b × a (переместительное свойство), (a × b) × c = a × (b × c) (сочетательное свойство), a × (b + c) = a × b + a × c (распределительное свойство). Для степеней: a^n означает умножение a на себя n раз. Свойства умножения включают: умножение на 1 даёт само число (a × 1 = a), умножение на 0 даёт 0 (a × 0 = 0). Примеры: 3 × 4 = 12, 7 × 5 = 35. При умножении многозначных чисел используется умножение столбиком, основанное на разрядах. Умножение является обратной операцией для деления: если a × b = c, то c ÷ b = a. Умножение широко применяется в повседневной жизни: при подсчёте стоимости товаров (цена × количество), в геометрии для нахождения площади прямоугольника (длина × ширина), в физике для вычисления работы (сила × расстояние). Эта тема тесно связана с делением, сложением и возведением в степень, а также служит основой для изучения дробей и процентов. Связанные темы: нет.
