Степень с целым показателем — это обобщение понятия степени на случай, когда показатель может быть любым целым числом, включая ноль и отрицательные значения.

основной текст
Определение и основные формулы: Степень с целым показателем a^n, где a — действительное число (a ≠ 0 при n ≤ 0), а n — целое число, определяется следующим образом: если n — натуральное число, то a^n = a * a * ... * a (n раз); если n = 0, то a^0 = 1 (при a ≠ 0); если n — отрицательное целое число, то a^(-k) = 1 / a^k, где k — натуральное число. Таким образом, степень с целым показателем позволяет работать с обратными величинами и единицей, сохраняя структуру степенных законов. Свойства и примеры: Основные свойства степени с целым показателем включают: a^m * a^n = a^(m+n), a^m / a^n = a^(m-n), (a^m)^n = a^(m*n), (a*b)^n = a^n * b^n, (a/b)^n = a^n / b^n (при b ≠ 0). Примеры: 2^3 = 8, 2^0 = 1, 2^(-3) = 1/8 = 0.125. Свойства справедливы для любых целых показателей, что делает их универсальными для алгебраических преобразований. Где применяется, связь с другими темами: Степень с целым показателем широко используется в алгебре, физике и экономике для записи больших и малых чисел (например, 10^9 для гигабайт, 10^(-3) для миллиметров). Она тесно связана с темой Возведение в степень, которая является базовой операцией, а также с Теоремой о делении с остатком, поскольку деление степеней с одинаковым основанием сводится к вычитанию показателей, что аналогично делению с остатком в арифметике. Кроме того, степень с целым показателем лежит в основе Степени с натуральным показателем (как частный случай) и Степени с рациональным показателем (через корни и дробные степени). Уравнение с угловым коэффициентом, хотя и относится к линейным функциям, может включать степени с целым показателем при описании наклона в более сложных зависимостях, например, в степенных функциях.
