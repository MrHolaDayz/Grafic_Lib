основной текст
Сочетание (или комбинация) — это подмножество из k элементов, выбранных из множества n элементов, при котором порядок элементов не важен. Основная формула для числа сочетаний: C(n, k) = n! / (k! * (n - k)!). Здесь n! — Факториал числа n, а k! и (n - k)! — факториалы соответствующих чисел. Например, C(5, 2) = 5! / (2! * 3!) = 120 / (2 * 6) = 10, что означает, что из 5 элементов можно составить 10 различных пар без учёта порядка. Важное свойство: C(n, k) = C(n, n - k), так как выбор k элементов равносилен выбору n - k элементов, которые не войдут в подмножество. Сочетания обладают рядом полезных свойств. Сумма всех сочетаний для фиксированного n равна 2^n, что следует из бинома Ньютона: (a + b)^n = сумма по k от 0 до n C(n, k) * a^(n-k) * b^k. Например, для n = 3: C(3,0) + C(3,1) + C(3,2) + C(3,3) = 1 + 3 + 3 + 1 = 8 = 2^3. Сочетания тесно связаны с треугольником Паскаля, где каждый элемент равен сумме двух вышестоящих: C(n, k) = C(n-1, k-1) + C(n-1, k). Практический пример: сколькими способами можно выбрать 3 книги из 10? Ответ: C(10, 3) = 120. Сочетания широко применяются в теории вероятностей, статистике, криптографии и задачах оптимизации. Например, при расчёте вероятности выигрыша в лотерее или числе возможных команд из группы. Сочетания связаны с Правилом суммы: если есть несколько непересекающихся способов выбора, их количества складываются. Правило произведения используется, когда выбор происходит последовательно, но для сочетаний порядок не важен, что отличает их от размещений. Факториал является основой для вычислений, а Двойной факториал может применяться в более сложных комбинаторных схемах.
