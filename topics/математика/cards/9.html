основной текст
Корень числа — одна из фундаментальных операций арифметики, обратная возведению в степень. Для натурального показателя n (n > 1) корнем n-й степени из числа a называют такое число x, что x^n = a. Обозначается это как x = ⁿ√a. Для квадратного корня (n = 2) показатель обычно опускают: √a. Важно помнить, что в области действительных чисел корень четной степени (2, 4, 6...) определяется только для неотрицательных a и дает неотрицательный результат (арифметический корень). Корень нечетной степени существует для любого действительного числа. Основные формулы: (ⁿ√a)^n = a, ⁿ√(a*b) = ⁿ√a * ⁿ√b (при a, b ≥ 0 для четных n), и ⁿ√(a/b) = ⁿ√a / ⁿ√b. Свойства корней тесно связаны со свойствами степеней: ⁿ√(a^m) = a^(m/n). Например, √9 = 3, так как 3^2 = 9, а ∛(-8) = -2, так как (-2)^3 = -8. Важно учитывать Порядок действий: сначала вычисляются корни и степени, затем умножение и деление, и только потом Сложение и вычитание. Например, √(4 + 9) ≠ √4 + √9, так как √13 ≈ 3.6, а 2 + 3 = 5. Извлечение корня часто используется при упрощении выражений, решении квадратных уравнений и в геометрии (например, нахождение стороны квадрата по его площади). Применение корней выходит далеко за пределы натуральных чисел. В комплексных числах корень n-й степени из числа имеет ровно n значений, что связано с аргументом комплексного числа и формулой Муавра. Модуль комплексного числа, по сути, является арифметическим квадратным корнем из суммы квадратов его действительной и мнимой частей. Понятие сопряженных чисел используется для избавления от корня в знаменателе дроби (например, умножение числителя и знаменателя на √a + √b для упрощения выражения 1/(√a - √b)).
