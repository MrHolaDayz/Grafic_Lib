Угол между скрещивающимися прямыми — это угол между двумя пересекающимися прямыми, которые параллельны данным скрещивающимся прямым. Он равен углу между направляющими векторами этих прямых и всегда находится в пределах от 0 до 90 градусов.

основной текст
Определение и основные формулы. Углом между скрещивающимися прямыми называется угол между двумя пересекающимися прямыми, которые проведены через произвольную точку пространства параллельно данным скрещивающимся прямым. Для его вычисления используют направляющие векторы a = (x1, y1, z1) и b = (x2, y2, z2). Косинус угла φ между прямыми находится по формуле: cos φ = |a·b| / (|a| * |b|) = |x1*x2 + y1*y2 + z1*z2| / (√(x1^2 + y1^2 + z1^2) * √(x2^2 + y2^2 + z2^2)). Модуль в числителе гарантирует, что угол берётся острым (0 ≤ φ ≤ 90°). Свойства и примеры. Угол не зависит от выбора точки, через которую проводятся параллельные прямые. Если cos φ = 1, прямые параллельны (или совпадают); если cos φ = 0 — перпендикулярны. Пример: для куба с ребром 1 найти угол между диагональю грани и скрещивающимся с ней ребром. Вводим координаты, находим направляющие векторы, подставляем в формулу — получаем cos φ = √2/2, то есть φ = 45°. Где применяется, связь с другими темами. Понятие используется в стереометрии для анализа взаимного расположения прямых в пространстве, при построении сечений многогранников, в инженерной графике и навигации. Связанные темы: Угол между векторами — лежит в основе формулы; Угол между прямыми — частный случай для пересекающихся прямых; Угол между плоскостями — аналогичен через нормали; Переход между формами — позволяет перейти от геометрического описания к координатному (векторному) методу решения.
