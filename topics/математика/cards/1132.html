основной текст
Условие параллельности прямых на плоскости устанавливает, когда две прямые не пересекаются. Если прямые заданы уравнениями с угловым коэффициентом y = k1*x + b1 и y = k2*x + b2, то условие параллельности имеет вид k1 = k2 (при b1 ≠ b2, иначе прямые совпадают). Для прямых, заданных общими уравнениями A1*x + B1*y + C1 = 0 и A2*x + B2*y + C2 = 0, условие параллельности формулируется как пропорциональность коэффициентов: A1/A2 = B1/B2 ≠ C1/C2. Если же A1/A2 = B1/B2 = C1/C2, прямые совпадают. Свойство параллельных прямых: они не имеют общих точек и сохраняют постоянное расстояние между собой. Пример: прямые y = 2x + 3 и y = 2x - 5 параллельны, так как их угловые коэффициенты равны 2. В общем виде, если даны прямые 3x + 4y - 7 = 0 и 6x + 8y + 1 = 0, то отношение коэффициентов 3/6 = 4/8 = 1/2, но свободные члены не пропорциональны (-7/1 ≠ 1/2), следовательно, прямые параллельны. Условие параллельности широко применяется в геометрии при построении параллельных линий, в физике для описания движения, в инженерных расчетах. Оно тесно связано с другими формами записи прямой: в каноническом уравнении (x - x0)/m = (y - y0)/n условие параллельности означает пропорциональность направляющих векторов (m1, n1) и (m2, n2); в параметрическом виде x = x0 + m*t, y = y0 + n*t параллельность также определяется коллинеарностью направляющих векторов. Понимание этого условия необходимо для анализа взаимного расположения прямых, решения систем уравнений и задач на расстояние между параллельными прямыми.
