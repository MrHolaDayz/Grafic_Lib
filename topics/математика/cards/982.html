Симметрическая разность двух множеств — это операция, результатом которой является множество элементов, входящих ровно в одно из исходных множеств (то есть элементы, принадлежащие либо первому, либо второму множеству, но не их пересечению).

основной текст
Симметрическая разность множеств A и B обозначается как A Δ B и определяется формулой: A Δ B = (A \ B) ∪ (B \ A) = (A ∪ B) \ (A ∩ B). Иными словами, это множество элементов, которые принадлежат объединению, но не принадлежат пересечению. В отличие от обычной разности, симметрическая разность коммутативна: A Δ B = B Δ A. Также она ассоциативна: (A Δ B) Δ C = A Δ (B Δ C). Важное свойство: A Δ A = ∅, A Δ ∅ = A. Пример: пусть A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Тогда A \ B = {1, 2}, B \ A = {5, 6}, следовательно, A Δ B = {1, 2, 5, 6}. Другой пример: если A = {x | x ≥ 0}, B = {x | x ≤ 0}, то A Δ B = {x | x ≠ 0} — все числа, кроме нуля. Симметрическая разность тесно связана с логической операцией "исключающее ИЛИ" (XOR) в булевой алгебре: характеристическая функция симметрической разности равна XOR характеристических функций множеств. Симметрическая разность широко применяется в теории множеств, комбинаторике, теории меры (как основа для определения кольца множеств), а также в компьютерных науках для обработки данных и сравнения наборов. Она позволяет выделить уникальные элементы двух коллекций. Связанные темы: Разность квадратов (a^2 - b^2 = (a - b)(a + b)) и Разность кубов (a^3 - b^3 = (a - b)(a^2 + ab + b^2)) являются алгебраическими формулами для разности чисел, а не для множеств, однако по духу они также описывают "вычитание" с сохранением структуры.
