основной текст
Матричный метод (или метод обратной матрицы) применяется для решения систем линейных уравнений, где число уравнений равно числу неизвестных, а матрица системы A является квадратной и невырожденной (det A ≠ 0). Система записывается в виде A·X = B, где A — матрица коэффициентов, X — столбец неизвестных, B — столбец свободных членов. Решение находится умножением обеих частей на обратную матрицу слева: X = A^(-1)·B. Обратная матрица вычисляется по формуле A^(-1) = (1/det A)·(A*), где A* — присоединённая матрица (транспонированная матрица алгебраических дополнений). Основное свойство матричного метода — его однозначность при условии существования обратной матрицы. Например, для системы: 2x + 3y = 7, x - y = 1, матрица A = [[2,3],[1,-1]], det A = -5 ≠ 0. Обратная матрица A^(-1) = (1/(-5))·[[-1,-3],[-1,2]] = [[0.2,0.6],[0.2,-0.4]], тогда X = A^(-1)·B = [[0.2*7+0.6*1],[0.2*7-0.4*1]] = [[2],[1]], то есть x=2, y=1. Метод требует вычисления обратной матрицы, что при больших размерах трудоёмко, поэтому его применяют в основном для систем небольшого порядка или в теоретических выкладках. Матричный метод тесно связан с методом Крамера, который также использует определители, но находит каждую переменную по отдельности. В отличие от метода Гаусса и метода Гаусса-Жордана, которые работают с расширенной матрицей и не требуют вычисления обратной, матричный метод даёт явную формулу решения. Для однородных систем (B = 0) матричный метод даёт только тривиальное решение X = 0, если det A ≠ 0; в случае det A = 0 система имеет нетривиальные решения, и матричный метод неприменим. Для неоднородных систем (B ≠ 0) метод работает только при det A ≠ 0, иначе система либо несов
