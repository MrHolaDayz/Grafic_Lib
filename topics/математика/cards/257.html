Неравенство Минковского — это неравенство треугольника для норм в векторных пространствах, обобщающее классическое неравенство треугольника на суммы векторов и интегралы. В простейшей форме для чисел оно утверждает, что корень степени p из суммы модулей сумм не превышает суммы корней степени p из соответствующих модулей.

основной текст
Неравенство Минковского для конечных последовательностей чисел записывается так: для p ≥ 1 и действительных чисел a_i, b_i выполняется (∑|a_i + b_i|^p)^(1/p) ≤ (∑|a_i|^p)^(1/p) + (∑|b_i|^p)^(1/p). Для p = 2 оно переходит в неравенство треугольника для евклидовой нормы: √(∑(a_i + b_i)^2) ≤ √(∑a_i^2) + √(∑b_i^2). Если 0 < p < 1, знак неравенства меняется на противоположный. Свойства: неравенство однородно (при умножении всех чисел на константу обе части умножаются на неё), и оно является обратным к неравенству Гёльдера. Пример: для p = 2, a = (3, 4), b = (1, 2): √((3+1)^2 + (4+2)^2) = √(16+36) = √52 ≈ 7.21; √(3^2+4^2) + √(1^2+2^2) = 5 + √5 ≈ 7.24, неравенство выполняется. Неравенство Минковского широко применяется в функциональном анализе для доказательства нормированности пространств L^p, в теории вероятностей для оценки моментов сумм случайных величин, а также в оптимизации и обработке сигналов. Оно тесно связано с неравенством треугольника (частный случай для p = 1) и неравенством Гёльдера, которое используется при его доказательстве. В алгебре и анализе оно служит фундаментом для понимания метрик и норм.
