Квадратное уравнение — это алгебраическое уравнение второй степени вида ax^2 + bx + c = 0, где a ≠ 0. Его решение в области комплексных чисел всегда существует и может быть найдено через дискриминант.

основной текст
Квадратное уравнение в общем виде записывается как ax^2 + bx + c = 0, где a, b и c — действительные или комплексные числа, причем a ≠ 0. Для нахождения корней используется дискриминант D = b^2 - 4ac. Если D ≥ 0, корни действительны и вычисляются по формуле x = (-b ± √D) / (2a). Если D < 0, корни являются комплексно-сопряженными числами: x = (-b ± i√|D|) / (2a), где i — мнимая единица. В комплексной плоскости квадратное уравнение всегда имеет два корня (с учетом кратности). Основное свойство квадратных уравнений — связь коэффициентов с корнями через теорему Виета: сумма корней равна -b/a, произведение — c/a. Пример: для уравнения x^2 + 4x + 5 = 0 дискриминант D = 16 - 20 = -4, корни: x = (-4 ± i√4) / 2 = -2 ± i. Эти корни являются комплексными числами, и их можно складывать, вычитать и умножать с другими комплексными числами. Если же D = 0, уравнение имеет один двукратный корень. Квадратные уравнения широко применяются в физике (например, для описания движения тела под действием силы тяжести), в экономике (модели спроса и предложения) и в инженерии. В контексте комплексных чисел решение таких уравнений служит мостом к более сложным темам, таким как Возведение в степень и Деление комплексных чисел. Понимание квадратных уравнений необходимо для изучения кубических и других полиномиальных уравнений. Связанные темы: Сложение и Вычитание комплексных чисел используются при проверке корней квадратного уравнения, а Умножение — при раскрытии скобок в формуле (x - x1)(x - x2) = 0. Например, для корней -2 ± i произведение (x + 2 - i)(x + 2 + i) = x^2 + 4x + 5 подтверждает исходное уравнение. Таким образом, арифметические операции с комплексными числами непосредственно связаны с решением квадратных уравнений.
