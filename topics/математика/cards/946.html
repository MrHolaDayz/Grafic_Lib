основной текст
Проверка статистических гипотез — это формальный метод статистического вывода, который позволяет определить, противоречат ли выборочные данные некоторому утверждению о генеральной совокупности. Основная идея заключается в формулировании двух противоположных гипотез: нулевой (H0), которая обычно утверждает отсутствие эффекта или различия, и альтернативной (H1), которая утверждает наличие эффекта. Ключевыми понятиями являются уровень значимости α (вероятность ошибки первого рода — отвергнуть верную H0) и p-значение (наименьший уровень значимости, при котором H0 может быть отвергнута). Основная формула для z-критерия (при известной дисперсии): z = (x̄ - μ0) / (σ / √n), где x̄ — выборочное среднее, μ0 — гипотетическое среднее по H0, σ — стандартное отклонение генеральной совокупности, n — объем выборки. Для t-критерия используется t = (x̄ - μ0) / (s / √n), где s — выборочное стандартное отклонение. Свойства проверки гипотез включают: возможность совершить ошибку первого рода (отвергнуть истинную H0) и ошибку второго рода (принять ложную H0). Мощность критерия — это вероятность отвергнуть ложную H0. Пример: исследователь хочет проверить, изменилось ли Среднее арифметическое роста в популяции после курса лечения. Формулируется H0: μ = 170 см (среднее не изменилось) и H1: μ ≠ 170 см. По выборке из 100 человек вычисляется t-статистика, и если p-значение меньше 0.05, H0 отвергается, делая вывод о статистически значимом изменении. Метод широко применяется в медицине (эффективность лекарств), экономике (проверка гипотез о доходности), социологии (сравнение групп) и науке. Проверка гипотез тесно связана с построением доверительных интервалов (оба основаны на выборочных данных и стандартной ошибке).
