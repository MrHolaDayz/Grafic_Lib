основной текст
Линейные неравенства — это алгебраические неравенства первой степени, которые можно привести к виду ax + b > 0, ax + b < 0, ax + b ≥ 0 или ax + b ≤ 0, где a ≠ 0. Основная формула для решения: если a > 0, то x > -b/a (или x < -b/a в зависимости от знака неравенства); если a < 0, то при делении обеих частей на отрицательное число знак неравенства меняется на противоположный. Например, неравенство 2x - 4 > 0 решается как x > 2, а -3x + 6 ≤ 0 даёт x ≥ 2. Для строгих неравенств (>, <) граничная точка не включается, для нестрогих (≥, ≤) — включается. Свойства линейных неравенств основаны на правилах преобразований: к обеим частям можно прибавлять одно и то же число, умножать или делить на положительное число без изменения знака, а при умножении или делении на отрицательное число знак неравенства меняется. Пример: решим 5x + 3 < 2x - 1. Переносим члены: 5x - 2x < -1 - 3, получаем 3x < -4, откуда x < -4/3. Графически решение изображается на числовой прямой в виде интервала (-∞; -4/3). Линейные неравенства часто встречаются в задачах на нахождение области допустимых значений и в системах неравенств. Линейные неравенства широко применяются в экономике (например, для описания бюджетных ограничений), физике (при расчёте диапазонов параметров) и технике (при оптимизации). Они тесно связаны с линейными преобразованиями, так как график линейного неравенства — полуплоскость, задаваемая прямой. В теории чисел они пересекаются с линейными сравнениями (например, при решении неравенств в целых числах) и с линейными диофантовыми уравнениями, где ищутся целочисленные решения, удовлетворяющие дополнительным ограничениям-неравенствам.
