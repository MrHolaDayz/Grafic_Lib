основной текст
Неравенство Коши-Буняковского (также известное как неравенство Коши-Шварца) является фундаментальным результатом в линейной алгебре и анализе. Для двух последовательностей действительных чисел a1, a2, ..., an и b1, b2, ..., bn оно формулируется как (∑ ai bi)^2 ≤ (∑ ai^2)(∑ bi^2). В векторной форме для векторов u и v в евклидовом пространстве неравенство принимает вид |u·v| ≤ ||u|| ||v||, где точка обозначает скалярное произведение, а ||·|| — евклидову норму. Равенство достигается тогда и только тогда, когда векторы коллинеарны (один является скалярным кратным другого). Свойства неравенства: оно симметрично относительно перестановки последовательностей, инвариантно к умножению всех элементов на константу, и является ключевым для доказательства неравенства треугольника для нормы. Пример: для чисел a = (1, 2), b = (3, 4) имеем (1*3 + 2*4)^2 = (3+8)^2 = 121, а произведение сумм квадратов (1^2+2^2)(3^2+4^2) = (1+4)(9+16) = 5*25 = 125, и действительно 121 ≤ 125. Неравенство широко применяется в математике, физике и статистике: для оценки корреляции случайных величин, в квантовой механике (принцип неопределенности Гейзенберга), в теории аппроксимации и оптимизации. Связь с другими темами: оно используется при решении Линейных неравенств (например, для оценки сумм), при анализе Квадратных неравенств (через дискриминант квадратичной формы), а Метод интервалов помогает находить области, где неравенство выполняется строго или с равенством.
