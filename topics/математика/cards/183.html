основной текст
Метод замены переменной заключается во введении новой переменной t, которая заменяет некоторое выражение от исходной переменной x. Например, для уравнения вида a * f(x)^2 + b * f(x) + c = 0 делают замену t = f(x), получая квадратное уравнение a * t^2 + b * t + c = 0. После нахождения t возвращаются к исходной переменной, решая уравнение f(x) = t. Основная формула: если t = g(x), то исходное уравнение F(g(x)) = 0 преобразуется в F(t) = 0. Свойства метода: он позволяет понижать степень уравнения, избавляться от радикалов (например, при замене t = √x) или сводить тригонометрические уравнения к алгебраическим. Пример: решить уравнение (x^2 + x)^2 - 4(x^2 + x) + 3 = 0. Замена t = x^2 + x дает t^2 - 4t + 3 = 0, откуда t = 1 или t = 3. Затем решаем x^2 + x = 1 и x^2 + x = 3, получая корни исходного уравнения. Метод широко применяется при решении квадратных уравнений, биквадратных уравнений (замена t = x^2), иррациональных уравнений (замена t = √(ax + b)) и показательных уравнений (замена t = a^x). Он тесно связан с методом подстановки в системах уравнений и с методами решения тригонометрических уравнений. Связанные темы: нет.
