основной текст
Сравнение чисел — это математическая операция, устанавливающая отношение порядка между числами. Основные знаки: больше ( > ), меньше ( < ), равно ( = ), а также больше или равно ( ≥ ) и меньше или равно ( ≤ ). Для любых двух действительных чисел a и b выполняется ровно одно из трех: a > b, a < b или a = b. На числовой оси число справа всегда больше числа слева. Например, 5 > 3, -2 < 0, -5 < -1, так как -1 лежит правее -5. Свойства сравнения: если a > b и b > c, то a > c (транзитивность); если a > b, то a + c > b + c для любого c; если a > b и c > 0, то ac > bc, а если c < 0, то ac < bc (умножение на отрицательное число меняет знак неравенства). Пример: сравнить -3 и -7: так как -3 > -7 (на оси -3 правее). Сравнение дробей: 2/3 и 3/5 приводят к общему знаменателю: 10/15 > 9/15, значит 2/3 > 3/5. Для отрицательных чисел: -2/3 и -3/5: -10/15 < -9/15, следовательно -2/3 < -3/5. Сравнение чисел широко применяется в алгебре, анализе, при решении неравенств и в оптимизации. Связанные темы: Равенство комплексных чисел — два комплексных числа равны, если равны их действительные и мнимые части, но сравнение по величине для них не определено (нет порядка на C). Свойства сопряженных чисел: для сравнения модулей используется |z| = √(a^2 + b^2). Свойства модуля позволяют сравнивать расстояния от нуля: |a| > |b| означает, что a дальше от нуля, но не определяет, какое число больше (например, |-5| > |3|, но -5 < 3).
