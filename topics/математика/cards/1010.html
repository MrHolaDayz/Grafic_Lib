Сюръекция — это отображение f: A → B, при котором каждый элемент множества B имеет хотя бы один прообраз в A. Иными словами, образ всего множества A совпадает со всем множеством B: f(A) = B.

основной текст
Сюръекция (или отображение «на») — это функция f: A → B, для которой выполняется условие: ∀ y ∈ B ∃ x ∈ A: f(x) = y. Это означает, что множество значений функции (образ) равно всему множеству B. В отличие от инъекции, где разные элементы переходят в разные образы, сюръекция гарантирует, что каждый элемент B «покрыт». Формально: Im(f) = B. Основное свойство сюръекции — существование правого обратного отображения: если f сюръективна, то существует g: B → A такое, что f(g(y)) = y для всех y ∈ B. Пример: функция f(x) = x^2 из R в R не является сюръекцией, так как отрицательные числа не имеют квадратного корня. Но f: R → [0, +∞), заданная той же формулой, сюръективна, так как для любого y ≥ 0 найдется x = √y. Другой пример: функция f(x) = x^3 из R в R сюръективна, поскольку кубический корень существует для любого действительного числа. Сюръекция широко применяется в алгебре (например, при изучении гомоморфизмов групп), в топологии (непрерывные сюръекции) и в теории множеств для сравнения мощностей. Связана с бинарными отношениями: сюръективное отображение можно рассматривать как функциональное отношение, где каждый элемент B является образом. Свойства рефлексивности и симметричности не присущи самой сюръекции, но они важны при рассмотрении отношения эквивалентности, порожденного прообразами (когда два элемента A эквивалентны, если их образы совпадают). В этом контексте сюръекция тесно связана с факторизацией множества по отношению эквивалентности.
