основной текст
Кубическое уравнение — это уравнение третьей степени, имеющее общий вид: ax^3 + bx^2 + cx + d = 0, где a, b, c, d — действительные числа, и a ≠ 0. Для его решения существует формула Кардано, которая выражает корни через радикалы. Сначала уравнение приводится к приведённому виду: y^3 + py + q = 0 с помощью замены x = y - b/(3a). Затем дискриминант D = (q/2)^2 + (p/3)^3 определяет тип корней: если D > 0 — один действительный и два комплексных; если D = 0 — все корни действительные, причём два равны; если D < 0 — три различных действительных корня (casus irreducibilis). Корни находятся по формуле: y = ∛(-q/2 + √D) + ∛(-q/2 - √D). Кубические уравнения обладают важными свойствами: они всегда имеют хотя бы один действительный корень, а сумма корней равна -b/a, сумма попарных произведений равна c/a, произведение равно -d/a (теорема Виета). Пример: уравнение x^3 - 6x^2 + 11x - 6 = 0 имеет корни 1, 2, 3 (разложение (x-1)(x-2)(x-3)). Для решения можно также использовать разложение на множители или графический метод — пересечение кубической параболы с осью x. Кубические уравнения широко применяются в физике (расчёт объёмов, колебаний), инженерии (проектирование кривых), экономике (модели роста) и компьютерной графике (сплайны). Они связаны с квадратными уравнениями через понижение степени после нахождения одного корня, а также с теорией групп и комплексными числами при анализе корней. В алгебре кубические уравнения являются шагом от квадратных к уравнениям высших степеней, но в отличие от них, не имеют универсальной формулы в радикалах для степени выше четвёртой. Связанные темы: квадратные уравнения, комплексные числа, теорема Виета, метод Кардано.
