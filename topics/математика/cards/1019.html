Два комплексных числа считаются равными, если равны их действительные и мнимые части. То есть, для чисел a + bi и c + di равенство выполняется тогда и только тогда, когда a = c и b = d.

основной текст
Два комплексных числа z₁ = a + bi и z₂ = c + di (где a, b, c, d — действительные числа, а i — Мнимая единица, i² = -1) равны, если совпадают их действительные и мнимые части: a = c и b = d. Это фундаментальное правило вытекает из определения комплексного числа как упорядоченной пары (a, b) действительных чисел. Например, равенство 3 + 2i = x + yi означает, что x = 3 и y = 2. Важно помнить, что Комплексное число равно нулю (0 + 0i) только если a = 0 и b = 0. Свойство равенства комплексных чисел тесно связано с понятием мнимой единицы и её степенями. Поскольку i² = -1, то при решении уравнений вида x² = -1 мы получаем x = i или x = -i, и эти числа не равны, так как их мнимые части различны (1 и -1). Пример: если (a + bi) = (c + di), то можно переносить слагаемые: (a - c) + (b - d)i = 0, что снова сводится к системе a - c = 0 и b - d = 0. Равенство комплексных чисел позволяет приравнивать выражения, содержащие i, к стандартной форме a + bi. Это правило широко применяется при решении уравнений с комплексными переменными, в алгебре и геометрии. Например, чтобы найти неизвестные коэффициенты в многочленах или разложить выражение на действительную и мнимую части. Связь с другими темами очевидна: без понимания равенства невозможно корректно работать с комплексным числом как с объектом, а мнимая единица и Степени мнимой единицы задают структуру для записи чисел. Именно через равенство определяется, что комплексное число однозначно задаётся парой (a, b), что является основой для всех дальнейших операций — сложения, умножения и сопряжения.
