основной текст
Горизонтальная асимптота функции f(x) определяется через предел: если lim_{x→+∞} f(x) = b или lim_{x→-∞} f(x) = b, то прямая y = b является горизонтальной асимптотой. Функция может иметь не более двух различных горизонтальных асимптот (одну на +∞ и одну на -∞). Основная формула для нахождения: b = lim_{x→∞} f(x). Если предел равен бесконечности, то горизонтальной асимптоты нет, а если равен конечному числу b, то она существует. Свойства: горизонтальная асимптота описывает поведение функции на больших расстояниях от начала координат. Например, для функции f(x) = (2x^2 + 1) / (x^2 - 3) предел при x→∞ равен 2, значит y = 2 — асимптота. Другой пример: f(x) = e^{-x} стремится к 0 при x→+∞, поэтому y = 0 — асимптота. Важно, что график может пересекать асимптоту в конечных точках, но на бесконечности расстояние стремится к нулю. Горизонтальные асимптоты широко применяются в анализе поведения функций, в физике (например, для описания процессов насыщения) и в экономике (модели роста с ограничением). Эта тема тесно связана с Асимптотами гиперболы, где гипербола имеет две асимптоты — горизонтальную и вертикальную. Также она опирается на понятие Предел последовательности, так как предел функции на бесконечности аналогичен пределу последовательности. Для строгого обоснования используется Определение предела на языке ε-N: для любого ε > 0 существует такое N, что для всех x > N выполняется |f(x) - b| < ε.
