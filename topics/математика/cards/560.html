основной текст
Угол между векторами — это угол, образованный двумя лучами, исходящими из одной точки и направленными вдоль этих векторов. Для ненулевых векторов a и b угол φ (0° ≤ φ ≤ 180°) определяется через их скалярное произведение: cos φ = (a · b) / (|a| * |b|). Если векторы заданы координатами в пространстве (a = (x1, y1, z1), b = (x2, y2, z2)), то скалярное произведение вычисляется как a · b = x1*x2 + y1*y2 + z1*z2, а длины векторов — |a| = √(x1^2 + y1^2 + z1^2), |b| = √(x2^2 + y2^2 + z2^2). Таким образом, cos φ = (x1*x2 + y1*y2 + z1*z2) / (√(x1^2 + y1^2 + z1^2) * √(x2^2 + y2^2 + z2^2)). Основные свойства угла между векторами: если векторы сонаправлены, угол равен 0° (cos φ = 1); если противоположно направлены — 180° (cos φ = -1); если перпендикулярны — 90° (cos φ = 0). Угол не зависит от длин векторов, а только от их направления. Пример: для векторов a = (1, 0, 0) и b = (0, 1, 0) cos φ = (1*0 + 0*1 + 0*0) / (1*1) = 0, следовательно φ = 90°. Для векторов a = (2, 2, 0) и b = (1, 0, 0) cos φ = (2*1 + 2*0 + 0*0) / (√(4+4) * √1) = 2 / √8 = 2 / (2√2) = 1/√2, значит φ = 45°.
