Алгебраическая форма комплексного числа — это запись вида z = a + bi, где a и b — действительные числа, а i — мнимая единица (i^2 = -1). Она является основной и наиболее наглядной формой представления комплексных чисел.
связанные темы
Тригонометрическая форма Показательная форма Формула Эйлера Переход между формами
основной текст
Алгебраическая форма комплексного числа определяется как z = a + bi, где a = Re(z) — действительная часть, b = Im(z) — мнимая часть, а i — мнимая единица, удовлетворяющая условию i^2 = -1. Для комплексно-сопряженного числа используется обозначение z = a - bi. Модуль числа вычисляется по формуле |z| = √(a^2 + b^2), а аргумент — φ = arctg(b/a) (с учетом четверти). Основные арифметические операции в алгебраической форме выполняются по правилам алгебры многочленов с учетом i^2 = -1. Например: сложение — (a + bi) + (c + di) = (a + c) + (b + d)i; умножение — (a + bi)(c + di) = (ac - bd) + (ad + bc)i; деление выполняется умножением числителя и знаменателя на сопряженное число. Пример: (1 + 2i) + (3 - i) = 4 + i; (1 + i)^2 = 1 + 2i + i^2 = 2i. Алгебраическая форма удобна для выполнения сложения, вычитания и умножения комплексных чисел, а также для решения квадратных уравнений с отрицательным дискриминантом (например, x^2 + 1 = 0 дает корни ±i). Однако для умножения и деления в степени часто удобнее тригонометрическая или Показательная форма. Переход между формами осуществляется через формулы: a = |z| cos φ, b = |z| sin φ, и обратно через модуль и аргумент. Связанные темы: Тригонометрическая форма (z = |z|(cos φ + i sin φ)), Показательная форма (z = |z| e^(iφ)), Формула Эйлера (e^(iφ) = cos φ + i sin φ). Алгебраическая форма служит основой для введения этих представлений и перехода между ними.
