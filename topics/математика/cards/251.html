Неравенство Коши (или неравенство Коши-Буняковского) связывает сумму произведений чисел с произведением их сумм квадратов, являясь одним из фундаментальных неравенств в алгебре и математическом анализе.

основной текст
Неравенство Коши (в классической форме для действительных чисел) утверждает, что для любых наборов чисел a1, a2, ..., an и b1, b2, ..., bn выполняется: (a1*b1 + a2*b2 + ... + an*bn)^2 ≤ (a1^2 + a2^2 + ... + an^2)*(b1^2 + b2^2 + ... + bn^2). Равенство достигается, когда наборы чисел пропорциональны, то есть существует такое число k, что ai = k*bi для всех i. Частный случай для двух чисел: (a1*b1 + a2*b2)^2 ≤ (a1^2 + a2^2)*(b1^2 + b2^2). Также существует форма для средних: среднее арифметическое не меньше среднего геометрического (неравенство Коши для средних), которое записывается как (a1 + a2 + ... + an)/n ≥ √(a1*a2*...*an) для неотрицательных чисел. Основные свойства неравенства Коши: оно однородно (если умножить все ai или bi на константу, неравенство сохраняется) и инвариантно относительно перестановок. Пример: для чисел a=3, b=4 и c=0, d=5 проверим (3*0 + 4*5)^2 = 20^2 = 400, а (3^2+4^2)*(0^2+5^2) = (9+16)*25 = 25*25 = 625, 400 ≤ 625 — верно. Другой пример: доказать, что для положительных x и y выполняется x/y + y/x ≥ 2. Применим неравенство Коши к числам √(x/y) и √(y/x): (√(x/y)*√(y/x) + 1*1)^2 ≤ (x/y + 1)*(y/x + 1), что после упрощения дает 4 ≤ (x/y+1)(y/x+1), откуда следует исходное неравенство.
