Длина вектора (или модуль вектора) — это неотрицательное число, равное расстоянию между началом и концом вектора. Она обозначается |a| и вычисляется как квадратный корень из суммы квадратов его координат.

основной текст
Длина (модуль) вектора a = {x; y; z} в трёхмерном пространстве вычисляется по формуле: |a| = √(x^2 + y^2 + z^2). Для двумерного случая (на плоскости) формула принимает вид: |a| = √(x^2 + y^2). Если вектор задан координатами своего начала A(x1, y1, z1) и конца B(x2, y2, z2), то его длина равна расстоянию между этими точками: |AB| = √((x2 - x1)^2 + (y2 - y1)^2 + (z2 - z1)^2). Длина нулевого вектора равна нулю. Модуль вектора обладает следующими свойствами: 1) |a| ≥ 0, причем |a| = 0 только для нулевого вектора; 2) |k * a| = |k| * |a|, где k — число; 3) |a + b| ≤ |a| + |b| (неравенство треугольника). Пример: для вектора a = {3; -4; 0} длина равна |a| = √(3^2 + (-4)^2 + 0^2) = √(9 + 16) = √25 = 5. Длина вектора является фундаментальным понятием, используемым во всех разделах геометрии, физике (например, при нахождении модуля скорости или силы) и компьютерной графике. Она тесно связана с понятием расстояния между точками и скалярным произведением, так как |a| = √(a·a). Знание длины вектора необходимо для вычисления углов между векторами, проекций и площади фигур.
