основной текст
Формула Бернулли (или схема Бернулли) применяется для повторных независимых испытаний, в каждом из которых вероятность успеха p постоянна. Вероятность получить ровно k успехов в n испытаниях выражается как: P_n(k) = C(n, k) * p^k * q^(n-k), где q = 1 - p — вероятность неудачи, а C(n, k) = n! / (k! * (n-k)!) — число сочетаний. Эта формула лежит в основе биномиального распределения. Основное свойство формулы Бернулли — сумма вероятностей для всех k от 0 до n равна единице, что следует из бинома Ньютона: (p + q)^n = Σ C(n,k) p^k q^(n-k). Пример: при бросании монеты 5 раз (p = 0.5) вероятность выпадения орла ровно 3 раза равна C(5,3)*(0.5)^3*(0.5)^2 = 10/32 = 0.3125. Формула Бернулли широко применяется в статистике, теории игр, контроле качества и биологии для моделирования бинарных исходов. Она тесно связана с другими математическими формулами: Формула Эйлера e^(iπ) + 1 = 0 используется в комплексном анализе, а Формула Муавра (cos x + i sin x)^n = cos(nx) + i sin(nx) является тригонометрическим аналогом биномиального распределения. Также Формула Эйлера для тригонометрии связывает экспоненту с синусом и косинусом, что позволяет обобщать вероятностные модели на непрерывные случаи.
